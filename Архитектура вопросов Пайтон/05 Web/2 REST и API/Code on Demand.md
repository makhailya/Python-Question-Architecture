# ⚙️ Code on Demand

## 🎯 Ответ на собеседовании

**Code on Demand** — это необязательный принцип REST, согласно которому **сервер может передавать клиенту исполняемый код**, который клиент затем выполняет.

Идея в том, что часть функциональности может быть перенесена с сервера на клиента.

Классический пример — сервер отправляет браузеру **JavaScript**:

```text id="m5k8pz"
Server
   ↓
JavaScript
   ↓
Browser
   ↓
Выполнение кода
```

---

## 🎤 Суперкоротко

**Code on Demand = сервер может отправить клиенту исполняемый код для выполнения.**

Например:

```text id="c8y2qn"
Server → JavaScript → Browser
```

---

## 🔄 Как работает

Например, браузер запрашивает страницу:

```python id="u4x6fk"
GET /app
```

Сервер отправляет JavaScript:

```python id="n7m3wr"
<script src="/static/app.js"></script>
```

Браузер загружает и выполняет этот код:

```text id="x3z9va"
Browser
   ↓
загружает app.js
   ↓
выполняет JavaScript
   ↓
появляется дополнительная функциональность
```

Таким образом, сервер может **динамически расширять возможности клиента**, передавая ему код.

---

## 💡 Зачем нужен

Основная идея — уменьшить количество функциональности, которую необходимо заранее реализовывать в клиенте.

Например:

```text id="f7q2ak"
Client
  ↓
получает данные + код
  ↓
выполняет код
```

Сервер может изменить поведение клиента, отправив новую версию исполняемого кода.

---

## 🌐 Пример из веб-разработки

Обычное веб-приложение:

```text id="2z4jtp"
Browser
   ↓
GET /index.html
   ↓
Server
   ↓
HTML + JavaScript
   ↓
Browser выполняет JavaScript
```

JavaScript является примером кода, который сервер предоставляет клиенту для выполнения.

---

## ⚠️ Важный момент

**Code on Demand — единственный необязательный принцип REST.**

Основные ограничения REST:

```text id="x8r5mq"
Client-Server
Stateless
Cacheable
Uniform Interface
Layered System
```

А:

```text id="h6n2wd"
Code on Demand
```

— **опциональный**.

То есть REST-система может полностью соответствовать REST без использования Code on Demand.

---

## 🆚 Code on Demand vs обычные данные

Обычный API возвращает данные:

```python id="p3n8yc"
{
    "name": "Ilya",
    "age": 31
}
```

Code on Demand предполагает передачу **исполняемого кода**:

```python id="w9k2sx"
function calculateTotal(price, quantity) {
    return price * quantity;
}
```

Клиент не просто получает данные — он получает код, который может выполнить.
