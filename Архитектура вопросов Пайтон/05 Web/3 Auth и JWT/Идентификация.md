# 🪪 Идентификация

## 🎤 Суперкоротко

**Идентификация** — это процесс, в котором пользователь сообщает системе, **кто он**.

Пример:

```text
Логин: ilya
```

Система получает утверждение:

> «Я — ilya».

**Идентификация отвечает на вопрос: «Кто ты?»**

---

## 🎯 Ответ на собеседовании

**Идентификация** — это процесс определения или заявления субъектом своей идентичности в системе.

Пользователь сообщает системе идентификатор, например:

* логин;
* email;
* номер телефона;
* ID пользователя.

Важно: **идентификация сама по себе не доказывает, что пользователь действительно является этим человеком.**

---

# 🔄 Идентификация ≠ Аутентификация

Допустим, пользователь вводит:

```text
Логин: ilya
```

Это:

```text
Идентификация
     ↓
«Я — ilya»
```

Но система ещё не знает, действительно ли это Илья.

Для этого нужна **аутентификация**.

```text
Идентификация
     ↓
Кто ты?
     ↓
Аутентификация
     ↓
Докажи это
```

---

# 📌 Примеры идентификаторов

Идентификатором может быть:

```text
username
email
phone
user_id
```

Например:

```python
user_identifier = "ilya@example.com"
```

Пользователь сообщает:

> «Моя учётная запись — [ilya@example.com](mailto:ilya@example.com)».

Это ещё не вход в систему.

---

# 🧠 Пример из жизни

В банке:

```text
«Я клиент Иванов»
        ↓
Идентификация
```

Банк затем просит подтвердить личность:

```text
Пароль / SMS / биометрия
        ↓
Аутентификация
```

После этого банк определяет:

```text
Что Иванову разрешено?
        ↓
Авторизация
```

---

# 🎯 Главное

```text
Идентификация
      ↓
Сообщить системе, КТО ты
```

Примеры:

* логин;
* email;
* телефон;
* ID.

**Идентификация не доказывает личность.**

---

# 🧠 Формула для запоминания

**Идентификация = назвать себя.**

> «Я — Илья».

**Аутентификация = доказать это.**

> «Вот мой пароль».

**Авторизация = определить права.**

> «Илье разрешено делать X».
