# 🌐 Frontend — клиентская часть приложения

## 🎤 Короткий ответ для собеседования

**Frontend** — это клиентская часть приложения, с которой взаимодействует пользователь.

Frontend отвечает за отображение интерфейса, обработку пользовательских действий и взаимодействие с Backend через API.

Основные технологии:

- **[[HTML — HyperText Markup Language]]** — структура страницы.
- **[[CSS — Cascading Style Sheets]]** — оформление и стили.
- **[[JavaScript — язык программирования для веб-разработки]]** — интерактивность и логика интерфейса.
- **[[TypeScript — типизированный JavaScript]]** — JavaScript с системой статической типизации.
- **[[React — библиотека для создания интерфейсов]], [[Vue.js — JavaScript-фреймворк для Frontend]], [[Angular — Frontend-фреймворк]]** — инструменты для разработки интерфейсов.

## 🗣️ Ответ на собеседовании

Frontend — это часть приложения, которая отвечает за пользовательский интерфейс.

Например, пользователь открывает сайт, нажимает кнопку или отправляет форму. Frontend обрабатывает действие и при необходимости отправляет HTTP-запрос на Backend.

Backend выполняет бизнес-логику, обращается к базе данных и возвращает результат, обычно в JSON.

Frontend получает ответ и обновляет интерфейс.

В Backend-разработке важно понимать, как Frontend взаимодействует с API, какие HTTP-методы использует, как работает авторизация и как обрабатываются ошибки.

## ⚙️ Как взаимодействуют Frontend и Backend

```text
       Пользователь
            |
            v
     Frontend (React)
            |
            | HTTP Request
            | GET /api/products
            v
     Backend (FastAPI)
            |
            v
       PostgreSQL
            |
            v
     Backend возвращает
          JSON
            |
            v
     Frontend отображает
         данные
```

### Пример запроса

Frontend отправляет:

```http
GET /api/products HTTP/1.1
Host: example.com
```

Backend возвращает:

```json
{
  "products": [
    {"id": 1, "name": "Ноутбук"},
    {"id": 2, "name": "Монитор"}
  ]
}
```

Frontend отображает список товаров пользователю.

## 🔧 Пример Frontend на JavaScript

```javascript
async function getProducts() {
    const response = await fetch("/api/products");

    if (!response.ok) {
        throw new Error("Ошибка получения товаров");
    }

    const data = await response.json();

    console.log(data.products);
}
```

### Разбор

`async` — объявляет асинхронную функцию.

`fetch()` — отправляет HTTP-запрос.

`await` — ожидает результат асинхронной операции, не блокируя основной поток браузера.

`response.ok` — проверяет успешность HTTP-статуса (200–299).

`response.json()` — преобразует JSON-ответ в JavaScript-объект.

`console.log()` — выводит данные в консоль браузера.

## ⚖️ Frontend vs Backend

| Frontend | Backend |
|---|---|
| Интерфейс пользователя | Бизнес-логика |
| HTML, CSS, JavaScript | Python, Java, Go и др. |
| React, Vue, Angular | FastAPI, Django |
| Отображение данных | Обработка данных |
| Запросы к API | Реализация API |
| Выполняется преимущественно в браузере | Выполняется на сервере |

**Важно:** Frontend может проверять правильность ввода данных, но Backend обязан самостоятельно выполнять валидацию и проверку прав доступа.

## 🔑 Что Backend-разработчику важно знать о Frontend

**1. REST API**

Frontend взаимодействует с Backend через HTTP.

Основные методы:

- `GET` — получение данных.
- `POST` — создание ресурса или выполнение операции.
- `PUT` — полное обновление ресурса.
- `PATCH` — частичное обновление.
- `DELETE` — удаление ресурса.

**2. JSON**

Основной формат обмена данными во многих веб-приложениях.

**3. CORS**

Механизм браузера, который регулирует доступ JavaScript к ответам от другого origin.

Например, Frontend работает на `localhost:3000`, а Backend — на `localhost:8000`.

**4. Авторизация**

Frontend может передавать токен доступа:

```http
Authorization: Bearer <access_token>
```

Backend проверяет токен и права пользователя.

**5. HTTP Status Codes**

| Код | Значение |
|---|---|
| 200 | Успешный запрос |
| 201 | Ресурс создан |
| 400 | Некорректный запрос |
| 401 | Требуется аутентификация |
| 403 | Доступ запрещён |
| 404 | Ресурс не найден |
| 422 | Ошибка обработки или валидации данных |
| 500 | Внутренняя ошибка сервера |

## ❓ Частые вопросы на собеседовании

**1. Что такое Frontend?**

Клиентская часть приложения, отвечающая за интерфейс и взаимодействие с пользователем.

**2. Как Frontend общается с Backend?**

Обычно через HTTP API с использованием JSON.

**3. Что такое SPA?**

Single Page Application — приложение, которое обновляет интерфейс без полной перезагрузки страницы при обычной навигации.

**4. Что такое React?**

JavaScript-библиотека для создания пользовательских интерфейсов на основе компонентов.

**5. Что такое CORS?**

Браузерный механизм контроля доступа к ресурсам между разными origin.

**6. Где должна выполняться валидация?**

На Frontend — для удобства пользователя, на Backend — обязательно для корректности и безопасности.

**7. Чем Frontend отличается от Backend?**

Frontend отвечает за взаимодействие с пользователем, Backend — за серверную логику, данные и API.
