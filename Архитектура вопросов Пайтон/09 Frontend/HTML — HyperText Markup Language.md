# 🌐 HTML — HyperText Markup Language

## 🎤 Короткий ответ для собеседования

**HTML (HyperText Markup Language)** — язык гипертекстовой разметки, который определяет структуру и содержимое веб-страницы.

С помощью HTML создаются заголовки, текст, ссылки, изображения, формы и другие элементы интерфейса.

HTML — **не язык программирования**, поскольку сам по себе не предназначен для реализации алгоритмов и бизнес-логики.

- **HTML** — структура страницы.
- **CSS** — внешний вид.
- **JavaScript** — интерактивность.

## 🗣️ Ответ на собеседовании

HTML — это язык разметки, который браузер использует для построения структуры веб-страницы.

Страница состоит из элементов, которые описываются тегами. Например, заголовки, абзацы, кнопки и формы.

Браузер разбирает HTML и формирует DOM — объектную модель документа. JavaScript может взаимодействовать с DOM и изменять содержимое страницы.

В Backend-разработке HTML встречается при работе с серверными шаблонами, например Django Templates или Jinja2, а также при создании форм и веб-интерфейсов.

## ⚙️ Структура HTML-документа

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это моя первая страница.</p>
    <button>Нажми меня</button>
</body>
</html>
```

### Разбор

| Элемент | Назначение |
|---|---|
| `<!DOCTYPE html>` | Объявляет современный HTML-документ |
| `<html>` | Корневой элемент страницы |
| `<head>` | Метаданные и настройки документа |
| `<meta>` | Метаданные, например кодировка |
| `<title>` | Название вкладки браузера |
| `<body>` | Основное содержимое страницы |
| `<h1>` | Заголовок первого уровня |
| `<p>` | Абзац текста |
| `<button>` | Кнопка |

## 🔑 Атрибуты HTML

**Атрибуты** — дополнительные настройки элементов.

```html
<a href="https://example.com">Открыть сайт</a>

<img src="photo.jpg" alt="Описание фотографии">

<input type="email" name="email" required>
```

- `href` — адрес ссылки.
- `src` — путь к ресурсу.
- `alt` — текстовая альтернатива изображению.
- `type` — тип поля ввода.
- `name` — имя поля при отправке формы.
- `required` — обязательность заполнения.

## 🔄 Как HTML взаимодействует с Backend

```text
Пользователь
     |
     v
HTML-форма
     |
     | HTTP POST
     v
Backend (Django / FastAPI)
     |
     v
Обработка данных
     |
     v
Ответ сервера
```

Пример формы:

```html
<form action="/login" method="post">
    <input type="text" name="username">
    <input type="password" name="password">
    <button type="submit">Войти</button>
</form>
```

При нажатии кнопки браузер отправляет POST-запрос на `/login` с данными формы.

Backend проверяет данные, выполняет необходимую логику и возвращает ответ.

**Важно:** HTML-валидация не заменяет серверную проверку данных.

## 🧠 DOM — Document Object Model

**DOM** — объектная модель HTML-документа, с которой может работать JavaScript.

```text
document
   |
   v
  html
   |
   ├── head
   |    └── title
   |
   └── body
        ├── h1
        ├── p
        └── button
```

Браузер формирует DOM на основе HTML. JavaScript может изменять элементы, их содержимое и атрибуты.

## ❓ Частые вопросы на собеседовании

**1. Что такое HTML?**

Язык разметки для описания структуры веб-страницы.

**2. HTML — язык программирования?**

Нет, это язык разметки.

**3. Чем HTML отличается от CSS?**

HTML определяет структуру и содержимое, CSS — оформление.

**4. Что такое DOM?**

Объектное представление документа, позволяющее программно работать с его элементами.

**5. Чем отличаются `div` и `span`?**

`div` — блочный контейнер по умолчанию, `span` — строчный. Оба не имеют собственного семантического значения.

**6. Что такое семантический HTML?**

Использование тегов по их смыслу: `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`. Это улучшает доступность и понятность структуры документа.

**7. Как HTML связан с Django?**

Django может генерировать HTML на сервере с помощью шаблонов Django Templates.

**8. Может ли HTML отправлять данные на Backend без JavaScript?**

Да. Через HTML-формы с методами GET и POST.

```text
HTML       → Структура

JavaScript → Интерактивность
```
