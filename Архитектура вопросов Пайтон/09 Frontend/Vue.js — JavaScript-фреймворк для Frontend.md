# 🟢 Vue.js — JavaScript-фреймворк для Frontend

## 🎤 Короткий ответ для собеседования

**Vue.js** — это прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов и одностраничных приложений (SPA).

Vue использует **компонентный подход** и **реактивность**: когда данные изменяются, интерфейс автоматически обновляется.

Основные концепции:

- **Components** — переиспользуемые части интерфейса.
- **Reactivity** — автоматическое отслеживание изменений данных.
- **Props** — передача данных от родителя к дочернему компоненту.
- **Events** — передача событий от дочернего компонента родителю.
- **Directives** — специальные атрибуты для управления отображением.
- **Composition API** — способ организации логики компонентов.

## 🗣️ Ответ на собеседовании

Vue — это JavaScript-фреймворк для разработки интерактивных веб-интерфейсов.

Он позволяет разбивать приложение на независимые компоненты и управлять их состоянием с помощью реактивной системы.

Например, пользователь нажимает кнопку, изменяется значение переменной, и Vue автоматически обновляет соответствующую часть интерфейса.

С Backend Vue взаимодействует через HTTP API. Например, отправляет запрос к FastAPI, получает JSON и отображает данные.

## 🧩 Компоненты Vue

Vue часто использует формат **Single File Component (SFC)** — файл `.vue`, содержащий логику, разметку и стили.

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <button @click="count++">
    Нажали: {{ count }}
  </button>
</template>

<style scoped>
button {
  color: blue;
}
</style>
```

### Разбор

- `<script setup>` — логика компонента.
- `ref(0)` — создаёт реактивное значение.
- `<template>` — HTML-подобная разметка.
- `@click` — обработчик события нажатия.
- `{{ count }}` — вывод значения в интерфейс.
- `<style scoped>` — стили, ограниченные компонентом с помощью механизма scoped CSS.

При изменении `count` Vue автоматически обновляет отображаемое значение.

## 🔑 Основные директивы Vue

**Директивы** — специальные атрибуты с префиксом `v-`.

| Директива | Назначение |
|---|---|
| `v-if` | Условное отображение |
| `v-else` | Альтернативная ветка |
| `v-for` | Вывод списка элементов |
| `v-model` | Двустороннее связывание данных |
| `v-bind` или `:` | Привязка атрибутов |
| `v-on` или `@` | Обработка событий |
| `v-show` | Управление видимостью через CSS |

Пример:

```vue
<template>
  <p v-if="isAuthenticated">Добро пожаловать!</p>

  <button @click="login">Войти</button>
</template>
```

`v-if` добавляет или удаляет элемент в зависимости от условия.

`@click` вызывает обработчик при нажатии.

## 🧠 Reactivity — реактивность

**Реактивность** — механизм, благодаря которому Vue отслеживает зависимости интерфейса от данных.

```javascript
import { ref } from 'vue'

const count = ref(0)

count.value++
```

`ref()` создаёт реактивную ссылку.

В JavaScript значение читается и изменяется через `.value`.

В шаблонах Vue автоматически распаковывает `ref`, поэтому писать `.value` обычно не требуется.

## 🌐 Vue и FastAPI

Пример получения данных с Backend:

```vue
<script setup>
import { ref, onMounted } from 'vue'

const users = ref([])

onMounted(async () => {
  const response = await fetch('/api/users')

  if (!response.ok) {
    throw new Error('HTTP error')
  }

  users.value = await response.json()
})
</script>

<template>
  <ul>
    <li v-for="user in users" :key="user.id">
      {{ user.name }}
    </li>
  </ul>
</template>
```

### Что происходит?

1. `ref([])` — создаёт реактивный список пользователей.
2. `onMounted()` — запускает функцию после монтирования компонента.
3. `fetch()` — отправляет HTTP-запрос.
4. `response.json()` — получает данные из JSON.
5. `users.value` — обновляет список.
6. `v-for` — отображает пользователей.

В production дополнительно обрабатывают сетевые ошибки, загрузку и отмену устаревших запросов.

## ⚖️ Vue vs React vs Angular

| Критерий | Vue | React | Angular |
|---|---|---|---|
| Тип | Фреймворк | Библиотека | Фреймворк |
| Подход | Компоненты | Компоненты | Компоненты |
| Разметка | Templates | JSX | Templates |
| Реактивность | `ref`, `reactive` | State, Hooks | Signals и другие механизмы |
| TypeScript | Поддерживается | Поддерживается | Основной язык разработки |

Vue часто выбирают за понятный синтаксис и возможность постепенно внедрять его в существующие проекты.

Для маршрутизации используют **Vue Router**, для управления общим состоянием — **Pinia**, а для серверного рендеринга — **Nuxt**.

## ❓ Частые вопросы на собеседовании

**1. Что такое Vue.js?**

JavaScript-фреймворк для создания реактивных пользовательских интерфейсов.

**2. Что такое реактивность?**

Автоматическое отслеживание изменений данных и обновление зависимых частей интерфейса.

**3. Что такое компонент?**

Независимая переиспользуемая часть интерфейса.

**4. Чем `v-if` отличается от `v-show`?**

`v-if` условно создаёт или удаляет элемент, а `v-show` переключает его видимость через CSS.

**5. Что такое `v-model`?**

Директива для двустороннего связывания данных, например с полем ввода.

**6. Чем Props отличаются от Events?**

Props передают данные от родительского компонента к дочернему, Events позволяют дочернему компоненту уведомлять родителя о событиях.

**7. Что такое Composition API?**

API Vue для организации логики компонентов с помощью функций, например `ref()`, `computed()` и `watch()`.

**8. Чем Vue отличается от React?**

Vue обычно использует HTML-подобные шаблоны и встроенную реактивность, а React — JSX и обновление состояния через Hooks.

**9. Как Vue взаимодействует с FastAPI?**

Через HTTP API с использованием `fetch()` или Axios, обычно обмениваясь JSON.

**10. Что такое Nuxt?**

Фреймворк на основе Vue для создания полноценных веб-приложений с поддержкой серверного рендеринга и других возможностей.
