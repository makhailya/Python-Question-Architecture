# ⚡ JavaScript — язык программирования для веб-разработки

## 🎤 Короткий ответ для собеседования

**JavaScript (JS)** — высокоуровневый, динамически типизированный язык программирования, который используется для создания интерактивных веб-приложений.

JavaScript позволяет:

- Обрабатывать действия пользователя.
- Изменять HTML и CSS через DOM.
- Отправлять HTTP-запросы к Backend API.
- Асинхронно обрабатывать операции.
- Разрабатывать серверные приложения с помощью Node.js.

**HTML — структура, CSS — оформление, JavaScript — логика и интерактивность.**

## 🗣️ Ответ на собеседовании

JavaScript — основной язык программирования для клиентской части веб-приложений.

Он выполняется в браузере, обрабатывает пользовательские события, изменяет DOM и взаимодействует с Backend через HTTP API.

Например, пользователь нажимает кнопку, JavaScript отправляет запрос через `fetch()`, получает JSON от FastAPI и обновляет интерфейс без полной перезагрузки страницы.

JavaScript поддерживает асинхронное программирование через Promise и `async/await`. Также его можно использовать на сервере через Node.js.

## 🔑 Основы синтаксиса

### Переменные

```javascript
let age = 25;           // Можно изменить
const name = "Илья";    // Нельзя переназначить
```

- `let` — объявляет переменную с возможностью переназначения.
- `const` — запрещает переназначение переменной.
- `var` — устаревший для современного кода способ объявления переменных.

Важно: `const` не делает содержимое объекта неизменяемым.

### Типы данных

| JavaScript | Python |
|---|---|
| `number` | `int`, `float` |
| `string` | `str` |
| `boolean` | `bool` |
| `null` | `None` |
| `undefined` | Нет прямого аналога |
| `Array` | `list` |
| `Object` | Частично похож на `dict` |

Также существуют `bigint`, `symbol` и другие особенности объектной модели JavaScript.

### Условия и циклы

```javascript
const age = 20;

if (age >= 18) {
    console.log("Совершеннолетний");
} else {
    console.log("Несовершеннолетний");
}

for (let i = 0; i < 3; i++) {
    console.log(i);
}
```

В отличие от Python, JavaScript использует фигурные скобки `{}` для блоков кода.

## 🧩 Функции

Обычная функция:

```javascript
function sum(a, b) {
    return a + b;
}

console.log(sum(2, 3)); // 5
```

Стрелочная функция:

```javascript
const sum = (a, b) => a + b;
```

Обе функции возвращают сумму двух аргументов, но стрелочные функции отличаются поведением `this` и некоторыми другими особенностями.

## 🌐 DOM — Document Object Model

**DOM** — объектная модель HTML-документа, через которую JavaScript взаимодействует с элементами страницы.

HTML:

```html
<button id="btn">Нажми</button>
```

JavaScript:

```javascript
const button = document.querySelector("#btn");

button.addEventListener("click", () => {
    alert("Кнопка нажата!");
});
```

### Разбор

- `querySelector()` — находит элемент по CSS-селектору.
- `addEventListener()` — регистрирует обработчик события.
- `"click"` — событие нажатия.
- `alert()` — показывает сообщение пользователю.

## 🔄 Асинхронность: Promise и async/await

JavaScript использует **Event Loop** для координации выполнения кода и асинхронных операций.

Основные понятия:

- **Call Stack** — стек выполнения функций.
- **Event Loop** — механизм обработки очередей задач.
- **Promise** — объект, представляющий результат асинхронной операции.
- **async/await** — удобный синтаксис работы с Promise.

### Пример запроса к FastAPI

```javascript
async function getUsers() {
    try {
        const response = await fetch("/api/users");

        if (!response.ok) {
            throw new Error("Ошибка HTTP");
        }

        const users = await response.json();

        console.log(users);
    } catch (error) {
        console.error(error);
    }
}
```

### Разбор

1. `async` — объявляет асинхронную функцию.
2. `fetch()` — отправляет HTTP-запрос и возвращает Promise.
3. `await` — ожидает результат Promise, не блокируя основной поток браузера.
4. `response.ok` — проверяет HTTP-статус 200–299.
5. `response.json()` — разбирает JSON.
6. `catch` — обрабатывает возникшую ошибку.

**Важно:** `await` не создаёт отдельный поток. Асинхронность JavaScript основана на Event Loop и возможностях среды выполнения.

## ❓ Частые вопросы на собеседовании

**1. Что такое JavaScript?**

Язык программирования, используемый для интерактивности веб-страниц и разработки приложений.

**2. Чем JavaScript отличается от Java?**

Это разные языки программирования с разными экосистемами и моделями выполнения.

**3. Что такое DOM?**

Объектное представление HTML-документа, с которым взаимодействует JavaScript.

**4. Что такое Event Loop?**

Механизм, координирующий выполнение задач и обработку результатов асинхронных операций.

**5. Что такое Promise?**

Объект, представляющий будущий результат асинхронной операции: ожидающий, выполненный или отклонённый.

**6. Чем `let` отличается от `const`?**

`let` позволяет переназначать переменную, `const` — нет.

**7. Что такое `async/await`?**

Синтаксис для удобной работы с асинхронными операциями на основе Promise.

**8. Что такое Node.js?**

Среда выполнения JavaScript вне браузера, часто используемая для Backend-разработки.

**9. Что такое TypeScript?**

Надмножество JavaScript с системой статической типизации, которое обычно компилируется в JavaScript.

**10. Как JavaScript взаимодействует с Python Backend?**

Через HTTP API, например с помощью `fetch()`, передавая и получая данные в JSON.
