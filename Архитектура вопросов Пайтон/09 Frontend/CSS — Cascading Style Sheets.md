# 🎨 CSS — Cascading Style Sheets

## 🎤 Короткий ответ для собеседования

**CSS (Cascading Style Sheets)** — каскадные таблицы стилей, которые используются для оформления HTML-страниц.

CSS отвечает за внешний вид интерфейса:

- Цвета и шрифты.
- Размеры элементов.
- Отступы и границы.
- Расположение элементов.
- Адаптацию под разные экраны.
- Анимации и визуальные эффекты.

**HTML определяет структуру страницы, CSS — её оформление, JavaScript — интерактивность.**

## 🗣️ Ответ на собеседовании

CSS — это язык стилей, который определяет, как HTML-элементы отображаются в браузере.

С помощью CSS можно управлять цветами, размерами, отступами и расположением элементов, создавать адаптивные интерфейсы.

Стили применяются через селекторы, которые позволяют выбирать HTML-элементы по тегу, классу или идентификатору.

В Backend-разработке CSS может использоваться при создании HTML-шаблонов Django или Jinja2, например для административных панелей и внутренних интерфейсов.

## ⚙️ Как работает CSS

```text
HTML → Структура страницы
         |
         v
CSS → Оформление элементов
         |
         v
Браузер → Отображение страницы
```

### Пример

HTML:

```html
<h1 class="title">Привет, мир!</h1>
```

CSS:

```css
.title {
    color: blue;
    font-size: 24px;
    text-align: center;
}
```

### Разбор

- `.title` — селектор класса.
- `color` — цвет текста.
- `font-size` — размер шрифта.
- `text-align` — выравнивание текста.
- `{ }` — блок CSS-объявлений.

## 🔑 Основные селекторы

| Селектор | Что выбирает |
|---|---|
| `p` | Все элементы `<p>` |
| `.card` | Элементы с классом `card` |
| `#header` | Элемент с ID `header` |
| `div p` | Все `<p>` внутри `<div>` |
| `div > p` | Непосредственные дочерние `<p>` |
| `button:hover` | Кнопку при наведении |

Пример:

```css
p {
    color: black;
}

.card {
    background-color: lightgray;
}

#header {
    height: 80px;
}
```

## 📦 Box Model — блочная модель

Каждый HTML-элемент представляется прямоугольной областью.

```text
┌────────────────────────────┐
│           Margin           │
│  ┌──────────────────────┐  │
│  │        Border        │  │
│  │  ┌────────────────┐  │  │
│  │  │    Padding     │  │  │
│  │  │  ┌──────────┐  │  │  │
│  │  │  │ Content  │  │  │  │
│  │  │  └──────────┘  │  │  │
│  │  └────────────────┘  │  │
│  └──────────────────────┘  │
└────────────────────────────┘
```

- **Content** — содержимое.
- **Padding** — внутренний отступ.
- **Border** — граница.
- **Margin** — внешний отступ.

```css
.card {
    width: 300px;
    padding: 20px;
    border: 1px solid black;
    margin: 10px;
    box-sizing: border-box;
}
```

`box-sizing: border-box` означает, что заданная ширина включает содержимое, padding и border.

## 📐 Flexbox и Grid

Это два основных инструмента расположения элементов.

### Flexbox

Используется преимущественно для расположения элементов по одной оси.

```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 10px;
}
```

- `display: flex` — включает Flexbox.
- `justify-content` — выравнивание по главной оси.
- `align-items` — выравнивание по поперечной оси.
- `gap` — расстояние между элементами.

### Grid

Используется для построения двумерных сеток.

```css
.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 20px;
}
```

Создаёт три колонки одинаковой ширины.

**Запомнить:** Flexbox — преимущественно одна ось, Grid — строки и колонки.

## 📱 Адаптивная вёрстка

**Responsive Design** — подход, при котором интерфейс адаптируется под разные размеры экранов.

Для этого используют Media Queries.

```css
.container {
    width: 80%;
}

@media (max-width: 600px) {
    .container {
        width: 100%;
    }
}
```

Если ширина области просмотра не превышает 600 пикселей, контейнер занимает 100% доступной ширины.

## 🧠 Что такое каскадность

**Каскадность** — механизм, определяющий, какое CSS-объявление применяется, если несколько правил задают одно и то же свойство.

Учитываются:

- Происхождение и важность стилей.
- Каскадные слои.
- Специфичность селекторов.
- Порядок объявления при прочих равных условиях.

Например:

```css
p {
    color: black;
}

.text {
    color: red;
}
```

```html
<p class="text">Привет!</p>
```

Текст будет красным, поскольку селектор класса `.text` имеет более высокую специфичность, чем селектор тега `p`, при равных остальных условиях.

## ❓ Частые вопросы на собеседовании

**1. Что такое CSS?**

Язык стилей для оформления HTML-документов.

**2. Чем CSS отличается от HTML?**

HTML отвечает за структуру и содержимое, CSS — за визуальное представление.

**3. Что такое селектор?**

Правило выбора HTML-элементов, к которым применяются стили.

**4. Чем отличаются `class` и `id`?**

`class` можно использовать у множества элементов. `id` должен быть уникальным в пределах документа.

**5. Что такое Box Model?**

Модель элемента, состоящая из content, padding, border и margin.

**6. Чем Flexbox отличается от Grid?**

Flexbox удобен для одномерного расположения, Grid — для двумерных сеток.

**7. Что такое Media Query?**

Условное применение CSS-стилей в зависимости от характеристик устройства или области просмотра.

**8. Что такое специфичность?**

Механизм сравнения селекторов при разрешении конфликтов CSS-правил.

**9. Как подключить CSS к HTML?**

Через внешний файл:

```html
<link rel="stylesheet" href="style.css">
```

**10. Нужен ли CSS Backend-разработчику?**

Глубокое знание необязательно для большинства Backend-позиций, но основы полезны при работе с HTML-шаблонами и внутренними веб-интерфейсами.
