# ⚛️ React — библиотека для создания интерфейсов

## 🎤 Короткий ответ для собеседования

**React** — это JavaScript-библиотека для разработки пользовательских интерфейсов, созданная Meta.

React позволяет строить интерфейсы из переиспользуемых **компонентов** и автоматически обновлять отображение при изменении данных.

Основные концепции:

- **Components** — независимые части интерфейса.
- **JSX** — синтаксис описания интерфейса внутри JavaScript.
- **Props** — передача данных между компонентами.
- **State** — внутреннее состояние компонента.
- **Hooks** — функции для работы с состоянием и другими возможностями React.
- **Virtual DOM** — представление интерфейса в памяти, используемое при согласовании изменений.

## 🗣️ Ответ на собеседовании

React — это библиотека для создания динамических веб-интерфейсов.

Основная идея React — компонентный подход. Интерфейс разбивается на небольшие независимые компоненты, которые можно повторно использовать.

Компоненты получают данные через props и могут хранить собственное состояние через state.

Когда состояние изменяется, React повторно вызывает необходимые компоненты, сравнивает результат с предыдущим представлением и обновляет нужные части интерфейса.

С Backend React обычно взаимодействует через REST API: отправляет HTTP-запросы, получает JSON и отображает данные пользователю.

## ⚙️ Как React взаимодействует с Backend

```text
        Пользователь
             |
             v
      React Frontend
             |
             | HTTP / JSON
             v
      FastAPI Backend
             |
             v
         PostgreSQL
             |
             v
        JSON Response
             |
             v
    React обновляет UI
```

Например, пользователь открывает страницу поставок. React отправляет `GET /api/supplies`, FastAPI получает данные из PostgreSQL и возвращает JSON.

React отображает полученные поставки в виде списка или таблицы.

## 🧩 Components — компоненты

**Компонент** — независимая часть пользовательского интерфейса.

```jsx
function Welcome() {
    return <h1>Привет, мир!</h1>;
}
```

Здесь:

- `function Welcome()` — объявление компонента.
- `return` — возвращает описание интерфейса.
- `<h1>` — JSX-разметка.

Компоненты можно вкладывать друг в друга:

```jsx
function App() {
    return (
        <div>
            <Welcome />
            <Welcome />
        </div>
    );
}
```

React отобразит компонент `Welcome` два раза.

## 🔑 Props и State

### Props — входные данные

**Props** позволяют родительскому компоненту передавать данные дочернему.

```jsx
function User({ name }) {
    return <h2>Привет, {name}!</h2>;
}

function App() {
    return <User name="Илья" />;
}
```

`name` передаётся из `App` в `User`.

Props нельзя изменять внутри компонента, который их получает.

### State — состояние

**State** — данные компонента, изменение которых может приводить к обновлению интерфейса.

```jsx
import { useState } from "react";

function Counter() {
    const [count, setCount] = useState(0);

    return (
        <button onClick={() => setCount(count + 1)}>
            Нажали: {count}
        </button>
    );
}
```

### Разбор

- `useState(0)` — создаёт состояние с начальным значением `0`.
- `count` — текущее значение.
- `setCount()` — функция обновления состояния.
- `onClick` — обработчик нажатия.
- После изменения состояния React обновляет отображение счётчика.

**Главное различие:** Props приходят извне, State управляется самим компонентом.

## 🪝 Hooks — хуки

**Hooks** — специальные функции React, позволяющие использовать состояние и другие возможности библиотеки.

| Hook | Назначение |
|---|---|
| `useState` | Управление состоянием |
| `useEffect` | Синхронизация с внешними системами |
| `useContext` | Получение данных из контекста |
| `useRef` | Хранение изменяемого значения или ссылки на DOM |
| `useMemo` | Кэширование результата вычисления |
| `useCallback` | Кэширование функции |

### Пример useEffect

```jsx
import { useEffect, useState } from "react";

function Users() {
    const [users, setUsers] = useState([]);

    useEffect(() => {
        fetch("/api/users")
            .then(response => response.json())
            .then(data => setUsers(data));
    }, []);

    return <p>Пользователей: {users.length}</p>;
}
```

`useEffect()` запускает побочный эффект после отображения компонента.

Пустой массив зависимостей `[]` означает, что эффект не должен повторяться из-за изменений props или state. В режиме разработки React Strict Mode может дополнительно запускать эффект для проверки корректности очистки.

Пример упрощённый: в production также нужны обработка ошибок, отмена устаревших запросов и проверка HTTP-статуса.

## 🧠 Virtual DOM

**Virtual DOM** — упрощённое представление пользовательского интерфейса в памяти.

Когда состояние изменяется:

1. React повторно вычисляет описание интерфейса.
2. Сопоставляет новое дерево элементов с предыдущим.
3. Определяет необходимые изменения.
4. Применяет изменения к реальному DOM.

Этот процесс называется **Reconciliation**.

Важно: Virtual DOM не гарантирует, что React всегда быстрее прямой работы с DOM. Его главное преимущество — декларативная модель разработки интерфейсов.

## ⚖️ React vs Vue vs Angular

| Технология | Особенность |
|---|---|
| React | Библиотека интерфейсов, компонентный подход |
| Vue | Прогрессивный JavaScript-фреймворк |
| Angular | Полноценный фреймворк с широким набором встроенных возможностей |

React часто используют вместе с TypeScript, React Router и инструментами управления серверными данными.

Для серверного рендеринга и полноценных веб-приложений на React также используют Next.js.

## ❓ Частые вопросы на собеседовании

**1. Что такое React?**

JavaScript-библиотека для создания пользовательских интерфейсов на основе компонентов.

**2. Что такое JSX?**

Расширение синтаксиса JavaScript, позволяющее описывать интерфейс с помощью разметки, похожей на HTML.

**3. Чем Props отличаются от State?**

Props передаются компоненту извне, State хранит его изменяемое состояние.

**4. Что такое Virtual DOM?**

Представление интерфейса в памяти, которое React использует для согласования обновлений.

**5. Что такое Hooks?**

Функции React для работы с состоянием, эффектами, контекстом и другими возможностями.

**6. Для чего нужен useEffect?**

Для синхронизации компонента с внешними системами: сетевыми запросами, подписками и другими побочными эффектами.

**7. Что такое SPA?**

Single Page Application — приложение, которое обычно обновляет содержимое без полной перезагрузки страницы при переходах.

**8. Как React взаимодействует с FastAPI?**

Через HTTP API, например с помощью `fetch()` или Axios, обмениваясь JSON-данными.

**9. Что такое key в React?**

Специальный атрибут, который помогает React определять идентичность элементов списка при обновлениях.

**10. Нужен ли React Backend-разработчику?**

Глубокое знание необязательно для большинства Backend-позиций, но важно понимать взаимодействие React с API, CORS, авторизацию и обработку HTTP-ошибок.
