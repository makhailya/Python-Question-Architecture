# Архитектура вопросов Python

Это корневая карта разделов для подготовки к собеседованию.

## Основные разделы

- **01 Python** — основы, типы и объекты, коллекции, хеш-таблицы, итераторы и генераторы, декораторы и контекстные менеджеры, память и GC, concurrency и asyncio
- **02 OOP** — основы ООП, инкапсуляция и дескрипторы, наследование и MRO, полиморфизм, абстракция и Protocols, typing и generics, паттерны
- **03 Алгоритмы и Сложность** — сложность, структуры данных, деревья и графы, поиск и обход
- **04 SQL и База Данных** — SQL, индексы и query planner, транзакции и concurrency, масштабирование и репликация, ORM и SQLAlchemy
- **05 Web** — network и HTTP, REST и API, auth и JWT, servers / proxy / балансировка, backend architecture и SOLID, frameworks
- **06 Архитектура и Микросервисы** — архитектура, Kafka и RabbitMQ, распределённые системы и транзакции, task orchestration
- **07 DevOps** — Docker и containers, Kubernetes, observability, testing и quality, Git и workflow, environment и infrastructure

## Дополнительно

- `0. Конспекты` — крупные сводные конспекты по темам

## Принцип

Сначала формируем основные темы, затем добавляем подтемы и отдельные вопросы.

- **Разделы `01`–`07`** — крупные темы.
- **Подпапки** — подтемы внутри раздела.
- **Заметки** — отдельные вопросы и понятия.
- **Ссылки `[[...]]`** — связи между понятиями.
