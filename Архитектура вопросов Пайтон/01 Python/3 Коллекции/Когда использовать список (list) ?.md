# Когда использовать список — When to Use List

## Коротко

Используй `list`, когда тебе нужна **упорядоченная изменяемая коллекция объектов**.

Список подходит, если элементы нужно добавлять, удалять или изменять после создания.

## На собеседовании достаточно сказать

> `list` используют, когда нужна упорядоченная изменяемая коллекция объектов с доступом к элементам по индексу.
>
> Список подходит, когда коллекцию нужно изменять: добавлять, удалять или заменять элементы.

## Что важно помнить

`list` удобно использовать, когда:

- порядок элементов имеет значение;
- нужны дубликаты;
- элементы могут изменяться;
- нужно добавлять или удалять элементы;
- нужен доступ к элементам по индексу.

Например:

```python
tasks = ["изучить Python", "решить задачу"]

tasks.append("повторить SQL")
```

Список изменился:

```
["изучить Python", "решить задачу"]
                    ↓
["изучить Python", "решить задачу", "повторить SQL"]
```

Если коллекция не должна изменяться, вместо list может подойти tuple (Кортеж).

## Простой пример

```python
shopping_list = ["хлеб", "молоко"]

shopping_list.append("сыр")
shopping_list.remove("молоко")

print(shopping_list)
# ["хлеб", "сыр"]
```

Здесь list подходит, потому что список покупок изменяется.

## Когда список использовать не стоит

Если тебе нужна коллекция уникальных элементов и порядок не является основной задачей, может подойти set.

Если данные должны быть неизменяемыми, может подойти tuple (Кортеж).

Если нужно хранить данные в формате ключ → значение, используется dict (Словарь).

## Главное

Выбор зависит от задачи:

```
Нужна изменяемая упорядоченная коллекция
                ↓
              list

Нужна неизменяемая упорядоченная коллекция
                ↓
             tuple

Нужны уникальные элементы
                ↓
               set

Нужны пары ключ → значение
                ↓
              dict
```
