# Множество — Set

## Коротко

`set` — это изменяемая неупорядоченная коллекция **уникальных хешируемых элементов**.

Основные свойства:

- элементы не повторяются;
- элементы должны быть хешируемыми;
- множество можно изменять;
- проверка наличия элемента в среднем выполняется за `O(1)`.

## На собеседовании достаточно сказать

> `set` — это изменяемая коллекция уникальных хешируемых элементов. Внутри множество использует хеш-таблицу, поэтому проверка наличия элемента, добавление и удаление в среднем имеют сложность O(1).

## Что важно помнить

### Дубликаты удаляются

```python
numbers = {1, 2, 2, 3, 3}

print(numbers)
# {1, 2, 3}
```

Каждый элемент может присутствовать только один раз.

## Элементы должны быть хешируемыми

Можно:

```python
numbers = {1, 2, 3}
```

Нельзя добавить list:

```python
numbers = {[1, 2, 3]}

# TypeError: unhashable type: 'list'
```

Потому что list является нехешируемым объектом.

### Set можно изменять

```Python
numbers = {1, 2, 3}

numbers.add(4)
numbers.remove(2)

print(numbers)
# {1, 3, 4}
```

Сам set является mutable, но его элементы должны быть hashable.

## Простой пример

Допустим, у нас есть список с повторяющимися значениями:

```python
numbers = [1, 2, 2, 3, 3, 3]

unique_numbers = set(numbers)

print(unique_numbers)
# {1, 2, 3}
```

set удобно использовать, когда нужно получить только уникальные значения.

Проверка наличия:

```python
if 3 in unique_numbers:
    print("Есть")
```

В среднем такая проверка имеет сложность O(1).

## Главное

Связь с dict и хеш-таблицей:

```
              Hash Table
              /        \
             ↓          ↓
           dict        set
             ↓          ↓
      ключ → значение  уникальные элементы
```

И dict, и set используют хеширование для быстрого поиска.

При этом set хранит только сами элементы, а dict хранит пары:

```
dict → ключ → значение
set  → элемент
```
