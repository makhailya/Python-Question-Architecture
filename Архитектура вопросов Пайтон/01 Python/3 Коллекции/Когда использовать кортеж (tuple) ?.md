# Когда использовать кортеж — When to Use Tuple

## Коротко

Используй `tuple`, когда нужна **упорядоченная неизменяемая коллекция объектов**.

Кортеж подходит, если после создания набор элементов не должен изменяться.

## На собеседовании достаточно сказать

> `tuple` используют, когда нужна упорядоченная неизменяемая коллекция объектов с доступом к элементам по индексу.
>
> Кортеж подходит, когда набор данных не должен изменяться после создания.

## Что важно помнить

`tuple` удобно использовать, когда:

- порядок элементов имеет значение;
- данные не должны изменяться;
- нужны дубликаты;
- нужен доступ к элементам по индексу;
- кортеж используется как составное значение.

Например, координаты точки:

```python
point = (10, 20)
```

После создания координаты не предполагается изменять.

## Tuple может использоваться как ключ словаря

Если все элементы кортежа являются хешируемыми, кортеж можно использовать как ключ dict:

```python
point = (10, 20)

locations = {
    point: "Точка A"
}
```

## Простой пример

```python
user = ("Ilya", 31)

name = user[0]
age = user[1]

print(name)
# Ilya

print(age)
# 31
```

Если попытаться изменить элемент:

```python
user[1] = 32
# TypeError
```

Кортеж неизменяем.

## Когда лучше использовать list

Если коллекцию нужно изменять:

```python
languages = ["Python", "SQL"]

languages.append("Docker")
```

Здесь list подходит лучше.

Если данные после создания не должны изменяться:

```python
coordinates = (10, 20)
```

здесь tuple подходит лучше.

## Главное

Выбор можно запомнить так:

```
Нужно изменять коллекцию
        ↓
      list

Не нужно изменять коллекцию
        ↓
     tuple
```
