# 🔢 `range()` в Python

## 🎤 Короткий ответ

`range()` — встроенный объект Python для представления **последовательности целых чисел**, чаще всего используемый в циклах.

Он принимает до трёх аргументов:

```python
range(start, stop, step)
```

* `start` — начало, включительно;
* `stop` — конец, **не включительно**;
* `step` — шаг.

```python
range(1, 5)
# 1, 2, 3, 4
```

`range()` не создаёт сразу список всех чисел, а представляет последовательность лениво и эффективно по памяти.

---

## 🗣️ Ответ на собеседовании

`range()` — встроенный тип Python, который представляет арифметическую последовательность целых чисел.

Он поддерживает три параметра: `start`, `stop` и `step`. `stop` всегда не входит в результат.

```python
range(2, 10, 2)
```

даёт последовательность:

```text
2, 4, 6, 8
```

Важная особенность — `range` не хранит все числа последовательности в виде списка. Он хранит параметры диапазона и позволяет получать элементы по мере необходимости. Поэтому `range(1_000_000_000)` занимает очень мало памяти по сравнению со списком из миллиарда элементов.

`range` является **итерируемым объектом**, поддерживает индексацию и `len()`, а при необходимости его можно преобразовать в `list`.

## 📚 Разбор поглубже

### 1. Базовый синтаксис

У `range()` три формы вызова:

```python
range(stop)
range(start, stop)
range(start, stop, step)
```

Например:

```python
range(5)
```

означает:

```text
0, 1, 2, 3, 4
```

```python
range(2, 5)
```

означает:

```text
2, 3, 4
```

```python
range(2, 10, 2)
```

означает:

```text
2, 4, 6, 8
```

---

### 2. Почему `stop` не включается

Основное правило:

```text
[start, stop)
```

То есть:

```python
range(1, 5)
```

даёт:

```text
1, 2, 3, 4
```

но не `5`.

Это удобно для индексов:

```python
items = ["a", "b", "c"]

for i in range(len(items)):
    print(items[i])
```

`range(len(items))` создаёт:

```text
0, 1, 2
```

что точно соответствует индексам списка.

---

### 3. `range(stop)`

Если передан только один аргумент:

```python
range(5)
```

то Python воспринимает его как:

```python
range(0, 5, 1)
```

То есть:

```text
start = 0
stop  = 5
step  = 1
```

---

### 4. `range(start, stop)`

Если указаны два аргумента:

```python
range(3, 8)
```

получаем:

```text
3, 4, 5, 6, 7
```

По умолчанию:

```text
step = 1
```

---

### 5. `range(start, stop, step)`

Третий аргумент определяет шаг:

```python
range(0, 10, 2)
```

Результат:

```text
0, 2, 4, 6, 8
```

Можно использовать отрицательный шаг:

```python
range(10, 0, -2)
```

Результат:

```text
10, 8, 6, 4, 2
```

---

### 6. Обратный диапазон

Чтобы идти назад:

```python
range(5, 0, -1)
```

получим:

```text
5, 4, 3, 2, 1
```

Обрати внимание:

```text
stop = 0
```

поэтому `0` не входит.

Если написать:

```python
range(5, 0, 1)
```

результат будет пустым:

```python
list(range(5, 0, 1))
# []
```

Потому что с положительным шагом невозможно добраться от `5` до `0`.

---

### 7. `step` не может быть равен нулю

Так нельзя:

```python
range(1, 10, 0)
```

Python выбросит:

```text
ValueError: range() arg 3 must not be zero
```

Шаг должен быть:

```text
step > 0
```

или:

```text
step < 0
```

---

### 8. `range()` — не список

Это важный момент.

```python
numbers = range(1_000_000)
```

не создаёт миллион элементов списка.

Проверим:

```python
type(numbers)
```

Получим:

```text
<class 'range'>
```

Если нужен именно список:

```python
numbers = list(range(1_000_000))
```

Тогда все элементы будут храниться в памяти.

---

### 9. Почему `range()` экономит память

Сравним:

```python
numbers = list(range(1_000_000))
```

и:

```python
numbers = range(1_000_000)
```

`range` достаточно хранить параметры:

```text
start
stop
step
```

Он может вычислить нужный элемент математически.

Условно:

```text
range(0, 1_000_000, 1)

start = 0
stop  = 1_000_000
step  = 1
```

Поэтому размер объекта `range` практически не зависит от количества чисел в диапазоне.

---

### 10. `range` является Iterable

Можно написать:

```python
for number in range(5):
    print(number)
```

`for` получает элементы из `range` последовательно.

Можно также получить итератор:

```python
numbers = range(3)

iterator = iter(numbers)

print(next(iterator))  # 0
print(next(iterator))  # 1
print(next(iterator))  # 2
```

То есть:

```text
range
  ↓
iter(range)
  ↓
iterator
  ↓
next()
```

---

### 11. `range` поддерживает индексацию

В отличие от многих ленивых итераторов, `range` поддерживает `[]`:

```python
numbers = range(10, 20)

print(numbers[0])  # 10
print(numbers[3])  # 13
```

Можно использовать отрицательные индексы:

```python
print(numbers[-1])  # 19
```

---

### 12. `range` поддерживает `len()`

```python
numbers = range(2, 10, 2)

print(len(numbers))
```

Результат:

```text
4
```

Потому что последовательность:

```text
2, 4, 6, 8
```

содержит четыре элемента.

---

### 13. `range` поддерживает `in`

Можно проверять принадлежность:

```python
numbers = range(0, 100, 2)

print(20 in numbers)
# True

print(21 in numbers)
# False
```

Для `range` такая проверка может выполняться эффективно, без полного перебора всех значений.

Например, Python может определить математически, подходит ли число под:

```text
start + step * n
```

---

### 14. `range` можно сравнивать

У `range` нет обычного сравнения последовательностей по значениям как у списков.

Например:

```python
range(5) == range(5)
```

даст:

```text
True
```

Но:

```python
range(0, 5, 1) == range(0, 5, 1)
```

тоже `True`.

При этом важно понимать, что `range` — это не список и сравнение имеет собственную семантику `range`.

---

### 15. `range` может быть очень большим

```python
numbers = range(10**18)
```

Сам объект создаётся без необходимости хранить `10**18` чисел в памяти.

Это одно из ключевых преимуществ `range`.

Но если сделать:

```python
list(range(10**18))
```

памяти потребуется уже огромное количество.

---

### 16. `range()` и `for`

Самое распространённое применение:

```python
for i in range(5):
    print(i)
```

Получим:

```text
0
1
2
3
4
```

Но если нам нужны сами элементы коллекции, обычно не стоит использовать `range(len(...))`.

❌ Менее читаемо:

```python
names = ["Ilya", "Anna", "Max"]

for i in range(len(names)):
    print(names[i])
```

✅ Обычно лучше:

```python
for name in names:
    print(name)
```

Если нужен одновременно индекс и элемент:

```python
for index, name in enumerate(names):
    print(index, name)
```

---

### 17. `range` и `enumerate`

Это частый вопрос на собеседовании.

Если нужны:

```text
индекс + значение
```

лучше:

```python
for index, value in enumerate(items):
    ...
```

а не:

```python
for index in range(len(items)):
    value = items[index]
```

`range(len(...))` нужен, когда действительно требуется работать именно с индексами.

---

### 18. `range` — последовательность

`range` относится к последовательностям и имеет свойства, характерные для них:

```python
numbers = range(2, 10)

numbers[0]
len(numbers)
3 in numbers
```

При этом он не хранит каждый элемент отдельно.

Можно представить его как описание арифметической прогрессии:

```text
start + n × step
```

пока значение не пересечёт границу `stop`.

---

### 19. Формула количества элементов

Для положительного шага:

```text
count = max(0, ceil((stop - start) / step))
```

Для отрицательного шага:

```text
count = max(0, ceil((start - stop) / (-step)))
```

На практике чаще достаточно помнить:

```text
range(start, stop, step)
```

и правило:

> `stop` не включается.

---

### 20. Частая ошибка

❌ Ожидать, что `range()` вернёт список:

```python
numbers = range(5)

print(numbers)
```

получим объект:

```text
range(0, 5)
```

Если нужен список:

```python
list(range(5))
```

получим:

```text
[0, 1, 2, 3, 4]
```

---

### 21. Частая ошибка с отрицательным шагом

❌

```python
range(10, 0)
```

Результат:

```python
[]
```

Потому что по умолчанию:

```text
step = 1
```

Для обратного движения нужен:

```python
range(10, 0, -1)
```

## 🎤 Вопросы на собеседовании

**Что такое `range()`?**

`range` — встроенный тип Python, представляющий последовательность целых чисел с заданными `start`, `stop` и `step`.

**Какие аргументы принимает `range()`?**

До трёх:

```python
range(start, stop, step)
```

`start` и `step` имеют значения по умолчанию `0` и `1`.

**Входит ли `stop` в `range`?**

Нет. Правая граница всегда исключается.

**Создаёт ли `range()` список?**

Нет. `range` — отдельный объект последовательности, который не хранит все элементы диапазона как список.

**Почему `range(1_000_000_000)` занимает мало памяти?**

Потому что объект хранит параметры диапазона, а не миллиард отдельных чисел.

**Можно ли использовать отрицательный `step`?**

Да:

```python
range(10, 0, -1)
```

**Можно ли использовать `step=0`?**

Нет, это вызывает `ValueError`.

**Является ли `range` итератором?**

Нет. `range` является **iterable/sequence**, а `iter(range(...))` возвращает отдельный итератор.

**Можно ли обращаться к `range` по индексу?**

Да:

```python
range(10, 20)[3]
```

**Чем `range(len(items))` отличается от `enumerate(items)`?**

`range(len(items))` даёт индексы, а `enumerate()` сразу предоставляет пары `(индекс, значение)`. Для одновременной работы с индексом и элементом обычно предпочтительнее `enumerate()`.

**Формула для собеседования:**

> **`range()` — это компактное представление последовательности целых чисел. `stop` не включается, `step` задаёт шаг, а сами элементы не хранятся в виде списка. Поэтому `range` эффективен по памяти и особенно часто используется в циклах.**
