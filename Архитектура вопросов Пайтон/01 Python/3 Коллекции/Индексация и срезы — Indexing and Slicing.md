# Индексация и срезы — Indexing and Slicing

## Коротко

**Индексация** позволяет получить отдельный элемент последовательности по его индексу.

**Срез (slice)** позволяет получить часть последовательности.

Индексы в Python начинаются с `0`:

```python
items = ["a", "b", "c"]

items[0]  # "a"
items[1]  # "b"
items[2]  # "c"
```

Для обращения с конца используются отрицательные индексы:

```python
items[-1]  # "c"
items[-2]  # "b"
```

Срез:

```python
items[start:stop:step]
```

При этом `stop` **не включается**.

## На собеседовании достаточно сказать

> Индексация позволяет получить элемент последовательности по индексу, начиная с нуля. Отрицательные индексы позволяют обращаться к элементам с конца. Срез имеет вид `start:stop:step`, при этом правая граница `stop` не включается. Срез обычно создаёт новый объект последовательности.

## Что важно помнить

### Индексация начинается с нуля

```python
numbers = [10, 20, 30, 40]
```

Индексы:

```text
10 → 0
20 → 1
30 → 2
40 → 3
```

Поэтому:

```python
numbers[0]  # 10
numbers[1]  # 20
numbers[2]  # 30
numbers[3]  # 40
```

---

## Отрицательные индексы

Python позволяет обращаться к элементам с конца:

```python
numbers = [10, 20, 30, 40]
```

Получаем:

```python
numbers[-1]  # 40
numbers[-2]  # 30
numbers[-3]  # 20
numbers[-4]  # 10
```

Можно представить:

```text
10   20   30   40
 ↑    ↑    ↑    ↑
 0    1    2    3
-4   -3   -2   -1
```

---

## Индексация строки

Индексация работает не только со списками:

```python
text = "Python"

print(text[0])
print(text[1])
print(text[-1])
```

Результат:

```text
P
y
n
```

Строка — последовательность символов, поэтому к её элементам можно обращаться по индексу.

---

## Индексация кортежа

То же самое работает с `tuple`:

```python
numbers = (10, 20, 30)

print(numbers[0])
print(numbers[-1])
```

Результат:

```text
10
30
```

---

## Индекс вне диапазона

Если обратиться к несуществующему индексу:

```python
numbers = [10, 20, 30]

print(numbers[5])
```

получим:

```text
IndexError
```

Индекс должен существовать.

---

# Срезы — Slicing

Срез имеет следующий синтаксис:

```python
sequence[start:stop:step]
```

Например:

```python
numbers = [0, 1, 2, 3, 4]

numbers[1:4]
```

Результат:

```text
[1, 2, 3]
```

Почему не `4`?

Потому что `stop` не включается.

```text
start → включается
stop  → не включается
```

---

## Срез с началом и концом

```python
numbers = [0, 1, 2, 3, 4]

numbers[1:4]
```

Получаем:

```text
[1, 2, 3]
```

Можно представить:

```text
[0, 1, 2, 3, 4]
    └───────┘
     1 до 4
```

Индекс `4` используется как граница, но сам элемент с индексом `4` не попадает в результат.

---

## Срез от начала

Начало можно не указывать:

```python
numbers = [0, 1, 2, 3, 4]

numbers[:3]
```

Это означает:

```python
numbers[0:3]
```

Результат:

```text
[0, 1, 2]
```

---

## Срез до конца

Конец можно не указывать:

```python
numbers[2:]
```

Результат:

```text
[2, 3, 4]
```

Это означает:

```python
numbers[2:len(numbers)]
```

---

## Копирование последовательности через срез

Можно получить поверхностную копию списка:

```python
numbers = [1, 2, 3]

copy = numbers[:]
```

Теперь:

```python
numbers is copy  # False
```

Это два разных списка.

```text
numbers ───> [1, 2, 3]

copy    ───> [1, 2, 3]
```

Но для вложенных изменяемых объектов это остаётся **поверхностной копией**.

Подробнее:

[[Копирование объектов — Object Copying]]

---

## `step`

Третий параметр среза — шаг:

```python
numbers[start:stop:step]
```

Например:

```python
numbers = [0, 1, 2, 3, 4, 5]

numbers[0:6:2]
```

Результат:

```text
[0, 2, 4]
```

Берём каждый второй элемент.

---

## Срез с шагом

```python
numbers = [0, 1, 2, 3, 4, 5]

numbers[::2]
```

Результат:

```text
[0, 2, 4]
```

Здесь:

```text
start → не указан
stop  → не указан
step  → 2
```

---

## Разворот последовательности

Отрицательный шаг позволяет двигаться в обратном направлении:

```python
numbers = [1, 2, 3, 4, 5]

numbers[::-1]
```

Результат:

```text
[5, 4, 3, 2, 1]
```

Это распространённый способ развернуть последовательность.

---

## Отрицательный `step`

Можно использовать отрицательный шаг с конкретными границами:

```python
numbers = [0, 1, 2, 3, 4, 5]

numbers[5:1:-1]
```

Результат:

```text
[5, 4, 3, 2]
```

Опять действует правило:

```text
stop не включается
```

---

## Срезы не вызывают `IndexError`

Это важное отличие от обычной индексации.

Например:

```python
numbers = [1, 2, 3]

print(numbers[10])
```

даст:

```text
IndexError
```

Но:

```python
print(numbers[1:10])
```

не вызовет ошибку:

```text
[2, 3]
```

Срез просто вернёт доступную часть последовательности.

---

## Срезы строк

Срезы работают со строками:

```python
text = "Python"

print(text[0:2])
```

Результат:

```text
Py
```

Можно получить последние символы:

```python
text[-3:]
```

Результат:

```text
hon
```

И развернуть строку:

```python
text[::-1]
```

Результат:

```text
nohtyP
```

---

## Срезы и изменяемость

Срез списка создаёт новый список:

```python
numbers = [1, 2, 3]

part = numbers[:]

part.append(4)

print(numbers)
print(part)
```

Результат:

```text
[1, 2, 3]
[1, 2, 3, 4]
```

Но если внутри есть вложенный список:

```python
numbers = [[1, 2], [3, 4]]

part = numbers[:]

part[0].append(99)

print(numbers)
```

получим:

```text
[[1, 2, 99], [3, 4]]
```

Потому что срез создал новую внешнюю коллекцию, но вложенные объекты остались общими.

---

## Индексация vs срез

### Индексация

```python
numbers[2]
```

Возвращает **один элемент**.

### Срез

```python
numbers[1:4]
```

Возвращает **часть последовательности**.

Упрощённо:

```text
[index]
→ один элемент

[start:stop:step]
→ последовательность
```

---

## Простой пример

```python
numbers = [10, 20, 30, 40, 50]

first = numbers[0]
last = numbers[-1]

middle = numbers[1:4]
every_second = numbers[::2]
reversed_numbers = numbers[::-1]

print(first)
print(last)
print(middle)
print(every_second)
print(reversed_numbers)
```

Результат:

```text
10
50
[20, 30, 40]
[10, 30, 50]
[50, 40, 30, 20, 10]
```

---

## Главное

Индексация:

```python
sequence[index]
```

Индексы начинаются с:

```text
0
```

С конца:

```text
-1
```

Срез:

```python
sequence[start:stop:step]
```

Главное правило:

```text
start → включается
stop  → НЕ включается
step  → шаг
```

Примеры:

```python
numbers[:3]    # первые 3 элемента
numbers[2:]    # с индекса 2 до конца
numbers[::2]   # каждый второй элемент
numbers[::-1]  # в обратном порядке
```

Главная формула:

> **Индекс → один элемент. Срез → часть последовательности.**
