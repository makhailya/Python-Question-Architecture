# `tuple` — кортеж

## 🎯 Ответ на собеседовании

> **`tuple` — встроенный неизменяемый (`immutable`) тип Python, представляющий упорядоченную последовательность элементов. Кортеж поддерживает индексацию, срезы и может содержать объекты разных типов. В отличие от `list`, после создания кортеж нельзя изменить: нельзя добавлять, удалять или заменять его элементы.**

### Если спросят: зачем нужен `tuple`, если есть `list`?

> **`tuple` используют, когда набор элементов не должен изменяться. Благодаря неизменяемости кортеж может использоваться как ключ словаря или элемент `set`, если все его элементы hashable.**

### Если спросят про `tuple` и mutable-объекты

> **Сам кортеж неизменяем, но он может содержать изменяемые объекты. Например, список внутри кортежа можно изменить.**

---

# Коротко

Кортеж:

```python
user = ("Илья", 31, "Python")
```

Это:

```text
упорядоченная последовательность
        +
    immutable
```

---

# Создание tuple

### Обычный кортеж

```python
numbers = (1, 2, 3)
```

### Можно без скобок

```python
numbers = 1, 2, 3
```

Python автоматически создаст `tuple`.

```python
type(numbers)
# <class 'tuple'>
```

---

# Кортеж из одного элемента

Здесь часто ошибаются.

Нужно поставить **запятую**:

```python
x = (10,)

type(x)
# tuple
```

А это:

```python
x = (10)

type(x)
# int
```

Скобки сами по себе не создают `tuple`.

Именно **запятая** создаёт кортеж.

```python
(10,)      # tuple
(10)       # int
```

---

# Пустой tuple

```python
empty = ()

print(type(empty))
# <class 'tuple'>
```

Также:

```python
empty = tuple()
```

---

# Элементы могут быть разных типов

```python
data = (
    "Илья",
    31,
    105.5,
    True,
    None
)
```

Кортеж может содержать практически любые Python-объекты.

---

# Индексация

Как и у списка, индексация начинается с `0`.

```python
languages = ("Python", "Java", "Go")

languages[0]
# 'Python'

languages[1]
# 'Java'
```

С конца:

```python
languages[-1]
# 'Go'
```

---

# Срезы

Можно получать часть кортежа:

```python
numbers = (10, 20, 30, 40, 50)

numbers[1:4]
# (20, 30, 40)
```

Срез возвращает **новый tuple**.

Можно использовать шаг:

```python
numbers[::2]
# (10, 30, 50)
```

Развернуть:

```python
numbers[::-1]
# (50, 40, 30, 20, 10)
```

---

# Immutable

Главное свойство `tuple`.

Нельзя:

```python
numbers = (1, 2, 3)

numbers[0] = 100
```

Получим:

```text
TypeError
```

Также нельзя:

```python
numbers.append(4)
```

или:

```python
numbers.remove(2)
```

Потому что `tuple` нельзя изменять.

---

# Но внутри может быть изменяемый объект ⚠️

Это важный вопрос на собеседовании.

```python
data = ([1, 2, 3], 10)
```

Сам `tuple` изменить нельзя:

```python
data[1] = 20
```

❌ Ошибка.

Но список внутри него изменить можно:

```python
data[0].append(4)

print(data)
# ([1, 2, 3, 4], 10)
```

Почему?

Потому что:

```text
tuple
 ├── ссылка → list ← его можно изменить
 └── ссылка → int
```

Неизменяемость `tuple` означает, что нельзя изменить **сами ссылки на его элементы**, но объект, на который ссылается элемент, может быть mutable.

# `len()`

Количество элементов:

```python
numbers = (10, 20, 30)

len(numbers)
# 3
```

---

# Проверка наличия

```python
numbers = (10, 20, 30)

20 in numbers
# True

50 in numbers
# False
```

# Методы tuple

У `tuple` всего два основных собственных метода:

### `count()`

Считает количество вхождений:

```python
numbers = (1, 2, 2, 3, 2)

numbers.count(2)
# 3
```

### `index()`

Возвращает индекс первого найденного элемента:

```python
numbers = (10, 20, 30)

numbers.index(20)
# 1
```

Если элемента нет:

```python
numbers.index(100)
```

будет:

```text
ValueError
```

---

# Распаковка tuple

Очень полезная возможность Python.

```python
user = ("Илья", 31)

name, age = user

print(name)
# Илья

print(age)
# 31
```

Количество переменных должно соответствовать количеству элементов.

---

# Распаковка со `*`

Можно собрать несколько элементов в список:

```python
numbers = (1, 2, 3, 4, 5)

first, *middle, last = numbers

print(first)
# 1

print(middle)
# [2, 3, 4]

print(last)
# 5
```

Обрати внимание: `middle` здесь будет **list**, а не tuple.

---

# Обмен переменных

Tuple unpacking позволяет красиво менять значения:

```python
a = 10
b = 20

a, b = b, a
```

После этого:

```python
a
# 20

b
# 10
```

Фактически Python использует упаковку/распаковку значений.

---

# `tuple()` — преобразование

Можно создать tuple из другой последовательности:

```python
numbers = tuple([1, 2, 3])

print(numbers)
# (1, 2, 3)
```

Из строки:

```python
tuple("Python")
```

Получим:

```python
('P', 'y', 't', 'h', 'o', 'n')
```

---

# Tuple как ключ `dict`

Поскольку `tuple` immutable, он может быть ключом словаря — **если все его элементы hashable**.

```python
coordinates = {
    (55.75, 37.61): "Москва"
}
```

Можно:

```python
coordinates[(55.75, 37.61)]
# 'Москва'
```

Но такой tuple:

```python
key = ([1, 2], 3)
```

нельзя использовать как ключ, потому что список `list` — mutable и unhashable.

---

# Tuple и `set`

Аналогично tuple может быть элементом `set`:

```python
points = {
    (1, 2),
    (3, 4)
}
```

Но:

```python
points = {
    ([1, 2], 3)
}
```

❌ вызовет ошибку.

---

# `tuple` vs `list`

|                          | `tuple`              | `list`               |
| ------------------------ | -------------------- | -------------------- |
| Упорядоченный            | ✅                    | ✅                    |
| Изменяемый               | ❌                    | ✅                    |
| Индексация               | ✅                    | ✅                    |
| Срезы                    | ✅                    | ✅                    |
| `append()`               | ❌                    | ✅                    |
| `remove()`               | ❌                    | ✅                    |
| `count()`                | ✅                    | ✅                    |
| `index()`                | ✅                    | ✅                    |
| Может быть ключом `dict` | ✅*                   | ❌                    |
| Обычно используется для  | фиксированных данных | изменяемых коллекций |

`*` Только если все элементы tuple hashable.

---

# Почему tuple может быть ключом dict?

Потому что ключ словаря должен быть **hashable**.

`tuple` immutable, поэтому его хеш может оставаться стабильным.

Например:

```python
point = (10, 20)

hash(point)
```

работает.

А:

```python
hash([10, 20])
```

даст:

```text
TypeError: unhashable type: 'list'
```

---

# Производительность

`tuple` обычно требует меньше памяти, чем `list`, и может быть немного эффективнее для хранения фиксированного набора данных.

Но не стоит говорить:

> «tuple всегда быстрее list».

Правильнее:

> **Tuple имеет меньший набор возможностей и обычно занимает меньше памяти, поскольку является неизменяемым. В конкретных операциях производительность зависит от задачи.**

---

# Где используется?

`tuple` удобно использовать для:

* фиксированных наборов значений;
* координат;
* RGB-значений;
* возврата нескольких значений из функции;
* ключей словаря;
* элементов `set`;
* структурированных неизменяемых данных.

Например:

```python
def get_user():
    return "Илья", 31
```

Функция возвращает tuple:

```python
name, age = get_user()
```

---

# Возврат нескольких значений из функции

Очень распространённый случай:

```python
def calculate(a, b):
    return a + b, a - b

result = calculate(10, 3)

print(result)
# (13, 7)
```

Можно сразу распаковать:

```python
sum_, difference = calculate(10, 3)
```

## ⭐ Самое главное

```python
numbers = (1, 2, 3)

numbers[0]
# 1

numbers[0] = 10
# TypeError
```

### Запомнить

**`tuple = упорядоченный + immutable + индексируемый`.**

И важный нюанс:

```python
(10)    # int
(10,)   # tuple
```

**Tuple особенно полезен для данных, которые после создания не должны менять свою структуру.**
