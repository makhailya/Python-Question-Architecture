`list` — это изменяемая упорядоченная коллекция объектов.

Список может содержать элементы разных типов:

```python
numbers = [1, 2, 3]
mixed = [1, "Python", True, 3.14]
```

Элементы списка имеют порядок и доступны по индексу.

# Что важно помнить

## Список изменяемый

После создания можно добавлять, удалять и изменять элементы:

```python
numbers = [1, 2, 3]

numbers[0] = 10
numbers.append(4)

print(numbers)
# [10, 2, 3, 4]
```

## Элементы имеют индексы

Индексация начинается с 0:

```python
numbers = [10, 20, 30]

print(numbers[0])  # 10
print(numbers[1])  # 20
print(numbers[2])  # 30
```

Можно использовать отрицательные индексы:

```python
print(numbers[-1])
# 30
```

## Список может содержать дубликаты

```python
numbers = [1, 2, 2, 3]
```

Два одинаковых элемента допустимы.

# Простой пример

```python
languages = ["Python", "SQL", "Docker"]

languages.append("Git")

print(languages)
# ["Python", "SQL", "Docker", "Git"]

print(languages[0])
# Python
```
