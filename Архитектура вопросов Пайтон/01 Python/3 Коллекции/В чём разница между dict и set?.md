# Словарь и множество — Dict vs Set

## Коротко

`dict` и `set` используют хеширование и в среднем обеспечивают операции за `O(1)`.

Главное отличие:

- `dict` хранит пары **ключ → значение**;
- `set` хранит только **уникальные элементы**.

## На собеседовании достаточно сказать

> `dict` — это изменяемая коллекция пар ключ → значение, где ключи должны быть хешируемыми.
>
> `set` — это изменяемая коллекция уникальных хешируемых элементов.
>
> Оба типа используют хеш-таблицу, поэтому поиск, добавление и удаление в среднем имеют сложность O(1).

## Что важно помнить

### Dict

В `dict` каждый элемент состоит из ключа и значения:

```python
user = {
    "name": "Ilya",
    "age": 31
}
```

Можно получить значение по ключу:

```python
print(user["name"])
# Ilya
```

Ключи должны быть уникальными:

```python
data = {
    "name": "Ilya",
    "name": "Alex"
}

print(data)
# {"name": "Alex"}
```

Последнее значение заменяет предыдущее.

## Set

set хранит только уникальные элементы:

```python
numbers = {1, 2, 2, 3}

print(numbers)
# {1, 2, 3}
```

Здесь нет пары «ключ → значение».

## Простой пример

Допустим, нужно хранить информацию о пользователе:

```python
user = {
    "name": "Ilya",
    "age": 31
}
```

Здесь нужен dict, потому что у нас есть соответствие:

```
name → Ilya
age  → 31
```

А если нужно хранить уникальные языки программирования:

```python
languages = {"Python", "Go", "Python"}

print(languages)
# {"Python", "Go"}
```

Здесь подходит set, потому что нам нужны только уникальные значения.

## Сравнение

| Характеристика                | `dict`          | `set`               |
| ----------------------------- | --------------- | ------------------- |
| Что хранит                    | Ключ → значение | Уникальные элементы |
| Дубликаты                     | Ключи — нет     | Элементы — нет      |
| Элементы должны быть hashable | Ключи — да      | Да                  |
| Изменяемый                    | Да              | Да                  |
| Поиск в среднем               | O(1)            | O(1)                |
| Добавление в среднем          | O(1)            | O(1)                |
| Удаление в среднем            | O(1)            | O(1)                |
## Главное

Можно запомнить:

```
dict
 ↓
ключ → значение

set
 ↓
уникальные элементы
```

Оба используют хеширование:

```
              Hash Table
              /        \
             ↓          ↓
           dict        set
             ↓          ↓
      key → value    unique values
```
