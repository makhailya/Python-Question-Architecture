# dict в Python

## 🎯 Ответ на собеседовании

> **`dict` — это изменяемая коллекция пар «ключ–значение» ([[Key-Value]]). Словарь используется, когда нужно хранить данные и быстро получать значение по уникальному ключу.**
>
> Ключ должен быть **хешируемым ([[Hashable-объекты]])**, а значения могут быть практически любыми объектами.
>
> В современных версиях Python словарь **сохраняет порядок добавления элементов**.
>
> Основные операции — получение, добавление, изменение и удаление элементов по ключу.

---

# 📌 Что такое `dict`

`dict` — встроенный тип Python для хранения данных в формате:

```text
ключ → значение
```

Пример:

```python
user = {
    "name": "Ilya",
    "age": 31,
    "city": "Yekaterinburg"
}
```

Здесь:

```text
"name" → "Ilya"
"age"  → 31
"city" → "Yekaterinburg"
```

Ключи должны быть уникальными.

---

# 🔑 Ключи и значения

В словаре есть две основные части:

### Key — ключ

Используется для поиска значения.

```python
user["name"]
```

### Value — значение

Данные, которые хранятся по ключу.

```python
"Ilya"
```

Значением может быть практически любой объект:

```python
data = {
    "name": "Ilya",
    "age": 31,
    "skills": ["Python", "Django"],
    "address": {
        "city": "Yekaterinburg"
    }
}
```

---

# ⚠️ Ключи должны быть hashable

Например, можно:

```python
data = {
    "name": "Ilya",
    1: "one",
    (10, 20): "point"
}
```

Нельзя:

```python
data = {
    [1, 2]: "list"
}
```

Потому что `list` — изменяемый и нехешируемый объект.

Также нельзя использовать:

```python
dict
set
list
```

в качестве ключей.

---

# 🔄 Изменяемость

`dict` — **mutable**, то есть его можно изменять после создания.

```python
user = {
    "name": "Ilya"
}

user["age"] = 31
```

Теперь:

```python
{
    "name": "Ilya",
    "age": 31
}
```

Можно также изменить существующее значение:

```python
user["age"] = 32
```

---

# 🏗️ Создание словаря

### Через `{}`

```python
user = {
    "name": "Ilya",
    "age": 31
}
```

### Пустой словарь

```python
user = {}
```

⚠️ Важно:

```python
{}
```

— это `dict`, а не `set`.

Пустое множество:

```python
set()
```

---

### Через `dict()`

```python
user = dict(name="Ilya", age=31)
```

Также:

```python
user = dict([
    ("name", "Ilya"),
    ("age", 31)
])
```

---

# 🔎 Получение значения

Основной способ:

```python
user["name"]
```

Если ключ существует:

```text
Ilya
```

Если ключа нет:

```python
user["email"]
```

получим:

```text
KeyError
```

---

# 🛡️ Метод `get()`

Чтобы не получить `KeyError`:

```python
user.get("email")
```

Если ключ отсутствует:

```text
None
```

Можно указать значение по умолчанию:

```python
user.get("email", "unknown@example.com")
```

Результат:

```text
unknown@example.com
```

### Разница

```python
user["email"]
```

→ ошибка, если ключа нет.

```python
user.get("email")
```

→ `None`, если ключа нет.

---

# ➕ Добавление и изменение

Одна и та же операция используется и для добавления, и для изменения:

```python
user["age"] = 31
```

Если ключа не было:

```text
добавление
```

Если ключ уже существует:

```text
изменение
```

Например:

```python
user = {"age": 30}

user["age"] = 31
```

Теперь:

```python
{"age": 31}
```

---

# ❌ Удаление

### `del`

```python
del user["age"]
```

Удаляет ключ и значение.

Если ключа нет:

```text
KeyError
```

---

### `pop()`

```python
age = user.pop("age")
```

Удаляет элемент и **возвращает его значение**.

Можно указать значение по умолчанию:

```python
age = user.pop("age", None)
```

---

### `popitem()`

Удаляет и возвращает **последнюю добавленную пару**:

```python
key, value = user.popitem()
```

---

### `clear()`

Удаляет всё содержимое:

```python
user.clear()
```

Результат:

```python
{}
```

---

# 🔍 Проверка наличия ключа

```python
"name" in user
```

Результат:

```python
True
```

Важно: `in` для `dict` проверяет именно **ключи**.

```python
"Ilya" in user
```

не проверяет значения.

Для значений:

```python
"Ilya" in user.values()
```

---

# 🔄 Перебор словаря

### Только ключи

```python
for key in user:
    print(key)
```

То же самое:

```python
for key in user.keys():
    print(key)
```

---

### Только значения

```python
for value in user.values():
    print(value)
```

---

### Ключи и значения

Наиболее распространённый вариант:

```python
for key, value in user.items():
    print(key, value)
```

---

# 📦 `keys()`, `values()`, `items()`

Словарь предоставляет специальные **представления (`view`)**:

```python
user.keys()
user.values()
user.items()
```

Например:

```python
user = {
    "name": "Ilya",
    "age": 31
}

print(user.keys())
print(user.values())
print(user.items())
```

Получаем представления ключей, значений и пар.

Они не являются обычными списками.

Если нужен именно список:

```python
list(user.keys())
list(user.values())
list(user.items())
```

---

# 🔁 Порядок элементов

Начиная с **Python 3.7**, сохранение порядка добавления элементов является гарантированной частью поведения Python.

```python
user = {}

user["name"] = "Ilya"
user["age"] = 31
user["city"] = "Yekaterinburg"
```

При переборе порядок будет:

```text
name
age
city
```

Важно:

> `dict` сохраняет **порядок вставки**, но это не означает, что словарь индексируется как `list`.

---

# 🆚 `dict` и `list`

### `list`

Данные организованы как последовательность:

```python
users = ["Ilya", "Alex", "Bob"]
```

Обращаемся по индексу:

```python
users[0]
```

### `dict`

Данные организованы как пары:

```python
users = {
    1: "Ilya",
    2: "Alex",
    3: "Bob"
}
```

Обращаемся по ключу:

```python
users[1]
```

---

# 🧠 Почему `dict` быстрый?

Словарь основан на **хеш-таблице**.

Упрощённо:

```text
key
 ↓
hash(key)
 ↓
поиск позиции
 ↓
value
```

Поэтому получение:

```python
user["name"]
```

в среднем выполняется за **O(1)**.

Основные операции:

```text
получение       → O(1) average
добавление      → O(1) average
изменение       → O(1) average
удаление        → O(1) average
проверка ключа  → O(1) average
```

Перебор всех элементов:

```text
O(n)
```

---

# 🔑 Уникальность ключей

Ключи в одном словаре должны быть уникальными.

Если записать:

```python
user = {
    "name": "Ilya",
    "name": "Alex"
}
```

останется:

```python
{
    "name": "Alex"
}
```

Последнее значение перезаписывает предыдущее.

---

# 🧩 Вложенные словари

Значением может быть другой словарь:

```python
users = {
    "user1": {
        "name": "Ilya",
        "age": 31
    },
    "user2": {
        "name": "Alex",
        "age": 25
    }
}
```

Получение:

```python
users["user1"]["name"]
```

Результат:

```text
Ilya
```

Такой подход часто встречается при работе с **JSON и API**.

---

# ✨ Dictionary Comprehension

Словарь можно создавать через comprehension:

```python
squares = {
    x: x ** 2
    for x in range(5)
}
```

Получим:

```python
{
    0: 0,
    1: 1,
    2: 4,
    3: 9,
    4: 16
}
```

Можно использовать условие:

```python
even = {
    x: x ** 2
    for x in range(10)
    if x % 2 == 0
}
```

---

# 🔀 Объединение словарей

Python позволяет объединять словари через `|`:

```python
a = {"name": "Ilya"}
b = {"age": 31}

result = a | b
```

Получим:

```python
{
    "name": "Ilya",
    "age": 31
}
```

Также можно обновить существующий словарь через `|=`:

```python
a |= b
```

Если ключи совпадают, значение из правого словаря заменяет значение слева.

---

# 📋 Копирование

```python
user_copy = user.copy()
```

Создаётся **поверхностная копия (`shallow copy`)**.

Это важно, если внутри есть изменяемые объекты:

```python
user = {
    "name": "Ilya",
    "skills": ["Python"]
}

copy = user.copy()

copy["skills"].append("Django")
```

Список `skills` изменится и в исходном словаре, потому что обе копии содержат ссылку на один вложенный список.

Для глубокой копии:

```python
import copy

deep_copy = copy.deepcopy(user)
```

# 📊 Основные методы `dict`

| Метод          | Назначение                            |
| -------------- | ------------------------------------- |
| `get()`        | получить значение безопасно           |
| `keys()`       | получить представление ключей         |
| `values()`     | получить представление значений       |
| `items()`      | получить представление пар            |
| `pop()`        | удалить элемент и вернуть значение    |
| `popitem()`    | удалить последнюю пару                |
| `update()`     | добавить/обновить несколько элементов |
| `clear()`      | очистить словарь                      |
| `copy()`       | поверхностная копия                   |
| `setdefault()` | получить значение или создать ключ    |

---

# ⚙️ `setdefault()`

Иногда используется для создания значения, если ключ отсутствует:

```python
data = {}

data.setdefault("users", []).append("Ilya")
```

Получим:

```python
{
    "users": ["Ilya"]
}
```

Если `"users"` уже существует, его значение просто возвращается.

---

# 🆚 `dict` vs `set`

Оба используют хеширование:

```text
dict → ключ → значение
set  → только уникальные элементы
```

Например:

```python
user = {
    "name": "Ilya",
    "age": 31
}
```

и:

```python
numbers = {1, 2, 3}
```

`dict` хранит **пары**, `set` — **уникальные значения**.

# 🧠 Шпаргалка

```text
dict
 ↓
изменяемая коллекция
 ↓
key → value
 ↓
key должен быть hashable
value может быть практически любым объектом
 ↓
ключи уникальны
 ↓
сохраняется порядок вставки
 ↓
быстрый доступ по ключу — O(1) average
```

### Запомнить главное:

> **`dict` — это изменяемая хеш-таблица, которая хранит пары «ключ–значение». Ключи уникальны и должны быть hashable, значения могут быть произвольными объектами.**
