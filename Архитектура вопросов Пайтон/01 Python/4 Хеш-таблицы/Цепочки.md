# Цепочки (chaining) в хеш-таблицах

## 🎯 Что сказать на собеседовании

> **Цепочки — другой способ разрешения коллизий. Вместо поиска другой позиции несколько элементов с конфликтующими хешами хранятся в одной позиции, например в связанном списке или другой структуре.**

---

## 📌 Упрощённый пример

Два ключа попали в одну позицию:

```text
hash(A) → 3
hash(B) → 3
```

При chaining:

```text
позиция 3
   ↓
[A] → [B] → [C]
```

Все конфликтующие элементы образуют **цепочку**.

---

# 🆚 Chaining vs Open Addressing

|                             | Открытая адресация    | Цепочки                  |
| --------------------------- | --------------------- | ------------------------ |
| Где хранятся элементы       | В самой таблице       | В структурах при ячейках |
| Коллизия                    | Ищется другая позиция | Добавляется в цепочку    |
| Дополнительные структуры    | Обычно не нужны       | Обычно нужны             |
| Используется CPython `dict` | ✅                     | ❌                        |

---

## 🧠 Главное

```text
Open Addressing:
A → позиция 3
B → позиция 4

Chaining:
позиция 3 → A → B
```

> **CPython `dict` использует открытую адресацию, а не chaining.**
