# Коллизии в хеш-таблице

## 🎯 Что сказать на собеседовании

> **Коллизия возникает, когда разные ключи приводят к одной и той же позиции в хеш-таблице. Хеш-функция не гарантирует уникальную позицию для каждого ключа, поэтому Python должен уметь разрешать коллизии.**

---

## 📌 Пример

Условно:

```text
key_A
  ↓
hash
  ↓
позиция 5


key_B
  ↓
hash
  ↓
позиция 5
```

Обе записи хотят попасть в одну позицию.

Это **коллизия**.

---

## 🧠 Важно

Коллизия **не означает**, что:

```python
hash(key_A) == hash(key_B)
```

обязательно означает:

```python
key_A == key_B
```

Наоборот, разные объекты могут иметь одинаковый хеш.

Поэтому Python при поиске проверяет не только хеш, но и сам ключ на равенство.

> **Одинаковый хеш ≠ одинаковый объект.**

---

## 📊 Влияние на сложность

При небольшом количестве коллизий:

```text
поиск → O(1) average
```

При очень большом количестве коллизий теоретически:

```text
поиск → O(n) worst case
```
