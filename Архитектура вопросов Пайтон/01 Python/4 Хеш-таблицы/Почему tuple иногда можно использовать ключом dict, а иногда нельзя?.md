# Tuple как ключ dict — Hashable Tuple

## Коротко

`tuple` является неизменяемым, но **не каждый `tuple` является хешируемым**.

Кортеж можно использовать как ключ `dict`, если **все его элементы являются хешируемыми**.

## На собеседовании достаточно сказать

> `tuple` может быть ключом `dict`, если все его элементы хешируемые. Сам `tuple` неизменяемый, но если внутри него находится нехешируемый объект, например `list`, то весь `tuple` тоже становится нехешируемым.

## Что важно помнить

Простой кортеж из хешируемых объектов можно использовать как ключ:

```python
point = (10, 20)

data = {
    point: "Точка"
}
```

Здесь int является хешируемым, поэтому весь tuple тоже хешируемый.

Но если внутри находится list:

```python
point = ([10, 20], 30)

data = {
    point: "Точка"
}
```

получим:

```
TypeError: unhashable type: 'list'
```

Причина:

```
tuple
 ↓
([10, 20], 30)
 ↓
есть list
 ↓
list — unhashable
 ↓
tuple — unhashable
```

## Простой пример

Работает:

```python
data = {
    (10, 20): "point"
}

print(data[(10, 20)])
# point
```

Не работает:

```python
data = {
    ([10, 20], 30): "point"
}

# TypeError: unhashable type: 'list'
```

## Главное

Важно не запоминать правило:

«Все tuple можно использовать как ключи».

Правильное правило:

```
tuple
  ↓
все элементы hashable?
  ├── Да → tuple hashable → можно использовать как ключ
  └── Нет → tuple unhashable → нельзя использовать как ключ
```

Например:

```
(1, 2, 3)           → hashable
("Python", 10)      → hashable
(1, (2, 3))         → hashable
(1, [2, 3])         → unhashable
```
