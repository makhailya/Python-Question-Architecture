# Разрешение коллизий — Collision Resolution

## Коротко

Если разные ключи получают одинаковый хеш, возникает **коллизия**.

Хеш-таблица должна определить, где хранить эти элементы.

Один из распространённых подходов — **открытая адресация (open addressing)**: при занятой позиции ищется другая свободная позиция.

## На собеседовании достаточно сказать

> Коллизия возникает, когда разные ключи имеют одинаковый хеш. Для её разрешения хеш-таблица может использовать открытое адресование и искать другую свободную позицию по определённой последовательности.
>
> Например, при линейном пробировании проверяется следующая позиция, пока не будет найдена подходящая.

## Что важно помнить

Представим таблицу:

```text
Индекс:

0
1
2  ← hash(key) указывает сюда
3
4
```

Но позиция 2 уже занята:

```
key A → hash → 2
key B → hash → 2
```

Возникает коллизия.

При линейном пробировании (linear probing) можно проверить следующую позицию:

```
2 → 3 → 4 → ...
```

Если 3 свободна, новый элемент помещается туда.

Упрощённо:

```
key A → 2
key B → 2 → занято → 3
key C → 2 → занято → 3 → занято → 4
```

## Простой пример

Представим небольшую таблицу:

```
Индекс    Значение
  0          -
  1          -
  2        key A
  3          -
  4          -
```

Для key B хеш также указывает на 2.

При линейном пробировании:

```
2 → занято
3 → свободно
```

Поэтому:

```
Индекс    Значение
  0          -
  1          -
  2        key A
  3        key B
  4          -
```

## Главное

Есть разные стратегии разрешения коллизий.

## Открытая адресация

Элемент ищет другую позицию внутри самой таблицы.

Основные варианты:

* линейное пробирование;
* квадратичное пробирование;
* двойное хеширование.

## Цепочки

Другой подход — хранить несколько элементов, соответствующих одной позиции, в отдельной структуре:

```
hash
 ↓
[ key A → key B → key C ]
```

Это называется цепочками (separate chaining).

Важно: конкретная реализация dict в Python имеет свои особенности и не сводится просто к классическому примеру «список цепочек». На собеседовании лучше не утверждать, что Python dict использует именно такой механизм без уточнения.
