# Таблица индексов в `dict`

## 🎯 Что сказать на собеседовании

> **Таблица индексов — это структура внутри реализации [[dict]]
>  в CPython, которая связывает позиции хеш-таблицы с записями ([[Таблица entries]]). Она помогает быстро определить, где находится нужная запись по хешу ключа.**

---

## 📌 Упрощённо

```text
hash(key)
   ↓
таблица индексов
   ↓
index → entry
   ↓
ключ + значение
```

Например:

```text
Индексы:

[  -1,   2,   0,  -1,   1 ]

                ↓
             entries

[ key_A, value_A ]
[ key_B, value_B ]
[ key_C, value_C ]
```

`-1` условно означает пустую позицию.

---

## 🧠 Зачем она нужна?

Она позволяет отделить:

* **поиск позиции** → таблица индексов;
* **хранение данных** → таблица entries.

Это является частью компактной реализации `dict` в CPython.

> **Таблица индексов отвечает: «где искать?»
> `entries` отвечают: «что там хранится?»**
