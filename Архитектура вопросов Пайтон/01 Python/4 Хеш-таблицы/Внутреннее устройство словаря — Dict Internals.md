# Внутреннее устройство словаря — Dict Internals

## Коротко

`dict` внутри реализован на основе **хеш-таблицы (hash table)**.

При добавлении пары `ключ → значение` Python вычисляет хеш ключа и использует его, чтобы определить, где хранить данные.

При поиске по ключу Python снова вычисляет его хеш и быстро находит нужную запись.

## На собеседовании достаточно сказать

> `dict` внутри реализован на основе хеш-таблицы. Для ключа вычисляется хеш, который используется для поиска позиции элемента. Благодаря этому получение, добавление и удаление элемента в среднем имеют сложность O(1).
>
> Если возникают коллизии, Python использует специальный механизм разрешения коллизий, поэтому несколько ключей с одинаковым хешем могут существовать в одном словаре.

## Что важно помнить

Упрощённо процесс выглядит так:

```text
ключ
 ↓
hash(key)
 ↓
определение позиции
 ↓
хранение пары ключ → значение
```

Например:

```python
user = {
    "name": "Ilya"
}
```

При обращении:

```python
user["name"]
```

Python использует ключ "name" и его хеш, чтобы найти соответствующую запись.

## Почему доступ быстрый?

Словарю не нужно последовательно проверять все элементы, как обычному списку при поиске значения.

В среднем:

```
Получение по ключу → O(1)
Добавление        → O(1)
Удаление          → O(1)
```

Но это средняя, а не гарантированная сложность для каждой отдельной операции.

## Что такое коллизия?

Коллизия возникает, когда разные ключи получают одинаковый хеш:

```
key A ──→ hash X
key B ──→ hash X
```

Python должен определить, как хранить и находить оба ключа.

Для этого используется механизм разрешения коллизий.

Важно: одинаковый хеш ещё не означает, что ключи одинаковые.

## Простой пример

```python
data = {
    "name": "Ilya",
    "age": 31
}

print(data["name"])
# Ilya
```

Упрощённо:

```
"name"
   ↓
hash("name")
   ↓
поиск позиции
   ↓
"Ilya"
```

## Главное

dict — это не просто набор пар ключ → значение.

В основе лежит хеш-таблица:

```
        dict
          ↓
    hash table
          ↓
      hash(key)
          ↓
       поиск
          ↓
    ключ → значение
```

Если два ключа имеют одинаковый хеш, возникает коллизия.
