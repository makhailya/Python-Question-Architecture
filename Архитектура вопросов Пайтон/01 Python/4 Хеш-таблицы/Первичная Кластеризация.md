# 🧩 Первичная кластеризация

## 🎤 Короткий ответ

**Первичная кластеризация (primary clustering)** — это проблема **[[Линейное пробирование]]**, при которой элементы с разными хешами постепенно объединяются в один длинный последовательный кластер занятых ячеек.

Чем больше становится такой кластер, тем больше ячеек приходится проверять при вставке и поиске.

> **Линейное пробирование → последовательные ячейки → кластеры → больше пробирований → снижение производительности.**

---

## 🎯 Формула для собеседования

```python
Коллизии
   ↓
линейное пробирование
   ↓
соседние ячейки заполняются
   ↓
образуется кластер
   ↓
кластер растёт
   ↓
поиск свободного места занимает больше времени
```

---

# 1. Что такое кластер

Кластер — это **последовательная группа занятых ячеек** в хеш-таблице.

Например:

```python
[ ] [X] [X] [X] [X] [ ] [ ] [ ] [ ]
```

Здесь:

```python
[X] [X] [X] [X]
```

— кластер.

При линейном пробировании новый элемент после коллизии ищет место:

```python
i → i+1 → i+2 → i+3 → ...
```

Поэтому свободные ячейки рядом постепенно заполняются.

---

# 2. Как возникает первичная кластеризация

Допустим, есть таблица:

```python
[ ] [ ] [ ] [ ] [ ] [ ] [ ] [ ] [ ] [ ]
```

Первый элемент получил индекс `3`:

```python
[ ] [ ] [ ] [A] [ ] [ ] [ ] [ ] [ ] [ ]
```

Следующий элемент тоже хешируется в `3`.

Возникает коллизия:

```python
3 → занят
4 → свободен
```

Получаем:

```python
[ ] [ ] [ ] [A] [B] [ ] [ ] [ ] [ ] [ ]
```

Следующий элемент снова попадает в `3`:

```python
3 → A
4 → B
5 → свободен
```

Получаем:

```python
[ ] [ ] [ ] [A] [B] [C] [ ] [ ] [ ] [ ]
```

И так кластер постепенно растёт:

```python
[ ] [ ] [ ] [A] [B] [C] [D] [E] [ ] [ ]
```

---

# 3. Почему это плохо

Представим:

```python
[ ] [A] [B] [C] [D] [E] [F] [ ] [ ]
```

Новый элемент хешируется в ячейку `1`.

Чтобы найти свободное место, нужно проверить:

```python
1 → A
2 → B
3 → C
4 → D
5 → E
6 → F
7 → свободно
```

Получается много проверок.

Поэтому:

```python
кластер ↑
   ↓
число пробирований ↑
   ↓
время операций ↑
```

---

# 4. Почему она называется «первичной»

**Первичная** — потому что проблема возникает непосредственно из-за того, что линейное пробирование использует **одинаковую последовательную последовательность ячеек**.

Если несколько ключей начинают пробирование с близких или одинаковых позиций, их последовательности пересекаются и объединяются в один кластер.

Например:

```python
Ключ A → 5 → 6 → 7
Ключ B → 6 → 7 → 8
Ключ C → 7 → 8 → 9
```

В результате:

```python
[ ] [ ] [ ] [ ] [ ] [A] [B] [C] [ ] [ ]
                         ↑
                    общий кластер
```

---

# 5. Связь с линейным пробированием

Это очень важная связка для собеседования:

```python
Линейное пробирование
        ↓
i + 1
i + 2
i + 3
        ↓
соседние ячейки
        ↓
последовательные блоки
        ↓
первичная кластеризация
```

Именно поэтому **первичная кластеризация является главным недостатком линейного пробирования**.

---

# 6. Связь с Load Factor

Первичная кластеризация особенно усиливается при увеличении **Load Factor**.

```python
Load Factor = N / M
```

где:

* `N` — количество элементов;
* `M` — количество ячеек.

Например:

```python
N = 8
M = 10

Load Factor = 0.8
```

Таблица заполнена на 80%.

Свободных ячеек мало:

```python
[ ] [X] [X] [X] [X] [X] [X] [X] [X] [ ]
```

Найти свободный слот становится сложнее.

Поэтому:

```python
Load Factor ↑
      ↓
кластеризация ↑
      ↓
пробирований ↑
      ↓
производительность ↓
```

---

# 7. Как уменьшают первичную кластеризацию

### Квадратичное пробирование

Вместо:

```python
i + 1
i + 2
i + 3
```

используется:

```python
i + 1²
i + 2²
i + 3²
```

То есть последовательность распределяется менее линейно.

---

### Двойное хеширование

Используется второй хеш:

```python
index = (hash1(key) + step * hash2(key)) % table_size
```

Разные ключи могут получать разные шаги пробирования.

Это ещё сильнее уменьшает тенденцию к образованию общих кластеров.

---

# 8. Первичная и вторичная кластеризация

|                 | Первичная кластеризация            | Вторичная кластеризация                    |
| --------------- | ---------------------------------- | ------------------------------------------ |
| Типично связана | Линейное пробирование              | Квадратичное пробирование                  |
| Причина         | Последовательные ячейки            | Одинаковая последовательность пробирования |
| Результат       | Большие непрерывные кластеры       | Ключи могут следовать одним маршрутом      |
| Решение         | Квадратичное / двойное хеширование | Двойное хеширование                        |

# 🧠 Главное

```python
Первичная кластеризация
=
образование длинных последовательных кластеров
из-за линейного пробирования.
```

Пример:

```python
[ ] [X] [X] [X] [X] [X] [ ] [ ] [ ]
      └─────────────┘
          кластер
```

Чем больше кластер:

```python
кластер ↑
   ↓
пробирований ↑
   ↓
O(1) в среднем становится менее эффективным
```

### 🎤 Идеальная формулировка на собеседовании

> **Первичная кластеризация — это эффект линейного пробирования, при котором занятые соседние ячейки объединяются в длинные кластеры. Из-за этого при последующих вставках и поиске приходится проверять всё больше ячеек, что ухудшает среднюю производительность хеш-таблицы.**
