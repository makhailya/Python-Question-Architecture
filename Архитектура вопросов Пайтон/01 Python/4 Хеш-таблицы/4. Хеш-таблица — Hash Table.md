# Хеш-таблица — Hash Table

## Коротко

**Хеш-таблица (hash table)** — это структура данных, которая позволяет хранить и быстро находить значения по ключу.

Для ключа вычисляется хеш, который используется для определения позиции, где хранится соответствующий элемент.

В среднем основные операции имеют сложность **O(1)**:

- поиск;
- добавление;
- удаление.

## На собеседовании достаточно сказать

> Хеш-таблица — это структура данных, которая использует хеш ключа для быстрого поиска элемента.
>
> Благодаря этому поиск, добавление и удаление в среднем выполняются за O(1).
>
> Если разные ключи получают одинаковый хеш, возникает коллизия, которую необходимо разрешать специальным механизмом.

## Что важно помнить

Упрощённо хеш-таблица работает так:

```text
ключ
 ↓
hash(key)
 ↓
определение позиции
 ↓
хранение значения
```

Например:

```python
key = "name"
```

Для ключа вычисляется хеш:

```python
hash(key)
```

Полученный хеш используется для определения позиции элемента в таблице.

При поиске Python снова получает хеш ключа и использует его для быстрого поиска.

## Коллизии

Иногда разные ключи могут иметь одинаковый хеш:

```
key A ──→ hash X
key B ──→ hash X
```

Это называется коллизией.

Хеш-таблица должна уметь разрешать такие ситуации.

Важно:

Одинаковый хеш не означает, что объекты равны.

## Простой пример

dict в Python использует хеш-таблицу:

```python
user = {
    "name": "Ilya",
    "age": 31
}

print(user["name"])
# Ilya
```

Когда мы выполняем:

```python
user["name"]
```

Python использует ключ "name" и его хеш, чтобы найти соответствующее значение.

## Главное

Хеш-таблица является основой для таких структур данных, как dict и set.

```
              Hash Table
              /        \
             ↓          ↓
           dict        set
             ↓
       ключ → значение
```

Поэтому понимание хеш-таблиц помогает понять, почему:

```python
user["name"]
```

работает в среднем за O(1), а поиск:

```python
"name" in ["name", "age", "city"]
```

в обычном списке имеет O(n) в худшем случае.
