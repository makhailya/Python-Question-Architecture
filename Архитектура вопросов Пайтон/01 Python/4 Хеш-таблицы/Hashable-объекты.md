# Hashable-объекты в Python

## 🎯 Что сказать на собеседовании

> **Hashable — это объект, у которого есть стабильное хеш-значение, получаемое через `hash()`.** Хешируемые объекты могут использоваться как ключи словаря и элементы `set`.
>
> Обычно hashable-объекты неизменяемы, потому что их хеш не должен изменяться в течение жизни объекта.

---

## 📌 Проверка

```python
hash("hello")
hash(123)
hash((1, 2))
```

Работает:

```text
str       → hashable
int       → hashable
tuple     → hashable*
frozenset → hashable
```

А:

```python
hash([1, 2])
```

даст:

```text
TypeError: unhashable type: 'list'
```

---

## ⚠️ Важный нюанс с `tuple`

`tuple` **не всегда** hashable.

```python
hash((1, 2))
```

✅ Работает.

Но:

```python
hash(([1, 2], 3))
```

❌ Не работает.

Причина — внутри `tuple` находится `list`, а `list` не hashable.

Поэтому правильнее говорить:

> **Tuple является hashable, если все его элементы hashable.**

---

## 🔑 Где используются hashable-объекты?

### Ключи `dict`

```python
data = {
    "name": "Ilya",
    (10, 20): "point"
}
```

### Элементы `set`

```python
items = {1, 2, 3}
```

Нельзя:

```python
items = {[1, 2], [3, 4]}
```

---

## 🧠 Главное

```text
hashable
    ↓
можно использовать как
    ↓
┌──────────────┐
│ dict key     │
│ set element  │
└──────────────┘
```

**Запомнить:**

> `hashable` → можно вызвать `hash()` → можно использовать ключом `dict` и элементом `set`.

Чаще всего hashable — это **неизменяемые объекты**.
