# Хеш-Функция — Hash Function

## Ответ для собеседования

Хеш-функция — это функция, которая преобразует объект или данные в числовое значение — хеш. В Python для этого используется встроенная функция hash(). Хеш нужен, например, для быстрого поиска ключей в dict и элементов в set. Для hashable-объектов хеш должен быть стабильным: если два объекта равны через, == их хеши должны совпадать.
