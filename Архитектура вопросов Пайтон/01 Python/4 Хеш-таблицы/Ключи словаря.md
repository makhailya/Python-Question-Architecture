# Ключи словаря в Python

## 🎯 Что сказать на собеседовании

> **Ключ словаря должен быть хешируемым объектом (`hashable`).** Поэтому в качестве ключей можно использовать, например, `int`, `str`, `tuple` из хешируемых элементов и `frozenset`, но нельзя использовать `list`, `dict` или `set`.

---

## 📌 Пример

```python
user = {
    "name": "Ilya",
    "age": 31,
    123: "value",
    (10, 20): "point"
}
```

Все эти ключи допустимы, потому что они хешируемые.

А так нельзя:

```python
data = {
    [1, 2]: "value"
}
```

```text
TypeError: unhashable type: 'list'
```

---

## 🔑 Почему ключ должен быть hashable?

`dict` использует **хеш-таблицу**.

Упрощённо:

```text
ключ
 ↓
hash(key)
 ↓
хеш-таблица
 ↓
значение
```

Благодаря этому словарь может очень быстро находить значение по ключу.

---

## 🧠 Главное

> **Ключ `dict` должен быть hashable.**

Типичные ключи:

```python
str
int
float
bool
tuple      # если элементы hashable
frozenset
```

Не подходят:

```python
list
dict
set
```
