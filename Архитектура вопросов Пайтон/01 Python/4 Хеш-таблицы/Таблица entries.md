# Таблица entries в `dict`

## 🎯 Что сказать на собеседовании

> **Таблица entries хранит сами записи словаря [[dict]]: ключ, его хеш и значение. Таблица индексов указывает, в какой entry находится нужная запись.**

---

## 📌 Упрощённо

Можно представить entry как:

```text
entry:
┌─────────┬─────────┬─────────┐
│  hash   │   key   │  value  │
└─────────┴─────────┴─────────┘
```

Например:

```python
user = {
    "name": "Ilya",
    "age": 31
}
```

Условно:

```text
entries:

0 → hash("name"), "name", "Ilya"
1 → hash("age"),  "age",  31
```

А таблица индексов хранит ссылки/индексы на эти entries.

---

## 🧠 Зачем это нужно?

Разделение позволяет:

* экономить память;
* эффективно хранить данные;
* сохранять порядок вставки;
* быстро находить элементы.

Именно поэтому современный `dict` в CPython называют **compact ordered hash table**.

> **`entries` — место, где лежат сами данные словаря.**
