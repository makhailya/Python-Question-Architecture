# Хешируемый объект — Hashable Object

## Коротко

**Хешируемый (hashable) объект** — это объект, для которого можно получить хеш с помощью `hash()` и который можно использовать, например, как ключ `dict` или элемент `set`.

Хешируемый объект должен иметь хеш, который не меняется в течение его жизни, и корректно поддерживать сравнение на равенство.

## На собеседовании достаточно сказать

> Хешируемый объект — это объект, для которого можно вычислить хеш через `hash()`. Такие объекты можно использовать как ключи словаря и элементы множества.
>
> Например, `int`, `str` и подходящий `tuple` являются хешируемыми, а `list`, `dict` и `set` — нет.

## Что важно помнить

Проверить, является ли объект хешируемым, можно с помощью:

```python
hash("Python")
# например, -123456789
```

У изменяемых объектов вроде list хеш получить нельзя:

```python
hash([1, 2, 3])
# TypeError: unhashable type: 'list'
```

Поэтому список нельзя использовать как ключ словаря:

```python
data = {
    [1, 2, 3]: "numbers"
}

# TypeError
```

А строку можно:

```python
data = {
    "name": "Ilya"
}
```

## Tuple

tuple может быть хешируемым:

```python
point = (10, 20)

hash(point)
```

Но это зависит от его элементов.

Например:

```python
point = (10, [20, 30])

hash(point)
# TypeError
```

Потому что внутри tuple находится list, который является нехешируемым.

## Простой пример

Хешируемые объекты:

```python
data = {
    "name": "Ilya",
    42: "answer",
    (10, 20): "point"
}
```

Нехешируемый объект:

```python
data = {
    [10, 20]: "point"
}

# TypeError: unhashable type: 'list'
```

Главное

Можно запомнить:

```
Hashable
   ↓
есть стабильный hash
   ↓
можно использовать как ключ dict
или элемент set
```

Примеры:

```
int       → hashable
str       → hashable
tuple     → hashable, если все элементы hashable
list      → unhashable
dict      → unhashable
set       → unhashable
```
