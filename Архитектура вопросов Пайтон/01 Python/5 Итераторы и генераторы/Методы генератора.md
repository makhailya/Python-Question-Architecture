# ⚙️ Методы генератора

🎯 **Ответ на собеседовании:**

Объект-генератор поддерживает методы:

* `__next__()` — получить следующее значение;
* `send()` — передать значение внутрь генератора;
* `throw()` — передать исключение внутрь генератора;
* `close()` — завершить генератор;
* `__iter__()` — вернуть самого себя как итератор.

---

## 1. `__next__()`

Получает следующее значение генератора.

```python
def numbers():
    yield 1
    yield 2

gen = numbers()

next(gen)  # 1
next(gen)  # 2
next(gen)  # StopIteration
```

`next(gen)` фактически вызывает:

```python
gen.__next__()
```

---

## 2. `send(value)`

Позволяет **передать значение внутрь генератора**.

Для этого генератор должен быть приостановлен на `yield`.

```python
def receiver():
    value = yield
    print(f"Получено: {value}")

gen = receiver()

next(gen)       # запускаем до yield
gen.send(42)    # передаём 42
```

Результат:

```text
Получено: 42
```

### Важный момент

Первый `send()` обычно должен быть:

```python
gen.send(None)
```

или проще:

```python
next(gen)
```

Потому что генератор сначала нужно довести до `yield`.

---

## 3. `throw(exception)`

Позволяет **выбросить исключение внутри генератора** в месте, где он остановился на `yield`.

```python
def generator():
    try:
        yield 1
    except ValueError:
        print("Получен ValueError")

gen = generator()

next(gen)              # 1
gen.throw(ValueError)
```

Результат:

```text
Получен ValueError
```

Это позволяет генератору самостоятельно обработать переданное исключение.

---

## 4. `close()`

Завершает генератор.

```python
def generator():
    try:
        yield 1
        yield 2
    finally:
        print("Очистка")

gen = generator()

next(gen)  # 1
gen.close()
```

При закрытии генератора внутри него возникает `GeneratorExit`.

Это позволяет выполнить очистку ресурсов через `finally`.

```python
def generator():
    try:
        yield 1
    finally:
        print("cleanup")
```

---

## 5. `__iter__()`

Генератор является итератором, поэтому:

```python
gen.__iter__() is gen
```

возвращает:

```text
True
```

Это позволяет использовать генератор в `for`:

```python
def numbers():
    yield 1
    yield 2

for number in numbers():
    print(number)
```

---

# `return` в генераторе

Генератор может завершиться через `return`:

```python
def generator():
    yield 1
    return 42
```

При завершении возникает `StopIteration`, а значение `42` становится:

```python
StopIteration.value
```

Например:

```python
gen = generator()

next(gen)  # 1

try:
    next(gen)
except StopIteration as e:
    print(e.value)
```

Результат:

```text
42
```

Это особенно связано с `yield from`.

# Сводная таблица

| Метод         | Назначение                      |
| ------------- | ------------------------------- |
| `__iter__()`  | Возвращает самого себя          |
| `__next__()`  | Получает следующее значение     |
| `send(value)` | Передаёт значение в генератор   |
| `throw(exc)`  | Передаёт исключение в генератор |
| `close()`     | Завершает генератор             |

---

## 🧠 Что достаточно знать Junior

Если спросят **«Какие методы есть у генератора?»**, хороший ответ:

> **Генератор является итератором и поддерживает `__iter__()` и `__next__()`. Дополнительно у генератора есть `send()` для передачи значений внутрь, `throw()` для передачи исключений и `close()` для завершения генератора.**

### Запомнить

```text
__next__() → получить значение
send()     → отправить значение
throw()    → отправить исключение
close()    → закрыть генератор
__iter__() → вернуть себя
```
