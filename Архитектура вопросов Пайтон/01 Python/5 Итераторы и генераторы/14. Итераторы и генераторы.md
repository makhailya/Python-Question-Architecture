Итератор — объект, реализующий:

	__iter__() — возвращает сам итератор (self);
	__next__() — возвращает следующее значение последовательности, в конце     — кидает исключение StopIteration.

Iterable vs Iterator — важный нюанс с собеса: список (list) сам по себе не является итератором, это iterable (объект с методом __iter__, но без __next__). Когда for берёт list, он сначала вызывает iter(list) — и получает новый объект-итератор. У кастомного же итератора __iter__ обычно возвращает self.

```python
class Counter:
    def __init__(self, limit):
        self.limit = limit
        self.current = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.current >= self.limit:
            raise StopIteration
        self.current += 1
        return self.current

for num in Counter(3):
    print(num)  # 1, 2, 3
```

Генератор — частный случай итератора, использующий ленивую отгрузку (lazy evaluation): значения не хранятся все сразу в памяти, а вычисляются по требованию (через next()).

# Два способа задать генератор:

```python
def gen_func():          # генераторная функция
    yield 1
    yield 2
    yield 3

gen_expr = (x**2 for x in range(3))  # генераторное выражение
```

По генератору/итератору можно пройти только один раз (если не обернуть логику в while True, чтобы создавать бесконечный цикл выдачи значений внутри). Чтобы «пройти заново» — нужно создать новый объект.

# Дополнительные методы генератора (помимо next()):

1. send(value) — отправить значение внутрь генератора (продолжает выполнение с точки yield, значение становится результатом выражения yield);

2. throw(exc) — возбудить исключение внутри генератора, в точке, где он остановлен;

3. close() — закрыть генератор (внутри кидается GeneratorExit), позволяет освободить ресурсы (например, закрыть файл), если это предусмотрено внутри генератора через try/finally.
