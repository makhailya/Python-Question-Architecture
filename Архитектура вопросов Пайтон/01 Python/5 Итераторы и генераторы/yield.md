# ⚙️ `yield`

🎯 **Ответ на собеседовании:**

`yield` используется в **генераторных функциях**. Он возвращает значение, **приостанавливает выполнение функции и сохраняет её состояние**, чтобы при следующем `next()` продолжить выполнение с этого места.

```python
def numbers():
    yield 1
    yield 2
    yield 3
```

```python
gen = numbers()

next(gen)  # 1
next(gen)  # 2
next(gen)  # 3
```

---

## `yield` vs `return`

| `return`                                | `yield`                               |
| --------------------------------------- | ------------------------------------- |
| Завершает функцию                       | Приостанавливает функцию              |
| Возвращает значение                     | Выдаёт значение                       |
| Состояние функции теряется              | Состояние сохраняется                 |
| Повторный вызов начинает функцию заново | `next()` продолжает с места остановки |
| Обычная функция                         | Генераторная функция                  |

Пример:

```python
def test():
    print("A")
    yield 1
    print("B")
    yield 2
    print("C")
```

```python
gen = test()

next(gen)
# A
# 1

next(gen)
# B
# 2

next(gen)
# C
# StopIteration
```

После каждого `yield` функция **останавливается**.

---

# Что происходит внутри

При вызове:

```python
gen = test()
```

тело функции ещё не выполняется.

При:

```python
next(gen)
```

выполнение начинается:

```text
test()
  ↓
print("A")
  ↓
yield 1
  ↓
пауза
```

Следующий:

```python
next(gen)
```

продолжает выполнение **после предыдущего `yield`**:

```text
yield 1
  ↓
print("B")
  ↓
yield 2
  ↓
пауза
```

# `yield` сохраняет состояние

Генератор помнит:

* где остановилось выполнение;
* значения локальных переменных;
* состояние цикла;
* состояние самого генератора.

Например:

```python
def counter():
    n = 0

    while n < 3:
        n += 1
        yield n
```

```python
gen = counter()

next(gen)  # 1
next(gen)  # 2
next(gen)  # 3
```

`n` не создаётся заново при каждом `next()`.

---

# `yield` и память 🧠

Главное практическое преимущество — **ленивые вычисления**.

Список:

```python
numbers = [x * 2 for x in range(1_000_000)]
```

сначала создаёт все элементы.

Генератор:

```python
numbers = (x * 2 for x in range(1_000_000))
```

вычисляет элементы по мере необходимости.

Это особенно полезно для:

* больших файлов;
* больших последовательностей;
* обработки данных;
* потоковой обработки;
* ETL;
* работы с большими объёмами данных.

# `yield` внутри цикла

Очень распространённый вариант:

```python
def even_numbers(numbers):
    for number in numbers:
        if number % 2 == 0:
            yield number
```

```python
for number in even_numbers(range(10)):
    print(number)
```

Получим:

```text
0
2
4
6
8
```

При этом все подходящие значения не создаются одновременно.

# `yield from`

`yield from` позволяет **делегировать итерацию другому iterable**.

Вместо:

```python
def numbers():
    for number in [1, 2, 3]:
        yield number
```

можно:

```python
def numbers():
    yield from [1, 2, 3]
```

Результат тот же:

```python
list(numbers())
# [1, 2, 3]
```

Особенно удобно для объединения генераторов:

```python
def first():
    yield 1
    yield 2

def second():
    yield 3
    yield 4

def all_numbers():
    yield from first()
    yield from second()
```

```python
list(all_numbers())
# [1, 2, 3, 4]
```

# `yield` может получать значение через `send()`

У генераторов есть более продвинутый механизм:

```python
value = yield result
```

Генератор может получать значение через:

```python
generator.send(value)
```

Например:

```python
def receiver():
    value = yield
    print(value)

gen = receiver()

next(gen)       # запускаем до yield
gen.send(42)    # передаём 42
```

Выведет:

```text
42
```

Для Junior-собеседования достаточно знать, что `yield` может взаимодействовать с `send()`. Детали обычно не требуются.

---

# `yield` и `StopIteration`

Когда генератор заканчивает выполнение:

```python
def numbers():
    yield 1
```

после:

```python
next(gen)  # 1
next(gen)  # StopIteration
```

Python автоматически сообщает, что значения закончились.

---

# Важный нюанс

Функция с `yield` **не возвращает обычное значение при вызове**:

```python
def numbers():
    yield 1
    yield 2

result = numbers()
```

`result` — это **объект-генератор**.

```python
type(result)
# <class 'generator'>
```

---

## 🧠 Коротко для собеседования

> **`yield` используется для создания генераторов. Он возвращает очередное значение, приостанавливает выполнение функции и сохраняет её состояние. При следующем вызове `next()` выполнение продолжается с места предыдущего `yield`. Благодаря этому генераторы реализуют ленивые вычисления и позволяют экономить память.**

### Главная формула

```text
yield
  ↓
выдать значение
  ↓
приостановить функцию
  ↓
сохранить состояние
  ↓
next()
  ↓
продолжить выполнение
  ↓
yield
  ↓
...
  ↓
StopIteration
```

**Самая важная фраза:**

> `yield` **не завершает функцию, а приостанавливает её до следующего `next()`**.
