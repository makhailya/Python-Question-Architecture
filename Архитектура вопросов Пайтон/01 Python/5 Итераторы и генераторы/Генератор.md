# ⚙️ Генератор

🎯 **Ответ на собеседовании:**

**Генератор** — это специальный вид **[[Итератор]]а**, который позволяет получать значения **лениво, по одному**, используя `yield`.

Генератор не создаёт все значения сразу, а вычисляет следующее значение только при необходимости.

```python id="r3l2ke"
def numbers():
    yield 1
    yield 2
    yield 3
```

Вызов функции:

```python id="2v2p9x"
gen = numbers()
```

не выполняет тело функции полностью. Создаётся объект-генератор.

Значения получаются через `next()`:

```python id="n2qj2w"
next(gen)  # 1
next(gen)  # 2
next(gen)  # 3
next(gen)  # StopIteration
```

---

# `yield` vs `return`

### `return`

Завершает функцию:

```python id="9xqz7a"
def get_number():
    return 10
```

### `yield`

**Приостанавливает выполнение** функции и сохраняет её состояние:

```python id="d3m5z9"
def numbers():
    yield 1
    yield 2
```

После первого `next()`:

```text id="4l3q5p"
yield 1
   ↓
функция приостанавливается
   ↓
next()
   ↓
продолжает выполнение
   ↓
yield 2
```

Генератор помнит:

* локальные переменные;
* текущую позицию выполнения;
* состояние функции.

---

# Генератор — это Iterator

Генератор поддерживает протокол итератора:

```python id="5qz8a1"
gen = numbers()

iter(gen) is gen
# True
```

И:

```python id="6a0r2s"
next(gen)
```

работает.

Поэтому:

> **Генератор является Iterator, а значит, одновременно является Iterable.**

Связка:

```text id="e8d1f4"
Generator
    ↓
Iterator
    ↓
Iterable
```

---

# Генератор и `for`

Генераторы особенно часто используются с `for`:

```python id="5j5l8d"
def numbers():
    for i in range(3):
        yield i


for number in numbers():
    print(number)
```

Получим:

```text id="6z0t8x"
0
1
2
```

`for` вызывает `next()` до тех пор, пока генератор не завершится и не возникнет `StopIteration`.

---

# Ленивые вычисления

Главное преимущество генераторов — **ленивость (lazy evaluation)**.

Например:

```python id="n9m5vy"
def numbers():
    for i in range(1_000_000):
        yield i
```

При создании:

```python id="m3d4n8"
gen = numbers()
```

миллион значений не создаётся сразу.

Значение вычисляется при:

```python id="j8f2qa"
next(gen)
```

Это позволяет работать с большими объёмами данных без необходимости хранить весь результат в памяти.

---

# Генераторное выражение

Генератор можно создать без отдельной функции:

```python id="r8c2mz"
gen = (x * 2 for x in range(10))
```

Это похоже на list comprehension:

```python id="1q4w7v"
numbers = [x * 2 for x in range(10)]
```

Но есть важная разница:

```text id="x8v0z1"
[x * 2 for x in range(10)]
        ↓
список → значения созданы сразу

(x * 2 for x in range(10))
        ↓
генератор → значения вычисляются по запросу
```

# Генераторная функция

Функция становится генераторной, если содержит `yield`:

```python id="7x4b3n"
def count():
    yield 1
    yield 2
```

Но вызов:

```python id="p9d2h7"
count()
```

возвращает **генератор**, а не обычный результат функции.

---

# Генератор можно использовать один раз

Как и другие итераторы, генератор хранит своё состояние:

```python id="2z6k1p"
gen = (x for x in range(3))

list(gen)
# [0, 1, 2]

list(gen)
# []
```

После исчерпания генератор не перематывается автоматически.

---

# `yield` может получать значение

Генераторы могут не только выдавать значения, но и получать их через `send()`:

```python id="q7n3kf"
def generator():
    value = yield 1
    print(value)
```

Это более продвинутая возможность генераторов и обычно не является обязательной для Junior Backend.

---

# Генератор vs список

|                                     | Генератор          | Список    |
| ----------------------------------- | ------------------ | --------- |
| Вычисление                          | Ленивое            | Сразу     |
| Память                              | Обычно меньше      | Больше    |
| `next()`                            | ✅                  | ❌         |
| Повторный обход                     | ❌ после исчерпания | ✅         |
| Индексация                          | ❌                  | ✅         |
| Подходит для больших потоков данных | ✅                  | Не всегда |

Например, для обработки большого файла:

```python id="6s9w4k"
def read_lines(file):
    for line in file:
        yield line
```

Можно обрабатывать строки по одной, не загружая весь файл в память.

# Генератор vs обычный Iterator

Генератор — это **готовая реализация механизма итератора**.

Собственный Iterator приходится писать вручную:

```python id="3p5w8x"
class Counter:
    def __iter__(self):
        return self

    def __next__(self):
        ...
```

С генератором достаточно:

```python id="8v6q2m"
def counter():
    for i in range(10):
        yield i
```

Python сам управляет состоянием генератора и реализацией `__next__`.

## 🧠 Коротко для собеседования

> **Генератор — это специальный итератор, создаваемый генераторной функцией с `yield` или генераторным выражением. Он вычисляет значения лениво, по одному, сохраняет своё состояние между вызовами и после завершения сообщает об окончании через `StopIteration`.**

### Главная цепочка

```text id="w7s3k2"
yield
  ↓
Generator
  ↓
Iterator
  ↓
next()
  ↓
следующее значение
  ↓
...
  ↓
StopIteration
```

### Самое важное:

**`yield` → приостанавливает функцию и возвращает значение, `next()` → продолжает выполнение с этого места.**
