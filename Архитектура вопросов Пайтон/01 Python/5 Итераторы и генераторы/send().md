# 📤 `send()`

🎯 **Ответ на собеседовании:**

`send(value)` — метод генератора, который позволяет **передать значение внутрь приостановленного генератора**.

Полученное значение можно получить в выражении `yield`:

```python
value = yield
```

---

## Простой пример

```python
def receiver():
    value = yield
    print(value)

gen = receiver()

next(gen)       # запускаем генератор до yield
gen.send(42)    # передаём значение
```

Результат:

```text
42
```

### Что происходит

```text
next(gen)
    ↓
yield
    ↓
генератор приостановлен
    ↓
send(42)
    ↓
yield получает 42
    ↓
value = 42
    ↓
print(42)
```

---

# `send()` возвращает значение

`send()` не только передаёт значение **внутрь**, но и возвращает следующее значение, которое выдаёт генератор.

```python
def generator():
    value = yield 10
    yield value * 2
```

```python
gen = generator()

print(next(gen))     # 10
print(gen.send(5))   # 10
```

Здесь:

```text
next(gen) → 10
send(5)   → передаёт 5 в первый yield
          → следующий yield выдаёт 10
```

---

# Почему сначала нужен `next()`?

Нельзя передать ненулевое значение через `send()` генератору, который ещё не запущен:

```python
gen = generator()

gen.send(42)
```

❌ Возникнет:

```text
TypeError
```

Сначала нужно запустить генератор:

```python
next(gen)
```

или:

```python
gen.send(None)
```

После этого он будет находиться на `yield`, и можно передавать значения.

---

# `send(None)`

`send(None)` эквивалентен обычному продвижению генератора:

```python
gen.send(None)
```

По сути, используется как:

```python
next(gen)
```

Поэтому часто генератор запускают:

```python
gen.send(None)
```

а затем уже:

```python
gen.send(value)
```

---

# Практический пример

Генератор может принимать данные и обрабатывать их:

```python
def accumulator():
    total = 0

    while True:
        value = yield total
        total += value
```

Использование:

```python
acc = accumulator()

next(acc)       # 0

print(acc.send(10))  # 10
print(acc.send(20))  # 30
print(acc.send(5))   # 35
```

Генератор сохраняет состояние `total` между вызовами.

```text
total = 0
   ↓
send(10)
   ↓
total = 10
   ↓
send(20)
   ↓
total = 30
   ↓
send(5)
   ↓
total = 35
```

---

# `send()` vs `next()`

|                              | `next()` | `send(value)`       |
| ---------------------------- | -------- | ------------------- |
| Продолжает генератор         | ✅        | ✅                   |
| Передаёт значение внутрь     | `None`   | Любое значение      |
| Получает значение от `yield` | ✅        | ✅                   |
| Может использоваться первым  | ✅        | Только `send(None)` |

---

## 🧠 Коротко для собеседования

> **`send(value)` позволяет передать значение внутрь приостановленного генератора. Это значение становится результатом выражения `yield`. При этом `send()` продолжает выполнение генератора и возвращает следующее значение, выданное генератором. Перед первым `send()` с ненулевым значением генератор нужно сначала запустить через `next()` или `send(None)`.**

### Запомнить

```text
yield
  ↓
генератор остановился
  ↓
send(42)
  ↓
yield → 42
  ↓
генератор продолжает работу
  ↓
следующий yield → результат send()
```
