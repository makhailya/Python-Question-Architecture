# 🔄 Итератор

🎯 **Ответ на собеседовании:**

**Итератор** — это объект, который позволяет **последовательно получать элементы** некоторого набора данных по одному.

Итератор реализует два метода:

```python
__iter__()
__next__()
```

* [[__iter__]]()` → возвращает сам итератор.
* [[__next__]]()` → возвращает следующий элемент.
* Когда элементы закончились, [[__next__]]()` выбрасывает `StopIteration`.

---

## Пример

```python
numbers = iter([10, 20, 30])

print(next(numbers))  # 10
print(next(numbers))  # 20
print(next(numbers))  # 30
print(next(numbers))  # StopIteration
```

`iter()` получает итератор из итерируемого объекта.

---

# Iterable vs Iterator

Это **не одно и то же**.

### Iterable — итерируемый объект

Объект, из которого можно получить итератор через:

```python
iter(obj)
```

Примеры:

```python
list
tuple
str
dict
set
range
```

Например:

```python
numbers = [1, 2, 3]

iterator = iter(numbers)
```

### Iterator — итератор

Объект, который непосредственно выдаёт элементы через:

```python
next(iterator)
```

Например:

```python
iterator = iter([1, 2, 3])

next(iterator)  # 1
next(iterator)  # 2
next(iterator)  # 3
```

---

## Почему список — не итератор?

```python
numbers = [1, 2, 3]

next(numbers)
```

❌ Ошибка:

```text
TypeError: 'list' object is not an iterator
```

Но список — **итерируемый объект**:

```python
iterator = iter(numbers)

next(iterator)  # 1
```

# Как работает `for`

Когда пишем:

```python
for number in numbers:
    print(number)
```

Python концептуально делает примерно следующее:

```python
iterator = iter(numbers)

while True:
    try:
        number = next(iterator)
        print(number)
    except StopIteration:
        break
```

То есть `for` работает через **протокол итератора**.

---

# Создание собственного итератора

Можно создать класс-итератор:

```python
class Counter:
    def __init__(self, limit):
        self.current = 0
        self.limit = limit

    def __iter__(self):
        return self

    def __next__(self):
        if self.current >= self.limit:
            raise StopIteration

        self.current += 1
        return self.current


counter = Counter(3)

for value in counter:
    print(value)
```

Результат:

```text
1
2
3
```

Здесь `Counter` является одновременно **iterable и iterator**.

# Почему `__iter__()` возвращает `self`?

У самого итератора уже есть состояние текущей позиции, поэтому:

```python
def __iter__(self):
    return self
```

Это стандартный паттерн для объектов-итераторов.

---

# Состояние итератора

Итератор **хранит текущее состояние обхода**.

```python
numbers = iter([10, 20, 30])

next(numbers)  # 10
next(numbers)  # 20
```

Итератор помнит, что `10` уже был возвращён.

Поэтому:

```python
numbers = [10, 20, 30]

it = iter(numbers)

list(it)  # [10, 20, 30]
list(it)  # []
```

Итератор **одноразовый**: после исчерпания его нельзя «перемотать» назад.

Чтобы начать сначала:

```python
it = iter(numbers)
```

---

# `iter()` и `next()`

### `iter()`

Получает итератор:

```python
it = iter([1, 2, 3])
```

### `next()`

Получает следующий элемент:

```python
next(it)
```

Если элементов больше нет:

```python
StopIteration
```

---

# Итератор и память 🧠

Итераторы позволяют обрабатывать данные **лениво**, не создавая сразу весь результат в памяти.

Например, вместо создания огромного списка можно выдавать элементы по одному.

Это особенно важно при работе с:

* большими файлами;
* базами данных;
* потоками данных;
* генераторами;
* большими последовательностями.

---

# Итератор vs генератор

**Генератор** — удобный способ создать итератор.

```python
def numbers():
    yield 1
    yield 2
    yield 3
```

```python
gen = numbers()

next(gen)  # 1
next(gen)  # 2
next(gen)  # 3
```

Генератор автоматически реализует необходимый протокол итератора.

---

## 🧠 Что запомнить

```text
Iterable
    ↓ iter()
Iterator
    ↓ next()
следующий элемент
    ↓
StopIteration
```

### Минимум для собеседования:

> **Итератор — объект, реализующий `__iter__()` и `__next__()`, который позволяет получать элементы последовательно. `__next__()` возвращает следующий элемент, а после окончания выбрасывает `StopIteration`. `for` использует этот протокол.**

**Ключевая разница:**

> **Iterable — из него можно получить итератор. Iterator — сам умеет выдавать следующий элемент через `next()`.**
