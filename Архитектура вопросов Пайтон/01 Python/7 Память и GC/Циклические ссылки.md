# Циклические ссылки

## 🎯 Ответ на собеседовании

> **Циклическая ссылка возникает, когда объекты прямо или косвенно ссылаются друг на друга, образуя цикл. Проблема в том, что их счётчики ссылок могут оставаться ненулевыми даже после того, как объекты стали недостижимыми из программы. Для обнаружения таких циклов в CPython используется циклический Garbage Collector.**

---

## 📌 Пример

```python
a = []
b = []

a.append(b)
b.append(a)
```

Получается:

```text
a ──→ b
↑     ↓
└─────┘
```

Теперь:

```python
del a
del b
```

Внешние имена удалены, но:

```text
a-объект → b-объект
    ↑         ↓
    └─────────┘
```

объекты продолжают ссылаться друг на друга.

---

## ❌ Почему Reference Counting не помогает?

Потому что условно:

```text
объект A → refcount = 1
объект B → refcount = 1
```

Каждый объект всё ещё имеет ссылку от другого объекта.

Поэтому счётчик не достигает `0`.

---

## ♻️ Что делает GC?

Циклический GC анализирует связи между объектами и может определить:

> «Эти объекты ссылаются друг на друга, но из работающей программы до них больше нельзя добраться».

После этого цикл может быть удалён.

---

## 🧠 Главное

```text
Reference Counting
       ↓
не обнаруживает циклы
       ↓
Cyclic GC
       ↓
находит недостижимые циклы
       ↓
освобождает объекты
```

> **Циклические ссылки — главная причина, почему одного Reference Counting недостаточно.**
