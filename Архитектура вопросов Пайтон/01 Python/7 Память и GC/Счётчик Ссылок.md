# Reference Counting — счётчик ссылок

## 🎯 Ответ на собеседовании

> **Reference Counting — механизм подсчёта ссылок на объект. В CPython у объекта есть счётчик ссылок. Когда он становится равен нулю, объект больше недостижим и обычно уничтожается немедленно.**

---

## 📌 Как это работает

```python
a = [1, 2, 3]
```

Условно:

```text
a ─────→ [1, 2, 3]

refcount = 1
```

Создаём ещё одну ссылку:

```python
b = a
```

Теперь:

```text
a ──┐
    ├──→ [1, 2, 3]
b ──┘

refcount = 2
```

Удаляем ссылки:

```python
del a
del b
```

Счётчик становится `0`.

```text
refcount = 0
       ↓
объект уничтожается
```

---

## 🔍 Посмотреть количество ссылок

Можно использовать:

```python
import sys

x = []
print(sys.getrefcount(x))
```

⚠️ `getrefcount()` сама временно создаёт дополнительную ссылку, поэтому значение обычно на единицу больше ожидаемого.

---

## ⚠️ Ограничение

Reference Counting не умеет самостоятельно корректно освобождать **циклические ссылки**.

Например:

```python
a = []
b = []

a.append(b)
b.append(a)
```

Даже если:

```python
del a
del b
```

объекты могут продолжать ссылаться друг на друга.

Для таких случаев нужен **циклический GC**.

---

## 🧠 Главное

```text
refcount == 0
       ↓
объект больше не нужен
       ↓
CPython обычно уничтожает его сразу
```

> **Reference Counting — основной механизм управления временем жизни объектов в CPython.**
