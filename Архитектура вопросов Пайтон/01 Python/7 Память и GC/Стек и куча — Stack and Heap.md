# Стек и куча — Stack and Heap

## Коротко

В контексте памяти программы часто выделяют:

- **Stack** — стек вызовов функций и локальных переменных/ссылок;
- **Heap** — область памяти, где находятся объекты Python.

В Python переменная обычно хранит не сам объект, а ссылку на объект.

## На собеседовании достаточно сказать

> В упрощённом представлении stack используется для стека вызовов функций и локального состояния, а объекты Python находятся в heap.
>
> Переменная хранит ссылку на объект, а сам объект размещается в памяти, управляемой Python.

## Что важно помнить

Например:

```python
x = [1, 2, 3]
```

Упрощённо можно представить:

```
Stack
  │
  │ x
  ↓
Heap
  │
  └── [1, 2, 3]
```

Переменная x ссылается на объект list.

Если создать ещё одну переменную:

```
y = x
```

получится:

```
Stack
  │
  ├── x ──┐
  │       ↓
  └── y ──→ [1, 2, 3]
             Heap
```

x и y ссылаются на один и тот же объект.

Поэтому:

```python
y.append(4)

print(x)
# [1, 2, 3, 4]
```

Изменился сам объект, поэтому изменение видно через обе ссылки.

## Простой пример

```python
def add_item(items):
    items.append(4)


numbers = [1, 2, 3]

add_item(numbers)

print(numbers)
# [1, 2, 3, 4]
```

Функция получает ссылку на существующий объект list.

## Главное

Важно не воспринимать модель stack/heap слишком буквально применительно к реализации CPython.

Для собеседования достаточно понимать основную идею:

```
Переменная
    ↓
ссылка
    ↓
Объект
    ↓
память, управляемая Python
```

Эта модель помогает понять:

* передачу аргументов;
* изменяемость объектов;
* ссылки на объекты;
* сборку мусора;
* подсчёт ссылок.
