# break, continue и pass

## Коротко

`break`, `continue` и `pass` управляют выполнением кода, но делают это по-разному:

- `break` — полностью завершает текущий цикл;
- `continue` — пропускает текущую итерацию и переходит к следующей;
- `pass` — ничего не делает и используется как пустая инструкция.

## На собеседовании достаточно сказать

> `break` полностью прерывает текущий цикл, `continue` пропускает текущую итерацию и переходит к следующей, а `pass` ничего не делает и обычно используется как заглушка, когда синтаксис требует наличия инструкции.

## Что важно помнить

### `break`

`break` полностью останавливает ближайший цикл.

```python
for number in range(10):
    if number == 5:
        break

    print(number)
```

Результат:

```text
0
1
2
3
4
```

Когда `number` становится `5`, цикл завершается.

Схема:

```text
итерация
   ↓
number == 5?
   ↓
  True
   ↓
 break
   ↓
выход из цикла
```

---

## `break` во вложенных циклах

`break` завершает только **ближайший цикл**, внутри которого он находится.

```python
for i in range(3):

    for j in range(3):

        if j == 1:
            break

        print(i, j)
```

Когда `j == 1`, завершается внутренний цикл.

Внешний цикл продолжает работу.

```text
внешний for
├── внутренний for
│     └── break → выход только из внутреннего
│
└── следующая итерация внешнего
```

---

## `continue`

`continue` не завершает цикл.

Он пропускает оставшуюся часть **текущей итерации** и переходит к следующей.

```python
for number in range(5):

    if number == 2:
        continue

    print(number)
```

Результат:

```text
0
1
3
4
```

При `number == 2`:

```python
continue
```

пропускает:

```python
print(number)
```

и цикл продолжает работу.

---

## `break` vs `continue`

```python
break
```

означает:

```text
закончить весь цикл
```

А:

```python
continue
```

означает:

```text
закончить только текущую итерацию
```

Сравнение:

```text
break
  ↓
выход из цикла


continue
  ↓
следующая итерация
```

---

## `pass`

`pass` — это инструкция, которая **ничего не делает**.

Например:

```python
if condition:
    pass
```

Код синтаксически корректен, но при выполнении ничего не происходит.

---

## Зачем нужен `pass`

Он часто используется как временная заглушка.

Например, мы хотим создать функцию, но пока не реализовали её:

```python
def process_data():
    pass
```

Python требует тело функции, поэтому вместо него можно поставить `pass`.

Позже:

```python
def process_data():
    # реализация
    ...
```

---

## `pass` не пропускает итерацию

Это важное отличие.

Например:

```python
for number in range(5):

    if number == 2:
        pass

    print(number)
```

Результат:

```text
0
1
2
3
4
```

`pass` ничего не изменил.

Если использовать `continue`:

```python
for number in range(5):

    if number == 2:
        continue

    print(number)
```

Результат:

```text
0
1
3
4
```

То есть:

```text
pass
→ ничего не делает

continue
→ пропускает остаток текущей итерации
```

---

## `pass` vs `...`

В Python можно встретить:

```python
pass
```

и:

```python
...
```

Оба варианта могут использоваться как заглушка:

```python
def function():
    pass
```

или:

```python
def function():
    ...
```

Но это разные конструкции.

`pass` — специальная пустая инструкция.

`...` — объект `Ellipsis`.

Для обычной пустой реализации функции чаще используют:

```python
pass
```

---

## `break` и `while`

`break` особенно часто используется для завершения бесконечного `while`:

```python
while True:
    command = input()

    if command == "exit":
        break
```

Цикл:

```python
while True:
```

сам по себе бесконечный.

`break` предоставляет способ выйти из него.

---

## `continue` и `while`

С `while` нужно быть внимательным.

Например:

```python
x = 0

while x < 5:

    if x == 2:
        continue

    print(x)
    x += 1
```

Такой код зациклится на `x == 2`.

Почему?

При `continue` выполнение сразу возвращается к проверке условия:

```text
x = 2
  ↓
continue
  ↓
проверка while
  ↓
x всё ещё 2
  ↓
continue
  ↓
...
```

Поэтому при использовании `continue` в `while` важно не забывать обновлять состояние цикла.

Например:

```python
x = 0

while x < 5:

    if x == 2:
        x += 1
        continue

    print(x)
    x += 1
```

Теперь цикл завершится нормально.

---

## `break` в поиске

Частый сценарий — найти первый подходящий элемент:

```python
numbers = [3, 8, 12, 14, 20]

for number in numbers:

    if number % 7 == 0:
        print(number)
        break
```

Результат:

```text
14
```

После нахождения нужного элемента дальнейший перебор не нужен.

---

## `continue` для фильтрации

Можно пропустить ненужные значения:

```python
numbers = [1, 2, 3, 4, 5]

for number in numbers:

    if number % 2 == 0:
        continue

    print(number)
```

Результат:

```text
1
3
5
```

Здесь `continue` пропускает чётные числа.

## Простой пример

```python
for number in range(10):

    if number == 3:
        continue

    if number == 7:
        break

    print(number)
```

Результат:

```text
0
1
2
4
5
6
```

Что произошло:

```text
0 → print
1 → print
2 → print
3 → continue
4 → print
5 → print
6 → print
7 → break
```
