# Переменные и присваивание — Variables and Assignment

## Коротко

В Python переменная — это **имя, связанное с объектом**.

Когда мы пишем:

```python
x = 10
```

Python связывает имя `x` с объектом `10`.

```text
x ───> 10
```

Оператор `=` выполняет **присваивание**, а не математическое равенство.

## На собеседовании достаточно сказать

> В Python переменная — это имя, связанное с объектом. Оператор `=` создаёт или изменяет связь имени с объектом. При присваивании объект не копируется: имя начинает ссылаться на существующий объект либо на новый объект, если он был создан в выражении.

## Что важно помнить

### `=` — это присваивание

```python
x = 10
```

Это означает:

> связать имя `x` с объектом `10`.

Это не означает:

```text
x равно 10
```

в математическом смысле.

Для сравнения используется:

```python
x == 10
```

---

## Переменная может ссылаться на объект другого типа

В Python переменная не имеет фиксированного типа.

Например:

```python
x = 10
```

Теперь:

```python
type(x)  # int
```

Можно сделать:

```python
x = "hello"
```

Теперь:

```python
type(x)  # str
```

А затем:

```python
x = [1, 2, 3]
```

Теперь:

```python
type(x)  # list
```

То есть тип относится прежде всего **к объекту**, а не к имени переменной.

```text
x ───> 10
       int

x ───> "hello"
       str

x ───> [1, 2, 3]
       list
```

---

## Одному объекту можно дать несколько имён

```python
a = [1, 2, 3]
b = a
```

Теперь:

```text
a ─────┐
       ├──> [1, 2, 3]
b ─────┘
```

Новый список не создаётся.

Проверка:

```python
a is b  # True
```

## Присваивание нового объекта

Рассмотрим:

```python
a = 10
b = a
```

Теперь:

```text
a ─────┐
       ├──> 10
b ─────┘
```

Если написать:

```python
b = 20
```

получим:

```text
a ───> 10

b ───> 20
```

Имя `b` просто перепривязалось к другому объекту.

`a` при этом не изменилось.

---

## Цепочка присваивания

Можно написать:

```python
a = b = c = 10
```

В результате все три имени связаны с объектом:

```text
a ─────┐
b ─────┼──> 10
c ─────┘
```

Это допустимый синтаксис Python.

---

## Множественное присваивание

Python позволяет присвоить несколько значений одновременно:

```python
a, b = 10, 20
```

Получаем:

```text
a ───> 10
b ───> 20
```

Это особенно удобно для обмена значениями.

Например:

```python
a = 10
b = 20

a, b = b, a
```

Теперь:

```text
a = 20
b = 10
```

Не нужен дополнительный временный объект:

```python
temp = a
a = b
b = temp
```

---

## Распаковка при присваивании

Множественное присваивание связано с распаковкой:

```python
numbers = [10, 20, 30]

a, b, c = numbers
```

Получаем:

```text
a = 10
b = 20
c = 30
```

Количество элементов должно соответствовать количеству переменных:

```python
a, b = [1, 2, 3]
```

даст ошибку:

```text
ValueError
```

Потому что переменных две, а значений три.

## Сокращённое присваивание

Python поддерживает операторы сокращённого присваивания:

```python
x += 1
x -= 1
x *= 2
x /= 2
```

Например:

```python
x = 10

x += 5
```

Результат:

```python
x == 15
```

Можно представить:

```python
x += 5
```

как:

```python
x = x + 5
```

Но для изменяемых объектов есть важный нюанс: конкретное поведение зависит от реализации операции объекта.

Например:

```python
items = [1, 2]

items += [3]
```

список изменяется.

Это отличается от простого присваивания новой ссылки:

```python
items = items + [3]
```

Вопрос о таких различиях связан с изменяемостью объектов.

## Присваивание и изменяемые объекты

Рассмотрим:

```python
a = [1, 2]
b = a
```

Теперь:

```python
b.append(3)
```

Изменится объект, на который ссылаются оба имени:

```text
a ─────┐
       ├──> [1, 2, 3]
b ─────┘
```

Но если:

```python
b = [10, 20]
```

то изменится только связь имени `b`:

```text
a ───> [1, 2, 3]

b ───> [10, 20]
```

Это принципиальное различие:

```text
изменение объекта
        ≠
перепривязывание имени
```

---

## Простое правило

Когда видишь:

```python
name = expression
```

можно мысленно читать:

> Вычислить выражение и связать имя `name` с получившимся объектом.

Например:

```python
x = 2 + 3
```

Python сначала вычисляет:

```text
2 + 3 → 5
```

а затем связывает:

```text
x ───> 5
```

---

## Простой пример

```python
x = 10

print(x)

x = "Python"

print(x)

x = [1, 2, 3]

print(x)
```

Результат:

```text
10
Python
[1, 2, 3]
```

Имя `x` последовательно связывалось с разными объектами:

```text
x ───> 10
      ↓
x ───> "Python"
      ↓
x ───> [1, 2, 3]
```

## Главное

Запомни:

```python
x = 10
```

`=` — это **присваивание**, а не сравнение.

```python
x == 10
```

`==` — это **сравнение значений**.

Переменная в Python:

```text
имя → объект
```

При присваивании:

```python
b = a
```

объект не копируется.

При новом присваивании:

```python
b = new_object
```

имя `b` перепривязывается.

Главная формула:

> **Переменная — это имя, присваивание — связывание имени с объектом.**
