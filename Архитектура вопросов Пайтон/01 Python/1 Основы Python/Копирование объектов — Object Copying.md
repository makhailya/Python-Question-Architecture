# Копирование объектов — Object Copying

## Коротко

В Python при присваивании объекта копируется не сам объект, а **ссылка на него**.

```python
a = [1, 2, 3]
b = a
```

Теперь `a` и `b` ссылаются на один и тот же список:

```text
a ─────┐
       ├──> [1, 2, 3]
b ─────┘
```

Если нужно создать отдельный объект, используют копирование.

Основные варианты:

- **поверхностная копия — `copy()`**
- **поверхностная копия — `copy.copy()`**
- **глубокая копия — `copy.deepcopy()`**

## На собеседовании достаточно сказать

> При обычном присваивании в Python объект не копируется — новая переменная получает ссылку на тот же объект. Для создания независимой копии можно использовать поверхностное или глубокое копирование. Поверхностная копия копирует сам внешний объект, но вложенные объекты остаются общими. Глубокая копия рекурсивно копирует и вложенные объекты.

## Что важно помнить

### Обычное присваивание — это не копирование

```python
a = [1, 2, 3]
b = a

b.append(4)

print(a)
print(b)
```

Результат:

```text
[1, 2, 3, 4]
[1, 2, 3, 4]
```

Почему?

Потому что `a` и `b` указывают на один объект:

```text
a ─────┐
       ├──> [1, 2, 3, 4]
b ─────┘
```

Проверить это можно через `is`:

```python
a is b  # True
```

---

## Поверхностная копия — Shallow Copy

Поверхностная копия создаёт **новый внешний объект**.

Например:

```python
a = [1, 2, 3]
b = a.copy()

print(a is b)  # False
```

Теперь:

```text
a ───> [1, 2, 3]

b ───> [1, 2, 3]
```

Это два разных списка.

Изменение самого списка `b` не изменит `a`:

```python
b.append(4)

print(a)  # [1, 2, 3]
print(b)  # [1, 2, 3, 4]
```

---

## Но с вложенными объектами есть нюанс

Рассмотрим:

```python
a = [[1, 2], [3, 4]]
b = a.copy()
```

Внешние списки разные:

```text
a ───────> [[1, 2], [3, 4]]

b ───────> [[1, 2], [3, 4]]
```

Но вложенные списки остаются общими:

```text
a ───> [  ───> [1, 2]
         └───> [3, 4]

b ───> [  ───> [1, 2]
         └───> [3, 4]
```

Поэтому:

```python
b[0].append(99)

print(a)
```

Получим:

```text
[[1, 2, 99], [3, 4]]
```

Хотя мы изменяли `b`.

Причина в том, что `b[0]` и `a[0]` — один и тот же вложенный объект.

```python
a[0] is b[0]  # True
```

---

## Глубокая копия — Deep Copy

Для полного копирования объекта вместе с вложенными объектами используется `deepcopy()`:

```python
from copy import deepcopy

a = [[1, 2], [3, 4]]
b = deepcopy(a)
```

Теперь вложенные списки тоже независимы:

```python
b[0].append(99)

print(a)
print(b)
```

Результат:

```text
[[1, 2], [3, 4]]
[[1, 2, 99], [3, 4]]
```

То есть:

```text
a ───> [ ───> [1, 2]
         └───> [3, 4] ]

b ───> [ ───> [1, 2, 99]
         └───> [3, 4] ]
```

---

## `copy()` и `deepcopy()`

| Способ | Внешний объект | Вложенные объекты |
|---|---|---|
| `b = a` | общий | общие |
| `b = a.copy()` | новый | общие |
| `copy.copy(a)` | новый | общие |
| `copy.deepcopy(a)` | новый | новые |

Главное различие:

```text
Shallow Copy
→ копируем внешний объект

Deep Copy
→ копируем объект и вложенные объекты
```

---

## Простой пример

```python
from copy import deepcopy

a = [[1, 2], [3, 4]]

b = a.copy()
c = deepcopy(a)

b[0].append(5)
c[1].append(6)

print(a)
print(b)
print(c)
```

Результат:

```text
[[1, 2, 5], [3, 4]]
[[1, 2, 5], [3, 4]]
[[1, 2], [3, 4, 6]]
```

Почему `a` изменился после изменения `b`?

Потому что `a` и `b` имеют общий вложенный список:

```python
a[0] is b[0]  # True
```

А `c` был создан через `deepcopy()`, поэтому его вложенные объекты независимы:

```python
a[1] is c[1]  # False
```

---

## Главное

Нужно различать три ситуации:

### 1. Присваивание

```python
b = a
```

Новый объект **не создаётся**.

### 2. Поверхностная копия

```python
b = a.copy()
```

Создаётся новый внешний объект, но вложенные объекты могут быть общими.

### 3. Глубокая копия

```python
b = deepcopy(a)
```

Создаётся независимая копия объекта вместе с вложенными объектами.

Формула для собеседования:

> `b = a` → одна ссылка на объект  
> `b = a.copy()` → новый внешний объект  
> `b = deepcopy(a)` → независимая копия всей структуры
