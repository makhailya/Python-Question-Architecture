# Передача изменяемого объекта — Passing Mutable Objects

## Коротко

Если передать в функцию изменяемый объект (`list`, `dict`, `set` и т. д.), функция получает ссылку на тот же объект.

Поэтому изменение этого объекта внутри функции будет видно после выхода из функции.

## Что важно помнить

Параметр функции и исходная переменная могут быть разными именами, но они могут ссылаться на **один и тот же объект**.

```python
def add_item(items):
    items.append(4)


numbers = [1, 2, 3]

add_item(numbers)

print(numbers)
# [1, 2, 3, 4]
```

Здесь:
```
numbers ──┐
          ├──> [1, 2, 3]
items ────┘
```

После items.append(4) изменяется сам список.

Важно отличать **изменение объекта от переприсваивания переменной**:

```python
def change_list(items):
    items.append(4)   # изменяем объект
```

и:

```python
def replace_list(items):
    items = [10, 20]  # меняем объект, на который ссылается имя items
```

Во втором случае исходный список снаружи не изменится:

```python
numbers = [1, 2, 3]

replace_list(numbers)

print(numbers)
# [1, 2, 3]
```

## Простой пример

```python
def add_language(languages):
    languages.append("Python")


languages = ["SQL"]

add_language(languages)

print(languages)
# ["SQL", "Python"]
```

Функция изменила тот же объект list, на который ссылается languages.

## Главное

Запомни две ситуации:

```
items.append(4)
        ↓
изменяем существующий объект
        ↓
изменение видно снаружи
```

```
items = [10, 20]
        ↓
параметр начинает ссылаться на другой объект
        ↓
исходный объект не изменяется
```
