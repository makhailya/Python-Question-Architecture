# Равенство и идентичность — Equality vs Identity

## Коротко

В Python операторы `==` и `is` проверяют разные вещи:

- `==` проверяет **равенство значений**.
- `is` проверяет **идентичность объектов** — являются ли две переменные ссылками на один и тот же объект.

## На собеседовании достаточно сказать

> `==` сравнивает значения объектов, а `is` проверяет, являются ли переменные ссылками на один и тот же объект.

Например, два разных списка могут иметь одинаковое содержимое:

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True
print(a is b)  # False
```

## Что важно помнить

### `==` — равенство значений

`==` проверяет, равны ли объекты по значению.

```python
a = [1, 2, 3]
b = [1, 2, 3]

a == b  # True
```

Списки разные, но содержат одинаковые элементы.

### `is` — идентичность объектов

`is` проверяет, указывают ли две переменные на **один и тот же объект**.

```python
a = [1, 2, 3]
b = a

a is b  # True
```

Здесь `a` и `b` ссылаются на один список.

Можно представить это так:

```text
a ─────┐
       ├──> [1, 2, 3]
b ─────┘
```

### Два разных объекта с одинаковым значением

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True
print(a is b)  # False
```

Получается:

```text
a ───> [1, 2, 3]

b ───> [1, 2, 3]

      одинаковое значение
      разные объекты
```

## Когда `is` даёт `True`

Если две переменные ссылаются на один объект:

```python
a = [1, 2, 3]
b = a

print(a == b)  # True
print(a is b)  # True
```

Потому что здесь объект только один:

```text
a ─────┐
       ├──> [1, 2, 3]
b ─────┘
```

## `is` и `None`

Для проверки `None` принято использовать именно `is`:

```python
value = None

if value is None:
    print("Значение отсутствует")
```

А не:

```python
if value == None:
    ...
```

Правильный вариант:

```python
value is None
value is not None
```

## Простой пример

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)  # True
print(a is b)  # False

print(a == c)  # True
print(a is c)  # True
```

Результат:

```text
True
False
True
True
```

### Почему?

`a` и `b`:

```text
a ───> [1, 2]

b ───> [1, 2]
```

Содержимое одинаковое, но объекты разные.

`a` и `c`:

```text
a ─────┐
       ├──> [1, 2]
c ─────┘
```

Это один и тот же объект.

## Важное замечание

Не стоит использовать `is` для обычного сравнения значений:

```python
a is b
```

если тебе нужно проверить именно значение, используй:

```python
a == b
```

Особенно не стоит полагаться на то, что некоторые маленькие числа или строки могут иметь одинаковую идентичность из-за особенностей интернирования объектов.

Для сравнения значений:

```python
==
```

Для проверки идентичности:

```python
is
```

Для `None`:

```python
is None
is not None
```

## Главное

| Оператор | Что проверяет |
|---|---|
| `==` | Равенство значений |
| `is` | Идентичность объектов |
| `is None` | Является ли объект `None` |

Главная формула:

> **`==` → одинаковое значение**  
> **`is` → один и тот же объект**
