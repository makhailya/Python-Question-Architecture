# Условия — if / elif / else

## Коротко

Условия позволяют выполнять разные участки кода в зависимости от значения выражения.

Основной синтаксис:

```python
if условие:
    # код
```

Можно добавить дополнительные условия через `elif` и альтернативную ветку через `else`:

```python
if condition:
    ...
elif another_condition:
    ...
else:
    ...
```

Python выполняет **только одну подходящую ветку** в такой конструкции.

## На собеседовании достаточно сказать

> Условные конструкции `if`, `elif` и `else` позволяют выполнять код в зависимости от логического значения выражения. `if` проверяется первым, `elif` проверяет дополнительные условия, а `else` выполняется, если ни одно из предыдущих условий не подошло.

## Что важно помнить

### `if`

`if` проверяет условие.

```python
age = 20

if age >= 18:
    print("Совершеннолетний")
```

Поскольку:

```python
age >= 18
```

даёт `True`, код внутри `if` выполняется.

---

## `else`

`else` выполняется, если условие `if` оказалось ложным.

```python
age = 16

if age >= 18:
    print("Совершеннолетний")
else:
    print("Несовершеннолетний")
```

Результат:

```text
Несовершеннолетний
```

Схема:

```text
        условие
           │
       ┌───┴───┐
     True     False
       │         │
      if       else
```

---

## `elif`

`elif` используется для проверки дополнительных условий.

```python
age = 20

if age < 18:
    print("Несовершеннолетний")
elif age < 65:
    print("Взрослый")
else:
    print("Пенсионный возраст")
```

Python проверяет условия сверху вниз.

Для `age = 20`:

```text
age < 18  → False
age < 65  → True
```

Выполнится только:

```python
print("Взрослый")
```

---

## Проверка идёт сверху вниз

Рассмотрим:

```python
x = 10

if x > 0:
    print("Положительное")
elif x > 5:
    print("Больше пяти")
```

Результат:

```text
Положительное
```

Хотя `x > 5` тоже `True`.

Почему?

Потому что первое условие уже подошло:

```python
x > 0
```

После выполнения этой ветки Python не проверяет последующие `elif`.

Поэтому порядок условий имеет значение.

---

## Несколько `elif`

Можно использовать несколько дополнительных условий:

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")
```

Для `score = 85`:

```text
score >= 90 → False
score >= 80 → True
```

Результат:

```text
B
```

После первого подходящего условия остальные `elif` не проверяются.

---

## `else` необязателен

Можно использовать только `if`:

```python
age = 20

if age >= 18:
    print("Adult")
```

Можно использовать:

```python
if condition:
    ...
elif another_condition:
    ...
```

`else` добавлять необязательно.

---

## `elif` без `if` невозможен

Так нельзя:

```python
elif x > 10:
    print(x)
```

`elif` всегда должен относиться к предыдущему `if`.

Правильно:

```python
if x > 5:
    print("Больше пяти")
elif x > 10:
    print("Больше десяти")
```

Но в этом примере порядок условий неправильный с точки зрения логики: при `x = 20` сработает первое условие.

Лучше:

```python
if x > 10:
    print("Больше десяти")
elif x > 5:
    print("Больше пяти")
```

---

## Условие может быть любым выражением

Например:

```python
x = 10

if x == 10:
    print("Десять")
```

Можно использовать:

```python
if x > 5:
    ...

if x != 0:
    ...

if name == "Ilya":
    ...
```

Также можно использовать Truthy/Falsy:

```python
name = "Ilya"

if name:
    print("Имя указано")
```

Здесь строка `"Ilya"` является Truthy.

## Несколько условий

Можно объединять условия с помощью:

```python
and
or
not
```

### `and`

Оба условия должны быть истинными:

```python
age = 25
has_ticket = True

if age >= 18 and has_ticket:
    print("Можно войти")
```

---

### `or`

Достаточно одного истинного условия:

```python
is_admin = False
is_moderator = True

if is_admin or is_moderator:
    print("Есть доступ")
```

---

### `not`

Инвертирует логическое значение:

```python
is_blocked = False

if not is_blocked:
    print("Доступ разрешён")
```

---

## Вложенные условия

`if` можно помещать внутрь другого `if`:

```python
age = 25
has_ticket = True

if age >= 18:
    if has_ticket:
        print("Можно войти")
```

Но слишком глубокая вложенность ухудшает читаемость.

Часто лучше объединить условия:

```python
if age >= 18 and has_ticket:
    print("Можно войти")
```

## Условия и сравнение

В условиях часто используются операторы сравнения:

```python
==
!=
>
<
>=
<=
```

Например:

```python
x = 10

if x >= 10:
    print("x не меньше 10")
```

Для проверки идентичности объекта используется:

```python
is
```

Например:

```python
value = None

if value is None:
    print("Нет значения")
```

## Условия и присваивание

Важно не путать:

```python
=
```

и:

```python
==
```

`=` — присваивание:

```python
x = 10
```

`==` — сравнение:

```python
x == 10
```

В условии обычно используется именно сравнение:

```python
if x == 10:
    print("x равен 10")
```

## Простой пример

```python
temperature = 25

if temperature < 0:
    print("Мороз")
elif temperature < 15:
    print("Холодно")
elif temperature < 25:
    print("Прохладно")
else:
    print("Тепло")
```

Для:

```python
temperature = 25
```

проверки идут:

```text
25 < 0   → False
25 < 15  → False
25 < 25  → False
```

Поэтому выполняется `else`:

```text
Тепло
```

## Главное

Базовая конструкция:

```python
if condition:
    ...
elif another_condition:
    ...
else:
    ...
```

Правила:

```text
if
↓
проверяется первым

elif
↓
проверяются последовательно

else
↓
выполняется, если ничего выше не подошло
```

В конструкции `if / elif / else` выполняется **максимум одна ветка**.

Условие может быть:

```python
if x > 10:
    ...

if name:
    ...

if value is None:
    ...
```

Главная формула:

> **`if` — если условие истинно; `elif` — иначе проверить следующее; `else` — если ничего не подошло.**
