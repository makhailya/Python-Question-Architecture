# 🐼 Pandas

## 🎤 Короткий ответ

**Pandas** — библиотека Python для работы с табличными и структурированными данными.

Основные структуры данных — **`Series`** и **`DataFrame`**. С их помощью удобно загружать данные из CSV, Excel, JSON и SQL, фильтровать и сортировать строки, группировать данные, объединять таблицы, обрабатывать пропуски и выполнять статистический анализ.

Если NumPy в первую очередь работает с числовыми массивами, то Pandas предоставляет более высокоуровневую модель для работы именно с **табличными данными**.

## 🗣️ Ответ на собеседовании

Pandas — это библиотека Python для анализа и обработки структурированных данных, прежде всего табличных.

Основная структура — `DataFrame`, то есть таблица со строками и столбцами. Отдельный столбец обычно представлен как `Series`.

Pandas позволяет загружать данные из CSV, Excel, JSON и баз данных, фильтровать и сортировать записи, группировать их через `groupby`, объединять таблицы через `merge`, работать с пропусками и выполнять различные агрегации.

Pandas построен вокруг табличной модели данных и тесно связан с NumPy. Поэтому он особенно удобен для ETL, аналитики и подготовки данных для ML.

Для backend-разработчика Pandas полезен, например, при обработке выгрузок, банковских CSV/Excel-файлов, подготовке данных и реализации небольших ETL-процессов.

## 2. Series

**`Series`** — одномерная структура данных с индексом.

```python
import pandas as pd

prices = pd.Series([100, 200, 300])

print(prices)
```

Условно:

```text
0    100
1    200
2    300
```

Здесь:

```text
0, 1, 2 → index
100, 200, 300 → values
```

Можно задать собственный индекс:

```python
prices = pd.Series(
    [100, 200, 300],
    index=["apple", "banana", "orange"]
)
```

Теперь:

```text
apple     100
banana    200
orange    300
```

---

## 3. DataFrame

**`DataFrame`** — основная структура Pandas для табличных данных.

```python
df = pd.DataFrame({
    "name": ["Иван", "Анна", "Пётр"],
    "age": [25, 31, 28],
    "salary": [100000, 150000, 120000]
})
```

Получаем:

```text
    name  age  salary
0   Иван   25  100000
1   Анна   31  150000
2   Пётр   28  120000
```

У `DataFrame` есть:

- строки;
- столбцы;
- индекс;
- значения;
- типы данных столбцов.

---

## 4. Получение столбца

Один столбец:

```python
df["salary"]
```

вернёт `Series`.

Несколько столбцов:

```python
df[["name", "salary"]]
```

вернут `DataFrame`.

Это важное отличие:

```text
df["salary"]
    ↓
Series

df[["salary"]]
    ↓
DataFrame
```

Каждая строка `DataFrame` имеет индекс.

По умолчанию:


## 6. `loc` и `iloc`

Один из частых вопросов на собеседовании.

### `loc`

Работает преимущественно с **именами индексов и метками**.

```python
df.loc["Анна"]
```

### `iloc`

Работает с **позициями**:

```python
df.iloc[1]
```

Условно:

```text
loc  → label
iloc → position
```

Можно выбирать строки и столбцы:

```python
df.loc["Анна", "salary"]
```

или:

```python
df.iloc[1, 2]
```

## 7. Фильтрация

Например, получить сотрудников старше 28 лет:

```python
df[df["age"] > 28]
```

Можно использовать несколько условий:

```python
df[
    (df["age"] > 25) &
    (df["salary"] > 110000)
]
```

Важно: для условий над Series используются `&` и `|`, а каждое условие обычно заключается в скобки.

## 10. `groupby`

`groupby` используется для группировки данных и последующей агрегации.

Например:

```python
df.groupby("department")["salary"].mean()
```

Логика:

```text
1. Разделить данные по department
2. Для каждой группы взять salary
3. Посчитать среднее
```

Можно использовать несколько агрегатных функций:

```python
df.groupby("department")["salary"].agg(
    ["count", "mean", "min", "max"]
)
```

Это очень распространённый паттерн в аналитике и ETL.

---

## 11. Агрегации

Pandas предоставляет:

```python
df["salary"].mean()
df["salary"].sum()
df["salary"].min()
df["salary"].max()
df["salary"].count()
```

Например:

```python
average_salary = df["salary"].mean()
```

Получаем среднюю зарплату.

## 12. Пропущенные значения

Pandas использует специальные значения для представления отсутствующих данных, например `NaN` и `pd.NA` в зависимости от типа данных.

Проверка:

```python
df.isna()
```

Количество пропусков:

```python
df.isna().sum()
```

Удаление строк с пропусками:

```python
df.dropna()
```

Заполнение:

```python
df["age"] = df["age"].fillna(0)
```

Но выбор стратегии зависит от смысла данных. Просто заменять все пропуски на `0` обычно неправильно.

## 13. `merge`

`merge` используется для объединения таблиц по ключу.

Например:

```python
users = pd.DataFrame({
    "user_id": [1, 2, 3],
    "name": ["Иван", "Анна", "Пётр"]
})

orders = pd.DataFrame({
    "user_id": [1, 1, 2],
    "amount": [1000, 2000, 1500]
})
```

Объединение:

```python
result = users.merge(
    orders,
    on="user_id",
    how="left"
)
```

По смыслу это близко к `JOIN` в SQL.

---

## 14. `merge` и SQL JOIN

Соответствие примерно такое:

| Pandas | SQL |
|---|---|
| `merge(..., how="inner")` | `INNER JOIN` |
| `merge(..., how="left")` | `LEFT JOIN` |
| `merge(..., how="right")` | `RIGHT JOIN` |
| `merge(..., how="outer")` | `FULL OUTER JOIN` |

Например:

```python
users.merge(
    orders,
    on="user_id",
    how="inner"
)
```

аналогично:

```sql
SELECT *
FROM users
INNER JOIN orders
    ON users.user_id = orders.user_id;
```

## 17. Pandas и NumPy

Связь можно представить так:

```text
NumPy
│
└── ndarray
    └── эффективные численные массивы

Pandas
│
├── Series
│
└── DataFrame
    └── табличные данные
```

Pandas использует NumPy-подобную модель массивных операций и исторически тесно с ним связан.

Но задачи разные:

**NumPy:**

> «У меня есть массив чисел, нужно эффективно выполнить математические операции».

**Pandas:**

> «У меня есть таблица данных, нужно отфильтровать, сгруппировать, объединить и проанализировать её».

---

## 18. Pandas и SQL

Если ты работаешь с PostgreSQL, полезно видеть соответствия:

```text
SQL                    Pandas

SELECT                  фильтрация / выбор столбцов
WHERE                   boolean indexing
GROUP BY                groupby()
JOIN                    merge()
ORDER BY                sort_values()
COUNT / AVG / SUM       count() / mean() / sum()
```

Но это не означает, что Pandas является заменой SQL.

Например, если у тебя 50 миллионов строк в PostgreSQL, часто правильнее выполнить фильтрацию и агрегацию **в самой БД**, а не выгружать всё в Pandas.

## 19. Pandas в ETL

Для backend-разработчика особенно полезен такой сценарий:

```text
API / CSV / Excel
       ↓
    Pandas
       ↓
Очистка данных
       ↓
Преобразование
       ↓
Валидация
       ↓
PostgreSQL
```

Например:

```python
df = pd.read_csv("transactions.csv")

df = df.dropna(subset=["amount"])

df["amount"] = df["amount"].astype(float)

df = df[df["amount"] > 0]
```

После этого данные можно передать дальше в БД или другой сервис.

## 20. Почему не стоит делать всё через `apply`

Можно написать:

```python
df["result"] = df["amount"].apply(
    lambda x: x * 1.2
)
```

Но если операция уже поддерживается векторизованно:

```python
df["result"] = df["amount"] * 1.2
```

обычно предпочтительнее второй вариант.

Общее правило:

> **Сначала ищем векторизованную операцию Pandas/NumPy, а `apply` используем, когда действительно нужна пользовательская функция.**

---

## 21. Важный нюанс: Pandas не обязательно работает «в памяти бесконечно»

`DataFrame` обычно находится в оперативной памяти.

Если CSV занимает несколько гигабайт, нельзя автоматически считать, что:

```python
df = pd.read_csv("huge.csv")
```

будет хорошим решением.

Для больших данных используют, например:

- чтение чанками через `chunksize`;
- фильтрацию до загрузки;
- SQL/БД для предварительной обработки;
- специализированные инструменты для out-of-core обработки;
- более подходящие форматы данных.

Пример чтения чанками:

```python
for chunk in pd.read_csv(
    "huge.csv",
    chunksize=100_000
):
    process(chunk)
```

## 🎤 Вопросы на собеседовании

### Что такое Pandas?

Библиотека Python для обработки и анализа структурированных данных. Основные структуры — `Series` и `DataFrame`.

### Что такое DataFrame?

Двумерная табличная структура Pandas со строками, столбцами, индексом и значениями.

### Что такое Series?

Одномерная структура данных Pandas с индексом.

### Чем `loc` отличается от `iloc`?

`loc` выбирает данные преимущественно по меткам, а `iloc` — по числовым позициям.

### Что делает `groupby`?

Разбивает данные на группы по указанному признаку и позволяет выполнять агрегации над каждой группой.

### Чем `merge` похож на SQL?

`merge` объединяет `DataFrame` по ключу и концептуально соответствует SQL `JOIN`.

### Как найти пропуски?

```python
df.isna()
```

или:

```python
df.isna().sum()
```

### Как загрузить CSV?

```python
df = pd.read_csv("data.csv")
```

### Чем Pandas отличается от NumPy?

NumPy ориентирован прежде всего на эффективные численные массивы, а Pandas — на табличные и структурированные данные с индексами, столбцами, фильтрацией, группировками и объединениями.

### Можно ли считать Pandas заменой SQL?

Нет. Pandas удобен для обработки данных в приложении, но для больших объёмов часто выгоднее выполнить фильтрацию, JOIN и агрегации непосредственно в базе данных.
