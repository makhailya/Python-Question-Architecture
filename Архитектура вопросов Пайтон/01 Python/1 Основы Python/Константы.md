# Константы в Python

## 🎯 Что сказать на собеседовании

> **В Python нет настоящих констант на уровне языка.** Обычно используют переменные, записанные в `UPPER_CASE`, чтобы договориться с разработчиками: это значение не следует изменять.

---

## 📌 Пример

```python
PI = 3.14159
MAX_CONNECTIONS = 100
API_URL = "https://example.com"
```

Python технически позволяет изменить значение:

```python
MAX_CONNECTIONS = 200
```

Поэтому `UPPER_CASE` — это **соглашение**, а не запрет.

---

## 🧠 Главное

```text
UPPER_CASE → принято считать константой
```

> Python не запрещает изменение констант — разработчик должен соблюдать соглашение.
