# 🔢 NumPy

## 🎤 Короткий ответ

**NumPy** — основная библиотека Python для численных вычислений и работы с многомерными массивами.

Главный объект NumPy — **`ndarray`**. В отличие от обычного Python `list`, массив NumPy хранит элементы одного типа и размещает их в компактной памяти, благодаря чему операции над большими массивами выполняются значительно быстрее.

NumPy предоставляет векторизованные операции, broadcasting, математические функции, работу с матрицами, статистику и линейную алгебру. На его основе работают многие библиотеки, например Pandas и часть научного Python-стека.

## 🗣️ Ответ на собеседовании

NumPy — библиотека для эффективных численных вычислений в Python. Её основной объект — многомерный массив `ndarray`.

Главное отличие от обычного списка Python в том, что элементы `ndarray` обычно имеют один тип и хранятся компактнее. Благодаря этому NumPy может выполнять операции над целыми массивами внутри оптимизированного кода, вместо того чтобы выполнять Python-цикл для каждого элемента.

Например, вместо цикла можно написать `arr * 2`, и NumPy умножит все элементы массива. Это называется **векторизацией**.

Также NumPy поддерживает многомерные массивы, broadcasting, агрегации, математические функции и линейную алгебру.

В backend-разработке NumPy встречается реже, чем в Data Science, но он является фундаментом экосистемы Python для работы с числовыми данными и используется внутри других библиотек.

## 📚 Разбор поглубже

### 1. Что такое NumPy

NumPy расшифровывается как **Numerical Python**.

Установка:

```bash
pip install numpy
```

Импорт:

```python
import numpy as np
```

`np` — общепринятый псевдоним.

---

### 2. Основной объект — ndarray

Создадим массив:

```python
import numpy as np

arr = np.array([1, 2, 3, 4, 5])

print(arr)
# [1 2 3 4 5]
```

Проверим тип:

```python
print(type(arr))
# <class 'numpy.ndarray'>
```

`ndarray` означает **N-dimensional array** — многомерный массив.

Например, двумерный:

```python
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

Получаем:

```text
1 2 3
4 5 6
```

---

### 3. ndarray vs Python list

Обычный список:

```python
numbers = [1, 2, 3, 4]
```

NumPy:

```python
numbers = np.array([1, 2, 3, 4])
```

Основные различия:

| | `list` | `numpy.ndarray` |
|---|---|---|
| Тип элементов | может быть разный | обычно один `dtype` |
| Численные операции | через Python-код | векторизованные |
| Многомерные данные | вложенные списки | встроенная поддержка |
| Память | больше накладных расходов | компактнее для числовых данных |
| Скорость численных операций | обычно ниже | обычно выше |
| Гибкость | очень высокая | ориентирован на числовые данные |

### 4. dtype

NumPy хранит информацию о типе элементов через `dtype`.

```python
arr = np.array([1, 2, 3])

print(arr.dtype)
```

Например, это может быть целочисленный тип NumPy.

Можно явно задать тип:

```python
arr = np.array([1, 2, 3], dtype=np.float64)
```

Теперь элементы будут представлены как `float64`.

Это важно, потому что NumPy может заранее знать размер каждого элемента в памяти.

---

### 5. shape

`shape` показывает размерность массива по каждой оси.

```python
arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(arr.shape)
# (2, 3)
```

То есть:

```text
2 строки
3 столбца
```

Также есть:

```python
arr.ndim
```

Количество измерений:

```text
2
```

И:

```python
arr.size
```

Общее количество элементов:

```text
6
```

### 6. Векторизация

Одна из главных возможностей NumPy — выполнять операцию сразу над массивом.

Python:

```python
numbers = [1, 2, 3, 4]

result = [x * 2 for x in numbers]
```

NumPy:

```python
numbers = np.array([1, 2, 3, 4])

result = numbers * 2
```

Получим:

```text
[2 4 6 8]
```

Не нужно писать явный Python-цикл.

Именно это называют **векторизацией**.

---

### 7. Операции над массивами

Можно складывать массивы поэлементно:

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

print(a + b)
# [11 22 33]
```

Умножение:

```python
print(a * b)
# [10 40 90]
```

Возведение в квадрат:

```python
print(a ** 2)
# [1 4 9]
```

Это отличается от поведения обычных Python-списков.

```python
[1, 2, 3] * 2
```

даст:

```text
[1, 2, 3, 1, 2, 3]
```

а:

```python
np.array([1, 2, 3]) * 2
```

даст:

```text
[2, 4, 6]
```

### 8. Broadcasting

**Broadcasting** позволяет NumPy выполнять операции над массивами разных, но совместимых форм.

Например:

```python
arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

arr + 10
```

Получим:

```text
11 12 13
14 15 16
```

Число `10` как бы применяется ко всем элементам.

Более интересный пример:

```python
arr + np.array([10, 20, 30])
```

Получим:

```text
11 22 33
14 25 36
```

Массив `[10, 20, 30]` был применён к каждой строке.

### 9. Агрегации

NumPy предоставляет готовые математические операции:

```python
arr = np.array([1, 2, 3, 4, 5])

np.sum(arr)
np.mean(arr)
np.min(arr)
np.max(arr)
np.std(arr)
```

Например:

```python
np.sum(arr)
# 15

np.mean(arr)
# 3.0
```

Для многомерного массива можно указывать `axis`:

```python
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

matrix.sum(axis=0)
```

Результат:

```text
[5 7 9]
```

Здесь суммируются элементы по строкам, то есть получаем сумму каждого столбца.

### 10. Индексация и срезы

Работа похожа на списки:

```python
arr = np.array([10, 20, 30, 40])

arr[0]
# 10

arr[1:3]
# [20 30]
```

Но NumPy поддерживает многомерную индексацию:

```python
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

matrix[0, 1]
# 2
```

То есть:

```text
matrix[строка, столбец]
```

### 11. Boolean indexing

Можно выбирать элементы по условию:

```python
arr = np.array([1, 5, 10, 15, 20])

arr[arr > 10]
```

Результат:

```text
[15 20]
```

Это очень полезно при обработке больших массивов.

### 12. Почему NumPy быстрее Python-циклов

Важно не говорить на собеседовании:

> «NumPy просто быстрее Python».

Причина более конкретная.

Операции NumPy реализованы в оптимизированном низкоуровневом коде, а Python-цикл требует работы интерпретатора для каждого элемента.

Условно:

```text
Python list

Python
  ↓
цикл
  ↓
элемент
  ↓
операция
  ↓
следующий элемент
```

NumPy:

```text
Python
  ↓
один вызов операции
  ↓
оптимизированный код
  ↓
обработка массива
```

Поэтому на больших числовых массивах выигрыш может быть существенным.

При этом NumPy не гарантированно быстрее абсолютно любой операции и любого размера данных: для маленьких задач накладные расходы самой библиотеки тоже имеют значение.

### 13. Память

Обычный Python `list` хранит ссылки на Python-объекты.

```text
list
├── ссылка → Python int
├── ссылка → Python int
├── ссылка → Python int
└── ссылка → Python int
```

NumPy для числового массива хранит данные в более компактном буфере с фиксированным `dtype`.

Это одна из причин, почему NumPy хорошо подходит для больших массивов чисел.

### 14. NumPy и Pandas

NumPy — фундамент для численных вычислений.

Pandas предназначен прежде всего для работы с табличными и структурированными данными.

Упрощённо:

```text
NumPy
└── массивы и численные операции

Pandas
└── таблицы
    ├── Series
    └── DataFrame
```

Pandas активно использует концепции и структуры NumPy, хотя современные версии Pandas не ограничены NumPy как единственным backend для хранения данных.

## 🎤 Вопросы на собеседовании

### Что такое NumPy?

Библиотека Python для эффективных численных вычислений. Основной объект — многомерный массив `ndarray`.

### Чем NumPy-массив отличается от list?

`ndarray` ориентирован на однородные числовые данные, хранит их компактнее и позволяет выполнять векторизованные операции.

### Что такое векторизация?

Выполнение операции сразу над массивом без явного Python-цикла по каждому элементу.

### Что такое broadcasting?

Механизм, который позволяет выполнять операции над массивами разных совместимых форм, автоматически расширяя меньший массив по правилам NumPy.

### Что такое `shape`?

Размер массива по каждой оси.

```python
np.array([[1, 2, 3], [4, 5, 6]]).shape
# (2, 3)
```

### Что такое `dtype`?

Тип данных, используемый элементами NumPy-массива.

### Почему NumPy быстрее Python-списков при численных вычислениях?

За счёт компактного хранения числовых данных и выполнения многих операций в оптимизированном низкоуровневом коде вместо Python-цикла.

### NumPy — это только матрицы?

Нет. `ndarray` поддерживает произвольное количество измерений: одномерные, двумерные, трёхмерные и более массивы.
