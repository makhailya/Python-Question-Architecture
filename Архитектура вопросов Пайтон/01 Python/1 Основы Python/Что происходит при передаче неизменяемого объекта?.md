# Передача неизменяемого объекта — Passing Immutable Objects

## Коротко

Если передать в функцию неизменяемый объект (`int`, `float`, `str`, `tuple` и т. д.), изменить сам объект внутри функции нельзя.

Если внутри функции выполнить присваивание параметру, параметр начнёт ссылаться на другой объект. Исходный объект снаружи не изменится.

## Что важно помнить

Например, передаём число:

```python
def change_number(number):
    number = 100


x = 10

change_number(x)

print(x)
# 10
```

До вызова:

```
x ──────> 10
```

Внутри функции:

```
x ──────> 10

number ─> 100
```

number получил ссылку на тот же объект 10, но после:

```python
number = 100
```

он стал ссылаться на другой объект.

Исходная переменная x при этом не изменилась.

## Простой пример

Со строкой происходит то же самое:

```python
def add_text(text):
    text = text + " Python"


language = "Hello"

add_text(language)

print(language)
# Hello
```

Строка str является неизменяемой, поэтому исходный объект не изменяется.

## Главное

Для собеседования важно различать:

```
Изменяемый объект
        ↓
можно изменить сам объект
        ↓
изменение видно снаружи
```

и:

```
Неизменяемый объект
        ↓
сам объект изменить нельзя
        ↓
создаётся другой объект
        ↓
исходный объект не изменяется
```

При этом Python всё равно использует **pass by assignment** — правило передачи аргументов одинаковое для mutable и immutable объектов.
