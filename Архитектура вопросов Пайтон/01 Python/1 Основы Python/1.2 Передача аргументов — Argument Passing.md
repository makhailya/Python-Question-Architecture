# Передача аргументов — Argument Passing

## Ответ для собеседования

В Python аргументы передаются по ссылке на объект, точнее это называется call by sharing. То есть функция получает ссылку на тот же объект, который был передан при вызове. Если объект изменяемый, например list, функция может изменить его содержимое, и это будет видно снаружи. Если объект неизменяемый, например int или str, изменить его нельзя — можно только создать новый объект, не изменяя исходный.
## Коротко

В Python аргументы передаются **по присваиванию (pass by assignment)**.

Функция получает ссылку на тот же объект, который передан в качестве аргумента.

Поэтому результат зависит от того, является объект **изменяемым (mutable)** или **неизменяемым (immutable)**.

## Что важно помнить

Если функция изменяет изменяемый объект, изменения будут видны снаружи:

```python
def add_item(items):
    items.append(4)


numbers = [1, 2, 3]

add_item(numbers)

print(numbers)
# [1, 2, 3, 4]
```

Функция получила доступ к тому же объекту list и изменила его.

Если внутри функции переменной присвоить новый объект, исходная переменная снаружи не изменится:

```python
def change_number(number):
    number = 100


x = 10

change_number(x)

print(x)
# 10
```

Внутри функции number просто стала ссылаться на другой объект.

## Простой пример

Изменяемый объект:

```python
def add_item(items):
    items.append("Python")


languages = ["SQL"]

add_item(languages)

print(languages)
# ["SQL", "Python"]
```

Неизменяемый объект:

```python
def change_name(name):
    name = "Python"


language = "SQL"

change_name(language)

print(language)
# SQL
```

## Главное

### Неправильно говорить просто:

«Python передаёт аргументы по ссылке».

### И неправильно говорить:

«Python передаёт аргументы по значению».

### Точнее:

Python передаёт аргументы по присваиванию (pass by assignment).

При этом функция получает ссылку на объект, а имя параметра внутри функции является отдельным именем.
