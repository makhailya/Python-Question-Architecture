# 🔙 `return` в Python

## 🎤 Короткий ответ

`return` завершает выполнение функции и возвращает вызывающему коду некоторое значение.

Если `return` без значения или он отсутствует, функция возвращает `None`.

```python
def add(a, b):
    return a + b


result = add(2, 3)
print(result)  # 5
```

После выполнения `return` код внутри текущей функции больше не выполняется.

---

## 🗣️ Ответ на собеседовании

`return` используется для завершения выполнения функции и передачи результата вызывающему коду.

Он может возвращать любое Python-значение: число, строку, объект, коллекцию или даже другую функцию. Если функция заканчивается без `return`, либо используется `return` без выражения, результатом будет `None`.

Важно, что `return` завершает именно текущий вызов функции. Если функция вызвала другую функцию, `return` во внутренней функции не завершает внешнюю.

```python
def get_name():
    return "Ilya"
    print("Этот код не выполнится")
```

Также функция технически всегда возвращает значение — если явно ничего не вернуть, Python возвращает `None`.

## 📚 Разбор поглубже

### 1. Что делает `return`

У `return` две основные функции:

1. завершает выполнение текущей функции;
2. передаёт значение наружу.

```python
def square(x):
    return x * x


result = square(5)
print(result)  # 25
```

Можно представить это так:

```text
вызов функции
      ↓
  выполнение
      ↓
   return
      ↓
значение возвращается
      ↓
вызывающий код
```

---

### 2. `return` без значения

Можно написать:

```python
def stop():
    return
```

Результат:

```python
result = stop()

print(result)  # None
```

То же самое происходит, если функция заканчивается без `return`:

```python
def stop():
    pass


result = stop()

print(result)  # None
```

---

### 3. `return` завершает функцию

После `return` выполнение текущей функции прекращается.

```python
def check_age(age):
    if age < 18:
        return "Несовершеннолетний"

    return "Совершеннолетний"
```

Если `age < 18`, второй `return` уже не выполнится.

Можно использовать `return` как ранний выход:

```python
def process_user(user):
    if user is None:
        return

    print(user.name)
```

Такой подход часто называют **early return**.

---

### 4. Можно вернуть любое значение

`return` не ограничен конкретным типом.

```python
def get_number():
    return 42


def get_name():
    return "Ilya"


def get_users():
    return ["Ilya", "Anna"]


def get_user():
    return {"name": "Ilya", "age": 31}
```

Можно вернуть даже объект функции:

```python
def get_function():
    def hello():
        return "Hello"

    return hello
```

```python
func = get_function()

print(func())  # Hello
```

Это связано с тем, что функции в Python являются объектами первого класса.

---

### 5. Можно вернуть несколько значений

На самом деле Python возвращает **один объект — кортеж**.

```python
def get_user():
    return "Ilya", 31
```

Фактически:

```python
return ("Ilya", 31)
```

Можно распаковать результат:

```python
name, age = get_user()

print(name)  # Ilya
print(age)   # 31
```

Поэтому фраза «функция возвращает два значения» удобна в разговоре, но технически возвращается один `tuple`.

---

### 6. `return` внутри цикла

`return` завершает не цикл, а **всю функцию**.

```python
def find_number(numbers, target):
    for number in numbers:
        if number == target:
            return number

    return None
```

При нахождении элемента функция сразу завершается.

Это отличается от `break`:

```python
break
```

`break` завершает только текущий цикл.

```text
return → завершает функцию
break  → завершает цикл
continue → переходит к следующей итерации
```

---

### 7. `return` внутри вложенной функции

`return` относится только к той функции, в которой он находится.

```python
def outer():
    def inner():
        return 10

    result = inner()
    print(result)

    return 20
```

Здесь:

```python
return 10
```

завершает `inner()`, но не `outer()`.

А:

```python
return 20
```

завершает `outer()`.

---

### 8. `return` и `finally`

Важный нюанс: `finally` выполняется даже при `return`.

```python
def test():
    try:
        return 10
    finally:
        print("finally")
```

Результат:

```text
finally
```

А возвращаемое значение будет:

```python
10
```

Но опасная конструкция:

```python
def test():
    try:
        return 10
    finally:
        return 20
```

Здесь `return 20` из `finally` подавит предыдущий `return`.

```python
print(test())  # 20
```

Поэтому `return` внутри `finally` обычно следует избегать.

---

### 9. `return` и `yield` — не одно и то же

`return` завершает функцию и возвращает итоговое значение.

`yield` приостанавливает выполнение генератора и отдаёт очередное значение.

```python
def regular():
    return 10
```

```python
def generator():
    yield 10
    yield 20
```

У генератора `return` имеет отдельную семантику: он завершает генератор, а значение попадает в `StopIteration.value`.

```python
def generator():
    yield 1
    return "done"
```

При завершении генератора:

```text
StopIteration.value == "done"
```

---

### 10. `return` не изменяет исходный объект сам по себе

Функция может вернуть объект:

```python
def get_user():
    return {"name": "Ilya"}
```

Получивший код получает ссылку на этот объект:

```python
user = get_user()

user["age"] = 31
```

`return` передаёт объект вызывающему коду; это не означает автоматическое копирование объекта.

---

### 11. `return` и аннотации типов

Можно указать ожидаемый тип результата:

```python
def add(a: int, b: int) -> int:
    return a + b
```

Для отсутствия полезного возвращаемого значения:

```python
def log_message(message: str) -> None:
    print(message)
```

Аннотация `-> None` не заставляет Python автоматически проверять результат. Это подсказка для разработчика, IDE и статических анализаторов.

---

### 12. Типичные ошибки

#### Ошибка 1. Ожидать значение без `return`

```python
def add(a, b):
    a + b


result = add(2, 3)

print(result)  # None
```

Правильно:

```python
def add(a, b):
    return a + b
```

---

#### Ошибка 2. Путать `print` и `return`

```python
def add(a, b):
    print(a + b)
```

Эта функция выводит результат, но не возвращает его.

```python
result = add(2, 3)

print(result)
```

Получим:

```text
5
None
```

Потому что `print()` и `return` решают разные задачи:

```text
print  → выводит информацию
return → передаёт значение вызывающему коду
```

---

#### Ошибка 3. Код после `return`

```python
def test():
    return 10
    print("Hello")
```

`print()` недостижим.

## 🎤 Вопросы на собеседовании

**Что делает `return`?**

Завершает текущую функцию и возвращает значение вызывающему коду.

**Что вернёт функция без `return`?**

`None`.

**Что произойдёт при `return` без значения?**

Функция завершится и вернёт `None`.

**Можно ли вернуть несколько значений?**

Да, синтаксически можно написать несколько выражений через запятую, но фактически Python создаст и вернёт один кортеж.

```python
return 10, 20
```

**Чем `return` отличается от `break`?**

`return` завершает функцию, а `break` — только ближайший цикл.

**Чем `return` отличается от `print`?**

`print` выводит значение, а `return` передаёт значение вызывающему коду.

**Можно ли использовать `return` внутри цикла?**

Да. В этом случае завершается вся функция, а не только цикл.

**Что происходит с `return` при наличии `finally`?**

`finally` выполняется перед фактическим выходом из функции. `return` внутри `finally` может переопределить предыдущий `return`.

**Можно ли вернуть функцию через `return`?**

Да. Функции в Python являются объектами первого класса.
