# Передача объектов в функции Python

## 🎯 Ответ на собеседовании

> В Python в функцию передаётся **ссылка на объект**, а параметр функции становится ещё одним именем, которое ссылается на этот объект.
>
> Если внутри функции мы **изменяем сам объект**, например через `.append()`, изменения будут видны снаружи.
>
> Если мы **присваиваем параметру новое значение**, мы просто переназначаем локальное имя — внешняя переменная не изменяется.
>
> Поэтому важно различать **изменение объекта** и **переназначение имени**.
>
> Технически это называют **call by sharing** или **передача объекта по ссылке**.

---

## 📌 Что происходит при вызове функции

Например:

```python
numbers = [1, 2, 3]

def add_number(items):
    items.append(4)

add_number(numbers)
```

После вызова:

```python
numbers
# [1, 2, 3, 4]
```

Почему?

У нас один объект `list`:

```text
numbers ──┐
          ↓
      [1, 2, 3]
          ↑
          │
      items
```

`numbers` и `items` — это **два имени, указывающих на один объект**.

Когда выполняется:

```python
items.append(4)
```

мы изменяем сам список.

Поэтому изменение видно через `numbers`.

---

# 🔄 Изменение объекта vs переназначение имени

Это главное, что нужно понимать.

### 1. Изменяем объект

```python
def add_item(items):
    items.append(10)

numbers = [1, 2]
add_item(numbers)

print(numbers)
# [1, 2, 10]
```

`.append()` изменяет существующий список.

---

### 2. Переназначаем имя

```python
def change_list(items):
    items = [100, 200]

numbers = [1, 2]

change_list(numbers)

print(numbers)
# [1, 2]
```

Здесь:

```python
items = [100, 200]
```

не изменяет старый список.

Мы просто заставили локальное имя `items` ссылаться на новый объект:

```text
До:

numbers ──┐
          ↓
        [1, 2]
          ↑
          │
        items


После items = [100, 200]:

numbers ─────→ [1, 2]

items ───────→ [100, 200]
```

После завершения функции локальное имя `items` исчезает.

---

# 🧱 Неизменяемые объекты

С неизменяемыми объектами эффект особенно хорошо заметен.

Например, `int`:

```python
def change_number(x):
    x = 100

number = 10

change_number(number)

print(number)
# 10
```

Почему `number` не стал `100`?

Потому что:

```python
x = 100
```

не изменяет объект `10`.

Создаётся/используется другой объект `100`, а локальное имя `x` начинает ссылаться на него.

То же самое относится к:

* `int`
* `float`
* `bool`
* `str`
* `tuple`
* `frozenset`
* `bytes`

---

# 🧩 Изменяемые объекты

Изменяемые объекты можно менять внутри функции.

Например:

```python
def modify(items):
    items.append(10)

numbers = [1, 2]

modify(numbers)

print(numbers)
# [1, 2, 10]
```

Типичные изменяемые объекты:

* `list`
* `dict`
* `set`
* `bytearray`

---

# ⚠️ Важный момент

Неправильно говорить:

> «Изменяемые объекты передаются по ссылке, а неизменяемые — по значению».

**Все аргументы передаются одинаково.**

Разница заключается в том, **можно ли изменить сам объект**.

Например:

```python
def func(items, number):
    items.append(10)
    number = 100

numbers = [1, 2]
x = 5

func(numbers, x)

print(numbers)
# [1, 2, 10]

print(x)
# 5
```

`numbers` изменился, потому что список изменяемый.

`x` не изменился, потому что `int` неизменяемый, а `number = 100` — это переназначение локального имени.

---

# 🔍 `id()` помогает увидеть это

Можно проверить идентичность объектов:

```python
def func(items):
    print(id(items))

numbers = [1, 2, 3]

print(id(numbers))

func(numbers)
```

`id(numbers)` и `id(items)` будут одинаковыми, потому что оба имени указывают на один объект.

# 🆚 Изменение vs переназначение

| Операция          | Что происходит    | Изменится объект снаружи? |
| ----------------- | ----------------- | ------------------------- |
| `items.append(1)` | изменяем объект   | ✅ Да                      |
| `items.pop()`     | изменяем объект   | ✅ Да                      |
| `items[0] = 100`  | изменяем объект   | ✅ Да                      |
| `items.clear()`   | изменяем объект   | ✅ Да                      |
| `items = [...]`   | переназначаем имя | ❌ Нет                     |
| `items = None`    | переназначаем имя | ❌ Нет                     |
| `x = 100`         | переназначаем имя | ❌ Нет                     |

---

# 🧠 Главное правило

Нужно всегда задавать себе вопрос:

> **Я сейчас изменяю существующий объект или заставляю имя ссылаться на другой объект?**

### Изменяем объект:

```python
items.append(10)
```

### Переназначаем имя:

```python
items = [10]
```

Это принципиально разные операции.

---

# 📌 Термины

### Mutable — изменяемый

Объект можно изменить после создания.

Примеры:

```python
list
dict
set
bytearray
```

### Immutable — неизменяемый

После создания объект нельзя изменить.

Примеры:

```python
int
float
bool
str
tuple
frozenset
bytes
```

---

# 🎤 Если нужно ответить совсем коротко

> **В Python аргументы передаются как ссылки на объекты. Параметр функции — это новое имя для того же объекта. Если мы мутируем объект, изменения видны снаружи. Если переназначаем параметр, меняется только локальное имя. Поэтому важно различать мутацию объекта и переназначение имени.**

---

## 🧠 Шпаргалка

```text
Python
   ↓
передаёт ссылку на объект
   ↓
параметр = новое имя для этого объекта
   ↓
┌──────────────────────┬──────────────────────┐
│ Изменяем объект      │ Переназначаем имя    │
│                      │                      │
│ items.append(10)     │ items = [...]        │
│ items.pop()          │ items = None         │
│ items[0] = 100       │ x = 100              │
│                      │                      │
│ → видно снаружи      │ → только локально    │
└──────────────────────┴──────────────────────┘
```

**Формула для запоминания:**

> **Не важно, mutable или immutable для способа передачи. Важно, что происходит внутри функции: мутация объекта или переназначение имени.**
