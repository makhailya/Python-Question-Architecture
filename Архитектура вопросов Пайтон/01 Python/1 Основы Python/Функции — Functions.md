# Функции — Functions

## Коротко

**Функция** — именованный блок кода, который выполняет определённую задачу и может принимать аргументы и возвращать результат.

Простейшая функция:

```python
def greet():
    print("Hello")
```

Вызов:

```python
greet()
```

Функция может принимать параметры:

```python
def greet(name):
    print(f"Hello, {name}")
```

И возвращать значение:

```python
def add(a, b):
    return a + b
```

## На собеседовании достаточно сказать

> Функция — это переиспользуемый блок кода, который может принимать аргументы и возвращать результат через `return`. В Python функции являются объектами первого класса, поэтому их можно присваивать переменным, передавать в другие функции и возвращать из функций.

## Что важно помнить

### Создание функции

Функция создаётся с помощью `def`:

```python
def greet():
    print("Hello")
```

Здесь:

```text
def     → объявление функции
greet   → имя функции
()      → параметры
:       → начало тела функции
```

## Вызов функции

Определение функции само по себе её не запускает:

```python
def greet():
    print("Hello")
```

Чтобы выполнить функцию:

```python
greet()
```

Результат:

```text
Hello
```

---

## Параметры и аргументы

```python
def greet(name):
    print(f"Hello, {name}")
```

`name` — **параметр функции**.

При вызове:

```python
greet("Ilya")
```

`"Ilya"` — **аргумент**.

Упрощённо:

```text
параметр → переменная в определении функции
аргумент → конкретное значение при вызове
```

## `return`

`return` возвращает значение из функции:

```python
def add(a, b):
    return a + b
```

Можно получить результат:

```python
result = add(2, 3)

print(result)
```

Результат:

```text
5
```

После выполнения `return` функция прекращает выполнение.

```python
def test():
    print("A")
    return 10
    print("B")
```

Результат:

```text
A
```

`print("B")` не выполнится.

---

## Функция без `return`

Если функция не возвращает значение явно:

```python
def hello():
    print("Hello")
```

результатом будет `None`:

```python
result = hello()

print(result)
```

Получим:

```text
Hello
None
```

## Функции — объекты первого класса

В Python функцию можно присвоить переменной:

```python
def greet():
    print("Hello")

say_hello = greet

say_hello()
```

Результат:

```text
Hello
```

Теперь:

```text
greet ─────┐
           ├──> объект-функция
say_hello ─┘
```

Функция не вызывается при присваивании:

```python
say_hello = greet
```

А здесь вызывается:

```python
say_hello()
```

## Функцию можно передать в другую функцию

```python
def greet():
    print("Hello")


def execute(func):
    func()


execute(greet)
```

Результат:

```text
Hello
```

Это один из основных принципов функционального программирования в Python.

## Функция может вернуть функцию

```python
def outer():
    def inner():
        print("Hello")

    return inner
```

Теперь:

```python
func = outer()

func()
```

Результат:

```text
Hello
```

## Значения параметров по умолчанию

Можно задать значение параметра по умолчанию:

```python
def greet(name="Ilya"):
    print(f"Hello, {name}")
```

Теперь:

```python
greet()
```

даст:

```text
Hello, Ilya
```

А:

```python
greet("Alex")
```

даст:

```text
Hello, Alex
```

Важный нюанс: значения параметров по умолчанию вычисляются **один раз при создании функции**, а не при каждом вызове.

Особенно важно помнить это для изменяемых объектов:

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

Такой код может привести к неожиданному поведению.

Лучше:

```python
def add_item(item, items=None):
    if items is None:
        items = []

    items.append(item)
    return items
```

## `*args`

`*args` позволяет передать произвольное количество позиционных аргументов:

```python
def add_all(*args):
    return sum(args)
```

Вызов:

```python
add_all(1, 2, 3, 4)
```

Внутри функции:

```python
args
```

будет кортежем:

```python
(1, 2, 3, 4)
```

---

## `**kwargs`

`**kwargs` позволяет принять произвольное количество именованных аргументов:

```python
def show_user(**kwargs):
    print(kwargs)
```

Вызов:

```python
show_user(name="Ilya", age=31)
```

Внутри:

```python
kwargs
```

будет словарём:

```python
{
    "name": "Ilya",
    "age": 31
}
```

## Функции могут быть вложенными

Функцию можно определить внутри другой функции:

```python
def outer():

    def inner():
        print("Hello")

    inner()
```

Такая конструкция особенно важна для понимания:

- замыканий;
- декораторов;
- области видимости.

## Простой пример

```python
def calculate(a, b):
    result = a + b
    return result


x = calculate(10, 20)

print(x)
```

Результат:

```text
30
```

Здесь:

```text
calculate → функция
a, b      → параметры
10, 20    → аргументы
result    → локальная переменная
return    → возвращает результат
x         → получает результат функции
```

## Главное

Функция создаётся через:

```python
def function_name():
    ...
```

Принимает параметры:

```python
def add(a, b):
    ...
```

Возвращает значение:

```python
return result
```

Если `return` отсутствует, результатом будет:

```python
None
```

Функции в Python являются объектами первого класса:

```text
функцию можно
├── присвоить переменной
├── передать в другую функцию
└── вернуть из функции
```

Главная формула:

> **Функция → принимает данные → выполняет код → может вернуть результат.**
