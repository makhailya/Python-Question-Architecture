# Распаковка — Unpacking

## Коротко

**Распаковка (unpacking)** — это получение отдельных элементов из коллекции или другого итерируемого объекта и присваивание их отдельным переменным.

Например:

```python
numbers = [10, 20, 30]

a, b, c = numbers
```

Получаем:

```text
a = 10
b = 20
c = 30
```

Python автоматически распределяет элементы коллекции по переменным.

## На собеседовании достаточно сказать

> Распаковка — это способ присвоить элементы итерируемого объекта отдельным переменным. Например, `a, b, c = [1, 2, 3]`. Также можно использовать `*` для сбора нескольких элементов в одну переменную.

## Что важно помнить

### Обычная распаковка

```python
numbers = [10, 20, 30]

a, b, c = numbers
```

Результат:

```python
a == 10
b == 20
c == 30
```

Можно распаковывать не только списки:

```python
a, b = (10, 20)

a, b = "AB"

a, b = {10, 20}
```

Распаковка работает с итерируемыми объектами.

---

## Количество переменных должно совпадать

Например:

```python
a, b = [1, 2]
```

Работает.

Но:

```python
a, b = [1, 2, 3]
```

даст:

```text
ValueError: too many values to unpack
```

А:

```python
a, b, c = [1, 2]
```

даст:

```text
ValueError: not enough values to unpack
```

То есть без `*` количество элементов должно соответствовать количеству переменных.

---

## Распаковка с `*`

Звёздочка `*` позволяет собрать несколько элементов в список.

Например:

```python
numbers = [1, 2, 3, 4, 5]

first, *middle, last = numbers
```

Получаем:

```python
first == 1
middle == [2, 3, 4]
last == 5
```

То есть:

```text
first  → 1
middle → [2, 3, 4]
last   → 5
```

---

## `*` может быть в середине

```python
numbers = [1, 2, 3, 4, 5]

a, *middle, b = numbers
```

Результат:

```python
a == 1
middle == [2, 3, 4]
b == 5
```

Звёздочка собирает все элементы, которые остались между обычными переменными.

---

## `*` может собрать всё оставшееся

```python
numbers = [1, 2, 3]

a, *rest = numbers
```

Получаем:

```python
a == 1
rest == [2, 3]
```

И наоборот:

```python
*start, last = numbers
```

Получим:

```python
start == [1, 2]
last == 3
```

---

## Результат `*` всегда список

Например:

```python
numbers = (1, 2, 3, 4)

a, *rest = numbers
```

Хотя исходный объект — `tuple`, переменная `rest` получит список:

```python
type(rest)
```

Результат:

```text
list
```

То есть:

```python
rest == [2, 3, 4]
```

---

## Обмен значениями

Распаковка позволяет удобно менять значения двух переменных местами:

```python
a = 10
b = 20

a, b = b, a
```

До:

```text
a = 10
b = 20
```

После:

```text
a = 20
b = 10
```

Python распаковывает правую часть и присваивает значения переменным.

---

## Распаковка в цикле

Распаковка часто используется при переборе последовательностей:

```python
users = [
    ("Ilya", 31),
    ("Alex", 25),
]

for name, age in users:
    print(name, age)
```

Результат:

```text
Ilya 31
Alex 25
```

На каждой итерации Python распаковывает кортеж:

```text
("Ilya", 31)
     ↓
name = "Ilya"
age = 31
```

---

## Распаковка словаря

При переборе словаря можно распаковывать пары ключ-значение через `items()`:

```python
user = {
    "name": "Ilya",
    "age": 31,
}

for key, value in user.items():
    print(key, value)
```

Результат:

```text
name Ilya
age 31
```

`items()` возвращает пары:

```text
("name", "Ilya")
("age", 31)
```

которые распаковываются в:

```python
key, value
```

---

## Распаковка при вызове функции

Распаковка используется не только при присваивании.

Например:

```python
numbers = [1, 2, 3]

print(*numbers)
```

Это передаст элементы списка как отдельные аргументы:

```python
print(1, 2, 3)
```

Результат:

```text
1 2 3
```

Здесь `*` выполняет распаковку последовательности при вызове функции.

---

## `**` для словаря

Для словаря используется `**`.

Например:

```python
user = {
    "name": "Ilya",
    "age": 31,
}

print(**user)
```

Но здесь будет ошибка, потому что `print()` не принимает произвольные именованные аргументы в таком виде.

Правильный пример — функция:

```python
def greet(name, age):
    print(name, age)


user = {
    "name": "Ilya",
    "age": 31,
}

greet(**user)
```

Это эквивалентно:

```python
greet(name="Ilya", age=31)
```

То есть:

```text
*  → распаковка последовательности
** → распаковка словаря
```

---

## Распаковка при создании коллекций

`*` также можно использовать для объединения элементов:

```python
a = [1, 2]
b = [3, 4]

result = [*a, *b]
```

Получим:

```python
[1, 2, 3, 4]
```

Для словарей используется `**`:

```python
a = {"name": "Ilya"}
b = {"age": 31}

result = {**a, **b}
```

Получим:

```python
{
    "name": "Ilya",
    "age": 31
}
```

---

## Простой пример

```python
numbers = [10, 20, 30, 40, 50]

first, *middle, last = numbers

print(first)
print(middle)
print(last)
```

Результат:

```text
10
[20, 30, 40]
50
```

Здесь:

```text
first  → первый элемент
middle → все элементы между первым и последним
last   → последний элемент
```

---

## Главное

Обычная распаковка:

```python
a, b, c = [1, 2, 3]
```

Распаковка с `*`:

```python
a, *rest = [1, 2, 3]
```

Результат:

```python
a == 1
rest == [2, 3]
```

При вызове функции:

```python
func(*args)
```

`*` распаковывает последовательность в отдельные позиционные аргументы.

Для словаря:

```python
func(**kwargs)
```

`**` распаковывает словарь в именованные аргументы.

Главная формула:

```text
a, b, c = iterable
        ↓
распаковка элементов

*a
 ↓
распаковка последовательности

**a
  ↓
распаковка словаря
```
