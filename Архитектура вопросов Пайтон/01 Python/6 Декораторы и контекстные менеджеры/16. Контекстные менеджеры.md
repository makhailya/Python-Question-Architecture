```python
class FileManager:
    def __init__(self, filename):
        self.filename = filename

    def __enter__(self):
        self.file = open(self.filename)
        return self.file            # это то, что попадёт в переменную после `as`

    def __exit__(self, exc_type, exc_value, traceback):
        self.file.close()
        return False                 # False — не подавляем исключение, True — подавляем

with FileManager("data.txt") as f:
    content = f.read()
```

1. __enter__(self) — вызывается на входе в блок with, обычно возвращает self (или другой полезный объект — именно он и «ловится» через as obj).

2. __exit__(self, exc_type, exc_value, traceback) — вызывается на выходе из блока (в том числе при исключении). Возвращает True, если исключение нужно подавить (программа продолжится дальше), или False/None, если исключение должно пробрасываться дальше.

3. Асинхронная версия — методы __aenter__ / __aexit__, используется как async with.
