# 🎛️ Параметризованный декоратор

🎯 **Ответ на собеседовании:**

**Параметризованный декоратор** — это декоратор, которому перед применением к функции можно передать дополнительные аргументы.

Например:

```python
@repeat(3)
def hello():
    print("Hello")
```

Здесь `3` — параметр декоратора.

Важно: `repeat(3)` сначала **возвращает обычный декоратор**, который затем получает функцию.

---

## Как это работает

Запись:

```python
@repeat(3)
def hello():
    print("Hello")
```

эквивалентна:

```python
def hello():
    print("Hello")

hello = repeat(3)(hello)
```

То есть получается **три уровня**:

```text
repeat(3)
    ↓
decorator(func)
    ↓
wrapper(*args, **kwargs)
```

---

# Пример

```python
from functools import wraps


def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)

            return result

        return wrapper

    return decorator
```

Использование:

```python
@repeat(3)
def hello():
    print("Hello")
```

Результат:

```text
Hello
Hello
Hello
```

---

# Почему здесь три функции?

Потому что нужно разделить три задачи:

### 1. `repeat(times)`

Получает **параметры декоратора**:

```python
repeat(3)
```

↓

### 2. `decorator(func)`

Получает **саму декорируемую функцию**:

```python
decorator(hello)
```

↓

### 3. `wrapper(*args, **kwargs)`

Выполняется **при вызове функции**:

```python
hello()
```

Схема:

```text
@repeat(3)
     ↓
repeat(3)
     ↓
decorator(hello)
     ↓
wrapper()
     ↓
hello()
```

# Декоратор без параметров

Обычный декоратор:

```python
@log
def hello():
    ...
```

примерно:

```python
hello = log(hello)
```

Структура:

```python
def log(func):
    def wrapper(*args, **kwargs):
        ...
        return func(*args, **kwargs)

    return wrapper
```

---

# Декоратор с параметрами

Параметризованный:

```python
@log(level="INFO")
def hello():
    ...
```

примерно:

```python
hello = log(level="INFO")(hello)
```

Поэтому появляется дополнительный уровень:

```python
def log(level):
    def decorator(func):
        def wrapper(*args, **kwargs):
            print(level)
            return func(*args, **kwargs)

        return wrapper

    return decorator
```

---

# Пример с логированием

```python
from functools import wraps


def log(level):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            print(f"[{level}] {func.__name__}")
            return func(*args, **kwargs)

        return wrapper

    return decorator
```

Использование:

```python
@log("INFO")
def get_user(user_id):
    return user_id
```

При:

```python
get_user(42)
```

получим:

```text
[INFO] get_user
```

# Важно: замыкание

Параметризованный декоратор обычно использует **замыкание**.

Например:

```python
def repeat(times):
    def decorator(func):
        def wrapper():
            for _ in range(times):
                func()

        return wrapper

    return decorator
```

`wrapper` помнит значение:

```python
times
```

которое было передано в `repeat()`.

То есть:

```text
repeat(3)
    ↓
times = 3
    ↓
wrapper запоминает times
```

---

# Параметры декоратора и параметры функции — разные вещи

Например:

```python
@repeat(3)
def hello(name):
    print(name)
```

Здесь:

```python
repeat(3)
```

→ параметр **декоратора**

А:

```python
hello("Ilya")
```

→ параметр **декорируемой функции**

Поэтому:

```python
def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                func(*args, **kwargs)

        return wrapper

    return decorator
```

`times` и `*args, **kwargs` находятся на разных уровнях.

# Async-параметризованный декоратор

В Backend может понадобиться декорировать `async def`:

```python
from functools import wraps


def retry(times):
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            for attempt in range(times):
                try:
                    return await func(*args, **kwargs)
                except Exception:
                    if attempt == times - 1:
                        raise

        return wrapper

    return decorator
```

Использование:

```python
@retry(3)
async def request():
    ...
```

Здесь важно, что `wrapper` тоже `async`, а исходная coroutine вызывается через `await`.

## 🧠 Коротко для собеседования

> **Параметризованный декоратор — это декоратор с дополнительными настройками. Из-за наличия параметров появляется дополнительный уровень вложенности: внешняя функция принимает параметры декоратора и возвращает сам декоратор, который принимает функцию и возвращает wrapper. Обычно это реализуется через замыкание.**

### Формула

```text
@decorator(arg)
def func():
    ...
```

эквивалентно:

```python
func = decorator(arg)(func)
```

### Три уровня:

```text
decorator(arg)
      ↓
 decorator(func)
      ↓
 wrapper(*args, **kwargs)
```

**Запомнить:** обычный декоратор → `func → wrapper`; параметризованный → `параметры → func → wrapper`.
