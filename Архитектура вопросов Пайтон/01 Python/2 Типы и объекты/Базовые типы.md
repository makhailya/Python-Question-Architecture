# 🧩 Базовые типы Python

## 🎤 Короткий ответ

В Python тип определяет, **какие значения представляет объект и какие операции над ним доступны**.

К базовым встроенным типам относятся:

* `int` — целые числа
* `float` — числа с плавающей точкой
* `complex` — комплексные числа
* `bool` — логические значения
* `str` — строки
* `bytes` — неизменяемая последовательность байт
* `bytearray` — изменяемая последовательность байт
* `NoneType` — тип значения `None`

Отдельно стоит выделять контейнерные типы:

* `list`
* `tuple`
* `set`
* `dict`

В Python всё является **объектами**, поэтому переменная хранит не «тип значения», а **ссылку на объект определённого типа**.

---

## 🗣️ Ответ на собеседовании

В Python всё является объектами, и каждый объект имеет определённый тип.

Если говорить о базовых встроенных типах, то основные — это числа `int`, `float`, `complex`, логический тип `bool`, строки `str`, байтовые типы `bytes` и `bytearray`, а также специальный тип `NoneType`, экземпляром которого является `None`.

Кроме простых типов есть контейнеры — `list`, `tuple`, `set` и `dict`, которые позволяют хранить несколько объектов.

Тип объекта можно получить через `type()` или проверить через `isinstance()`.

При этом важно понимать, что переменная в Python не имеет фиксированного типа как, например, переменная в некоторых статически типизированных языках. Имя просто ссылается на объект, а тип принадлежит самому объекту.

Например:

```python
x = 10
x = "hello"
```

Сначала `x` ссылается на объект `int`, а затем — на объект `str`.

# 📚 Разбор поглубже

## 1. Что такое тип

Тип — это характеристика объекта, которая определяет его поведение и доступные операции.

```python
x = 10

print(type(x))
```

Результат:

```python
<class 'int'>
```

Можно проверить принадлежность объекта типу:

```python
x = 10

print(isinstance(x, int))
```

Результат:

```python
True
```

### `type()` и `isinstance()`

`type()` позволяет получить конкретный тип объекта:

```python
type(10)
```

`isinstance()` проверяет, является ли объект экземпляром указанного типа с учётом наследования:

```python
isinstance(10, int)
```

На практике для проверки типа обычно предпочтительнее `isinstance()`.

# 2. Числовые типы

## `int`

Целые числа:

```python
age = 31
count = -10
big_number = 1_000_000
```

Поддерживают арифметические операции:

```python
a = 10
b = 3

a + b
a - b
a * b
a // b
a % b
a ** b
```

В Python `int` имеет **произвольную точность**: размер целого числа ограничен доступной памятью, а не фиксированным количеством бит.

---

## `float`

Числа с плавающей точкой:

```python
price = 19.99
temperature = -2.5
```

```python
type(19.99)
```

Результат:

```python
<class 'float'>
```

Важно помнить, что `float` использует двоичное представление с плавающей точкой, поэтому некоторые десятичные значения невозможно представить абсолютно точно.

Например:

```python
0.1 + 0.2
```

может дать:

```python
0.30000000000000004
```

---

## `complex`

Комплексные числа:

```python
z = 2 + 3j
```

У комплексного числа есть действительная и мнимая части:

```python
z.real
z.imag
```

В обычной backend-разработке используется редко.

---

# 3. `bool`

Логический тип.

Имеет два значения:

```python
True
False
```

```python
is_active = True
is_deleted = False
```

Интересный момент Python:

```python
isinstance(True, int)
```

Результат:

```python
True
```

Потому что `bool` является подклассом `int`.

Поэтому:

```python
True == 1
False == 0
```

дают:

```python
True
True
```

Но это **разные объекты и разные типы**:

```python
type(True)
# bool

type(1)
# int
```

---

# 4. `str`

Строка — последовательность Unicode-символов.

```python
name = "Ilya"
text = "Python"
```

Строки являются **неизменяемыми** объектами.

Например:

```python
text = "Python"

text[0] = "J"
```

приведёт к ошибке:

```text
TypeError
```

Вместо изменения существующей строки создаётся новая:

```python
text = "Python"
text = "Java"
```

Имя `text` теперь просто ссылается на другой объект.

---

# 5. `bytes`

`bytes` — неизменяемая последовательность байтов.

```python
data = b"hello"
```

Каждый элемент — целое число от `0` до `255`:

```python
data[0]
```

Результат:

```python
104
```

`bytes` часто встречается при работе с:

* сетевыми протоколами;
* файлами;
* бинарными данными;
* кодировками;
* криптографией.

---

# 6. `bytearray`

`bytearray` похож на `bytes`, но является **изменяемым**.

```python
data = bytearray(b"hello")

data[0] = 72
```

Теперь первый байт изменён.

Главное различие:

```text
bytes      → immutable
bytearray  → mutable
```

---

# 7. `NoneType`

В Python существует специальное значение:

```python
None
```

Его тип:

```python
type(None)
```

Результат:

```python
<class 'NoneType'>
```

`None` обычно означает отсутствие значения.

Например:

```python
result = None
```

Проверять `None` принято через `is`:

```python
if result is None:
    print("Нет результата")
```

а не через:

```python
if result == None:
    ...
```

# 8. Контейнерные типы

Кроме простых типов Python предоставляет контейнеры.

## `list`

Изменяемая упорядоченная коллекция:

```python
numbers = [1, 2, 3]
```

```python
numbers.append(4)
```

---

## `tuple`

Неизменяемая упорядоченная коллекция:

```python
point = (10, 20)
```

---

## `set`

Коллекция уникальных элементов:

```python
numbers = {1, 2, 3}
```

Дубликаты не хранятся:

```python
numbers = {1, 1, 2, 2, 3}

print(numbers)
```

---

## `dict`

Коллекция пар `ключ → значение`:

```python
user = {
    "name": "Ilya",
    "age": 31,
}
```

Доступ осуществляется по ключу:

```python
user["name"]
```

`dict` построен на основе **хеш-таблицы**, поэтому его внутреннее устройство — отдельная большая тема.

# 9. Mutable и Immutable (Изменяемые и Неизменяемые)

Типы Python удобно дополнительно разделять по изменяемости объектов.

### Immutable (Неизменяемые)

Объект нельзя изменить после создания.

Примеры:

```text
int
float
complex
bool
str
bytes
tuple
frozenset
NoneType
```

### Mutable (Изменяемые)

Объект можно изменить после создания.

Примеры:

```text
list
dict
set
bytearray
```

Это разделение особенно важно для понимания:

* передачи аргументов в функции;
* ссылок на объекты;
* `id()`;
* копирования;
* хешируемости;
* работы `dict` и `set`.

Подробно это будет разобрано в теме **«Mutable / Immutable»**.

# 10. Всё в Python — объект

Одна из фундаментальных идей Python:

```text
переменная
    ↓
ссылка
    ↓
объект
    ├── значение
    ├── тип
    └── identity
```

Например:

```python
x = 10
```

Упрощённо можно представить:

```text
x ───────► объект int(10)
```

Если выполнить:

```python
x = "hello"
```

получим:

```text
x ───────► объект str("hello")
```

Тип относится **к объекту**, а не к имени `x`.

Поэтому:

```python
x = 10
x = "hello"
x = [1, 2, 3]
```

полностью нормально для Python.

# 11. `type`, `id` и `is`

Для понимания объектов полезно различать три понятия:

### Тип

```python
type(x)
```

Что это за объект?

### Identity

```python
id(x)
```

Какой конкретно объект?

### Identity comparison

```python
x is y
```

Являются ли `x` и `y` ссылками на **один и тот же объект**?

Например:

```python
a = []
b = a
```

Здесь:

```text
a ──┐
    ├──► один объект list
b ──┘
```

Поэтому:

```python
a is b
```

даст:

```python
True
```

# 🎤 Вопросы на собеседовании

### Какие базовые типы есть в Python?

Основные:

```text
int
float
complex
bool
str
bytes
bytearray
NoneType
```

Также часто отдельно рассматривают контейнерные типы:

```text
list
tuple
set
dict
```

### Чем `type()` отличается от `isinstance()`?

`type()` возвращает конкретный тип объекта.

`isinstance()` проверяет, является ли объект экземпляром указанного типа или его наследника.

### Всё ли в Python является объектом?

Да. Числа, строки, функции, классы, модули и экземпляры классов являются объектами.

### Что такое `None`?

`None` — специальный объект, обозначающий отсутствие значения. Его тип — `NoneType`.

### Почему `is` используют для проверки `None`?

Потому что `is` проверяет identity — является ли это тем же самым объектом:

```python
value is None
```

### `bool` — это отдельный тип?

Да, но `bool` является подклассом `int`:

```python
issubclass(bool, int)
# True
```

### Какие типы изменяемые?

Основные изменяемые встроенные типы:

```text
list
dict
set
bytearray
```

### Какие неизменяемые?

Например:

```text
int
float
complex
bool
str
bytes
tuple
frozenset
NoneType
```

### Почему это важно?

Потому что изменяемость влияет на поведение объектов при передаче в функции, копировании, работе со ссылками и использовании объектов в качестве ключей `dict` или элементов `set`.
