# Изменяемые и неизменяемые типы данных — Mutable vs Immutable

##Ответ для собеседования

Изменяемые (mutable) объекты можно изменить после создания, не создавая новый объект. Например, list, dict и set. Неизменяемые (immutable) после создания изменить нельзя: например, int, float, str и tuple. Если мы как будто изменяем immutable-объект, Python на самом деле создаёт новый объект и связывает с ним имя переменной.
## Коротко

**Изменяемые (mutable)** объекты можно изменить после создания.

**Неизменяемые (immutable)** объекты после создания изменить нельзя — при «изменении» создаётся новый объект.

### Изменяемые

- `list`
- `dict`
- `set`
- `bytearray`

### Неизменяемые

- `int`
- `float`
- `bool`
- `str`
- `tuple`
- `frozenset`
- `bytes`
- `NoneType`

## Простой пример

```python
numbers = [1, 2, 3]
numbers.append(4)

print(numbers)
# [1, 2, 3, 4]
```

Список изменился — list является mutable.

А со строкой:

```
name = "Ilya"
name = name + "!"

print(name)
# Ilya!
```

Здесь исходная строка не изменяется. Создаётся новый объект str.

## Что важно помнить

Неизменяемость относится к самому объекту, а не к переменной.

```
x = 10
x = 20
```

Мы не изменили объект 10. Переменная x теперь просто ссылается на другой объект.
