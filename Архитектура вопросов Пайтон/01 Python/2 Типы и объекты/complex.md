# `complex` — комплексные числа

## 🎯 Ответ на собеседовании

> **`complex` — встроенный тип Python для представления комплексных чисел, состоящих из действительной и мнимой частей. Мнимая единица в Python обозначается `j`. Тип `complex` является immutable и поддерживает арифметические операции с комплексными числами.**

### Пример

```python
z = 3 + 4j

print(z.real)
# 3.0

print(z.imag)
# 4.0
```

### Если спросят про `immutable`

> **`complex` — неизменяемый тип. При выполнении операции создаётся новый объект, а существующий не изменяется.**

### Если спросят, где используется

> **Комплексные числа используются в математических, инженерных и научных вычислениях, например при работе с сигналами, электрическими цепями и преобразованиями Фурье.**

---

# Коротко

Комплексное число имеет вид:

```text
a + bj
```

где:

* `a` — действительная часть;
* `b` — мнимая часть;
* `j` — мнимая единица.

Например:

```python
z = 3 + 4j
```

Здесь:

```text
3 → действительная часть
4 → мнимая часть
j → мнимая единица
```

---

# Создание `complex`

### Обычная запись

```python
z = 3 + 4j
```

Важно: Python использует именно **`j`**, а не `i`.

```python
z = 3 + 4j
```

Правильно.

```python
z = 3 + 4i
```

Так нельзя — `i` не является обозначением мнимой единицы в синтаксисе Python.

---

# Через `complex()`

Можно создать число с помощью функции:

```python
z = complex(3, 4)

print(z)
# (3+4j)
```

Первый аргумент:

```text
действительная часть
```

Второй:

```text
мнимая часть
```

Можно создать только мнимую часть:

```python
z = complex(0, 5)

print(z)
# 5j
```

Или только действительную:

```python
z = complex(5)

print(z)
# (5+0j)
```

---

# Действительная и мнимая части

У `complex` есть атрибуты:

```python
z = 3 + 4j

print(z.real)
# 3.0

print(z.imag)
# 4.0
```

Обрати внимание: даже если мы создали:

```python
z = 3 + 4j
```

части возвращаются как `float`:

```python
type(z.real)
# float

type(z.imag)
# float
```

---

# Арифметические операции

Комплексные числа поддерживают основные математические операции.

```python
a = 3 + 4j
b = 1 + 2j
```

### Сложение

```python
a + b
# (4+6j)
```

### Вычитание

```python
a - b
# (2+2j)
```

### Умножение

```python
a * b
# (-5+10j)
```

### Деление

```python
a / b
# (2.2-0.4j)
```

### Возведение в степень

```python
a ** 2
# (-7+24j)
```

# Сопряжённое число

У комплексного числа:

```python
z = 3 + 4j
```

сопряжённое число:

```text
3 - 4j
```

Получить его можно методом:

```python
z.conjugate()
```

Результат:

```python
(3-4j)
```

---

# Модуль комплексного числа

Модуль комплексного числа:

```text
|a + bj| = √(a² + b²)
```

Например:

```python
z = 3 + 4j

abs(z)
# 5.0
```

Потому что:

```text
√(3² + 4²)
= √25
= 5
```

---

# Нельзя сравнивать комплексные числа через `<` и `>`

Это важная особенность.

Можно проверить равенство:

```python
a = 3 + 4j
b = 3 + 4j

a == b
# True
```

Но:

```python
a < b
```

вызовет:

```text
TypeError
```

То же самое касается:

```python
a > b
a <= b
a >= b
```

Почему?

Для комплексных чисел не существует естественного порядка вроде:

```text
3 < 5
```

# `complex` и `float`

Комплексное число может содержать `float`:

```python
z = 3.5 + 4.2j
```

Его части:

```python
z.real
# 3.5

z.imag
# 4.2
```

Но нельзя просто сделать:

```python
float(3 + 4j)
```

Это вызовет:

```text
TypeError
```

Потому что нельзя однозначно преобразовать комплексное число в обычное действительное число: оно содержит две компоненты.

---

# `complex` и `int`

Можно создать комплексное число из `int`:

```python
z = complex(10, 5)

print(z)
# (10+5j)
```

Также:

```python
complex(10)
# (10+0j)
```

---

# `complex` — immutable

Как и `int` и `float`, тип `complex` является **immutable**.

Например:

```python
z = 3 + 4j
```

Нельзя изменить:

```python
z.real = 10
```

Python выдаст ошибку.

Чтобы получить другое значение, создаётся новый объект:

```python
z = z + 1
```

---

# Число `j`

В Python:

```python
1j
```

— это комплексное число:

```python
type(1j)
# <class 'complex'>
```

Можно делать:

```python
2j + 3j
# 5j
```

И:

```python
3 + 2j
```

---

# Полезные свойства

```python
z = 3 + 4j

z.real
# 3.0

z.imag
# 4.0

z.conjugate()
# (3-4j)

abs(z)
# 5.0
```

---

# `cmath`

Для работы с комплексными числами существует отдельный модуль:

```python
import cmath
```

Например:

```python
cmath.sqrt(-1)
```

Результат:

```text
1j
```

Обычный `math` для отрицательного числа:

```python
import math

math.sqrt(-1)
```

даст ошибку `ValueError`.

А `cmath` умеет работать с комплексными результатами.

# Где используется?

`complex` встречается преимущественно в:

* математике;
* физике;
* обработке сигналов;
* электротехнике;
* цифровой обработке сигналов;
* научных вычислениях;
* преобразовании Фурье;
* некоторых задачах машинного обучения и обработки изображений.

В обычном backend-разработчике Python используется значительно реже, чем `int` и `float`.

# 🧠 Шпаргалка

```text
complex
│
├── комплексное число
│
├── формат:
│      a + bj
│
├── a → real
├── b → imag
├── j → мнимая единица
│
├── immutable
│
├── .real → действительная часть
├── .imag → мнимая часть
├── .conjugate() → сопряжённое число
├── abs() → модуль
│
├── == → можно
├── < > <= >= → нельзя
│
└── cmath → работа с комплексными числами
```

## 🎯 Самая короткая версия

**`complex` — immutable встроенный тип Python для комплексных чисел вида `a + bj`; имеет `.real` и `.imag`, поддерживает арифметические операции, но не поддерживает обычное сравнение через `<` и `>`.**
