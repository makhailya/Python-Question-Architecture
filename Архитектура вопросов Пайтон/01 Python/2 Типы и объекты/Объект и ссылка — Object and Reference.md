# Объект и ссылка — Object and Reference

## Коротко

В Python переменная — это **имя, которое ссылается на объект**, а не контейнер, который хранит значение внутри себя.

Например:

```python
a = [1, 2, 3]
```

В памяти создаётся объект списка, а имя `a` начинает ссылаться на него:

```text
a ───> [1, 2, 3]
```

Если написать:

```python
b = a
```

новый список не создаётся.

Теперь `a` и `b` ссылаются на один и тот же объект:

```text
a ─────┐
       ├──> [1, 2, 3]
b ─────┘
```

## На собеседовании достаточно сказать

> В Python переменная является именем, связанным с объектом. При присваивании `b = a` объект не копируется — оба имени ссылаются на один и тот же объект. Это особенно важно для изменяемых объектов, потому что изменение через одну ссылку будет видно через другую.

## Что важно помнить

### Переменная — это имя объекта

Когда мы пишем:

```python
x = 10
```

можно представить это так:

```text
x ───> 10
```

`x` не является самим объектом `10`.

Это имя, связанное с объектом.

---

### Несколько переменных могут ссылаться на один объект

```python
a = [1, 2, 3]
b = a
c = b
```

Получается:

```text
a ─────┐
b ─────┼──> [1, 2, 3]
c ─────┘
```

Объект один, а ссылок на него три.

Проверить это можно с помощью `is`:

```python
a is b  # True
b is c  # True
a is c  # True
```

---

## Изменение объекта

Списки — изменяемые объекты.

```python
a = [1, 2, 3]
b = a

b.append(4)
```

После этого:

```python
print(a)
print(b)
```

получим:

```text
[1, 2, 3, 4]
[1, 2, 3, 4]
```

Почему?

Потому что `a` и `b` ссылаются на один объект:

```text
a ─────┐
       ├──> [1, 2, 3, 4]
b ─────┘
```

Мы изменили сам объект через ссылку `b`, поэтому изменение видно и через `a`.

---

## Присваивание меняет связь имени с объектом

Рассмотрим:

```python
a = [1, 2, 3]
b = a

b = [4, 5, 6]
```

Здесь второй список — уже новый объект.

Получаем:

```text
a ───> [1, 2, 3]

b ───> [4, 5, 6]
```

Важно отличать:

```python
b.append(4)
```

от:

```python
b = [4, 5, 6]
```

В первом случае мы **изменяем существующий объект**.

Во втором случае мы **перепривязываем имя `b` к другому объекту**.

---

## `id()` и идентичность объекта

У каждого объекта во время его жизни есть идентификатор, который можно получить через `id()`:

```python
a = [1, 2, 3]
b = a

print(id(a))
print(id(b))
```

Идентификаторы будут одинаковыми:

```text
140000000000
140000000000
```

Потому что `a` и `b` ссылаются на один объект.

```python
a is b  # True
```

Оператор `is` фактически позволяет проверить идентичность объектов.

---

## Объект и значение — не одно и то же

Можно иметь два разных объекта с одинаковым значением:

```python
a = [1, 2, 3]
b = [1, 2, 3]
```

Получаем:

```text
a ───> [1, 2, 3]

b ───> [1, 2, 3]
```

Значения одинаковые:

```python
a == b  # True
```

Но объекты разные:

```python
a is b  # False
```

То есть:

```text
== → сравнивает значения
is → проверяет идентичность объектов
```

## Что происходит с неизменяемыми объектами

Рассмотрим число:

```python
a = 10
b = a
```

Оба имени связаны с объектом:

```text
a ─────┐
       ├──> 10
b ─────┘
```

Но число — неизменяемый объект.

Если написать:

```python
b = 20
```

объект `10` не изменяется.

Имя `b` просто начинает ссылаться на другой объект:

```text
a ───> 10

b ───> 20
```

Это важное отличие от изменения изменяемого объекта.

Подробнее:

[[1.1 Изменяемые и неизменяемые типы данных — Mutable vs Immutable]]

## Простой пример

```python
a = [1, 2, 3]
b = a

print(a is b)  # True

b.append(4)

print(a)  # [1, 2, 3, 4]
print(b)  # [1, 2, 3, 4]

b = [10, 20]

print(a)  # [1, 2, 3, 4]
print(b)  # [10, 20]
```

Что произошло:

1. `b = a` — `a` и `b` ссылаются на один список.
2. `b.append(4)` — изменили общий объект.
3. `b = [10, 20]` — создали новый список и перепривязали `b`.
4. `a` продолжает ссылаться на старый список.

---

## Главное

Нужно запомнить три вещи:

### 1. Переменная — это имя

```python
a = [1, 2, 3]
```

`a` — имя, связанное с объектом.

### 2. Присваивание не копирует объект

```python
b = a
```

Теперь две ссылки указывают на один объект.

### 3. Изменение объекта и перепривязывание имени — разные вещи

Изменение:

```python
b.append(4)
```

Перепривязывание:

```python
b = [4, 5, 6]
```

Формула:

```text
a = объект
b = a

→ a и b ссылаются на один объект
```

А если:

```python
b = новый_объект
```

то:

```text
a ───> старый объект
b ───> новый объект
```
