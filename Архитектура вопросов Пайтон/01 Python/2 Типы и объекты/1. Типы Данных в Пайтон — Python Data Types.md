# **Изменяемые**: `list`, `dict`, `set`, `bytearray`.
# **Неизменяемые**: `int`, `float`, `complex`, `bool`, `str`, `tuple`, `frozenset`, `bytes`, `NoneType`, `memoryview`.

# - **Передача аргументов**:

в Python всё передаётся **по ссылке** (передаётся ссылка на объект). Но если внутри функции переменной присваивают новое значение — это просто переопределение локального имени, на внешний объект это не влияет. А если объект **изменяемый** и мы вызываем его методы (`.append()`, `.pop()`) — меняется тот же объект, на который ссылается и внешняя переменная. Разница не в способе передачи, а в том, «мутируем» мы объект или «переопределяем» имя.
# Ответ для собеседования

В Python есть несколько основных типов данных. Из простых типов — int, float, complex, bool и NoneType. Для коллекций используются list, tuple, set и dict, также есть str и bytes. Кроме того, в Python можно создавать собственные типы данных с помощью классов. Важный момент — в Python всё является объектом, включая числа, строки и функции.

# Коротко

## Основные встроенные типы Python:

## Числовые типы:
- `int` — целые числа
- `float` — числа с плавающей точкой
- `complex` — комплексные числа
## Логические типы:
- `bool` — логические значения
## Строки:
- `str` — строки
## Коллекции:
- `list` — списки
- `tuple` — кортежи
- `set` — множества
- `dict` — словари
## Специальные типы:
- `NoneType` — `None`
- bytes — байтовые строки

# Что важно помнить

Тип принадлежит объекту, а не переменной:

```python
x = 10
x = "hello"
```

x сначала ссылается на int, затем на str.

Проверить тип можно через:
```python
type(x)
```
