# 🧊 frozendict в Python

## 🎤 Короткий ответ

`frozendict` — неизменяемый аналог словаря `dict`. После создания нельзя добавлять, удалять или изменять элементы.

В стандартной библиотеке Python полноценного `frozendict` нет. Ближайшая альтернатива — `MappingProxyType` из модуля `types`.

Некоторые реализации `frozendict` поддерживают хеширование, поэтому их можно использовать как ключи других словарей или элементы множеств.

## 🗣️ Ответ на собеседовании

Обычный словарь `dict` является изменяемой коллекцией: после создания можно добавлять ключи, удалять их и менять значения.

`frozendict` решает задачу неизменяемого словаря. Он позволяет создать структуру данных, содержимое которой нельзя изменить после создания. Это полезно для хранения конфигураций, передачи данных между компонентами и создания хешируемых структур.

Важно понимать, что неизменяемость самого контейнера не обязательно означает неизменяемость вложенных объектов. Например, если внутри находится список, его содержимое всё ещё может изменяться.

В стандартной библиотеке есть `MappingProxyType` — read-only представление словаря. Однако оно отличается от `frozendict`: если изменить исходный словарь, изменения будут видны через proxy.

## 📚 Разбор поглубже

### 1. Что такое frozendict

Обычный `dict` позволяет изменять данные:

```python
user = {
    "name": "Ilya",
    "age": 31
}

user["age"] = 32
user["city"] = "Moscow"
```

`frozendict` запрещает изменение содержимого:

```python
from frozendict import frozendict

user = frozendict({
    "name": "Ilya",
    "age": 31
})

user["age"] = 32  # TypeError
```

Здесь используется сторонняя библиотека `frozendict`.

### 2. Установка

```bash

```

Импорт:

```python
from frozendict import frozendict
```

### 3. Сравнение dict и frozendict

| Характеристика | dict | frozendict |
|---|---|---|
| Изменение значений | Да | Нет |
| Добавление ключей | Да | Нет |
| Удаление ключей | Да | Нет |
| Доступ по ключу | Да | Да |
| Итерация | Да | Да |
| Хеширование | Нет | Зависит от реализации и содержимого |
| Использование как ключа другого dict | Нет | Возможно, если хешируемый |

### 4. frozendict и хеширование

Обычный словарь нельзя использовать как ключ другого словаря, потому что `dict` не является хешируемым:

```python
data = {
    {"name": "Ilya"}: "value"
}
```

Результат:

```text
TypeError: unhashable type: 'dict'
```

Некоторые реализации `frozendict` поддерживают хеширование:

```python
from frozendict import frozendict

config = frozendict({
    "host": "localhost",
    "port": 8000
})

cache = {
    config: "database_config"
}
```

Это возможно, если все значения внутри словаря тоже хешируемы.

### 5. MappingProxyType — встроенная альтернатива

В стандартной библиотеке Python есть `MappingProxyType` из модуля `types`.

Он предоставляет доступ к словарю только для чтения:

```python
from types import MappingProxyType

settings = {
    "host": "localhost",
    "port": 8000
}

readonly_settings = MappingProxyType(settings)

print(readonly_settings["host"])

readonly_settings["port"] = 9000  # TypeError
```

Но есть важный нюанс:

```python
settings["port"] = 9000

print(readonly_settings["port"])
# 9000
```

Почему так происходит?

`MappingProxyType` не создаёт независимую копию словаря. Он предоставляет read-only представление исходного объекта и отражает изменения оригинала.

| Свойство | frozendict | MappingProxyType |
|---|---|---|
| Встроен в Python | Нет | Да |
| Запрещает изменение через себя | Да | Да |
| Отражает изменения исходного dict | Обычно нет | Да |
| Может быть хешируемым | В некоторых реализациях | Нет |
| Основная задача | Неизменяемый словарь | Read-only представление |

### 6. Поверхностная и глубокая неизменяемость

Неизменяемость контейнера не означает, что все вложенные объекты тоже неизменяемы.

Пример:

```python
from frozendict import frozendict

data = frozendict({
    "name": "Ilya",
    "skills": ["Python", "SQL"]
})

data["name"] = "Alex"  # Ошибка

data["skills"].append("Docker")  # Допустимо
```

Сам словарь изменить нельзя, но вложенный список остаётся изменяемым.

Это называется:

- **Shallow immutability** — поверхностная неизменяемость контейнера.
- **Deep immutability** — глубокая неизменяемость, при которой вложенные объекты также неизменяемы.

### 7. Когда использовать frozendict

- Для хранения конфигураций, которые не должны случайно изменяться.
- Для передачи неизменяемых данных между компонентами.
- Для создания хешируемых структур данных.
- Для кэширования по составным ключам.
- Когда важно защитить состояние объекта от изменения.

Для простых read-only конфигураций часто достаточно `MappingProxyType`. Если нужна самостоятельная неизменяемая структура с возможностью хеширования, можно использовать `frozendict`.

### 8. Типичные ошибки

**Ошибка 1. Считать frozendict встроенным типом Python.**

Полноценного встроенного `frozendict` нет. Есть сторонние реализации и `MappingProxyType` в стандартной библиотеке.

**Ошибка 2. Считать неизменяемость глубокой.**

Вложенные списки и словари могут оставаться изменяемыми.

**Ошибка 3. Путать frozendict и MappingProxyType.**

`MappingProxyType` отражает изменения исходного словаря, поскольку является его read-only представлением.

**Ошибка 4. Считать любой frozendict хешируемым.**

Хеширование зависит от конкретной реализации и хешируемости вложенных значений.

## 🎤 Вопросы на собеседовании

**1. Чем frozendict отличается от dict?**

`dict` изменяемый, а `frozendict` запрещает изменение содержимого после создания.

**2. Есть ли frozendict в стандартной библиотеке Python?**

Нет полноценного встроенного типа. Ближайшая альтернатива — `MappingProxyType` из модуля `types`.

**3. Можно ли использовать frozendict как ключ другого словаря?**

Да, если конкретная реализация поддерживает хеширование и все значения внутри объекта хешируемы.

**4. Что такое поверхностная неизменяемость?**

Это когда нельзя изменить сам контейнер, но можно изменить вложенные изменяемые объекты.

**5. Чем MappingProxyType отличается от frozendict?**

`MappingProxyType` — read-only представление исходного словаря. `frozendict` обычно представляет самостоятельную неизменяемую структуру.
