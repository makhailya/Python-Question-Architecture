# `float` — числа с плавающей точкой

## 🎯 Ответ на собеседовании

> **`float` — встроенный тип Python для представления чисел с плавающей точкой, то есть дробных чисел. В CPython обычно реализован на основе 64-битного IEEE 754 double precision. `float` является immutable-типом и имеет ограниченную точность, поэтому некоторые десятичные значения нельзя представить в памяти абсолютно точно.**

### Если спросят про `immutable`

> **`float` — неизменяемый тип. При изменении значения создаётся новый объект, а не изменяется существующий.**

### Если спросят про точность

> **`float` имеет ограниченную точность, потому что обычно хранится в формате IEEE 754 double precision. Поэтому операции с некоторыми дробными числами могут давать неожиданный результат из-за ошибок представления.**

Например:

```python
0.1 + 0.2
# 0.30000000000000004
```

# Коротко

`float` используется для хранения **чисел с плавающей точкой**:

```python
price = 99.99
temperature = -10.5
pi = 3.14159
```

Тип:

```python
type(3.14)
# <class 'float'>
```

# Создание `float`

### Обычная запись

```python
x = 3.14
```

### Через `float()`

```python
x = float(10)

print(x)
# 10.0
```

Из строки:

```python
x = float("3.14")

print(x)
# 3.14
```

---

# `int` → `float`

```python
x = 10

y = float(x)

print(y)
# 10.0
```

Обратное преобразование:

```python
x = 3.99

y = int(x)

print(y)
# 3
```

Важно: `int()` **отбрасывает дробную часть**, а не округляет число.

```python
int(3.99)   # 3
int(-3.99)  # -3
```

# Главная особенность — неточная арифметика

Одна из самых популярных тем на собеседованиях.

```python
print(0.1 + 0.2)
```

Результат:

```text
0.30000000000000004
```

Почему?

Компьютер хранит числа в **двоичной системе**, а некоторые десятичные дроби невозможно представить в ней точно.

Например, `0.1` в двоичной системе имеет бесконечное представление.

Python хранит ближайшее возможное значение.

Поэтому:

```python
0.1 + 0.2 == 0.3
```

получится:

```python
False
```

---

# Как правильно сравнивать `float`

Для приблизительного сравнения используют `math.isclose()`:

```python
import math

print(math.isclose(0.1 + 0.2, 0.3))
# True
```

Можно задать допустимую погрешность:

```python
math.isclose(
    0.1 + 0.2,
    0.3,
    rel_tol=1e-9
)
```

# IEEE 754

В CPython `float` обычно представляет собой **64-битное число IEEE 754 double precision**.

Упрощённо число состоит из:

```text
┌────────┬───────────────┬─────────────────────────────┐
│  знак  │   exponent    │          fraction           │
└────────┴───────────────┴─────────────────────────────┘
   1 бит      11 бит                  52 бита
```

Всего:

```text
1 + 11 + 52 = 64 бита
```

Это позволяет хранить очень большие и очень маленькие значения, но точность остаётся ограниченной.

---

# Ограниченная точность

`float` имеет примерно **15–17 значащих десятичных цифр** точности.

Например:

```python
x = 1.1234567890123456789

print(x)
```

Часть цифр будет потеряна из-за ограниченной точности.

# Очень большие и маленькие числа

`float` поддерживает специальные значения:

```python
float("inf")
```

Получим:

```text
inf
```

Также:

```python
float("-inf")
```

И специальное значение:

```python
float("nan")
```

# `NaN`

`NaN` означает:

> **Not a Number**

```python
x = float("nan")
```

Интересная особенность:

```python
x == x
# False
```

Даже с самим собой `NaN` не равен.

Проверять его можно так:

```python
import math

math.isnan(x)
# True
```

---

# Infinity

Можно получить бесконечность:

```python
x = float("inf")

print(x)
# inf
```

Например:

```python
10 < float("inf")
# True
```

Проверить:

```python
math.isinf(x)
# True
```

# `float` и деньги

Для финансовых расчётов `float` часто **не подходит**, потому что возможны ошибки представления.

Например:

```python
price = 0.1 + 0.2

print(price)
# 0.30000000000000004
```

Для точных денежных расчётов обычно используют `Decimal`:

```python
from decimal import Decimal

price = Decimal("0.1") + Decimal("0.2")

print(price)
# 0.3
```

Важно передавать строку:

```python
Decimal("0.1")
```

а не:

```python
Decimal(0.1)
```

потому что в последнем случае неточность `float` уже существует до создания `Decimal`.

---

# Округление

Для округления используется `round()`:

```python
round(3.14159, 2)
# 3.14
```

Но нужно помнить, что `round()` тоже работает с особенностями представления `float`.

Например:

```python
round(2.675, 2)
# 2.67
```

Это связано не с «ошибкой `round()`», а с тем, что `2.675` уже хранится в памяти не совсем как математическое `2.675`.

---

# Immutable

`float` — immutable:

```python
x = 10.5

x += 1
```

Python не меняет объект `10.5`.

Создаётся новый объект:

```text
x → 10.5

x += 1

x → 11.5
```

# Где используется?

`float` используется там, где нужна работа с дробными значениями:

* математические вычисления;
* физические величины;
* проценты;
* координаты;
* статистика;
* научные расчёты;
* машинное обучение;
* измерения;
* графика.

Для **финансовых расчётов**, где важна точность до копейки/цента, обычно лучше использовать `Decimal`.
