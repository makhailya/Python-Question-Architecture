# `int` — целые числа

# 🎯 Ответ на собеседовании

> **`int` — встроенный неизменяемый тип Python для представления целых чисел. Он поддерживает отрицательные и положительные значения, битовые и арифметические операции и имеет произвольную точность — размер числа ограничивается в основном доступной памятью.**

### Если спросят про `immutable`

> **`int` immutable: его значение нельзя изменить. При операции вроде `x += 1` создаётся новый объект `int`, а переменная начинает ссылаться на него.**

### Если спросят про `bool`

> **`bool` является подклассом `int`: `True` соответствует `1`, а `False` — `0`. Поэтому `isinstance(True, int)` возвращает `True`.**

### Если спросят про точность

> **В Python `int` использует произвольную точность, поэтому стандартный целочисленный тип не ограничен 32 или 64 битами.**
## Коротко

`int` — встроенный тип Python для представления **целых чисел**.

```python
age = 31
temperature = -10
count = 0
```

Числа могут быть:

* положительными;
* отрицательными;
* нулём;
* очень большими.

```python
x = 42
y = -100
z = 0
```

---

## Главное свойство — `immutable`

`int` — **неизменяемый (`immutable`) тип**.

Это означает, что после создания объекта `int` его значение изменить нельзя.

```python
x = 10

x += 5

print(x)
# 15
```

Кажется, будто `10` изменилось на `15`, но на самом деле Python создал **новый объект** `int`.

Условно:

```text
x → 10

x += 5

x → 15
```

Старый объект `10` не изменяется.

---

## Произвольная точность

В Python `int` не имеет фиксированного ограничения вроде `32-bit` или `64-bit`.

Число может быть практически любого размера — ограничение определяется доступной памятью.

```python
x = 10 ** 100

print(x)
```

Python спокойно работает с таким числом.

Поэтому в Python нет отдельного типа вроде:

```text
int32
int64
bigint
```

для обычных целых чисел — стандартный `int` поддерживает произвольную точность.

# Создание `int`

Обычный способ:

```python
x = 42
```

Из строки:

```python
x = int("42")

print(x)
# 42
```

Из `float`:

```python
x = int(3.99)

print(x)
# 3
```

Важно: `int()` **не округляет**, а отбрасывает дробную часть.

```python
int(3.99)   # 3
int(-3.99)  # -3
```

---

# Системы счисления

`int()` умеет преобразовывать числа из разных систем счисления.

```python
x = int("1010", 2)

print(x)
# 10
```

Здесь:

```text
"1010" → двоичная система
2      → основание системы
```

Также есть удобные функции:

```python
bin(10)
# '0b1010'

oct(10)
# '0o12'

hex(10)
# '0xa'
```

# Арифметические операции

```python
a = 10
b = 3
```

### Сложение

```python
a + b
# 13
```

### Вычитание

```python
a - b
# 7
```

### Умножение

```python
a * b
# 30
```

### Обычное деление

```python
a / b
# 3.3333333333333335
```

Результат всегда `float`.

### Целочисленное деление

```python
a // b
# 3
```

Результат — целая часть результата деления.

### Остаток от деления

```python
a % b
# 1
```

### Возведение в степень

```python
a ** b
# 1000
```

---

# Важное отличие `/` и `//`

```python
10 / 3
# 3.3333333333333335

10 // 3
# 3
```

`/` → обычное деление → `float`

`//` → целочисленное деление → обычно `int`

Но есть нюанс с отрицательными числами:

```python
-10 // 3
# -4
```

Python округляет результат `//` **в сторону минус бесконечности**, а не просто отбрасывает дробную часть.

# Сравнение

`int` можно сравнивать:

```python
a = 10
b = 20

a == b   # False
a != b   # True
a < b    # True
a > b    # False
a <= b   # True
a >= b   # False
```

# Логические значения

`bool` является подклассом `int`.

```python
print(isinstance(True, int))
# True

print(isinstance(False, int))
# True
```

Фактически:

```python
True  == 1
False == 0
```

Например:

```python
True + True
# 2

False + 10
# 10
```

Это часто спрашивают на собеседованиях.

---

# `int` и `bool`

Хотя `bool` является подклассом `int`, логически это разные типы:

```python
type(True)
# <class 'bool'>

type(1)
# <class 'int'>
```

То есть:

```python
type(True) == int
# False
```

Но:

```python
isinstance(True, int)
# True
```

# Методы `int`

У `int` есть несколько полезных методов.

Например:

```python
x = 10

x.bit_length()
# 4
```

`bit_length()` показывает, сколько бит необходимо для представления числа без учёта знака.

```python
10
```

в двоичной системе:

```text
1010
```

Поэтому:

```python
10.bit_length()
# 4
```

---

## `to_bytes()`

Позволяет представить число в виде последовательности байтов:

```python
x = 258

data = x.to_bytes(2, byteorder="big")

print(data)
# b'\x01\x02'
```

Обратное преобразование:

```python
x = int.from_bytes(data, byteorder="big")

print(x)
# 258
```

Это используется при работе с бинарными данными и сетевыми протоколами.

`int` поддерживает битовые операции:

```python
a = 5      # 101
```


### OR

```python
a | b

```

### XOR

```python

```

### NOT

```python
~a

```

```python

```

Битовые операции часто используются при работе с флагами, масками, протоколами и низкоуровневыми данными.

# `int` и память

Важно понимать:

```python
x = 100
```

`x` — это **не просто область памяти с числом 100**.

В Python `int` является полноценным объектом.

У него есть:

* тип;
* значение;
* служебная информация;
* методы.

Переменная `x` фактически **ссылается на объект** `int`.

# Малые целые числа и кеширование

CPython кеширует определённый диапазон небольших целых чисел.

Поэтому иногда можно увидеть:

```python
a = 10
b = 10

a is b
# True
```

Но не стоит использовать `is` для сравнения чисел.

Правильно:

```python
a == b
```

`is` проверяет **идентичность объектов**, а `==` — **равенство значений**.

# `int` vs `float`

|                       | `int` | `float`    |
| --------------------- | ----- | ---------- |
| Целые числа           | ✅     | ❌          |
| Дробные числа         | ❌     | ✅          |
| Immutable             | ✅     | ✅          |

# Особенности преобразования

```python
int("123")
# 123
```

Но:

```python
int("12.5")
```

даст:

```text
ValueError
```

Сначала нужно преобразовать в `float`:

```python
int(float("12.5"))
# 12
```
