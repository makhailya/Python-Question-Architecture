# ⚙️ Процесс (Process)

## 🎯 Ответ на собеседовании

**Процесс** — это экземпляр выполняющейся программы, которому операционная система выделяет **собственное виртуальное адресное пространство и системные ресурсы**.

Например, когда мы запускаем Python-программу:

```bash
python app.py
```

ОС создаёт процесс Python.

---

## 📌 Что есть у процесса

Процесс имеет собственные:

* 🧠 адресное пространство;
* 📦 память;
* 🔢 идентификатор (**PID**);
* 📂 открытые файлы и другие ресурсы;
* ⚙️ состояние выполнения;
* 🧵 один или несколько потоков.

Упрощённо:

```text
Process
│
├── Memory
├── Resources
├── PID
└── Threads
    ├── Thread 1
    ├── Thread 2
    └── Thread 3
```

---

## 🧠 Память процессов изолирована

Два процесса не используют одну и ту же обычную память:

```text
Process A                Process B
┌─────────────┐          ┌─────────────┐
│ counter = 10│          │ counter = 20│
│             │          │             │
└─────────────┘          └─────────────┘
      ↑                        ↑
 отдельная память        отдельная память
```

Если процесс A изменит `counter`, значение в процессе B автоматически не изменится.

Для обмена данными используются механизмы **IPC (Inter-Process Communication)**:

* `Queue`;
* `Pipe`;
* shared memory;
* `Manager`;
* сокеты;
* файлы;
* БД и т.д.

---

## 🧵 Процесс и поток

**Процесс** — контейнер ресурсов и памяти.

**Поток** — единица выполнения внутри процесса.

```text
Process
│
├── Thread 1
├── Thread 2
└── Thread 3
```

Потоки одного процесса:

```text
Process
┌─────────────────────────────┐
│        общая память         │
│                             │
│ Thread 1  Thread 2  Thread 3│
└─────────────────────────────┘
```

А разные процессы:

```text
Process A              Process B
┌────────────┐         ┌────────────┐
│ Memory A   │         │ Memory B   │
│ Threads    │         │ Threads    │
└────────────┘         └────────────┘
```

---

## ⚡ Процессы и CPU

Несколько процессов могут реально выполняться **параллельно на разных ядрах CPU**:

```text
Core 1 → Process A
Core 2 → Process B
Core 3 → Process C
Core 4 → Process D
```

Поэтому процессы хорошо подходят для **CPU-bound** задач.

---

## 🐍 Процесс в Python

Для создания процессов используется `multiprocessing`:

```python
from multiprocessing import Process


def worker():
    print("Работа процесса")


p = Process(target=worker)

p.start()
p.join()
```

* `start()` — запускает процесс;
* `join()` — ждёт его завершения.

---

## 🔐 Процессы и GIL

В обычном **GIL-enabled CPython** каждый процесс имеет свой Python-интерпретатор и свой GIL.

Поэтому:

```text
Process 1 → GIL 1 → CPU Core 1
Process 2 → GIL 2 → CPU Core 2
Process 3 → GIL 3 → CPU Core 3
```

Это позволяет нескольким процессам выполнять Python-код **параллельно на разных ядрах**.

Именно поэтому `multiprocessing` часто используют для CPU-bound задач.

---

## ⚠️ Недостатки процессов

По сравнению с потоками процессы:

* тяжелее;
* потребляют больше памяти;
* дороже создаются;
* требуют IPC для обмена данными;
* сложнее в управлении.

Поэтому создавать отдельный процесс для каждой маленькой задачи обычно неэффективно.

---

## 🆚 Процесс vs поток

|               | Процесс                        | Поток                               |
| ------------- | ------------------------------ | ----------------------------------- |
| Память        | Раздельная                     | Общая                               |
| Изоляция      | 🟢 Высокая                     | 🔴 Низкая                           |
| Создание      | Дороже                         | Дешевле                             |
| Обмен данными | IPC                            | Общая память                        |
| GIL           | Отдельный для каждого процесса | Общий внутри процесса               |
| CPU-bound     | 🟢 Хорошо                      | ⚠️ Ограничено GIL в обычном CPython |
| I/O-bound     | 🟡 Можно                       | 🟢 Хорошо                           |

---

## 🧠 Главное

```text
Программа
    ↓ запуск
Процесс
    ↓
имеет собственную память
    ↓
содержит один или несколько потоков
```

Процессы **изолированы друг от друга**, но могут выполняться параллельно на разных ядрах CPU.

### 🎤 Суперкоротко

> **Процесс — это выполняющийся экземпляр программы с собственным адресным пространством и ресурсами. Процессы изолированы друг от друга, могут иметь несколько потоков и способны выполняться параллельно на разных ядрах. В Python для работы с процессами используется `multiprocessing`, который часто применяют для CPU-bound задач.**
