# 🤖 Machine Learning (ML) — машинное обучение

## 🎤 Короткий ответ для собеседования

**Machine Learning (ML)** — это область искусственного интеллекта, в которой алгоритмы обучаются на данных, выявляют закономерности и используют их для прогнозирования или принятия решений без явного программирования каждого правила.

Например, модель может обучиться определять спам, прогнозировать стоимость квартиры или рекомендовать товары.

Основные виды машинного обучения:

- **[[Supervised Learning — обучение с учителем]]** 
- **[[Unsupervised Learning — обучение без учителя]]** 
- **[[Reinforcement Learning (RL) — обучение с подкреплением]]** — обучение с подкреплением.

## 🗣️ Ответ на собеседовании

Машинное обучение — это подход, при котором мы не прописываем все правила вручную, а обучаем модель на данных.

Например, если нужно определять спам, мы собираем письма с метками «спам» и «не спам», разделяем данные на обучающую и тестовую выборки и обучаем алгоритм находить закономерности.

После обучения модель может классифицировать новые письма, которых раньше не видела.

В Python для классического машинного обучения часто используют Scikit-learn, а для нейросетей — PyTorch или TensorFlow.

## 🧩 Основные виды машинного обучения

| Вид | Как работает | Пример |
|---|---|---|
| Supervised | Обучается на данных с правильными ответами | Определение спама |
| Unsupervised | Ищет структуру в данных без готовых ответов | Сегментация клиентов |
| Reinforcement | Обучается через действия и вознаграждения | Управление игровым агентом |

### Supervised Learning

Два распространённых типа задач:

- **Classification** — предсказание категории: спам или не спам.
- **Regression** — предсказание числового значения: цена квартиры.

### Unsupervised Learning

Например, кластеризация пользователей по похожему поведению без заранее заданных категорий.

### Reinforcement Learning

Агент взаимодействует со средой, получает вознаграждения и обучается выбирать действия, увеличивающие ожидаемую суммарную награду.

## 🔑 Основные понятия ML

| Термин | Значение |
|---|---|
| Dataset | Набор данных |
| Feature | Признак объекта |
| Label / Target | Правильный ответ или целевая переменная |
| Model | Обучаемая математическая модель |
| Training | Процесс обучения |
| Inference | Использование обученной модели |
| Loss Function | Функция ошибки |
| Overfitting | Переобучение |
| Underfitting | Недообучение |
| Hyperparameters | Настройки алгоритма обучения |

### Overfitting — переобучение

Модель слишком хорошо запомнила обучающие данные, но плохо работает на новых.

### Underfitting — недообучение

Модель недостаточно хорошо выявила закономерности и допускает много ошибок даже на обучающих данных.

**Главная цель:** добиться хорошего качества на новых, ранее не встречавшихся данных.

## 🐍 Пример Machine Learning на Python

Используем Scikit-learn для простой классификации.

```python
from sklearn.tree import DecisionTreeClassifier

# Данные: [количество часов подготовки]
X = [[1], [2], [3], [5], [7], [9]]

# Результат: 0 — не сдал, 1 — сдал
y = [0, 0, 0, 1, 1, 1]

# Создаём модель
model = DecisionTreeClassifier(random_state=42)

# Обучаем модель
model.fit(X, y)

# Получаем прогноз
result = model.predict([[6]])

print(result[0])
```

### Разбор

1. `X` — признаки, по которым модель обучается.
2. `y` — известные правильные ответы.
3. `DecisionTreeClassifier()` — алгоритм классификации на основе дерева решений.
4. `fit(X, y)` — обучение модели.
5. `predict([[6]])` — прогноз для нового значения.
6. `result[0]` — предсказанная категория.

Это учебный пример с искусственными данными. В реальном проекте необходимо оценивать качество на отдельной выборке и учитывать дополнительные признаки.

## 📊 Как оценивают качество модели

| Метрика | Назначение |
|---|---|
| Accuracy | Доля правильных классификаций |
| Precision | Доля правильных положительных прогнозов среди предсказанных положительных |
| Recall | Доля найденных положительных объектов |
| F1-score | Гармоническое среднее Precision и Recall |
| MAE | Средняя абсолютная ошибка регрессии |
| RMSE | Корень из средней квадратичной ошибки |

Например, при обнаружении мошеннических операций важно учитывать не только общую точность, но и количество пропущенных случаев мошенничества.

## ⚖️ Machine Learning vs Deep Learning vs LLM

| Технология | Особенность |
|---|---|
| Machine Learning | Общая область обучения моделей на данных |
| Deep Learning | ML с использованием многослойных нейронных сетей |
| LLM | Большие нейросетевые модели для обработки и генерации языка |

**Важно:** не каждое ML-решение требует нейронной сети или LLM.

Для табличных данных нередко достаточно логистической регрессии, случайного леса или градиентного бустинга.

## ❓ Частые вопросы на собеседовании

**1. Что такое Machine Learning?**

Обучение моделей на данных для выявления закономерностей и построения прогнозов.

**2. Чем ML отличается от обычного программирования?**

В обычном программировании правила задаёт разработчик. В ML параметры модели подбираются в процессе обучения на данных.

**3. Что такое Training и Inference?**

Training — обучение модели. Inference — применение обученной модели к новым данным.

**4. Что такое Feature?**

Признак объекта, который используется моделью для предсказания.

**5. Чем Classification отличается от Regression?**

Classification предсказывает категорию, Regression — числовое значение.

**6. Что такое Overfitting?**

Переобучение, когда модель хорошо работает на обучающих данных, но плохо обобщает на новые.

**7. Зачем разделять данные на Train, Validation и Test?**

Train — обучение, Validation — подбор модели и гиперпараметров, Test — итоговая независимая оценка качества.

**8. Какие библиотеки используются в Python?**

Scikit-learn, PyTorch, TensorFlow, Pandas и NumPy.

**9. Как ML связан с Backend?**

Backend может загружать обученную модель, принимать данные через API, запускать inference и возвращать прогноз клиенту.

**10. Нужно ли Backend-разработчику обучать модели?**

Не всегда. Часто задача Backend-разработчика — интегрировать готовую модель, организовать API, обработку запросов, масштабирование и мониторинг.
