# 🧠 Deep Learning (DL) — глубокое обучение

## 🎤 Короткий ответ для собеседования

**Deep Learning (глубокое обучение)** — это подраздел Machine Learning, основанный на использовании многослойных искусственных нейронных сетей.

Нейросети обучаются на данных, автоматически выявляя сложные закономерности и формируя внутренние представления признаков.

Deep Learning применяется в:

- **[[LLM (Large Language Model)]]** — больших языковых моделях.
- **[[NLP (Natural Language Processing) — обработка естественного языка]]** 
- **[[Computer Vision (CV) — компьютерное зрение]]** — распознавании изображений.
- **[[Speech Recognition (ASR) — распознавание речи]]** 
- **[[Generative AI (GenAI) — генеративный искусственный интеллект]]** — генерации текста, изображений и аудио.

## 🗣️ Ответ на собеседовании

Deep Learning — это направление машинного обучения, которое использует многослойные нейронные сети.

В отличие от многих классических ML-алгоритмов, глубокие нейросети могут самостоятельно извлекать сложные признаки из исходных данных.

Например, при распознавании изображений первые слои могут выделять простые элементы, такие как границы, а последующие — более сложные структуры.

Модель обучается с помощью функции потерь, обратного распространения ошибки и оптимизатора, который корректирует веса нейронной сети.

На Deep Learning основаны современные LLM, включая модели архитектуры Transformer.

## ⚙️ Как работает нейронная сеть

```text
      Входные данные
            |
            v
      Input Layer
            |
            v
      Hidden Layer 1
            |
            v
      Hidden Layer 2
            |
            v
      Hidden Layer 3
            |
            v
      Output Layer
            |
            v
        Результат
```

Нейронная сеть состоит из слоёв, содержащих искусственные нейроны.

Каждый нейрон получает входные значения, умножает их на веса, добавляет смещение и применяет функцию активации.

Упрощённая формула нейрона:

\[
y = f(w_1x_1 + w_2x_2 + b)
\]

Где:

- `x` — входные данные.
- `w` — веса нейрона.
- `b` — смещение (bias).
- `f` — функция активации.
- `y` — результат.

**Главная задача обучения — подобрать веса и смещения так, чтобы модель допускала меньше ошибок.**

## 🔄 Как обучается Deep Learning-модель

```text
       Данные
          |
          v
   Forward Pass
   Прямой проход
          |
          v
     Prediction
      Прогноз
          |
          v
    Loss Function
   Расчёт ошибки
          |
          v
   Backpropagation
   Расчёт градиентов
          |
          v
      Optimizer
  Обновление весов
          |
          └──► Повторение
```

### Основные этапы

1. **Forward Pass** — данные проходят через нейросеть, формируется прогноз.
2. **Loss Function** — вычисляется ошибка прогноза.
3. **Backpropagation** — рассчитываются градиенты ошибки по параметрам сети.
4. **Optimizer** — обновляет веса, используя градиенты.
5. **Epoch** — один полный проход по обучающей выборке.

Цикл повторяется до завершения обучения.

### Transformer

**Transformer** — архитектура нейронной сети, основанная на механизме Attention.

Attention позволяет модели учитывать связи между элементами последовательности.

Большинство современных LLM используют архитектуры на основе Transformer.

## 🐍 Пример нейросети на Python

Используем PyTorch для создания простой нейронной сети.

```python
import torch
from torch import nn

# Создаём нейронную сеть
model = nn.Sequential(
    nn.Linear(2, 8),
    nn.ReLU(),
    nn.Linear(8, 1),
    nn.Sigmoid(),
)

# Входные данные
x = torch.tensor([[0.5, 0.8]])

# Получаем результат
prediction = model(x)

print(prediction)
```

### Разбор

1. `torch` — библиотека для работы с тензорами и нейросетями.
2. `nn.Sequential()` — объединяет слои в последовательную модель.
3. `nn.Linear(2, 8)` — слой с двумя входами и восемью выходами.
4. `nn.ReLU()` — нелинейная функция активации.
5. `nn.Linear(8, 1)` — преобразует восемь значений в одно.
6. `nn.Sigmoid()` — ограничивает результат диапазоном от 0 до 1.
7. `torch.tensor()` — создаёт тензор входных данных.
8. `model(x)` — выполняет прямой проход через нейросеть.

**Важно:** здесь показана только архитектура и выполнение Forward Pass. Модель ещё не обучена, поэтому результат не является осмысленным прогнозом.

## ⚖️ Machine Learning vs Deep Learning

| Критерий | Machine Learning | Deep Learning |
|---|---|---|
| Основа | Разные алгоритмы | Глубокие нейронные сети |
| Признаки | Часто создаются вручную | Могут извлекаться автоматически |
| Объём данных | Иногда достаточно небольших наборов | Часто нужны большие наборы |
| Вычисления | Обычно менее требовательны | Часто требуется GPU |
| Примеры | Random Forest, XGBoost | CNN, Transformer |
| Интерпретируемость | Зависит от алгоритма | Часто сложнее |

Deep Learning не всегда лучше классического ML. Для небольших табличных данных алгоритмы вроде градиентного бустинга могут оказаться эффективнее.

## ❓ Частые вопросы на собеседовании

**1. Что такое Deep Learning?**

Подраздел Machine Learning, использующий многослойные нейронные сети.

**2. Чем Deep Learning отличается от Machine Learning?**

Deep Learning — частный случай ML, основанный на глубоких нейросетях.

**3. Что такое нейронная сеть?**

Математическая модель из связанных вычислительных элементов с обучаемыми параметрами.

**4. Что такое Forward Pass?**

Прохождение входных данных через нейросеть для получения результата.

**5. Что такое Backpropagation?**

Алгоритм вычисления градиентов функции ошибки по параметрам нейросети.

**6. Что такое Loss Function?**

Функция, оценивающая ошибку предсказания модели.

**7. Что такое Epoch?**

Один полный проход по обучающей выборке.

**8. Зачем нужен GPU?**

GPU ускоряет параллельные математические операции, особенно умножение матриц.

**9. Что такое Transformer?**

Архитектура нейронной сети, использующая Attention для обработки зависимостей между элементами данных.

**10. Как Deep Learning связан с LLM?**

LLM — большие языковые модели, построенные на глубоких нейронных сетях, преимущественно архитектуры Transformer.
