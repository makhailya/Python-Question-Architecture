# 🤖 AI (Artificial Intelligence) — искусственный интеллект

## 🎤 Короткий ответ для собеседования

**AI (Artificial Intelligence)** — это область информатики, занимающаяся созданием систем, способных выполнять задачи, которые обычно требуют человеческого интеллекта.

Например: распознавание речи, анализ изображений, понимание текста, прогнозирование и принятие решений.

Основные направления:

- **[[Machine Learning (ML) — машинное обучение]]  — машинное обучение.
- **Deep Learning (DL)** — глубокое обучение.
- **Natural Language Processing (NLP)** — обработка естественного языка.
- **Computer Vision (CV)** — компьютерное зрение.
- **Generative AI** — генерация текста, изображений, аудио и других данных.

## 🗣️ Ответ на собеседовании

AI — это искусственный интеллект, то есть технологии, позволяющие компьютерным системам решать задачи, связанные с анализом информации, распознаванием закономерностей и принятием решений.

Одно из основных направлений AI — Machine Learning, где модели обучаются на данных.

Внутри ML существует Deep Learning, использующий многослойные нейронные сети. На таких сетях построены современные большие языковые модели, например GPT.

Как Python Backend-разработчик, я могу интегрировать AI-модели через API, организовать обработку запросов, реализовать RAG, подключить векторную базу данных и обеспечить мониторинг работы модели.

## 🐍 Пример AI-интеграции на Python

Пример обращения к локальной LLM через Ollama.

```python
import requests

# Адрес локального API
url = "http://localhost:11434/api/generate"

# Параметры запроса
payload = {
    "model": "gemma3:1b",
    "prompt": "Что такое Python?",
    "stream": False,
}

# Отправляем запрос модели
response = requests.post(
    url,
    json=payload,
    timeout=60,
)

# Проверяем HTTP-статус
response.raise_for_status()

# Получаем ответ
result = response.json()

print(result["response"])
```

### Разбор

1. `requests` — библиотека для HTTP-запросов.
2. `url` — адрес локального Ollama API.
3. `model` — название установленной модели.
4. `prompt` — текст запроса.
5. `stream=False` — получение ответа целиком.
6. `requests.post()` — отправка запроса.
7. `raise_for_status()` — проверка HTTP-ошибок.
8. `response.json()` — преобразование JSON в Python-словарь.
9. `result["response"]` — текст ответа модели.

Для работы примера Ollama должен быть запущен, а указанная модель — установлена.

## ⚖️ AI vs ML vs DL vs LLM

| Термин | Что означает |
|---|---|
| AI | Вся область искусственного интеллекта |
| ML | Методы обучения на данных |
| DL | Подраздел ML с глубокими нейросетями |
| LLM | Большая языковая модель, обычно основанная на Transformer |

**Запомнить:** не весь AI использует ML, не весь ML использует нейросети, и не каждая нейросеть является LLM.

## ❓ Частые вопросы на собеседовании

**1. Что такое AI?**

Область информатики, занимающаяся созданием систем, способных выполнять интеллектуальные задачи.

**2. Чем AI отличается от ML?**

AI — широкая область, а ML — одно из её направлений, основанное на обучении моделей на данных.

**3. Что такое Deep Learning?**

Подраздел ML, использующий многослойные нейронные сети.

**4. Что такое LLM?**

Большая языковая модель, обученная обрабатывать и генерировать текст.

**5. Что такое Generative AI?**

Генеративный AI — модели, способные создавать новый контент, например текст, изображения и аудио.

**6. Что такое RAG?**

Retrieval-Augmented Generation — подход, при котором перед генерацией ответа система получает релевантную информацию из внешних источников.

**7. Что такое Embeddings?**

Числовые векторы, представляющие смысловые или другие характеристики данных.

**8. Что такое AI Agent?**

Система, которая использует AI-модель для выбора действий и выполнения задач, часто с помощью внешних инструментов.

**9. Что такое Inference?**

Процесс применения обученной модели для получения результата на новых входных данных.

**10. Как AI интегрируется с FastAPI?**

Backend принимает HTTP-запрос, подготавливает данные, обращается к модели через API и возвращает результат клиенту.
