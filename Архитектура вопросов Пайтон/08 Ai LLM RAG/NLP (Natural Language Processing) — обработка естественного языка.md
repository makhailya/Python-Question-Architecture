# 🧠 NLP (Natural Language Processing) — обработка естественного языка

## 🎤 Короткий ответ для собеседования

**NLP (Natural Language Processing)** — это направление искусственного интеллекта, занимающееся обработкой, анализом, пониманием и генерацией человеческого языка.

NLP используется в чат-ботах, переводчиках, поисковых системах, голосовых помощниках и LLM.

Основные задачи:

- **Text Classification** — классификация текста.
- **NER** — распознавание именованных сущностей.
- **Sentiment Analysis** — анализ тональности.
- **Machine Translation** — машинный перевод.
- **Text Summarization** — суммаризация текста.
- **Text Generation** — генерация текста.

## 🗣️ Ответ на собеседовании

NLP — это область искусственного интеллекта, которая позволяет компьютерным системам работать с человеческим языком.

Например, определять тональность сообщений, извлекать из текста имена и организации, переводить тексты или отвечать на вопросы.

Раньше для NLP широко использовали статистические методы и классическое машинное обучение. Сейчас многие задачи решаются нейронными сетями, особенно архитектурой Transformer.

Большие языковые модели, такие как GPT, являются одним из современных инструментов NLP.

## ⚙️ Как работает NLP

Упрощённый процесс обработки текста:

```text
        Исходный текст
              |
              v
         Tokenization
      Разбиение на токены
              |
              v
       Представление текста
       (TF-IDF / Embeddings)
              |
              v
          NLP-модель
              |
              v
       Анализ или генерация
              |
              v
           Результат
```

Например:

```text
Вход:
"Доставка задержалась, я недоволен"

             |
             v
      Sentiment Analysis
             |
             v
Результат:
Negative
```

Конкретные этапы зависят от выбранного алгоритма. Современные Transformer-модели часто обрабатывают токены непосредственно через обучаемые векторные представления.

## 🔑 Основные понятия NLP

| Термин | Значение |
|---|---|
| Tokenization | Разбиение текста на токены |
| Token | Единица текста |
| Lemmatization | Приведение слова к начальной форме |
| Stemming | Выделение основы слова |
| Stop Words | Часто встречающиеся служебные слова |
| TF-IDF | Числовое представление важности слов |
| Embeddings | Векторные представления текста |
| NER | Извлечение именованных сущностей |
| Transformer | Нейросетевая архитектура с Attention |
| Attention | Механизм учёта связей между элементами |

### Tokenization

Разбиение текста на отдельные элементы.

```text
"Я изучаю Python"

        ↓

["Я", "изучаю", "Python"]
```

Это пример разбиения по словам. Токенизаторы LLM могут делить текст иначе.

### Lemmatization

Приведение слов к нормальной форме:

```text
"машины" → "машина"
"бежал"  → "бежать"
```

### Embeddings

Преобразование текста в числовой вектор, отражающий его характеристики и смысловые связи.

```text
"Купить автомобиль"
        |
        v
 [0.12, -0.45, 0.87, ...]
```

Такие векторы применяются в семантическом поиске и RAG.

## 🐍 Пример NLP на Python

Простая классификация текста с помощью Scikit-learn.

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline

# Обучающие тексты
texts = [
    "Отличный сервис",
    "Очень понравилось",
    "Ужасное обслуживание",
    "Совсем не понравилось",
]

# Метки тональности
labels = [1, 1, 0, 0]

# Создаём NLP-модель
model = make_pipeline(
    TfidfVectorizer(),
    MultinomialNB(),
)

# Обучаем модель
model.fit(texts, labels)

# Получаем прогноз
result = model.predict(["Отличное обслуживание"])

print(result[0])
```

### Разбор

1. `TfidfVectorizer` — преобразует текст в числовые признаки.
2. `MultinomialNB` — алгоритм классификации.
3. `make_pipeline()` — объединяет обработку текста и классификатор.
4. `fit()` — обучает модель.
5. `predict()` — определяет категорию нового текста.
6. `1` означает положительную тональность, `0` — отрицательную.

Это учебный пример с очень маленькой выборкой. Для реального определения тональности потребуются более разнообразные данные и оценка качества.

## ⚖️ NLP vs LLM vs RAG

| Технология | Назначение |
|---|---|
| NLP | Общая область обработки человеческого языка |
| LLM | Большая языковая модель |
| RAG | Подход к генерации с использованием найденных внешних данных |
| Embeddings | Векторное представление текста |
| Transformer | Архитектура нейронной сети |

**Главное отличие:** NLP — область задач, LLM — тип модели, а RAG — архитектурный подход к использованию модели.

## ❓ Частые вопросы на собеседовании

**1. Что такое NLP?**

Направление AI, связанное с обработкой, анализом и генерацией естественного языка.

**2. Что такое Tokenization?**

Разбиение текста на токены.

**3. Что такое Lemmatization?**

Приведение слова к его начальной форме.

**4. Чем Stemming отличается от Lemmatization?**

Stemming выделяет основу слова по правилам, а Lemmatization определяет его нормальную словарную форму.

**5. Что такое NER?**

Named Entity Recognition — распознавание в тексте сущностей, например имён, организаций и географических объектов.

**6. Что такое Sentiment Analysis?**

Определение эмоциональной окраски текста, например положительной или отрицательной.

**7. Что такое Embeddings?**

Числовые векторные представления данных, позволяющие сравнивать их характеристики и смысловую близость.

**8. Как NLP связан с LLM?**

LLM используются для решения многих NLP-задач, включая генерацию, перевод и анализ текста.

**9. Какие Python-библиотеки применяются в NLP?**

NLTK, spaCy, Scikit-learn, Transformers и Sentence Transformers.

**10. Как NLP применяется в Backend?**

Через интеграцию моделей и сервисов обработки текста, например для классификации сообщений, семантического поиска и RAG.
