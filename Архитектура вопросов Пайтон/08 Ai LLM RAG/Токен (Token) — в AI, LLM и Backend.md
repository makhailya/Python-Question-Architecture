# 🔑 Токен (Token) — в AI, LLM и Backend

## 🎤 Короткий ответ для собеседования

**Токен (Token)** — это единица данных, значение которой зависит от контекста.

В IT чаще всего встречаются два значения:

- **В AI и LLM** — единица текста, которую обрабатывает языковая модель. Это может быть слово, часть слова, символ или последовательность символов.
- **В Backend и авторизации** — строка или структура данных, используемая для подтверждения прав доступа, например Access Token или JWT.

## 🗣️ Ответ на собеседовании

Если говорить про LLM, токен — это базовая единица текста, с которой работает языковая модель.

Перед обработкой текст разбивается токенизатором на токены, которые преобразуются в числовые идентификаторы.

Модель обрабатывает последовательность этих идентификаторов и генерирует новые токены.

Количество токенов влияет на размер контекстного окна, скорость генерации и стоимость использования API.

## 🤖 Токены в LLM

### Как работает токенизация

```text
Пользователь:
"Привет, мир!"
       |
       v
    Tokenizer
       |
       v
 [Токен 1, Токен 2, ...]
       |
       v
  Token IDs
       |
       v
      LLM
       |
       v
 Генерация новых токенов
       |
       v
    Готовый ответ
```

Разные модели используют разные токенизаторы, поэтому один и тот же текст может разбиваться на разное количество токенов.

### Основные понятия

| Термин | Значение |
|---|---|
| Token | Единица текста |
| Tokenizer | Алгоритм разбиения текста на токены |
| Token ID | Числовой идентификатор токена |
| Input Tokens | Токены входного запроса |
| Output Tokens | Токены ответа модели |
| Context Window | Максимальный объём контекста модели |
| Tokens/sec | Скорость генерации токенов |

### Пример

```text
Input:
"Объясни, что такое Python"

       ↓

LLM обрабатывает токены

       ↓

Output:
"Python — язык программирования..."
```

Количество токенов не равно количеству слов.

Одно слово может состоять из нескольких токенов, особенно если оно редкое или содержит необычные символы.

## ⚙️ Почему токены важны

**1. Контекстное окно**

Если модель поддерживает контекст 32 000 токенов, это означает, что она может обрабатывать ограниченное количество токенов в рамках своего контекста.

В этот лимит могут входить системные инструкции, история диалога, документы и генерируемый ответ.

**2. Скорость**

Производительность LLM часто измеряют в `tokens/sec`.

Например:

```text
Модель A: 20 tokens/sec
Модель B: 80 tokens/sec
```

При прочих равных модель B быстрее генерирует текст.

**3. Стоимость API**

Облачные провайдеры часто рассчитывают стоимость отдельно за входные и выходные токены.

## 🐍 Пример токенизации на Python

Для примера используем библиотеку `tiktoken`.

```python
import tiktoken

# Загружаем токенизатор
encoding = tiktoken.get_encoding("cl100k_base")

# Исходный текст
text = "Привет, мир!"

# Преобразуем текст в токены
tokens = encoding.encode(text)

# Выводим идентификаторы
print(tokens)

# Выводим количество токенов
print(len(tokens))
```

### Разбор

1. `tiktoken` — библиотека токенизации.
2. `get_encoding()` — выбирает конкретную схему токенизации.
3. `encode()` — преобразует строку в список числовых идентификаторов.
4. `len(tokens)` — подсчитывает количество токенов.

Этот токенизатор используется для демонстрации. У другой LLM результат может отличаться.

## 🔐 Токены в Backend

В Backend токен часто используется для аутентификации и авторизации.

Например, после входа пользователь получает Access Token.

```text
Пользователь
     |
     v
POST /login
     |
     v
Backend проверяет пароль
     |
     v
Выдаёт Access Token
     |
     v
GET /profile
Authorization: Bearer <token>
     |
     v
Backend проверяет токен
     |
     v
Возвращает данные
```

### Основные виды

| Токен | Назначение |
|---|---|
| Access Token | Доступ к защищённым ресурсам |
| Refresh Token | Получение нового Access Token |
| JWT | Формат токена с набором утверждений (claims) |
| API Token | Доступ к API |

**Важно:** JWT — это формат токена, а не механизм шифрования. Обычный подписанный JWT содержит данные, которые можно прочитать без секретного ключа. Подпись защищает от незаметного изменения содержимого.

## ❓ Частые вопросы на собеседовании

**1. Что такое токен в LLM?**

Единица текста, которую модель обрабатывает и генерирует.

**2. Токен равен слову?**

Нет. Токен может представлять слово, часть слова или отдельные символы.

**3. Что такое токенизация?**

Преобразование текста в последовательность токенов.

**4. Что такое Token ID?**

Числовой идентификатор токена в словаре токенизатора.

**5. Что такое Context Window?**

Ограничение на количество токенов, доступных модели в контексте.

**6. Что означает tokens/sec?**

Количество токенов, генерируемых моделью за секунду.

**7. Что такое Access Token?**

Токен, используемый для доступа к защищённым ресурсам.

**8. Чем Access Token отличается от Refresh Token?**

Access Token используется для обращения к API, а Refresh Token — для получения нового Access Token.

**9. Что такое JWT?**

JSON Web Token — стандартизированный формат передачи утверждений между сторонами.

**10. Чем токен LLM отличается от токена авторизации?**

В LLM токен — единица текста. В авторизации токен — средство представления доступа или полномочий.

В Backend токен — средство представления доступа или полномочий, например Access Token или JWT.
