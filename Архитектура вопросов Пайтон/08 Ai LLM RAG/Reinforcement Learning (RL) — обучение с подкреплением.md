# 🤖 Reinforcement Learning (RL) — обучение с подкреплением

## 🎤 Короткий ответ для собеседования

**Reinforcement Learning (обучение с подкреплением)** — это метод машинного обучения, при котором агент обучается принимать решения, взаимодействуя со средой и получая вознаграждение (Reward) за свои действия.

Цель агента — научиться выбирать действия, которые максимизируют ожидаемую суммарную награду за определённый период.

Основные понятия:

- **Agent** — агент, который принимает решения.
- **Environment** — среда, с которой взаимодействует агент.
- **State** — состояние среды.
- **Action** — действие агента.
- **Reward** — вознаграждение.
- **Policy** — стратегия выбора действий.

## 🗣️ Ответ на собеседовании

Reinforcement Learning — это обучение с подкреплением, при котором агент учится методом проб и ошибок.

Например, мы обучаем игрового бота. Агент наблюдает состояние игры, выбирает действие и получает вознаграждение или штраф в зависимости от результата.

Постепенно он формирует стратегию, которая позволяет получать максимальную суммарную награду.

В отличие от Supervised Learning, здесь нет готового правильного ответа для каждого действия. Агент самостоятельно исследует среду и учится на последствиях своих решений.

## ⚙️ Как работает Reinforcement Learning

```text
          ┌─────────────────┐
          │      Agent      │
          │  Принимает      │
          │  решение        │
          └────────┬────────┘
                   │
                 Action
                   │
                   ▼
          ┌─────────────────┐
          │   Environment   │
          │      Среда      │
          └────────┬────────┘
                   │
             State + Reward
                   │
                   └──────────► Agent
```

Цикл повторяется:

1. Агент получает информацию о состоянии среды.
2. Выбирает действие.
3. Среда изменяется.
4. Агент получает награду и новое состояние.
5. Обновляет стратегию на основе опыта.

## 🎮 Пример: обучение игрового бота

Представим агента, который должен пройти лабиринт.

| Действие | Вознаграждение |
|---|---:|
| Достиг выхода | +100 |
| Столкнулся с препятствием | −10 |
| Сделал обычный шаг | −1 |

Агент постепенно учится находить путь к выходу с максимальной суммарной наградой.

**Важно:** награда за отдельное действие не всегда отражает его долгосрочную пользу. Иногда агенту нужно временно получить отрицательную награду, чтобы в дальнейшем достичь цели.

## 🔑 Основные понятия RL

| Термин | Значение |
|---|---|
| Agent | Обучаемая система |
| Environment | Окружение агента |
| State (S) | Состояние среды |
| Action (A) | Выбранное действие |
| Reward (R) | Сигнал вознаграждения |
| Policy (π) | Стратегия выбора действий |
| Episode | Один завершённый цикл взаимодействия |
| Q-value | Оценка ожидаемой суммарной награды от действия в состоянии |
| Discount Factor (γ) | Коэффициент важности будущих наград |

### Exploration vs Exploitation

**Exploration (исследование)** — агент пробует новые действия, чтобы получить дополнительную информацию.

**Exploitation (использование опыта)** — агент выбирает действия, которые уже показали хороший результат.

Хорошая стратегия должна балансировать между исследованием и использованием накопленного опыта.

## 🧮 Q-Learning

**Q-Learning** — алгоритм обучения с подкреплением, который оценивает полезность действий в разных состояниях.

Агент хранит значения в Q-таблице:

| State | Влево | Вправо |
|---|---:|---:|
| S1 | 2 | 8 |
| S2 | 10 | 3 |
| S3 | 1 | 15 |

Чем выше Q-value, тем больше ожидаемая суммарная награда при выборе действия и последующем оптимальном поведении.

При использовании жадной стратегии агент выбирает действие с максимальным Q-value.

## 🐍 Простой пример на Python

Рассмотрим выбор действия с максимальной ожидаемой наградой.

```python
# Оценки действий в текущем состоянии
q_values = {
    "left": 2,
    "right": 8,
    "forward": 5,
}

# Выбираем действие с максимальной оценкой
best_action = max(q_values, key=q_values.get)

print(best_action)
```

### Разбор

1. `q_values` — словарь с оценками действий.
2. Ключи — возможные действия агента.
3. Значения — оценки ожидаемой награды.
4. `max()` — находит действие с наибольшим значением.
5. `key=q_values.get` — указывает сравнивать значения словаря.
6. `print()` — выводит `right`.

**Важно:** это только пример выбора действия по уже известным Q-values. Полный Q-Learning также включает взаимодействие со средой, исследование и обновление оценок.

## ⚖️ Сравнение трёх подходов ML

| Критерий | Supervised | Unsupervised | Reinforcement |
|---|---|---|---|
| Данные | С правильными ответами | Без правильных ответов | Опыт взаимодействия |
| Обратная связь | Labels | Обычно отсутствует | Rewards |
| Цель | Предсказание | Поиск структуры | Выбор оптимальных действий |
| Пример | Определение спама | Кластеризация клиентов | Игровой агент |

## 🧠 Reinforcement Learning и LLM

Обучение с подкреплением также применяется при дополнительной настройке языковых моделей.

Например, **RLHF (Reinforcement Learning from Human Feedback)** — подход, в котором человеческие предпочтения используются для формирования сигнала обучения.

Упрощённая схема:

```text
Предобученная LLM
       |
       v
Примеры ответов
       |
       v
Оценки предпочтений людей
       |
       v
Сигнал вознаграждения
       |
       v
RL-оптимизация
       |
       v
Настроенная LLM
```

RLHF — один из подходов к настройке LLM. Не все современные модели обучаются именно таким способом.

## ❓ Частые вопросы на собеседовании

**1. Что такое Reinforcement Learning?**

Обучение агента через взаимодействие со средой и получение вознаграждений.

**2. Чем RL отличается от Supervised Learning?**

В Supervised Learning модель обучается на правильных ответах, а в RL агент получает награду за действия и учится максимизировать долгосрочный результат.

**3. Что такое Agent?**

Система, которая наблюдает среду и выбирает действия.

**4. Что такое Reward?**

Числовой сигнал, показывающий результат действия с точки зрения заданной цели.

**5. Что такое Policy?**

Стратегия, определяющая выбор действий агентом в различных состояниях.

**6. Что такое Q-Learning?**

Алгоритм, который обучается оценивать ожидаемую суммарную награду действий в состояниях.

**7. Что такое Exploration и Exploitation?**

Исследование новых действий и использование уже накопленных знаний.

**8. Что такое PPO?**

Proximal Policy Optimization — алгоритм обучения с подкреплением для оптимизации стратегии агента с ограничением слишком больших изменений политики.

**9. Что такое RLHF?**

Reinforcement Learning from Human Feedback — обучение с подкреплением на основе сигнала, сформированного с использованием человеческих предпочтений.

**10. Где применяется RL?**

В робототехнике, играх, управлении ресурсами, оптимизации последовательных решений и настройке некоторых AI-моделей.
