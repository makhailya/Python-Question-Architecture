# 🤖 Generative AI (GenAI) — генеративный искусственный интеллект

## 🎤 Короткий ответ для собеседования

**Generative AI (генеративный искусственный интеллект)** — это направление AI, в котором модели обучаются на данных и способны генерировать новый контент: текст, изображения, аудио, видео и программный код.

Основные технологии:

- **LLM** — генерация и обработка текста.
- **Transformers** — архитектура многих современных генеративных моделей.
- **Diffusion Models** — генерация изображений и других данных.
- **GAN** — генеративно-состязательные нейросети.
- **RAG** — дополнение генерации внешними знаниями.

## 🗣️ Ответ на собеседовании

Generative AI — это направление искусственного интеллекта, связанное с созданием нового контента на основе закономерностей, изученных во время обучения.

Например, LLM может генерировать текст и программный код, а диффузионная модель — изображения.

В Backend-разработке генеративный AI часто интегрируют через API. Например, можно построить RAG-систему, которая ищет релевантные документы, передаёт их в LLM и формирует ответ на вопрос пользователя.

При этом важно контролировать качество ответов, задержки, количество токенов и безопасность передаваемых данных.

## ⚙️ Как работает Generative AI

```text
       Пользователь
            |
            v
          Prompt
            |
            v
     Генеративная модель
            |
            v
      Генерация контента
            |
            v
          Ответ
```

Например:

```text
Prompt:
"Напиши функцию сортировки на Python"
                 |
                 v
                LLM
                 |
                 v
def sort_numbers(numbers):
    return sorted(numbers)
```

Модель не извлекает готовый ответ из базы данных по умолчанию. Она генерирует результат на основе обученных параметров и предоставленного контекста.

### LLM vs Diffusion Models

**LLM** обычно генерирует текст последовательно, предсказывая следующие токены.

**Diffusion Models** обычно начинают с шума и постепенно преобразуют его в результат, например изображение.

## 🔄 Generative AI и RAG

Одна из распространённых архитектур Backend-приложений с GenAI — RAG.

```text
        Пользователь
             |
             v
       FastAPI Backend
             |
             v
      Embedding Model
             |
             v
       Vector Database
             |
             v
    Релевантные документы
             |
             v
         Prompt + Context
             |
             v
             LLM
             |
             v
       Ответ пользователю
```

**Зачем нужен RAG?**

Чтобы модель могла использовать актуальные или внутренние документы, которые не обязательно присутствовали в её обучающих данных.

RAG помогает снизить риск галлюцинаций, но не устраняет их полностью.

## 🐍 Пример Generative AI на Python

Используем локальную LLM через Ollama.

```python
import requests

# Адрес локального API
url = "http://localhost:11434/api/generate"

# Запрос к модели
payload = {
    "model": "gemma3:1b",
    "prompt": "Объясни, что такое FastAPI",
    "stream": False,
}

# Отправляем HTTP-запрос
response = requests.post(
    url,
    json=payload,
    timeout=60,
)

# Проверяем статус ответа
response.raise_for_status()

# Получаем результат
result = response.json()

print(result["response"])
```

### Разбор

1. `requests` — библиотека для HTTP-запросов.
2. `url` — адрес локального Ollama API.
3. `model` — название модели, которая должна быть установлена.
4. `prompt` — инструкция для генерации.
5. `stream=False` — получение ответа целиком.
6. `requests.post()` — отправка запроса.
7. `raise_for_status()` — проверка HTTP-ошибок.
8. `response.json()` — преобразование JSON в словарь.
9. `result["response"]` — сгенерированный текст.

Для выполнения примера Ollama должен быть запущен, а модель — установлена.

## ⚖️ Generative AI vs Predictive AI

| Критерий | Generative AI | Predictive AI |
|---|---|---|
| Цель | Создание контента | Прогнозирование |
| Результат | Текст, код, изображение | Число или категория |
| Пример | Генерация письма | Прогноз цены |
| Модели | LLM, Diffusion | Random Forest, XGBoost |

**Важно:** это разделение по назначению. Одна модель может использоваться для нескольких типов задач.

## ⚠️ Основные проблемы Generative AI

- **Hallucinations** — модель может генерировать убедительную, но ложную информацию.
- **Prompt Injection** — вредоносные инструкции во входных данных.
- **Latency** — задержка генерации.
- **Token Cost** — стоимость обработки токенов.
- **Data Privacy** — риск раскрытия конфиденциальных данных.
- **Non-determinism** — ответы могут отличаться при повторных запросах.

В production важно использовать валидацию результатов, ограничения доступа, мониторинг и оценку качества ответов.

## ❓ Частые вопросы на собеседовании

**1. Что такое Generative AI?**

Направление AI, связанное с генерацией нового контента на основе обученных моделей.

**2. Чем Generative AI отличается от обычного ML?**

Generative AI ориентирован на создание контента, а многие классические ML-задачи — на классификацию и прогнозирование.

**3. Что такое LLM?**

Большая языковая модель для обработки и генерации текста.

**4. Что такое Prompt?**

Входная инструкция или контекст, передаваемый модели.

**5. Что такое RAG?**

Подход, при котором генерация дополняется информацией, найденной во внешних источниках.

**6. Чем RAG отличается от Fine-tuning?**

RAG добавляет внешний контекст во время выполнения запроса, а Fine-tuning изменяет параметры модели посредством дополнительного обучения.

**7. Что такое Hallucination?**

Генерация недостоверной информации, которая может выглядеть правдоподобной.

**8. Что такое Temperature?**

Параметр, влияющий на распределение вероятностей при выборе следующих токенов и разнообразие генерации.

**9. Что такое Multimodal AI?**

Модели, способные работать с несколькими типами данных, например текстом и изображениями.

**10. Как Generative AI интегрируется с FastAPI?**

Backend принимает запрос, подготавливает контекст, обращается к модели через API, обрабатывает результат и возвращает его клиенту.
