# 👁️ Computer Vision (CV) — компьютерное зрение

## 🎤 Короткий ответ для собеседования

**Computer Vision (компьютерное зрение)** — это направление искусственного интеллекта, позволяющее компьютерным системам анализировать и интерпретировать изображения и видео.

Computer Vision применяется для распознавания объектов, обнаружения лиц, анализа медицинских снимков, обработки видео и автоматизации производства.

Основные задачи:

- **Image Classification** — классификация изображений.
- **Object Detection** — обнаружение объектов.
- **Image Segmentation** — сегментация изображений.
- **OCR** — распознавание текста на изображениях.
- **Object Tracking** — отслеживание объектов на видео.

## 🗣️ Ответ на собеседовании

Computer Vision — это область искусственного интеллекта, которая занимается анализом изображений и видео.

Например, система может определить, что изображено на фотографии, найти расположение объектов или распознать текст документа.

Для решения таких задач применяют классические алгоритмы обработки изображений и нейронные сети, например CNN и Vision Transformer.

В Python часто используют OpenCV, PyTorch и готовые модели вроде YOLO.

С точки зрения Backend-разработчика, я могу интегрировать модель компьютерного зрения через API: принимать изображение, запускать inference и возвращать результат клиенту.

## ⚙️ Как работает Computer Vision

```text
       Изображение / Видео
               |
               v
       Предобработка данных
               |
               v
          CV-модель
               |
               v
       Анализ изображения
               |
               v
            Результат
```

Например, модель обнаруживает автомобиль:

```text
Изображение с автомобилем
            |
            v
       YOLO-модель
            |
            v
Object: Car
Confidence: 0.96
Bounding Box: [x1, y1, x2, y2]
```

- `Car` — обнаруженный класс объекта.
- `Confidence` — оценка уверенности модели.
- `Bounding Box` — координаты прямоугольника вокруг объекта.

## 🧩 Основные задачи Computer Vision

| Задача | Что делает | Пример |
|---|---|---|
| Classification | Определяет класс изображения | Кошка или собака |
| Detection | Находит объекты и их координаты | Автомобили на дороге |
| Segmentation | Определяет принадлежность пикселей | Выделение человека |
| OCR | Извлекает текст | Распознавание документов |
| Tracking | Отслеживает объект в кадрах | Движение автомобиля |

### Classification vs Detection vs Segmentation

```text
Classification:
"На изображении есть кошка"

Detection:
"Кошка находится в координатах X, Y"

Segmentation:
"Вот конкретные пиксели, принадлежащие кошке"
```

### CNN — Convolutional Neural Network

**CNN (свёрточная нейронная сеть)** — архитектура нейросети, хорошо подходящая для обработки изображений.

Свёрточные слои выявляют локальные признаки:

```text
Изображение
     |
     v
Границы и линии
     |
     v
Текстуры и формы
     |
     v
Сложные признаки
     |
     v
Результат
```

### YOLO — You Only Look Once

**YOLO** — семейство моделей для обнаружения объектов.

Позволяет за один проход модели определить классы и координаты нескольких объектов на изображении.

Часто используется в системах, где важна высокая скорость обработки.

## 🐍 Пример на Python

Используем OpenCV для обнаружения границ объектов.

Установка:

```bash
pip install opencv-python
```

Код:

```python
import cv2

# Загружаем изображение
image = cv2.imread("photo.jpg")

# Проверяем загрузку
if image is None:
    raise FileNotFoundError("Изображение не найдено")

# Преобразуем в оттенки серого
gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY,
)

# Находим границы
edges = cv2.Canny(gray, 100, 200)

# Сохраняем результат
cv2.imwrite("edges.jpg", edges)
```

### Разбор

1. `import cv2` — подключаем OpenCV.
2. `cv2.imread()` — загружаем изображение.
3. `if image is None` — проверяем, удалось ли открыть файл.
4. `cv2.cvtColor()` — переводим изображение в оттенки серого.
5. `cv2.Canny()` — обнаруживаем границы на изображении.
6. `cv2.imwrite()` — сохраняем обработанное изображение.

**Важно:** Canny — классический алгоритм обработки изображений, а не обучаемая нейросеть. Computer Vision включает оба подхода.

## 🌐 Computer Vision в Python Backend

## ❓ Частые вопросы на собеседовании

**1. Что такое Computer Vision?**

Направление AI для анализа и интерпретации изображений и видео.

**2. Что такое CNN?**

Свёрточная нейронная сеть, использующая свёрточные слои для извлечения признаков из данных, в том числе изображений.

**3. Что такое Object Detection?**

Обнаружение объектов на изображении с определением их классов и координат.

**4. Чем Classification отличается от Detection?**

Classification определяет класс изображения, а Detection дополнительно локализует отдельные объекты.

**5. Что такое Segmentation?**

Разделение изображения на области или определение классов отдельных пикселей.

**6. Что такое YOLO?**

Семейство нейросетевых моделей для быстрого обнаружения объектов.

**7. Что такое OCR?**

Optical Character Recognition — технология распознавания текста на изображениях.

**8. Что такое OpenCV?**

Библиотека компьютерного зрения для обработки изображений и видео.

**9. Что такое Vision Transformer?**

Архитектура, применяющая механизмы Transformer к визуальным данным.

**10. Как Computer Vision интегрируется с FastAPI?**

Backend принимает изображение, выполняет предобработку, передаёт данные модели и возвращает результат inference через API.
