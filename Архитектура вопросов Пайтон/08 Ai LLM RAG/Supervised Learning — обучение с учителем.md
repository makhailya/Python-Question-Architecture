# 🤖 Supervised Learning — обучение с учителем

## 🎤 Короткий ответ для собеседования

**Supervised Learning (обучение с учителем)** — это метод машинного обучения, при котором модель обучается на размеченных данных, где для каждого примера известен правильный ответ.

Модель изучает зависимость между входными признаками (**Features**) и целевой переменной (**Target**), чтобы предсказывать результат для новых данных.

Два основных типа задач:

- **Classification (классификация)** — предсказание категории.
- **Regression (регрессия)** — предсказание числового значения.

## 🗣️ Ответ на собеседовании

Supervised Learning — это обучение модели на данных, для которых заранее известны правильные ответы.

Например, мы хотим определять спам. Собираем письма, каждому присваиваем метку «спам» или «не спам» и обучаем модель находить закономерности.

После обучения модель получает новое письмо и предсказывает его категорию.

Для оценки качества данные разделяют на обучающую, валидационную и тестовую выборки.

Основные задачи обучения с учителем — классификация и регрессия.

## ⚙️ Как работает Supervised Learning

```text
       Размеченные данные
          (X и y)
              |
              v
       Обучение модели
              |
              v
      Обученная модель
              |
              v
         Новые данные
              |
              v
         Предсказание
```

Например, обучаем модель предсказывать, сдаст ли студент экзамен.

| Часов подготовки (X) | Сдал экзамен (y) |
|---|---|
| 1 | 0 |
| 2 | 0 |
| 3 | 0 |
| 6 | 1 |
| 8 | 1 |

Здесь:

- `X` — входные признаки (Features).
- `y` — правильные ответы (Labels/Target).
- `0` — не сдал.
- `1` — сдал.

Модель учится находить связь между количеством часов подготовки и результатом экзамена.

## 🧩 Classification vs Regression

| Критерий | Classification | Regression |
|---|---|---|
| Задача | Предсказать категорию | Предсказать число |
| Результат | Спам / не спам | Цена квартиры |
| Пример | Мошенническая операция или нет | Прогноз выручки |
| Алгоритмы | Logistic Regression, Decision Tree | Linear Regression, Random Forest Regressor |
| Метрики | Accuracy, Precision, Recall, F1 | MAE, MSE, RMSE |

**Запомнить:** классификация отвечает на вопрос «К какому классу относится объект?», регрессия — «Какое числовое значение ожидается?».

## 🐍 Пример на Python

Используем Scikit-learn для обучения модели классификации.

```python
from sklearn.tree import DecisionTreeClassifier

# Признаки: часы подготовки
X = [[1], [2], [3], [6], [8]]

# Правильные ответы
y = [0, 0, 0, 1, 1]

# Создаём модель
model = DecisionTreeClassifier(random_state=42)

# Обучаем модель
model.fit(X, y)

# Предсказываем результат для 5 часов
prediction = model.predict([[5]])

print(prediction[0])
```

### Разбор

1. `DecisionTreeClassifier` — алгоритм классификации на основе дерева решений.
2. `X` — данные, по которым модель обучается.
3. `y` — известные правильные ответы.
4. `model.fit(X, y)` — обучение модели.
5. `model.predict([[5]])` — получение прогноза.
6. `prediction[0]` — предсказанный класс: `0` или `1`.

Это учебный пример. На пяти записях нельзя объективно оценить качество модели.

## 📊 Разделение данных

Обычно используют три выборки:

| Выборка | Назначение |
|---|---|
| Train | Обучение модели |
| Validation | Подбор гиперпараметров и выбор модели |
| Test | Финальная проверка качества |

Например, данные можно разделить в пропорции 70% / 15% / 15%, но универсального соотношения нет.

**Важно:** тестовые данные нельзя использовать для обучения или подбора гиперпараметров. Иначе оценка качества может оказаться завышенной.

## ⚠️ Основные проблемы

**Overfitting (переобучение)** — модель запоминает обучающие примеры и плохо работает на новых данных.

**Underfitting (недообучение)** — модель слишком простая или недостаточно обучена, поэтому плохо выявляет закономерности.

**Data Leakage (утечка данных)** — во время обучения используется информация, которая не должна быть доступна при реальном прогнозировании.

**Class Imbalance (дисбаланс классов)** — один класс встречается значительно чаще другого, из-за чего обычная Accuracy может вводить в заблуждение.

## ❓ Частые вопросы на собеседовании

**1. Что такое Supervised Learning?**

Обучение модели на размеченных данных с известными правильными ответами.

**2. Чем отличается от Unsupervised Learning?**

В Supervised Learning есть целевая переменная, а в Unsupervised Learning алгоритм ищет структуру данных без заранее заданных правильных ответов.

**3. Какие основные задачи решает?**

Классификацию и регрессию.

**4. Что такое Features и Labels?**

Features — входные признаки, Labels — правильные ответы для обучения.

**5. Что делает метод `fit()`?**

Обучает модель на переданных данных.

**6. Что делает метод `predict()`?**

Возвращает предсказания обученной модели.

**7. Как проверить качество классификации?**

Использовать Accuracy, Precision, Recall, F1-score и другие метрики в зависимости от задачи.

**8. Что такое Overfitting?**

Переобучение, при котором модель хорошо работает на Train, но плохо на новых данных.

**9. Какие алгоритмы применяются?**

Linear Regression, Logistic Regression, Decision Trees, Random Forest, Gradient Boosting, SVM и нейронные сети.

**10. Как Supervised Learning связан с Backend?**

Backend может принимать данные через API, передавать их обученной модели для inference и возвращать прогноз клиенту.
