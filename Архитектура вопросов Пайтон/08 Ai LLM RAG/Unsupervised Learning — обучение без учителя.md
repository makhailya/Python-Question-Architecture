# 🧠 Unsupervised Learning — обучение без учителя

## 🎤 Короткий ответ для собеседования

**Unsupervised Learning (обучение без учителя)** — это метод машинного обучения, при котором модель обучается на данных без заранее известных правильных ответов (Labels).

Алгоритм самостоятельно выявляет закономерности, сходства и скрытые структуры в данных.

Основные задачи:

- **Clustering** — кластеризация объектов.
- **Dimensionality Reduction** — снижение размерности данных.
- **Association Rules** — поиск ассоциативных закономерностей.
- **Anomaly Detection** — обнаружение аномалий (один из возможных подходов).

## 🗣️ Ответ на собеседовании

Unsupervised Learning — это обучение без учителя, когда у нас есть данные, но нет правильных ответов.

Например, интернет-магазин хочет разделить покупателей на группы по поведению. Мы передаём алгоритму информацию о покупках, частоте заказов и среднем чеке.

Алгоритм самостоятельно находит похожих покупателей и объединяет их в кластеры.

В отличие от Supervised Learning, здесь мы не предсказываем заранее заданную категорию, а пытаемся обнаружить структуру самих данных.

## ⚙️ Как работает Unsupervised Learning

```text
      Исходные данные
       (только X)
            |
            v
     Подготовка данных
            |
            v
      ML-алгоритм
            |
            v
   Поиск закономерностей
            |
            v
    Обнаруженная структура
```

Например, у нас есть покупатели:

| Клиент | Покупок в месяц | Средний чек |
|---|---:|---:|
| A | 2 | 500 ₽ |
| B | 3 | 700 ₽ |
| C | 15 | 8 000 ₽ |
| D | 18 | 9 000 ₽ |

Алгоритм может обнаружить две группы:

- **Кластер 1:** редкие покупки с небольшим чеком.
- **Кластер 2:** частые покупки с высоким чеком.

При этом мы заранее не указывали, к какой группе относится каждый покупатель.

## 🧩 Основные методы

| Метод | Назначение | Пример |
|---|---|---|
| K-Means | Разделение объектов на K кластеров | Сегментация клиентов |
| DBSCAN | Поиск плотных групп и шумовых точек | Географические данные |
| Hierarchical Clustering | Построение иерархии кластеров | Группировка документов |
| PCA | Снижение размерности | Сжатие набора признаков |
| Isolation Forest | Поиск аномалий | Подозрительные операции |

### K-Means — кластеризация

Один из наиболее известных алгоритмов обучения без учителя.

Принцип работы:

1. Выбираем количество кластеров `K`.
2. Алгоритм инициализирует центры кластеров.
3. Каждая точка относится к ближайшему центру.
4. Центры пересчитываются.
5. Процесс повторяется до выполнения условия остановки.

Например, при `K = 3` алгоритм разделит покупателей на три группы.

**Важно:** количество кластеров в обычном K-Means задаётся заранее.

## 🐍 Пример на Python

Используем Scikit-learn для кластеризации покупателей.

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# [Количество покупок, средний чек]
X = [
    [2, 500],
    [3, 700],
    [15, 8000],
    [18, 9000],
]

# Приводим признаки к сопоставимому масштабу
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Создаём модель с двумя кластерами
model = KMeans(n_clusters=2, random_state=42, n_init=10)

# Обучаем и получаем номера кластеров
labels = model.fit_predict(X_scaled)

print(labels)
```

### Разбор

1. `KMeans` — алгоритм кластеризации.
2. `X` — данные без правильных ответов.
3. `StandardScaler()` — стандартизирует признаки, чтобы большой масштаб среднего чека не доминировал над количеством покупок.
4. `n_clusters=2` — указываем два кластера.
5. `fit_predict()` — обучает модель и возвращает номера кластеров.
6. `labels` — номера групп, найденных алгоритмом.

**Обрати внимание:** номера `0` и `1` — условные идентификаторы кластеров, а не заранее известные правильные ответы.

## ⚖️ Supervised vs Unsupervised Learning

| Критерий | Supervised | Unsupervised |
|---|---|---|
| Размеченные данные | Нужны | Не нужны |
| Правильные ответы | Известны | Не заданы |
| Основная цель | Предсказание | Поиск структуры |
| Пример | Определение спама | Группировка клиентов |
| Алгоритмы | Logistic Regression, Random Forest | K-Means, DBSCAN, PCA |

## 📊 Как оценивают качество?

Оценивать Unsupervised Learning сложнее, поскольку правильные ответы обычно отсутствуют.

Для кластеризации используют:

- **Silhouette Score** — оценивает компактность и разделимость кластеров.
- **Davies–Bouldin Index** — оценивает сходство кластеров между собой.
- **Inertia** — сумму квадратов расстояний точек до центров кластеров в K-Means.

Метрики не гарантируют, что найденные группы будут полезны для бизнеса. Результаты необходимо интерпретировать.

## ❓ Частые вопросы на собеседовании

**1. Что такое Unsupervised Learning?**

Обучение на данных без заранее заданных правильных ответов для выявления скрытых закономерностей.

**2. Чем отличается от Supervised Learning?**

В Supervised Learning есть целевая переменная, а в Unsupervised Learning модель работает без неё.

**3. Что такое кластеризация?**

Объединение похожих объектов в группы на основе их признаков.

**4. Что такое K-Means?**

Алгоритм, который разделяет объекты на K кластеров по близости к их центрам.

**5. Что такое DBSCAN?**

Алгоритм кластеризации на основе плотности точек, способный находить кластеры произвольной формы и выделять шум.

**6. Что такое PCA?**

Метод снижения размерности, который преобразует признаки в новые компоненты, сохраняющие максимально возможную дисперсию при заданном числе компонентов.

**7. Нужно ли заранее задавать количество кластеров?**

Зависит от алгоритма. Для K-Means — да, для DBSCAN — нет.

**8. Что такое Anomaly Detection?**

Поиск объектов, значительно отличающихся от большинства наблюдений.

**9. Какие библиотеки используются в Python?**

Scikit-learn, NumPy, Pandas и SciPy.

**10. Где применяется Unsupervised Learning?**

В сегментации клиентов, анализе поведения, поиске аномалий, группировке документов и исследовании данных.
