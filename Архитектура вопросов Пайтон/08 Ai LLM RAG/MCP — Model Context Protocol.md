# 🔌 MCP — Model Context Protocol

## 🎤 Короткий ответ для собеседования

**MCP (Model Context Protocol)** — это открытый протокол, который стандартизирует взаимодействие AI-приложений с внешними инструментами и источниками данных.

С помощью MCP языковая модель через AI-приложение может получать доступ к базам данных, файлам, API, GitHub и другим системам.

**Главная идея:** MCP предоставляет единый стандарт подключения инструментов к AI-приложениям вместо разработки отдельной интеграции для каждого сервиса.

## 🗣️ Ответ на собеседовании

MCP — это протокол для интеграции LLM-приложений с внешними системами.

Он использует клиент-серверную архитектуру. AI-приложение выступает хостом, создаёт MCP-клиенты и подключается к MCP-серверам.

Серверы предоставляют инструменты, ресурсы и шаблоны промптов.

Например, через MCP-сервер для PostgreSQL AI-ассистент может получить доступ к разрешённым операциям с базой данных.

Сам протокол не является языковой моделью и не выполняет рассуждения. Он стандартизирует обмен данными и вызов инструментов.

## ⚙️ Архитектура MCP

```text
             Пользователь
                  |
                  v
            AI-приложение
             (MCP Host)
                  |
             MCP Client
                  |
                  | MCP Protocol
                  v
             MCP Server
                  |
          ┌───────┼────────┐
          |       |        |
          v       v        v
       GitHub  PostgreSQL  Files
```

### Основные компоненты

| Компонент | Назначение |
|---|---|
| MCP Host | AI-приложение, например IDE-ассистент |
| MCP Client | Поддерживает соединение с MCP-сервером |
| MCP Server | Предоставляет доступ к инструментам и данным |
| Tools | Операции, которые можно вызвать |
| Resources | Данные, доступные для чтения |
| Prompts | Шаблоны взаимодействия с моделью |

Один MCP Host может одновременно подключаться к нескольким MCP-серверам.

## 🔑 Три основные возможности MCP

### 1. Tools — инструменты

Позволяют выполнять операции.

Например:

```text
get_user(user_id)
search_documents(query)
create_issue(title)
execute_sql(query)
```

Модель может выбрать инструмент, но фактический вызов выполняется AI-приложением через MCP-клиент с учётом разрешений.

### 2. Resources — ресурсы

Предоставляют данные и контекст.

Например:

```text
file:///project/README.md
postgres://database/schema
```

### 3. Prompts — шаблоны

Предоставляют заранее подготовленные сценарии взаимодействия.

Например:

```text
review_code
explain_database_schema
analyze_logs
```

## 🔄 Как происходит вызов инструмента

```text
1. Пользователь:
   "Покажи последние заказы"
              |
              v
2. LLM выбирает инструмент
   get_recent_orders
              |
              v
3. MCP Client отправляет запрос
              |
              v
4. MCP Server выполняет операцию
              |
              v
5. Возвращает результат
              |
              v
6. LLM формирует ответ
```

MCP использует сообщения JSON-RPC 2.0.

Для локального взаимодействия часто применяется **stdio**, а для удалённого — **Streamable HTTP**.

## 🐍 Пример MCP-сервера на Python

Один из способов создания MCP-сервера — использовать Python SDK и FastMCP.

Установка:

```bash
pip install "mcp[cli]"
```

Пример:

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("Calculator")


@mcp.tool()
def add(a: int, b: int) -> int:
    """Складывает два числа."""
    return a + b


if __name__ == "__main__":
    mcp.run()
```

### Разбор

- `FastMCP("Calculator")` — создаёт MCP-сервер.
- `@mcp.tool()` — регистрирует функцию как инструмент.
- `add()` — обычная Python-функция.
- `a: int, b: int` — типы аргументов.
- `return a + b` — возвращает результат.
- `mcp.run()` — запускает сервер, по умолчанию через stdio в данном варианте SDK.

После подключения совместимый MCP-клиент сможет обнаружить инструмент `add` и вызывать его.

## ⚖️ MCP vs REST API vs Function Calling

| Технология | Назначение |
|---|---|
| REST API | Интерфейс взаимодействия приложений по HTTP |
| Function Calling | Механизм, позволяющий модели запрашивать вызов функций |
| MCP | Стандарт подключения инструментов и данных к AI-приложениям |

**Важно:** MCP не заменяет REST API.

MCP-сервер может внутри себя обращаться к обычному REST API, PostgreSQL или другой системе.

Function Calling и MCP могут использоваться совместно: модель выбирает инструмент, а MCP обеспечивает стандартизированный способ его обнаружения и вызова.

## 🔐 Безопасность MCP

MCP-сервер может предоставлять доступ к чувствительным операциям, поэтому важно:

- Ограничивать права инструментов.
- Проверять входные параметры.
- Использовать аутентификацию и авторизацию.
- Не передавать секреты модели без необходимости.
- Подтверждать опасные действия.
- Не доверять автоматически данным от внешних серверов.

Например, MCP-инструмент для PostgreSQL лучше подключать с минимально необходимыми правами, а не с правами администратора.

## ❓ Частые вопросы на собеседовании

**1. Что такое MCP?**

Открытый протокол для стандартизированного подключения AI-приложений к внешним инструментам и данным.

**2. Что такое MCP Server?**

Программа, которая предоставляет инструменты, ресурсы и промпты через MCP.

**3. Что такое MCP Client?**

Компонент AI-приложения, который поддерживает соединение с MCP-сервером.

**4. Чем MCP отличается от API?**

API предоставляет интерфейс конкретного сервиса, а MCP стандартизирует способ предоставления таких возможностей AI-приложениям.

**5. Что такое Tools?**

Операции, которые AI-приложение может вызывать через MCP-сервер.

**6. Что такое Resources?**

Источники данных, предоставляемые MCP-сервером.

**7. Какие транспорты поддерживает MCP?**

В частности, stdio и Streamable HTTP.

**8. Может ли MCP работать с локальной LLM?**

Да, если AI-приложение поддерживает MCP и умеет использовать инструменты с выбранной моделью.

**9. MCP — это AI-агент?**

Нет. MCP — протокол интеграции. Агент может использовать MCP для выполнения действий.

**10. Как MCP связан с RAG?**

MCP-сервер может предоставлять инструменты поиска документов или ресурсы, которые AI-приложение использует для получения контекста перед генерацией ответа.

**Главная формула для собеседования:**

MCP — это стандарт взаимодействия AI-приложений с внешними инструментами и данными. MCP Host управляет подключениями, MCP Client обменивается сообщениями с MCP Server, а сервер предоставляет Tools, Resources и Prompts.

**MCP — не модель, не агент и не замена REST API, а протокол интеграции.**
