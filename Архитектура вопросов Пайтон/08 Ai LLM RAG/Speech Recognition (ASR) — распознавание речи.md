# 🎙️ Speech Recognition (ASR) — распознавание речи

## 🎤 Короткий ответ для собеседования

**Speech Recognition (распознавание речи)** — это технология искусственного интеллекта, которая преобразует человеческую речь из аудиосигнала в текст.

Также используется термин **ASR (Automatic Speech Recognition)** — автоматическое распознавание речи.

Основные применения:

- **Speech-to-Text (STT)** — преобразование речи в текст.
- **Transcription** — транскрибация аудиозаписей.
- **Voice Assistants** — голосовые помощники.
- **Real-time ASR** — распознавание речи в реальном времени.
- **Speech Analytics** — анализ разговоров и звонков.

## 🗣️ Ответ на собеседовании

Speech Recognition — это технология автоматического преобразования устной речи в текст.

Система получает аудиосигнал, выполняет его предварительную обработку и передаёт данные модели распознавания речи.

Современные ASR-системы используют глубокие нейронные сети, в том числе архитектуры Transformer.

Например, модель Whisper может распознавать речь на разных языках и возвращать текст транскрипции.

Как Python Backend-разработчик, я могу интегрировать ASR-модель через API, организовать обработку аудиофайлов, потоковое распознавание и сохранение транскрипций.

### VAD vs ASR

**VAD (Voice Activity Detection)** определяет, есть ли речь в аудиосигнале.

**ASR** преобразует обнаруженную речь в текст.

```text
Аудиопоток
    |
    v
   VAD
    |
    ├── Тишина → Пропускаем
    |
    └── Речь
         |
         v
        ASR
         |
         v
        Текст
```

VAD помогает уменьшить количество ненужных вызовов ASR, но не является обязательной частью каждой системы распознавания.

## 🐍 Пример Speech Recognition на Python

Используем `faster-whisper` для локального распознавания речи.

Установка:

```bash
pip install faster-whisper
```

Код:

```python
from faster_whisper import WhisperModel

# Загружаем модель
model = WhisperModel(
    "small",
    device="cpu",
    compute_type="int8",
)

# Распознаём аудиофайл
segments, info = model.transcribe(
    "audio.wav",
    language="ru",
)

# Выводим текст
for segment in segments:
    print(segment.text)
```

### Разбор

1. `WhisperModel` — класс для работы с моделью распознавания.
2. `"small"` — размер модели Whisper.
3. `device="cpu"` — выполнение на процессоре.
4. `compute_type="int8"` — использование вычислений с пониженной точностью для уменьшения требований к ресурсам.
5. `transcribe()` — запускает процесс транскрибации.
6. `language="ru"` — указывает русский язык.
7. `segments` — последовательность распознанных фрагментов.
8. `segment.text` — текст конкретного фрагмента.

Модель при первом запуске может загружаться из интернета. Пример использует CPU; поддержка ускорения зависит от оборудования и реализации.

## ⚡ Batch ASR vs Streaming ASR

| Критерий | Batch ASR | Streaming ASR |
|---|---|---|
| Вход | Готовый аудиофайл | Поток аудио |
| Результат | После обработки | Частями во время речи |
| Задержка | Зависит от длительности файла | Обычно ниже для промежуточного текста |
| Пример | Транскрибация интервью | Голосовой ассистент |

Для потокового распознавания часто используют WebSocket или другие способы передачи аудиоданных в реальном времени.

## 📊 Как оценивают качество ASR

Основная метрика — **WER (Word Error Rate)**.

Она учитывает:

- **S (Substitutions)** — замены слов.
- **D (Deletions)** — пропущенные слова.
- **I (Insertions)** — лишние слова.
- **N** — количество слов в эталонной транскрипции.

Формула:

\[
WER = \frac{S + D + I}{N}
\]

Чем ниже WER, тем меньше ошибок распознавания.

Например, WER = 0.1 означает, что суммарное количество ошибок составляет 10% от числа слов эталонного текста. WER может превышать 100%.

## ❓ Частые вопросы на собеседовании

**1. Что такое Speech Recognition?**

Технология автоматического преобразования речи в текст.

**2. Что такое ASR?**

Automatic Speech Recognition — автоматическое распознавание речи.

**3. Чем ASR отличается от TTS?**

ASR преобразует речь в текст, а TTS — текст в синтезированную речь.

**4. Что такое VAD?**

Алгоритм определения участков аудио, содержащих речь.

**5. Что такое Whisper?**

Семейство нейросетевых моделей для многоязычного распознавания речи и связанных задач.

**6. Чем Whisper отличается от faster-whisper?**

Whisper — модели и исходная реализация OpenAI, а faster-whisper — альтернативная оптимизированная реализация на базе CTranslate2.

**7. Что такое Streaming ASR?**

Распознавание речи по мере поступления аудиоданных.

**8. Что такое Speaker Diarization?**

Определение временных участков речи разных говорящих.

**9. Что такое WER?**

Метрика качества ASR, показывающая отношение количества ошибок распознавания слов к количеству слов в эталонном тексте.

**10. Как интегрировать ASR с FastAPI?**

Принимать аудио через HTTP или WebSocket, обрабатывать его моделью и возвращать текст либо промежуточные результаты распознавания.
