# 🧩 Класс в Python

## 🎤 Короткий ответ

**Класс — это описание структуры и поведения объектов.** Он определяет, какие данные объект может хранить и какие действия может выполнять.

Объект — это **экземпляр класса**.

```python
class User:
    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print(f"Привет, я {self.name}")


user = User("Илья")

user.say_hello()
```

Здесь:

```text
User → класс
user → объект (экземпляр User)
name → атрибут объекта
say_hello() → метод
```

---

## 🗣️ Ответ на собеседовании

> Класс в Python — это конструкция, которая описывает данные и поведение объектов. На основе класса можно создавать экземпляры — конкретные объекты.
>
> У класса могут быть атрибуты, методы, свойства и специальные методы, например `__init__`.
>
> При создании объекта вызывается класс, и Python создаёт экземпляр этого класса. В `__init__` обычно задаётся начальное состояние объекта.
>
> Например, класс `User` может описывать пользователя, хранить его имя и предоставлять метод для какого-либо действия.
>
> В Python классы являются объектами первого класса: сам класс тоже является объектом и обычно является экземпляром метакласса `type`.

# 📚 Разбор поглубже

## 1. Что такое класс

Класс можно рассматривать как **описание того, каким должен быть объект**.

Например:

```python
class User:
    pass
```

Мы создали класс `User`.

Теперь можем создать экземпляр:

```python
user = User()
```

Получается:

```text
User
 ↓
экземпляр
 ↓
user
```

Сам класс — это не конкретный пользователь.

```text
User → описание пользователя

user1 → конкретный пользователь
user2 → другой конкретный пользователь
```

---

## 2. Создание объекта

Класс вызывается как функция:

```python
user = User()
```

Но технически происходит больше, чем просто вызов обычной функции.

Упрощённо:

```text
User()
 ↓
__new__()
 ↓
создание экземпляра
 ↓
__init__()
 ↓
инициализация объекта
```

Поэтому важно различать:

* `__new__()` — создаёт экземпляр;
* `__init__()` — инициализирует уже созданный экземпляр.

---

# 3. `__init__`

Чаще всего начальное состояние объекта задают через `__init__`.

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

Создание:

```python
user = User("Илья", 31)
```

Теперь:

```python
print(user.name)
print(user.age)
```

Получим:

```text
Илья
31
```

---

# 4. Что такое `self`

`self` — ссылка на **конкретный экземпляр**, для которого вызывается метод.

```python
class User:
    def __init__(self, name):
        self.name = name

    def hello(self):
        print(self.name)
```

Когда выполняем:

```python
user = User("Илья")
user.hello()
```

Python фактически передаёт объект в метод:

```python
User.hello(user)
```

Поэтому:

```python
self.name
```

означает:

> взять атрибут `name` у текущего экземпляра.

Важно: `self` — не специальное ключевое слово Python. Это соглашение об имени первого параметра экземплярного метода.

---

# 5. Атрибуты объекта

Атрибут — это данные, связанные с объектом.

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

У разных экземпляров могут быть разные значения:

```python
user1 = User("Илья", 31)
user2 = User("Анна", 28)
```

Получаем:

```text
user1.name → Илья
user2.name → Анна
```

При этом оба объекта принадлежат одному классу `User`.

---

# 6. Методы

Метод — функция, определённая внутри класса.

```python
class User:
    def say_hello(self):
        print("Привет!")
```

Использование:

```python
user = User()
user.say_hello()
```

Метод обычно работает с состоянием экземпляра через `self`.

```python
class User:
    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print(f"Привет, {self.name}!")
```

---

# 7. Атрибут класса и атрибут экземпляра

Это важное различие.

### Атрибут экземпляра

Создаётся у конкретного объекта:

```python
class User:
    def __init__(self, name):
        self.name = name
```

У каждого объекта своё значение:

```python
user1.name
user2.name
```

---

### Атрибут класса

Принадлежит самому классу:

```python
class User:
    role = "user"
```

Теперь:

```python
print(User.role)
```

И экземпляры также могут получить этот атрибут:

```python
user = User()

print(user.role)
```

Python ищет атрибут примерно так:

```text
объект
  ↓
класс
  ↓
базовые классы
```

---

# 8. Что происходит при обращении к атрибуту

Например:

```python
user.name
```

Python должен найти `name`.

Упрощённо:

```text
user
 ↓
ищем name в объекте
 ↓
если не нашли → ищем в классе
 ↓
если не нашли → ищем в базовых классах
```

Механизм доступа к атрибутам в Python сложнее и включает `__getattribute__`, `__getattr__` и дескрипторы, но для базового уровня важно понимать сам принцип поиска.

# 9. Класс тоже является объектом

Это один из важных вопросов на собеседовании.

```python
class User:
    pass
```

Можно проверить:

```python
print(type(User))
```

Результат:

```text
<class 'type'>
```

То есть:

```text
User
 ↓
экземпляр type
```

А:

```python
user = User()
```

даёт:

```text
user
 ↓
экземпляр User
```

Получается:

```text
type
 ↑
User
 ↑
user
```

---

# 10. `type` как метакласс

В обычной ситуации:

```python
type(user)
```

возвращает:

```text
User
```

А:

```python
type(User)
```

возвращает:

```text
type
```

Поэтому:

```python
user → экземпляр User
User → экземпляр type
```

`type` — стандартный метакласс Python.

---

# 11. Класс может содержать разные элементы

Например:

```python
class User:
    role = "user"

    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print(f"Привет, {self.name}")

    @classmethod
    def create_guest(cls):
        return cls("Guest")

    @staticmethod
    def is_valid_name(name):
        return bool(name)
```

Здесь:

```text
User
├── role                  ← атрибут класса
├── __init__              ← специальный метод
├── say_hello()           ← экземплярный метод
├── create_guest()        ← classmethod
└── is_valid_name()       ← staticmethod
```

---

# 12. Класс — это не просто «шаблон»

Формулировка «класс — это шаблон для создания объектов» допустима как упрощение, но на собеседовании лучше сказать точнее:

> Класс — это объект Python, который определяет структуру и поведение экземпляров.

Почему это лучше?

Потому что класс сам является полноценным объектом и может:

* иметь атрибуты;
* иметь методы;
* передаваться как значение;
* сохраняться в переменной;
* использоваться как аргумент функции;
* динамически создаваться.

Например:

```python
class User:
    pass


MyClass = User

user = MyClass()
```

---

# 13. Класс и объект

Главное различие:

```text
Класс
└── описывает структуру и поведение

Объект
└── конкретный экземпляр класса
```

Например:

```python
class Car:
    def __init__(self, brand):
        self.brand = brand
```

Создаём:

```python
car1 = Car("BMW")
car2 = Car("Toyota")
```

```text
Car
├── car1 → BMW
└── car2 → Toyota
```

Оба объекта используют одну структуру класса, но имеют собственное состояние.

---

# 14. Проверка типа объекта

Можно использовать `type()`:

```python
user = User()

print(type(user))
```

И `isinstance()`:

```python
print(isinstance(user, User))
```

`isinstance()` особенно полезен при наследовании.

```python
class Admin(User):
    pass


admin = Admin()

print(isinstance(admin, Admin))  # True
print(isinstance(admin, User))   # True
```

Потому что `Admin` наследуется от `User`.

---

# 15. Что происходит при создании экземпляра

Когда выполняется:

```python
user = User("Илья")
```

упрощённо можно представить:

```text
User("Илья")
      ↓
__new__()
      ↓
создание объекта
      ↓
__init__(self, "Илья")
      ↓
готовый экземпляр
      ↓
user
```

При этом `__new__()` отвечает за создание объекта, а `__init__()` — за его инициализацию.

---

# 16. Класс и ООП

Класс является одним из основных инструментов объектно-ориентированного программирования.

Через классы в Python реализуются:

```text
ООП
├── Инкапсуляция
├── Наследование
├── Полиморфизм
└── Абстракция
```

Но сам по себе класс **не равен ООП**.

Класс — механизм языка, а ООП — подход к организации программы вокруг объектов, их состояния и поведения.

# 🎤 Вопросы на собеседовании

### Что такое класс?

Класс — это объект Python, который описывает структуру и поведение экземпляров.

### Что такое объект?

Конкретный экземпляр класса.

### Что такое экземпляр класса?

Объект, созданный на основе определённого класса.

### Для чего нужен `__init__`?

Для инициализации экземпляра после его создания.

### Чем `__new__` отличается от `__init__`?

`__new__` отвечает за создание экземпляра, а `__init__` — за его инициализацию.

### Что такое `self`?

Ссылка на текущий экземпляр класса. Это соглашение об имени первого параметра экземплярного метода.

### Что такое атрибут экземпляра?

Атрибут, связанный с конкретным объектом:

```python
self.name = name
```

### Что такое атрибут класса?

Атрибут, определённый непосредственно в классе и общий для экземпляров, если они не переопределяют его.

### Является ли класс объектом?

Да. Например:

```python
class User:
    pass

type(User)
```

даёт `type`.

### Что такое метакласс?

Класс, экземплярами которого являются классы. В обычном Python-коде классы по умолчанию создаются метаклассом `type`.

### Чем `type()` отличается от `isinstance()`?

`type(obj)` возвращает непосредственный тип объекта, а `isinstance(obj, Class)` проверяет принадлежность объекта классу с учётом наследования.
