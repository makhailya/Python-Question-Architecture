# 🧩 `__new__`

🎯 **Ответ на собеседовании:**

`__new__` — это специальный метод, который **создаёт и возвращает новый экземпляр класса**.

Он вызывается **до `__init__`** и получает `cls`, а не `self`.

```python
class User:
    def __new__(cls, name):
        print("__new__")
        return super().__new__(cls)

    def __init__(self, name):
        print("__init__")
        self.name = name


user = User("Ilya")
```

Вывод:

```text
__new__
__init__
```

## Как создаётся объект

Упрощённо:

```text
User("Ilya")
    ↓
__new__(User, "Ilya")
    ↓
создаётся объект
    ↓
__init__(self, "Ilya")
    ↓
объект готов
```

То есть:

* `__new__` → **создаёт объект**
* `__init__` → **инициализирует уже созданный объект**

---

## `__new__` vs `__init__`

|                                   | `__new__`      | `__init__`                 |
| --------------------------------- | -------------- | -------------------------- |
| Когда вызывается                  | До `__init__`  | После `__new__`            |
| Первый аргумент                   | `cls`          | `self`                     |
| Задача                            | Создать объект | Инициализировать объект    |
| Должен вернуть объект             | **Да**         | Нет, должен вернуть `None` |
| Можно заменить создаваемый объект | Да             | Нет                        |

### Важный момент

`__new__` — `staticmethod`-подобный специальный метод: Python автоматически передаёт ему `cls`.

```python
class A:
    def __new__(cls):
        return super().__new__(cls)
```

---

## Почему `__new__` должен вернуть объект?

Потому что именно результат `__new__` становится `self` для последующего `__init__`.

```python
class A:
    def __new__(cls):
        obj = super().__new__(cls)
        return obj

    def __init__(self):
        print("init")
```

Если `__new__` вернул экземпляр `A`, Python затем вызовет:

```python
A.__init__(obj)
```

Если `__new__` вернул объект **другого типа**, поведение меняется: `__init__` исходного класса может вообще не вызываться.

---

## Где используется `__new__`

### 1. Singleton

Можно контролировать создание экземпляров:

```python
class Singleton:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)

        return cls._instance
```

```python
a = Singleton()
b = Singleton()

print(a is b)
# True
```

### 2. Неизменяемые типы

`__new__` особенно важен для immutable-объектов:

```python
class MyInt(int):
    def __new__(cls, value):
        return super().__new__(cls, value)
```

Для `int`, `str`, `tuple` и других immutable-типов значение должно быть установлено **при создании объекта**, поэтому используется `__new__`.

### 3. Контроль создания объектов

Можно:

* вернуть существующий экземпляр;
* вернуть экземпляр другого класса;
* запретить создание;
* изменить процесс создания объекта.

---

## `__new__` и наследование

Обычно используется:

```python
return super().__new__(cls)
```

а не:

```python
return object.__new__(cls)
```

Первый вариант корректнее для сложной иерархии наследования, потому что продолжает цепочку через **MRO**.

---

## Важная особенность

`__new__` вызывается при каждом выражении создания:

```python
obj = MyClass()
```

Но `__init__` вызывается только если `__new__` вернул экземпляр соответствующего класса.

Упрощённо:

```python
obj = MyClass.__new__(MyClass)

if isinstance(obj, MyClass):
    MyClass.__init__(obj)
```

---

## Частый вопрос: можно ли создать объект только через `__new__`?

Да.

```python
class A:
    def __new__(cls):
        return super().__new__(cls)

    def __init__(self):
        print("init")


obj = A.__new__(A)
```

Объект создан, но `__init__` автоматически не запускался.

---

## Запомнить 🧠

```text
__new__  → СОЗДАЁТ объект
__init__ → НАСТРАИВАЕТ объект
```

И главное:

> **`__new__` отвечает за создание экземпляра и возвращает его, а `__init__` получает уже созданный экземпляр и инициализирует его.**
