# 🧩 `__init__`

🎯 **Ответ на собеседовании:**

`__init__` — специальный метод, который **инициализирует уже созданный объект**. Он вызывается автоматически после `__new__`.

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age


user = User("Ilya", 31)

print(user.name)  # Ilya
```

## Как создаётся объект

Упрощённо:

```text
User("Ilya", 31)
       ↓
__new__()     → создаёт объект
       ↓
__init__()    → инициализирует объект
       ↓
готовый объект
```

Поэтому:

> **`__new__` создаёт экземпляр, а `__init__` инициализирует его.**

---

## Особенности `__init__`

### 1. Получает `self`

```python
class User:
    def __init__(self, name):
        self.name = name
```

`self` — это уже созданный экземпляр.

---

### 2. Не должен возвращать объект

`__init__` должен вернуть `None`:

```python
class User:
    def __init__(self):
        self.name = "Ilya"
```

Нельзя:

```python
def __init__(self):
    return self  # TypeError
```

`__init__` не отвечает за создание объекта.

---

### 3. Вызывается после `__new__`

```python
class User:
    def __new__(cls):
        print("new")
        return super().__new__(cls)

    def __init__(self):
        print("init")
```

```text
new
init
```

---

## Что обычно делают в `__init__`

В нём устанавливают начальное состояние объекта:

```python
class Account:
    def __init__(self, username, balance=0):
        self.username = username
        self.balance = balance
```

После:

```python
account = Account("ilya", 1000)
```

объект содержит:

```python
account.username  # "ilya"
account.balance   # 1000
```

---

## `__new__` vs `__init__`

|                       | `__new__`                                    | `__init__`                                 |
| --------------------- | -------------------------------------------- | ------------------------------------------ |
| Назначение            | Создание объекта                             | Инициализация объекта                      |
| Получает              | `cls`                                        | `self`                                     |
| Вызывается            | Первым                                       | После `__new__`                            |
| Возвращает            | Экземпляр                                    | `None`                                     |
| Может заменить объект | ✅ Да                                         | ❌ Нет                                      |
| Типичные применения   | immutable-типы, Singleton, контроль создания | Установка атрибутов и начального состояния |

## Важный нюанс с наследованием

Если дочерний класс не определяет свой `__init__`, используется родительский:

```python
class User:
    def __init__(self, name):
        self.name = name


class Admin(User):
    pass


admin = Admin("Ilya")
```

Здесь используется:

```python
User.__init__()
```

Если дочерний класс определяет `__init__`, родительский автоматически **не вызывается**:

```python
class Admin(User):
    def __init__(self, name, level):
        self.level = level
```

Тогда для инициализации части `User` нужно явно вызвать:

```python
class Admin(User):
    def __init__(self, name, level):
        super().__init__(name)
        self.level = level
```

---

## Частый вопрос: является ли `__init__` конструктором?

Строго говоря, **нет**.

В Python:

* `__new__` — создаёт экземпляр;
* `__init__` — инициализирует экземпляр.

Поэтому корректнее говорить:

> **`__init__` — инициализатор объекта, а не конструктор в строгом смысле.**

Но на собеседовании допустимо сказать, что `__init__` — это «конструктор» в бытовом смысле, если сразу уточнить эту разницу.
