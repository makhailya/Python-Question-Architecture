```python
class Pizza:
    def __init__(self, ingredients):
        self.ingredients = ingredients

    @classmethod
    def margherita(cls):        # работает с классом, может вернуть cls(...)
        return cls(["сыр", "томаты"])

    @staticmethod
    def validate(ingredient):   # просто функция, логически внутри класса
        return isinstance(ingredient, str)
```

	Оба не требуют экземпляра класса для вызова.
	
1. classmethod получает cls — может обращаться к атрибутам класса, создавать экземпляры (часто используется как альтернативный конструктор).

2. staticmethod не получает ни self, ни cls — по сути обычная функция, которую просто удобно хранить внутри класса.

	Забавный факт с собеса: и classmethod, и staticmethod — тоже дескрипторы (non-data).
