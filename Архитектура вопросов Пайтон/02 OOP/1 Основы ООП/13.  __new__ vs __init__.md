```python
class Point:
    def __new__(cls, *args, **kwargs):
        print("__new__: создаём объект")
        instance = super().__new__(cls)
        return instance

    def __init__(self, x, y):
        print("__init__: инициализируем атрибуты")
        self.x = x
        self.y = y
```

1. __new__ вызывается первым — это аналог конструктора, он создаёт и возвращает новый объект.

2. __init__ вызывается вторым, принимает уже созданный объект и заполняет его атрибутами; ничего не возвращает (None).

	Ни __new__, ни __init__ дескрипторами не являются — это отдельный механизм создания объектов.
