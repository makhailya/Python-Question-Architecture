# 🧱 ООП — объектно-ориентированное программирование

## 🎯 Ответ на собеседовании

**ООП (объектно-ориентированное программирование)** — парадигма программирования, в которой программа строится вокруг **объектов**, объединяющих данные и поведение.

Объект создаётся на основе **класса**.

```python
class User:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hello, {self.name}"


user = User("Ilya")
```

Здесь:

```text
User → класс
user → объект (экземпляр класса)
name → атрибут
greet() → метод
```

---

# 🧩 Класс и объект

### Класс

**Класс** — описание структуры и поведения объектов.

```python
class User:
    name = "Unknown"
```

### Объект

**Объект** — конкретный экземпляр класса.

```python
user1 = User()
user2 = User()
```

```text
User
 ↓
 ├── user1
 └── user2
```

У объектов могут быть разные состояния:

```python
user1.name = "Ilya"
user2.name = "Alex"
```

---

# 📦 Атрибуты и методы

### Атрибут

Хранит данные объекта или класса:

```python
class User:
    def __init__(self, name):
        self.name = name
```

`self.name` — атрибут экземпляра.

### Метод

Функция, определённая внутри класса:

```python
class User:
    def greet(self):
        return "Hello"
```

---

# 🔑 `self`

`self` — ссылка на **текущий экземпляр объекта**.

```python
class User:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print(self.name)
```

При:

```python
user.greet()
```

Python фактически передаёт объект как первый аргумент метода:

```python
User.greet(user)
```

`self` — это **соглашение об имени**, а не ключевое слово языка.

# 🧬 Четыре принципа ООП

Традиционно выделяют:

1. **Инкапсуляция**
2. **Наследование**
3. **Полиморфизм**
4. **Абстракция**

---

## 1. 🔒 Инкапсуляция

**Инкапсуляция** — объединение данных и методов для работы с ними внутри объекта и ограничение прямого доступа к внутренней реализации.

В Python нет настоящих `private` полей в стиле некоторых языков, но есть соглашения и механизм name mangling.

```python
class BankAccount:
    def __init__(self, balance):
        self._balance = balance

    def deposit(self, amount):
        self._balance += amount
```

Один `_` означает:

> «Это внутренний атрибут, не предназначенный для внешнего использования».

Двойное подчёркивание:

```python
self.__balance
```

запускает **name mangling**:

```text
__balance
    ↓
_ClassName__balance
```

Это не полноценная приватность.

---

# 2. 🧬 Наследование

**Наследование** позволяет создать новый класс на основе существующего и переиспользовать его поведение.

```python
class Animal:
    def speak(self):
        print("Some sound")


class Dog(Animal):
    def speak(self):
        print("Woof")
```

```text
Animal
  ↓
 Dog
```

`Dog` наследует интерфейс/поведение `Animal`, но может его переопределять.

---

## `super()`

`super()` позволяет обратиться к реализации родительского класса.

```python
class Animal:
    def __init__(self, name):
        self.name = name


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
```

---

# 3. 🔄 Полиморфизм

**Полиморфизм** — возможность работать с объектами разных типов через общий интерфейс.

```python
class Dog:
    def speak(self):
        return "Woof"


class Cat:
    def speak(self):
        return "Meow"


def make_sound(animal):
    print(animal.speak())
```

Можно передать:

```python
make_sound(Dog())
make_sound(Cat())
```

Функции не важно, `Dog` это или `Cat`.

Ей достаточно, чтобы объект поддерживал необходимый интерфейс.

В Python это тесно связано с **duck typing**:

> Если объект ведёт себя как нужный тип, его можно использовать независимо от его конкретного класса.

---

# 4. 🎯 Абстракция

**Абстракция** — выделение существенного интерфейса объекта и сокрытие деталей реализации.

Например:

```python
from abc import ABC, abstractmethod


class Payment(ABC):

    @abstractmethod
    def pay(self, amount):
        pass
```

Конкретные реализации:

```python
class CardPayment(Payment):
    def pay(self, amount):
        print(f"Card: {amount}")


class CashPayment(Payment):
    def pay(self, amount):
        print(f"Cash: {amount}")
```

Код, использующий `Payment`, может работать с общим методом `pay()`.

---

# 🧱 Композиция

**Композиция** — построение объекта из других объектов.

```python
class Engine:
    def start(self):
        print("Engine started")


class Car:
    def __init__(self):
        self.engine = Engine()
```

Здесь:

```text
Car
 ↓
Engine
```

`Car` **содержит** `Engine`.

Часто композиция предпочтительнее глубокого наследования:

> **Composition over inheritance** — предпочитай композицию наследованию, когда она лучше отражает отношения между объектами.

---

# 🆚 Наследование vs композиция

|                   | Наследование       | Композиция             |
| ----------------- | ------------------ | ---------------------- |
| Отношение         | `is-a`             | `has-a`                |
| Пример            | `Dog is an Animal` | `Car has an Engine`    |
| Переиспользование | Через родителя     | Через вложенный объект |
| Связанность       | Выше               | Обычно ниже            |
| Гибкость          | Ниже               | Выше                   |

---

# 📌 Виды методов

### Обычный метод

Работает с экземпляром:

```python
class User:
    def hello(self):
        return "Hello"
```

Получает `self`.

### `classmethod`

Работает с классом:

```python
class User:
    @classmethod
    def create(cls):
        return cls()
```

Получает `cls`.

### `staticmethod`

Не получает автоматически ни `self`, ни `cls`:

```python
class Math:
    @staticmethod
    def add(a, b):
        return a + b
```

---

# 🧠 Магические методы

Специальные методы Python, обычно начинающиеся и заканчивающиеся двойным подчёркиванием:

```python
__init__
__str__
__repr__
__len__
__eq__
__lt__
```

Например:

```python
class User:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return self.name
```

Теперь:

```python
print(User("Ilya"))
```

использует `__str__`.

# 🐍 Особенности ООП в Python

Python поддерживает:

* классы;
* наследование;
* множественное наследование;
* абстрактные классы;
* полиморфизм;
* duck typing;
* свойства через `@property`;
* магические методы;
* протоколы и структурную типизацию.

Например, множественное наследование:

```python
class A:
    pass


class B:
    pass


class C(A, B):
    pass
```

При сложном множественном наследовании Python использует **MRO (Method Resolution Order)** — порядок поиска методов.

Узнать его:

```python
C.mro()
```
