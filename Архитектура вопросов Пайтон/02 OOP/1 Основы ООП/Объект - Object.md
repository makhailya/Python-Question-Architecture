# 🧩 Объект в Python

## 🎤 Короткий ответ

**Объект — это конкретная сущность в памяти Python, у которой есть тип, состояние и поведение.**

Практически всё в Python является объектом:

```python
number = 42
name = "Ilya"
items = [1, 2, 3]
```

У каждого объекта есть:

* **идентичность** — какой именно это объект;
* **тип** — что это за объект;
* **значение / состояние** — какие данные он содержит.

Например:

```python
user = User("Илья")
```

`user` — это объект, `User` — его класс.

## 🗣️ Ответ на собеседовании

> Объект в Python — это экземпляр некоторого типа, который существует в памяти и имеет идентичность, тип и состояние.
>
> В Python практически всё является объектом: числа, строки, списки, функции и даже классы.
>

> Идентичность объекта можно получить через `id()`, тип — через `type()`. Важный момент: две переменные могут ссылаться на один и тот же объект, поэтому `is` проверяет идентичность, а `==` — равенство значений.

# 📚 Разбор поглубже

## 1. Что такое объект

Объект — это сущность, с которой Python может работать во время выполнения программы.

Например:

```python
number = 42
name = "Ilya"
items = [1, 2, 3]
```

Здесь объектами являются:

```text
42
"Ilya"
[1, 2, 3]
```

А переменные:

```text
number
name
items
```

— это имена, которые ссылаются на объекты.

Это важное различие.

---

# 2. Переменная — не объект

Рассмотрим:

```python
x = 42
```

Упрощённо:

```text
x ──────→ 42
          ↑
        объект
```

`x` — имя.

`42` — объект.

Поэтому правильнее говорить:

> переменная ссылается на объект

а не:

> переменная содержит объект внутри себя.

---

# 3. Три основных свойства объекта

В Python удобно выделять три характеристики:

```text
Объект
├── Identity — идентичность
├── Type     — тип
└── Value    — значение / состояние
```

---

## 4. Идентичность

Идентичность отвечает на вопрос:

> Это именно тот же объект или другой?

Получить идентификатор можно через:

```python
x = 42

print(id(x))
```

`id()` возвращает идентификатор объекта, уникальный в рамках его времени жизни.

Для проверки идентичности используется:

```python
is
```

Например:

```python
a = []
b = a

print(a is b)
```

Результат:

```text
True
```

Потому что обе переменные ссылаются на один объект.

---

# 5. Тип объекта

Тип показывает, каким объектом является значение.

```python
x = 42

print(type(x))
```

Результат:

```text
<class 'int'>
```

Другие примеры:

```python
type("hello")      # str
type([1, 2, 3])    # list
type({"a": 1})     # dict
type(lambda: None) # function
```

Тип определяет доступное объекту поведение.

Например, у строки есть:

```python
name = "Ilya"

name.upper()
name.lower()
```

А у списка есть:

```python
items = [1, 2, 3]

items.append(4)
items.pop()
```

---

# 6. Состояние объекта

Состояние — это данные, которые описывают текущее состояние объекта.

Например:

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

Создаём объект:

```python
user = User("Илья", 31)
```

Его состояние:

```text
name = "Илья"
age = 31
```

Если изменить:

```python
user.age = 32
```

объект останется тем же самым, но его состояние изменится.

---

# 7. Поведение объекта

Объект может иметь поведение, которое реализуется методами.

```python
class User:
    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print(f"Привет, {self.name}")
```

Теперь:

```python
user = User("Илья")

user.say_hello()
```

Здесь:

```text
User
├── состояние
│   └── name
│
└── поведение
    └── say_hello()
```

---

# 8. Объект и класс

Связь можно представить так:

```text
Класс User
    │
    ├── user1
    ├── user2
    └── user3
```

Например:

```python
class User:
    def __init__(self, name):
        self.name = name


user1 = User("Илья")
user2 = User("Анна")
```

Получаем два разных объекта:

```text
user1 ──→ User("Илья")

user2 ──→ User("Анна")
```

Они имеют один тип:

```python
type(user1) is User
type(user2) is User
```

но являются разными объектами:

```python
user1 is user2
```

Результат:

```text
False
```

# 9. `is` и `==`

Это один из важных вопросов на собеседовании.

### `is`

Проверяет:

> Это один и тот же объект?

```python
a = []
b = a

a is b
```

```text
True
```

---

### `==`

Проверяет:

> Равны ли объекты по значению?

```python
a = [1, 2, 3]
b = [1, 2, 3]

a == b
```

```text
True
```

Но:

```python
a is b
```

```text
False
```

Потому что это два разных списка.

```text
a ──→ [1, 2, 3]
          ↑
          │ одинаковое содержимое
          ↓
b ──→ [1, 2, 3]

a == b → True
a is b → False
```

# 10. Всё в Python является объектом

Это фундаментальная особенность Python.

Объектами являются:

```text
int
str
list
dict
set
tuple
function
class
module
```

Например, функция тоже объект:

```python
def hello():
    print("Hello")


print(type(hello))
```

Результат:

```text
<class 'function'>
```

Функцию можно передать как значение:


# 11. Даже класс является объектом

Например:

```python
class User:
    pass
```

Проверяем:

```python
type(User)
```

Получаем:

```text
<class 'type'>
```

То есть:

```text
user
 ↓
экземпляр User

User
 ↓
экземпляр type
```

Поэтому Python часто называют языком, где **классы являются объектами первого класса**.

# 12. Изменяемые и неизменяемые объекты

Объекты Python можно разделить по возможности изменения их состояния.

### Immutable

После создания состояние нельзя изменить.

Примеры:

```text
int
float
bool
str
tuple
frozenset
```

Например:

```python
x = 10

x = x + 1
```

Это не изменение объекта `10`.

Создаётся или используется другой объект:

```text
x ──→ 10

после x = x + 1

x ──→ 11
```

---

### Mutable

Состояние объекта можно изменить.

Например:

```python
items = [1, 2, 3]

items.append(4)
```

Здесь изменяется существующий список.

```text
items ──→ [1, 2, 3]

append(4)

items ──→ [1, 2, 3, 4]
```

---

# 13. Почему это важно

Изменяемость влияет на поведение ссылок.

```python
a = [1, 2, 3]
b = a

b.append(4)
```

Теперь:

```python
print(a)
```

получим:

```text
[1, 2, 3, 4]
```

Почему?

Потому что:

```text
a ──┐
    ├──→ один объект list
b ──┘
```

Изменение через `b` видно через `a`.

# 14. Объект хранится в памяти

Упрощённо можно представить:

```text
Переменная
    ↓
ссылка
    ↓
┌───────────────┐
│    Объект     │
│               │
│ type          │
│ state         │
│ behavior      │
└───────────────┘
```

В CPython внутренняя структура объекта содержит как минимум информацию, необходимую для определения его типа и управления временем жизни объекта.

Точная внутренняя структура зависит от реализации Python.

---

# 15. Время жизни объекта

Объект существует, пока он нужен программе.

Например:

```python
user = User("Илья")
```

После удаления ссылки:

```python
del user
```

объект может стать недостижимым.

В CPython основным механизмом управления временем жизни является **подсчёт ссылок**, а циклический GC дополнительно обнаруживает циклические ссылки.

```text
02 OOP
└── Объект
    └── Управление памятью
        ├── Reference Counting
        └── Garbage Collector
```

Это уже связывает тему объектов с разделом **«Память и GC»**.

# 16. Объект может иметь атрибуты

Например:

```python
class User:
    pass


user = User()

user.name = "Илья"
user.age = 31
```

Теперь объект имеет:

```text
user
├── name
└── age
```

Получить атрибут:

```python
print(user.name)
```

Изменить:

```python
user.age = 32
```

Удалить:

```python
del user.age
```

Механизм работы с атрибутами подробно связан с:

```text
__getattribute__
__getattr__
__setattr__
__delattr__
Descriptors
```

# 17. Объект может иметь поведение через тип

Например:

```python
items = [1, 2, 3]
```

Мы можем вызвать:

```python
items.append(4)
```

Метод `append()` не обязательно хранится непосредственно внутри каждого списка.

Он определяется типом `list`.

Упрощённо:

```text
items
  ↓
объект list
  ↓
тип list
  ↓
append()
```

Поиск атрибутов в Python значительно сложнее и включает MRO и дескрипторы, но принципиально поведение объекта определяется его типом.

# 18. Важная связь: объект → класс → тип

Для обычного объекта:

```python
class User:
    pass

user = User()
```

можно построить цепочку:

```text
user
 ↓
экземпляр
 ↓
User
 ↓
экземпляр
 ↓
type
```

То есть:

```python
type(user) is User
type(User) is type
```

Это один из фундаментальных моментов объектной модели Python.

# 🎤 Вопросы на собеседовании

### Что такое объект?

Объект — это экземпляр некоторого типа, существующий во время выполнения программы и имеющий идентичность, тип и состояние.

### Что такое идентичность объекта?

Это признак, позволяющий отличить один объект от другого. В Python с ним связан `id()`.

### Что делает `is`?

Проверяет, являются ли две ссылки ссылками на один и тот же объект.

### Чем `is` отличается от `==`?

`is` проверяет идентичность, а `==` — равенство значений.

### Всё ли в Python является объектом?

Практически всё: числа, строки, функции, классы, модули и экземпляры пользовательских классов.

### Является ли класс объектом?

Да. Например, обычный класс `User` является экземпляром метакласса `type`.

### Что такое состояние объекта?

Данные, характеризующие текущее состояние объекта. Например, `name` и `age` у `User`.

### Что такое поведение объекта?

Операции, которые объект может выполнять, обычно представленные его методами.

### Что такое ссылка на объект?

Имя переменной связывается с объектом и позволяет обращаться к нему.

```python
a = []
b = a
```

Здесь `a` и `b` ссылаются на один объект списка.

### Что произойдёт здесь?

```python
a = [1, 2]
b = a

b.append(3)
```

`a` тоже станет `[1, 2, 3]`, потому что `a` и `b` ссылаются на один изменяемый объект.

### Чем mutable отличается от immutable?

Mutable-объект можно изменить после создания, immutable — нельзя изменить его состояние после создания.
