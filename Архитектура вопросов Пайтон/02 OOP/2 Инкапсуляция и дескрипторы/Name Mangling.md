# Name Mangling

## 🎯 Ответ на собеседовании

**Name mangling** — механизм Python, который автоматически изменяет имя атрибута или метода, начинающегося с `__`, внутри класса.

Имя преобразуется примерно так:

```text
__name → _ClassName__name
```

Это позволяет избежать случайного конфликта имён в классах-наследниках.

---

## 📌 Пример

```python
class User:
    def __init__(self):
        self.__password = "123"


user = User()

print(user.__password)  # AttributeError
```

Но фактически Python хранит атрибут под именем:

```python
print(user._User__password)
# 123
```

То есть:

```text
__password
↓
_User__password
```

---

## 🧬 Зачем нужен Name Mangling?

Основное назначение — **избежать конфликтов имён при наследовании**.

```python
class Parent:
    def __init__(self):
        self.__value = "parent"


class Child(Parent):
    def __init__(self):
        super().__init__()
        self.__value = "child"
```

Здесь это будут **два разных атрибута**:

```python
self._Parent__value
self._Child__value
```

Поэтому `Child.__value` не перезаписывает `Parent.__value`.

---

## ⚠️ Важно: это не настоящая приватность

В Python нет строгих `private` атрибутов, как, например, в некоторых других языках.

Name mangling **не запрещает доступ**:

```python
user._User__password
```

Поэтому правильнее говорить:

> `__attribute` — это механизм предотвращения конфликтов имён, а не механизм безопасности.

---

## `_name` vs `__name`

| Запись     | Значение                                                       |
| ---------- | -------------------------------------------------------------- |
| `name`     | обычный публичный атрибут                                      |
| `_name`    | внутренний атрибут по соглашению                               |
| `__name`   | запускает name mangling                                        |
| `__name__` | специальный атрибут/метод Python, name mangling не применяется |

Например:

```python
class User:
    def __init__(self):
        self.name = "Ilya"        # public
        self._age = 31            # internal
        self.__password = "123"   # name mangling
```

---

## 🔑 Правило преобразования

Для:

```python
class MyClass:
    self.__value = 10
```

Python преобразует имя примерно в:

```python
self._MyClass__value
```

При этом `__` должно находиться **в начале имени**, а имя не должно заканчиваться двумя подчёркиваниями.

---

## 🧠 Главное

* `__name` → запускает **name mangling**.
* Имя превращается в `_ClassName__name`.
* Главная цель — **избежать конфликтов имён при наследовании**.
* Это **не защита данных**.
* Доступ технически возможен через `_ClassName__name`.
* `_name` — только соглашение, `__name` — реальное изменение имени.
* `__name__` — обычно специальные имена Python и name mangling к ним не применяется.

## 🎤 Суперкоротко

> **Name mangling** — это автоматическое преобразование имён атрибутов и методов с `__` в `_ClassName__name`. Оно нужно прежде всего для предотвращения конфликтов имён при наследовании и не является механизмом приватности.
