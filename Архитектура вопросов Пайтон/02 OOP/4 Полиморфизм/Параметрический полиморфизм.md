# Параметрический полиморфизм

## 🎯 Ответ на собеседовании

**Параметрический полиморфизм** — это возможность написать один алгоритм или функцию, который работает с **разными типами данных**, не завязываясь на конкретный тип.

В Python это естественно поддерживается благодаря **динамической типизации**, а в аннотациях типов может выражаться через **[[Generics и TypeVar]]**.

---

## 📌 Простой пример

```python id="7w8f1d"
def first(items):
    return items[0]
```

Функция работает с разными типами:

```python id="x3k2ma"
first([1, 2, 3])          # 1
first(["a", "b", "c"])    # "a"
first((10, 20, 30))       # 10
```

Нам не нужно создавать:

```text
first_int()
first_str()
first_tuple()
```

Один алгоритм работает с разными типами.

---

## 🏷️ Через `TypeVar`

В статической типизации это можно выразить явно:

```python id="z6n2qc"
from typing import TypeVar

T = TypeVar("T")


def first(items: list[T]) -> T:
    return items[0]
```

Здесь `T` — **параметр типа**.

Если передать:

```python id="m8c3vl"
numbers: list[int]
names: list[str]
```

то статический анализатор понимает:

```text
first(numbers) → int
first(names)   → str
```

При этом сама функция одна.

---

## 🧩 Generics

Современный Python позволяет использовать generics и без `TypeVar` в простых случаях:

```python id="7q4z1n"
def first[T](items: list[T]) -> T:
    return items[0]
```

Это синтаксис параметров типов, появившийся в **Python 3.12**.

Для твоего Python 3.13 он доступен.

---

## 🔄 Чем отличается от динамического полиморфизма?

### Динамический

Разные объекты предоставляют один интерфейс:

```python id="m5z7px"
class Dog:
    def speak(self):
        print("Гав")


class Cat:
    def speak(self):
        print("Мяу")


def make_sound(animal):
    animal.speak()
```

Выбор реализации происходит в runtime.

```text id="c8f3qa"
Dog → Dog.speak()
Cat → Cat.speak()
```

---

### Параметрический

Один алгоритм работает с разными **типами**, не изменяя свою логику:

```python id="0l4yqj"
def first[T](items: list[T]) -> T:
    return items[0]
```

```text id="eq2p9r"
list[int]  → T = int
list[str]  → T = str
```

Логика функции остаётся одинаковой.

---

## 🆚 Три вида полиморфизма

| Вид                 | Идея                               | Python                      |
| ------------------- | ---------------------------------- | --------------------------- |
| **Статический**     | Один интерфейс → разные сигнатуры  | `@overload` / type checking |
| **Динамический**    | Один интерфейс → разные реализации | Duck typing, overriding     |
| **Параметрический** | Один алгоритм → разные типы        | Generics, `TypeVar`         |

---

## 💼 Пример из Backend

Например, универсальный репозиторий:

```python id="7pq2bn"
from typing import TypeVar

T = TypeVar("T")


class Repository:
    def save(self, obj: T) -> T:
        ...
```

Или более типизированный вариант:

```python id="z7y2wf"
class Repository[T]:
    def save(self, obj: T) -> T:
        return obj
```

Один `Repository[T]` можно использовать с разными моделями:

```python id="0n4j9c"
UserRepository = Repository[User]
OrderRepository = Repository[Order]
```

Алгоритм репозитория остаётся общим, а конкретный тип задаётся параметром.

---

## ⚠️ Важный нюанс

Не стоит говорить:

> «Параметрический полиморфизм — это просто динамическая типизация».

Это разные понятия.

**Динамическая типизация** означает, что тип объекта определяется во время выполнения.

**Параметрический полиморфизм** означает, что одна абстракция/алгоритм параметризуется типом и может работать с множеством типов.

В Python эти концепции могут пересекаться, но не являются одним и тем же.

---

## 🧠 Главное

* **Параметрический полиморфизм** → один алгоритм работает с разными типами.
* Тип выступает **параметром**.
* В Python для явного описания используются **Generics и `TypeVar`**.
* `list[T]`, `Repository[T]` — типичные примеры.
* `T` не означает конкретный тип — он становится конкретным при использовании обобщённой функции/класса.
* Не путать с динамическим полиморфизмом.

## 🎤 Суперкоротко

> Параметрический полиморфизм — это возможность написать одну обобщённую функцию или структуру, которая работает с разными типами данных. В Python он выражается через Generics и `TypeVar`, например `def first[T](items: list[T]) -> T`.
