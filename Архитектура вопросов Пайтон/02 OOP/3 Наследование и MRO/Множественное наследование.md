# Множественное наследование

## 🎯 Ответ на собеседовании

**Множественное наследование** — это когда один класс наследуется **сразу от нескольких классов**.

В Python это записывается через запятую:

```python
class Child(Parent1, Parent2):
    pass
```

При таком наследовании Python использует **MRO (Method Resolution Order)**, чтобы определить порядок поиска методов и атрибутов.

---

## 📌 Пример

```python
class Flyable:
    def fly(self):
        print("Летит")


class Swimmable:
    def swim(self):
        print("Плывёт")


class Duck(Flyable, Swimmable):
    pass
```

`Duck` наследуется сразу от двух классов:

```text
Flyable
    \
     Duck
    /
Swimmable
```

Поэтому:

```python
duck = Duck()

duck.fly()
duck.swim()
```

Оба метода доступны.

---

## 🔍 MRO

Для:

```python
class Duck(Flyable, Swimmable):
    pass
```

MRO будет примерно:

```text
Duck
↓
Flyable
↓
Swimmable
↓
object
```

Посмотреть:

```python
print(Duck.mro())
```

---

## 🧩 Зачем это нужно?

Часто множественное наследование используется для **комбинации небольших независимых классов**, например mixin-классов.

```python
class JsonMixin:
    def to_json(self):
        ...


class LoggingMixin:
    def log(self):
        ...


class User(JsonMixin, LoggingMixin):
    pass
```

`User` получает функциональность сразу от двух классов.

---

## ⚠️ Проблема: одинаковые методы

Если оба родителя имеют одинаковый метод:

```python
class A:
    def hello(self):
        print("A")


class B:
    def hello(self):
        print("B")


class C(A, B):
    pass
```

При:

```python
C().hello()
```

будет:

```text
A
```

Потому что `A` находится раньше `B` в MRO:

```text
C → A → B → object
```

Если поменять порядок:

```python
class C(B, A):
    pass
```

получим:

```text
C → B → A → object
```

и:

```text
B
```

---

## 💎 Diamond Problem

При множественном наследовании может возникнуть **ромбовидное наследование**:

```text
      A
     / \
    B   C
     \ /
      D
```

```python
class A:
    def hello(self):
        print("A")


class B(A):
    pass


class C(A):
    pass


class D(B, C):
    pass
```

Python использует **C3 Linearization**, чтобы построить корректный MRO:

```text
D → B → C → A → object
```

`A` при этом не вызывается дважды.

---

## 🔑 Множественное наследование и `super()`

`super()` работает согласно MRO.

```python
class A:
    def hello(self):
        print("A")


class B(A):
    def hello(self):
        print("B")
        super().hello()


class C(A):
    def hello(self):
        print("C")
        super().hello()


class D(B, C):
    def hello(self):
        print("D")
        super().hello()
```

MRO:

```text
D → B → C → A → object
```

Поэтому:

```python
D().hello()
```

выведет:

```text
D
B
C
A
```

Это один из главных моментов, которые важно понимать: **`super()` переходит к следующему классу в MRO**, а не обязательно напрямую к родителю.

---

## 🧠 Главное

* **Множественное наследование** → класс имеет несколько родителей.
* Синтаксис: `class C(A, B)`.
* При конфликте методов используется **MRO**.
* MRO строится с помощью **C3 Linearization**.
* `super()` продолжает поиск по MRO.
* Частое практическое применение — **Mixin-классы**.
* Слишком сложное множественное наследование может сделать код трудным для понимания.

## 🎤 Суперкоротко

> Множественное наследование — это когда класс наследуется от нескольких классов. Python разрешает такие отношения через MRO и C3 Linearization, а `super()` позволяет последовательно пройти по этому порядку.
