# C3-линеаризация

## 🎯 Ответ на собеседовании

**C3-линеаризация** — это алгоритм, который Python использует для построения **[[MRO (Method Resolution Order)]]** при наследовании, особенно при [[Множественное наследование]].

Он определяет **однозначный и согласованный порядок классов**, в котором Python будет искать методы и атрибуты.

C3 появилась в Python 2.3 и используется в современном Python.

---

## 📌 Пример

```python
class A:
    pass


class B(A):
    pass


class C(A):
    pass


class D(B, C):
    pass
```

Структура наследования:

```text
      A
     / \
    B   C
     \ /
      D
```

C3-линеаризация строит MRO:

```text
D → B → C → A → object
```

Проверить:

```python
print(D.mro())
```

---

## 🧠 Зачем нужна C3?

Главная задача — корректно разрешить **множественное наследование** и избежать неоднозначности.

Например:

```python
class A:
    def hello(self):
        print("A")


class B(A):
    pass


class C(A):
    def hello(self):
        print("C")


class D(B, C):
    pass
```

MRO:

```text
D → B → C → A → object
```

При:

```python
D().hello()
```

Python ищет:

```text
D       — нет hello
↓
B       — нет hello
↓
C       — есть hello ← вызываем
```

Результат:

```text
C
```

---

## 🔑 Основные гарантии C3

C3 должна соблюдать несколько важных правил.

### 1. Сохраняется порядок родителей

Если написано:

```python
class D(B, C):
    pass
```

то `B` должен находиться в MRO раньше `C`.

```text
D → B → C ...
```

---

### 2. Сохраняется порядок наследования

Если:

```text
B → A
```

то в MRO `B` должен находиться раньше `A`.

То есть нельзя получить:

```text
A → B
```

---

### 3. Класс не появляется несколько раз

Для:

```text
      A
     / \
    B   C
     \ /
      D
```

MRO:

```text
D → B → C → A → object
```

а не:

```text
D → B → A → C → A
```

`A` появляется только один раз.

---

## ⚙️ Как работает алгоритм

C3 строит итоговый MRO путём **слияния (merge)** MRO родителей и списка самих родителей.

Упрощённо:

```text
MRO(D) = [D] + merge(
    MRO(B),
    MRO(C),
    [B, C]
)
```

Для нашего примера:

```text
MRO(B) = [B, A, object]
MRO(C) = [C, A, object]
```

Затем C3 объединяет эти последовательности так, чтобы сохранить все ограничения порядка.

Получается:

```text
[D, B, C, A, object]
```

На собеседовании обычно **не требуется вручную воспроизводить весь алгоритм**, если вопрос не про внутреннюю механику MRO.

---

## ⚠️ Что будет при противоречивом наследовании?

Если невозможно построить согласованный MRO, Python выдаст:

```text
TypeError: Cannot create a consistent method resolution
order (MRO)
```

Например, если требования к порядку родителей противоречат друг другу, класс создать нельзя.

## 🔗 C3 и `super()`

`super()` напрямую связан с MRO.

```python
class A:
    def hello(self):
        print("A")


class B(A):
    def hello(self):
        print("B")
        super().hello()


class C(A):
    def hello(self):
        print("C")
        super().hello()


class D(B, C):
    def hello(self):
        print("D")
        super().hello()
```

MRO:

```text
D → B → C → A → object
```

Поэтому:

```python
D().hello()
```

даст:

```text
D
B
C
A
```

`super()` переходит к **следующему классу в MRO**, который был построен C3-линеаризацией.

---

## 🧩 Связь терминов

```text
Множественное наследование
          ↓
         MRO
          ↓
   C3-линеаризация
          ↓
определяет порядок классов
          ↓
       super()
```

---

## 🎤 Суперкоротко

> **C3-линеаризация** — алгоритм построения MRO в Python. Она определяет согласованный порядок поиска методов при наследовании, сохраняет порядок указанных родителей, порядок наследования и не допускает дублирования классов. `super()` затем использует полученный MRO.
