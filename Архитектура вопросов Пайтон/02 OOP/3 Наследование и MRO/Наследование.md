# 🧬 Наследование

## 🎯 Ответ на собеседовании

**Наследование** — принцип ООП, который позволяет создать новый класс (**потомок**) на основе существующего класса (**родителя**) и получить его атрибуты и методы.

Потомок может:

* использовать унаследованное поведение;
* добавлять своё;
* переопределять методы родителя.

```python
class Animal:
    def speak(self):
        return "Some sound"


class Dog(Animal):
    def bark(self):
        return "Woof"
```

Теперь:

```python
dog = Dog()

dog.speak()  # Some sound
dog.bark()   # Woof
```

`Dog` наследует метод `speak()` от `Animal`.

---

## 📌 Базовый и производный класс

Терминология:

```text
Animal → родительский / базовый класс
   ↓
Dog → дочерний / производный класс
```

В Python:

```python
class Dog(Animal):
    ...
```

`Dog` является подклассом `Animal`.

Проверить:

```python
issubclass(Dog, Animal)  # True
```

Проверить конкретный объект:

```python
isinstance(dog, Animal)  # True
```

---

# 🔄 Переопределение метода

Потомок может изменить реализацию метода родителя:

```python
class Animal:
    def speak(self):
        return "Some sound"


class Dog(Animal):
    def speak(self):
        return "Woof"
```

Теперь:

```python
Dog().speak()
# Woof
```

Метод `Dog.speak()` **переопределяет** `Animal.speak()`.

---

# 🔝 `super()`

`super()` позволяет обратиться к реализации родительского класса.

```python
class Animal:
    def __init__(self, name):
        self.name = name


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
```

Здесь:

```python
super().__init__(name)
```

вызывает следующий `__init__` согласно **MRO**.

Это особенно важно при множественном наследовании.

---

# 🧩 Множественное наследование

Python позволяет наследоваться сразу от нескольких классов:

```python
class Flyable:
    def fly(self):
        return "Flying"


class Swimmable:
    def swim(self):
        return "Swimming"


class Duck(Flyable, Swimmable):
    pass
```

Теперь:

```python
duck = Duck()

duck.fly()
duck.swim()
```

`Duck` получает поведение обоих классов.

```text
Flyable ──┐
          ├──→ Duck
Swimmable ┘
```

---

# 🧭 MRO

При наследовании от нескольких классов возникает вопрос:

> **В каком порядке Python должен искать методы?**

Для этого существует **MRO (Method Resolution Order)** — порядок разрешения методов.

Посмотреть:

```python
Duck.mro()
```

Например:

```text
Duck
 ↓
Flyable
 ↓
Swimmable
 ↓
object
```

Python ищет нужный метод согласно этому порядку.

---

# 🧠 `object`

Все обычные классы Python в конечном итоге наследуются от `object`.

```text
Dog
 ↓
Animal
 ↓
object
```

Поэтому:

```python
isinstance(dog, object)
```

вернёт:

```python
True
```

---

# 📌 Что наследуется?

Потомок получает доступ к атрибутам и методам родительского класса.

```python
class Animal:
    species = "animal"

    def eat(self):
        return "Eating"


class Dog(Animal):
    pass
```

```python
dog = Dog()

dog.species  # animal
dog.eat()    # Eating
```

Но это не означает, что все данные буквально копируются из класса в класс. Python **ищет атрибуты по цепочке классов**.

---

# 🆚 Наследование vs композиция

Наследование обычно выражает отношение:

> **is-a — является**

```text
Dog is an Animal
```

Композиция:

> **has-a — содержит**

```text
Car has an Engine
```

Пример композиции:

```python
class Engine:
    def start(self):
        return "Started"


class Car:
    def __init__(self):
        self.engine = Engine()
```

Здесь `Car` не наследуется от `Engine`, а **содержит** его.

---

# ⚠️ Не стоит злоупотреблять наследованием

Глубокие и сложные иерархии:

```text
A
↓
B
↓
C
↓
D
↓
E
```

могут сделать код сложным для понимания и сильно связать классы между собой.

Поэтому часто используют принцип:

> **Composition over inheritance — предпочитай композицию наследованию**, если отношение между объектами лучше выражается через «содержит», а не через «является».

---

# 🧠 Главное

```text
Родительский класс
       ↓
    наследование
       ↓
Дочерний класс
       ↓
использует / расширяет / переопределяет
поведение родителя
```

Важно знать:

* базовый и производный класс;
* переопределение методов;
* `super()`;
* `isinstance()`;
* `issubclass()`;
* множественное наследование;
* MRO;
* `object`;
* композицию vs наследование.

### 🎤 Суперкоротко

> **Наследование позволяет создать новый класс на основе существующего и переиспользовать его атрибуты и методы. Дочерний класс может расширять или переопределять поведение родителя. В Python поддерживается множественное наследование, а порядок поиска методов определяется MRO.**
