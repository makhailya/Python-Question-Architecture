# Бинарное дерево — Binary Tree

## Коротко

Бинарное дерево (`binary tree`) — это структура данных, состоящая из узлов (`nodes`), где каждый узел может иметь не более двух дочерних узлов:

- `left` — левый потомок
- `right` — правый потомок

Упрощённо:

```text
        10
       /  \
      5    20
     / \     \
    2   7     30
```

Верхний узел называется корнем (root).

Узлы без дочерних элементов называются листьями (leaf).

## На собеседовании достаточно сказать

Бинарное дерево — это структура данных, состоящая из узлов, где каждый узел имеет не более двух потомков: левого и правого. Верхний узел называется корнем, а узлы без потомков — листьями.

## Что важно помнить

У каждого узла может быть:

```
0 потомков
1 потомок
2 потомка
```

Но не больше двух.

Например:

```
        A
       / \
      B   C
     /
    D
```

Здесь:

* A — корень (root)
* B и C — дочерние узлы (children) для A
* D — дочерний узел для B
* C и D — листья (leaf)

## Реализация узла

Простейший вариант:

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
```

Создадим дерево:

```python
root = Node(10)

root.left = Node(5)
root.right = Node(20)

root.left.left = Node(2)
root.left.right = Node(7)
```

Получаем:

```
        10
       /  \
      5    20
     / \
    2   7
```

## Бинарное дерево ≠ бинарное дерево поиска

Это важно не путать.

Бинарное дерево ограничивает только количество потомков:

```
        10
       /  \
      20    5
```

Такое дерево допустимо.

Бинарное дерево поиска (BST) дополнительно имеет правило расположения значений:

```
        10
       /  \
      5    20
```

Для каждого узла:

```
левое поддерево < узел < правое поддерево
```

Поэтому:

```
        10
       /  \
      5    20
```

— корректный BST.

А:

```
        10
       /  \
      20    5
```

— обычное бинарное дерево, но не BST.

Главное

Нужно запомнить три вещи:

```
Binary Tree
│
├── root — корень
├── node — узел
└── максимум 2 children
       ├── left
       └── right
```

Бинарное дерево — это просто ограничение на количество потомков.

BST — это бинарное дерево + правило расположения значений.
