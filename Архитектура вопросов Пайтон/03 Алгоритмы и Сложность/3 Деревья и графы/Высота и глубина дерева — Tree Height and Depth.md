# Высота и глубина дерева — Tree Height and Depth

## Коротко

**Глубина узла (`depth`)** — количество рёбер от корня (`root`) до этого узла.

**Высота узла (`height`)** — количество рёбер от этого узла до самого глубокого листа.

Высота всего дерева — высота его корня.

Например:

```text
        10          ← depth = 0
       /  \
      5    20       ← depth = 1
     / \
    2   7           ← depth = 2
```

У дерева выше высота равна 2.

На собеседовании достаточно сказать
## 
Глубина узла — это расстояние от корня до этого узла, обычно измеряемое количеством рёбер. Высота узла — расстояние от него до самого глубокого листа. Высота дерева — это высота корневого узла.

## Что важно помнить

Глубина

Корень имеет глубину:

```
depth = 0
```

Его дети:

```
depth = 1
```

Следующий уровень:

```
depth = 2
```

Например:

```
        A          depth 0
       / \
      B   C        depth 1
     /
    D              depth 2
```

## Высота

Для листа высота обычно равна:

```
height = 0
```

потому что до самого глубокого потомка нужно пройти 0 рёбер.

Например:

```
        A
       /
      B
     /
    C
```

Высота:

```
C → 0
B → 1
A → 2
```

Следовательно, высота дерева равна 2.

## Высота и глубина — не одно и то же

Важно не перепутать:

```
depth
↓
от корня к узлу

height
↓
от узла к самому глубокому листу
```

Можно представить:

```
        A
       / \
      B   C
     /
    D

    ↑
    │ depth
    │
   root
```

А высота считается в обратную сторону:

```
        A
       /
      B
     /
    D
    ↑
    │
    height
    │
    A
```

Сложность

Если дерево содержит n узлов, нахождение высоты обычным обходом дерева занимает:

```
O(n)
```

потому что в общем случае необходимо посетить узлы дерева.

## Главное

Запомнить:

```
Depth = от корня до узла

Height = от узла до самого глубокого листа
```

И:

```
height(tree) = height(root)
```

Для корня глубина всегда 0.

Для листа высота обычно 0.
