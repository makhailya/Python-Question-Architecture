# Обход дерева — Tree Traversal

## Коротко

Обход дерева (`Tree Traversal`) — это способ посетить все узлы дерева в определённом порядке.

Для бинарного дерева основные способы:

- `Preorder` — сначала корень
- `Inorder` — корень между левым и правым поддеревом
- `Postorder` — сначала потомки, затем корень
- `Level-order` — по уровням

Рассмотрим дерево:

```text
        10
       /  \
      5    20
     / \     \
    2   7     30
```

## На собеседовании достаточно сказать

Обход дерева — это способ последовательно посетить все его узлы. Для бинарного дерева существуют основные обходы DFS: preorder, inorder и postorder, а также BFS — level-order. Они отличаются порядком посещения узлов.

Что важно помнить

Preorder

Порядок:

```
Root → Left → Right
```

Для нашего дерева:

```
10 → 5 → 2 → 7 → 20 → 30
```

Сначала посещаем текущий узел, затем левое и правое поддерево.

⸻

## Inorder

Порядок:

```
Left → Root → Right
```

Для нашего дерева:

```
2 → 5 → 7 → 10 → 20 → 30
```

Особенно важно для BST.

Если выполнить inorder для корректного BST, значения будут получены в отсортированном порядке.

⸻

## Postorder

Порядок:

```
Left → Right → Root
```

Для нашего дерева:

```
2 → 7 → 5 → 30 → 20 → 10
```

Сначала обрабатываем потомков, затем текущий узел.

⸻

## Level-order

Обход выполняется по уровням сверху вниз:

```
10
5 20
2 7 30
```

Результат:

```
10 → 5 → 20 → 2 → 7 → 30
```

Для такого обхода обычно используется очередь (queue).

## Простой пример

Рекурсивный inorder:

```python
def inorder(node):
    if node is None:
        return

    inorder(node.left)
    print(node.value)
    inorder(node.right)
```

Для дерева:

```
        10
       /  \
      5    20
     / \
    2   7
```

Результат:

```
2
5
7
10
20
```

Потому что порядок:

```
Left → Root → Right
```

## Главное

Нужно запомнить три DFS-обхода:

```
Preorder:
Root → Left → Right

Inorder:
Left → Root → Right

Postorder:
Left → Right → Root
```

И отдельно:

```
Level-order:
уровень за уровнем
```

Для BST особенно важен inorder, потому что он позволяет получить элементы в отсортированном порядке.
