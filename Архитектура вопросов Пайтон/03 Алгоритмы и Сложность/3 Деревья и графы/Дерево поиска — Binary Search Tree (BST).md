# Дерево поиска — Binary Search Tree (BST)

## Коротко

Бинарное дерево поиска (`Binary Search Tree`, `BST`) — это бинарное дерево, в котором значения организованы по правилу:

```text
левое поддерево < текущий узел < правое поддерево
```

Например:

```
        10
       /  \
      5    20
     / \   / \
    2   7 15 30
```

Для каждого узла:

* слева находятся меньшие значения;
* справа находятся большие значения.

## На собеседовании достаточно сказать

Бинарное дерево поиска — это бинарное дерево, в котором для каждого узла значения в левом поддереве меньше значения узла, а значения в правом поддереве больше. Благодаря этому поиск, вставка и удаление в среднем случае могут выполняться за O(log n), но в худшем случае сложность может деградировать до O(n).

## Что важно помнить

Главное отличие от обычного бинарного дерева:

```
Binary Tree
→ максимум два потомка

BST
→ максимум два потомка
→ + значения упорядочены
```

Например:

```
        10
       /  \
      5    20
```

Это корректный BST.

А:

```
        10
       /  \
      20    5
```

Это бинарное дерево, но не BST.

Поиск

Допустим, ищем 15:

```
        10
          \
          20
         /
        15
```

Сравниваем:

```
15 > 10 → идём вправо
15 < 20 → идём влево
15 == 15 → нашли
```

За счёт этого нам не нужно проверять все узлы.

## Сложность

Для сбалансированного дерева:

```
Поиск    → O(log n)
Вставка  → O(log n)
Удаление → O(log n)
```

Но если дерево сильно перекошено:

```
10
  \
   20
     \
      30
        \
         40
```

оно начинает напоминать связный список.

В таком случае:

```
Поиск    → O(n)
Вставка  → O(n)
Удаление → O(n)
```

Поэтому форма дерева сильно влияет на производительность.

## Простой пример

Упрощённый узел:

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
```

Создадим BST:

```python
root = Node(10)

root.left = Node(5)
root.right = Node(20)

root.left.left = Node(2)
root.left.right = Node(7)
```

Получаем:

```
        10
       /  \
      5    20
     / \
    2   7
```

Здесь для каждого узла выполняется правило:

```
left < node < right
```

## Главное

Запомнить:

```
BST = Binary Tree + порядок значений
```

И главное правило:

```
        10
       /  \
   < 10    > 10
```

Средняя сложность поиска — O(log n), если дерево достаточно сбалансировано.

В худшем случае — O(n).
