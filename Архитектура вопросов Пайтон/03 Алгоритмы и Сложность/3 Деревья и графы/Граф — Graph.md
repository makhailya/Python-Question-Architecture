# Граф — Graph

## Коротко

Граф (`Graph`) — это структура данных, состоящая из вершин (`vertices` / `nodes`) и рёбер (`edges`), которые соединяют вершины.

Пример:

```text
    A
   / \
  B   C
   \ /
    D
```

Здесь:

* A, B, C, D — вершины;
* линии между ними — рёбра.

## На собеседовании достаточно сказать

Граф — это структура данных, состоящая из вершин и рёбер, которые описывают связи между вершинами. Графы могут быть ориентированными или неориентированными, а рёбра могут иметь веса.

## Что важно помнить

Вершина

Вершина (vertex) — отдельный объект графа.

Например:

```
A
```

## Ребро

Ребро (edge) — связь между двумя вершинами.

```
A ─── B
```

Здесь A и B — вершины, а связь между ними — ребро.

## Неориентированный граф

Связь работает в обе стороны:

```
A ─── B
```

Можно перейти:

```
A → B
B → A
```

Например, связь между двумя пользователями социальной сети.

⸻

## Ориентированный граф

У ребра есть направление:

```
A → B
```

Можно перейти:

```
A → B
```

но это не означает, что можно перейти обратно:

```
B → A
```

Например, подписка одного пользователя на другого.

⸻

## Взвешенный граф

Рёбрам можно назначать вес:

```
A ──5── B
```

Например, если вершины — города, вес может обозначать расстояние:

```
Москва ──700── Санкт-Петербург
```

Вес может представлять:

* расстояние;
* стоимость;
* время;
* пропускную способность;
* другой числовой параметр.

## Граф и дерево

Дерево является частным случаем графа.

У дерева:

* нет циклов;
* между двумя вершинами существует единственный путь;
* если в дереве n вершин, то рёбер n - 1.

Граф может иметь:

```
циклы
несколько путей
направления
веса
```

Например:

```
Граф:

A ─── B
│   / │
│  /  │
C ─── D
```

Здесь существует несколько путей между некоторыми вершинами.

Простой пример

Граф можно представить с помощью словаря списков смежности:

```python
graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C"],
}
```

Например:

```python
graph["A"]
```

получим:

```python
["B", "C"]
```

То есть из вершины A есть рёбра к B и C.

Такая структура называется списком смежности (adjacency list).

## Главное

Запомнить:

```
Graph
│
├── Vertex / Node
│   └── вершина
│
└── Edge
    └── ребро
```

Основные виды:

```
Неориентированный
A ─── B

Ориентированный
A ───→ B

Взвешенный
A ──5── B
```

Граф используется для представления связей между объектами.
