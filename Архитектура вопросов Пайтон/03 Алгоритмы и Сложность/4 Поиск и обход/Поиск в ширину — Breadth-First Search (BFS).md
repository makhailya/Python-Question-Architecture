# Поиск в ширину — Breadth-First Search (BFS)

## Коротко

BFS (`Breadth-First Search`) — алгоритм обхода графа, который исследует вершины **по уровням**: сначала ближайшие к стартовой вершине, затем следующие.

Для работы BFS обычно используется очередь (`queue`).

Пример:

```text
        A
       / \
      B   C
     /     \
    D       E
```

Если начать с A:

```
A → B → C → D → E
```

## На собеседовании достаточно сказать

### BFS — это алгоритм обхода графа в ширину. Он сначала посещает вершину, затем всех её соседей, затем соседей следующего уровня. Обычно для реализации используется очередь. На графе без весов BFS позволяет найти кратчайший путь по количеству рёбер.

Что важно помнить

Главный принцип:

```
старт
  ↓
все соседи
  ↓
соседи соседей
  ↓
следующий уровень
```

Для предотвращения повторного посещения вершин обычно используют visited.

## Простой пример

```python
from collections import deque

graph = {
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["E"],
    "D": [],
    "E": [],
}

def bfs(graph, start):
    visited = {start}
    queue = deque([start])

    while queue:
        node = queue.popleft()
        print(node)

        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

bfs(graph, "A")
```

Результат:

```
A
B
C
D
E
```

## Почему используется deque

В BFS нужно:

```python
queue.popleft()
```

Удаление с начала deque выполняется за:

```
O(1)
```

Если использовать обычный list:

```python
queue.pop(0)
```

удаление с начала имеет сложность:

```
O(n)
```

Поэтому для очереди BFS лучше использовать collections.deque.

## Сложность

Для графа, представленного списком смежности:

```
Время:  O(V + E)
Память: O(V)
```

где:

* V — количество вершин;
* E — количество рёбер.

Каждая вершина посещается максимум один раз, а рёбра просматриваются при обходе соседей.

## BFS и кратчайший путь

Если граф невзвешенный, BFS может найти кратчайший путь по количеству рёбер.

Например:

```
A ─ B ─ D
│
C ─ E ─ D
```

Из A в D:

```
A → B → D
```

Расстояние:

```
2 ребра
```

### BFS сначала проверит вершины на расстоянии 1, затем на расстоянии 2, поэтому первый найденный путь до вершины будет кратчайшим по числу рёбер.

## Главное

Запомнить:

```
BFS
│
├── обход в ширину
├── идёт по уровням
├── использует Queue
├── visited защищает от повторов
└── O(V + E)
```

И важное применение:

```
BFS + невзвешенный граф
→ кратчайший путь по количеству рёбер
```
