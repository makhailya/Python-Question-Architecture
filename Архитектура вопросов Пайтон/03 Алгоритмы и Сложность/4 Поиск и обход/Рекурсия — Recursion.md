# Рекурсия — Recursion

## Коротко

Рекурсия — это способ решения задачи, при котором функция вызывает саму себя.

У рекурсивной функции обязательно должно быть условие остановки — **базовый случай (`base case`)**.

Общая структура:

```python
def function(...):
    if base_case:
        return

    function(...)
```

## На собеседовании достаточно сказать

Рекурсия — это когда функция вызывает саму себя. У рекурсивной функции должен быть базовый случай, который останавливает дальнейшие вызовы. Каждый рекурсивный вызов добавляется в стек вызовов, поэтому слишком глубокая рекурсия может привести к RecursionError.

## Что важно помнить

У рекурсии есть две основные части:

1. Базовый случай

Условие, при котором функция перестаёт вызывать себя.

```python
if n == 0:
    return
```

## Рекурсивный вызов

Функция вызывает саму себя с изменённым аргументом:

```python
function(n - 1)
```

Без базового случая рекурсия не остановится.

## Простой пример

Посчитать сумму чисел от 1 до n:

```python
def sum_numbers(n):
    if n == 0:
        return 0

    return n + sum_numbers(n - 1)
```

Для:

```python
sum_numbers(3)
```

вызовы будут выглядеть так:

```
sum_numbers(3)
    ↓
3 + sum_numbers(2)
        ↓
        2 + sum_numbers(1)
                ↓
                1 + sum_numbers(0)
                        ↓
                        0
```

Затем результаты возвращаются обратно:

```
0
↓
1 + 0 = 1
↓
2 + 1 = 3
↓
3 + 3 = 6
```

Результат:

```python
6
```

## Стек вызовов

Каждый вызов функции помещается в стек (call stack).

Например:

```
sum_numbers(3)
sum_numbers(2)
sum_numbers(1)
sum_numbers(0)
```

Когда базовый случай достигнут, функции начинают завершаться в обратном порядке.

Это принцип:

```
LIFO
```

То есть последний вызов завершается первым.

## Рекурсия в DFS

DFS часто реализуют именно через рекурсию:

```python
def dfs(graph, node, visited):
    visited.add(node)

    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
```

Каждый переход в соседнюю вершину создаёт новый вызов dfs().

Поэтому DFS и рекурсия связаны со [[Стек — Stack]].

## Ограничение рекурсии в Python

Python ограничивает глубину рекурсивных вызовов.

При слишком глубокой рекурсии можно получить:

```
RecursionError: maximum recursion depth exceeded
```

Поэтому для очень глубоких структур иногда лучше использовать обычный цикл и явный стек.

## Рекурсия vs цикл

Одну и ту же задачу часто можно решить двумя способами.

Рекурсивно:

```python
def countdown(n):
    if n == 0:
        return

    print(n)
    countdown(n - 1)
```

Через цикл:

```python
def countdown(n):
    while n > 0:
        print(n)
        n -= 1
```

Рекурсивный вариант иногда проще для задач с деревьями и графами, но цикл позволяет избежать глубокой рекурсии.

## Главное

Запомнить:

```
Рекурсия
│
├── функция вызывает сама себя
├── нужен Base Case
├── вызовы хранятся в Call Stack
└── слишком глубокая рекурсия → RecursionError
```

Главное правило:

```
Base Case
    ↓
останавливает рекурсию

Recursive Case
    ↓
продолжает рекурсию
```
