# Куча — Heap

## Коротко

Куча (`Heap`) — это структура данных в виде почти полного бинарного дерева, которая поддерживает специальное свойство порядка.

Основные виды:

- `Min-Heap` — минимальный элемент находится в корне.
- `Max-Heap` — максимальный элемент находится в корне.

Пример `Min-Heap`:

```text
        1
       / \
      3   5
     / \
    7   9
```

Для каждого узла значение родителя не больше значений его потомков.

## На собеседовании достаточно сказать

Куча — это структура данных на основе почти полного бинарного дерева, которая поддерживает специальное свойство порядка. В Min-Heap минимальный элемент находится в корне, а в Max-Heap максимальный. В Python для работы с Min-Heap используется модуль heapq.

## Что важно помнить

Min-Heap

Для каждого узла:

```
parent <= children
```

Например:

```
        1
       / \
      3   5
     / \
    7   9
```

Корень всегда содержит минимальный элемент.

Но важно:

Куча не является полностью отсортированной структурой.

Например:

```
        1
       / \
      5   3
```

может быть корректной кучей, хотя 5 > 3.

Главное условие — родитель должен соответствовать правилу кучи.

Max-Heap

В Max-Heap наоборот:

```
parent >= children
```

Например:

```
        10
       /  \
      7    8
     / \
    3   5
```

В корне находится максимальный элемент.

## Куча в Python

В Python есть модуль:

```python
import heapq
```

По умолчанию heapq реализует Min-Heap.

Например:

```python
import heapq

numbers = [5, 2, 8, 1, 3]

heapq.heapify(numbers)

print(numbers[0])
```

Результат:

```
1
```

heapify() преобразует список в структуру кучи.

## Добавление элемента

```python
heapq.heappush(numbers, 0)
```

## Извлечение минимального элемента

```python
minimum = heapq.heappop(numbers)
```

heappop() удаляет и возвращает минимальный элемент.

## Сложность основных операций

| Операция                       | Сложность |
| ------------------------------ | --------: |
| Получить минимум               |      O(1) |
| Добавить элемент               |  O(log n) |
| Извлечь минимум                |  O(log n) |
| Построить heap через `heapify` |      O(n) |
| Поиск произвольного элемента   |      O(n) |
## Простой пример

Можно использовать кучу как очередь с приоритетом:

```python
import heapq

tasks = []

heapq.heappush(tasks, (2, "Написать код"))
heapq.heappush(tasks, (1, "Исправить баг"))
heapq.heappush(tasks, (3, "Написать документацию"))

print(heapq.heappop(tasks))
```

Результат:

```
(1, 'Исправить баг')
```

Элемент с наименьшим приоритетом извлекается первым.

## Главное

Запомнить:

```
Heap
│
├── Min-Heap
│   └── минимум в корне
│
└── Max-Heap
    └── максимум в корне
```

Основные сложности:

```
получить min/max → O(1)
добавить          → O(log n)
извлечь min/max   → O(log n)
```

В Python:

```python
import heapq
```

heapq — это реализация Min-Heap на основе списка.
