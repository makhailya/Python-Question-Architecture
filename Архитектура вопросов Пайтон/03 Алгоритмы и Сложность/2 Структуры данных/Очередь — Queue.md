# Очередь — Queue

## Коротко

`queue` — это структура данных, работающая по принципу **FIFO (First In, First Out)**: первым добавили — первым извлекли.

Элементы добавляются в конец очереди, а удаляются с начала.

## На собеседовании достаточно сказать

> Очередь — это структура данных, работающая по принципу FIFO: первый добавленный элемент извлекается первым.
>
> Основные операции — добавление в конец (`enqueue`) и удаление с начала (`dequeue`). Для эффективной реализации в Python удобно использовать `collections.deque`, где эти операции имеют сложность O(1).

## Что важно помнить

Представь обычную очередь людей:

```text
Первый → [1] [2] [3] ← Последний
           ↓
         выйдет первым
```

Если элементы добавлялись так:

```
1 → 2 → 3
```

то извлекаться они будут:

```
1 → 2 → 3
```

## Основные операции

Enqueue — добавить элемент в конец очереди:

```
enqueue(4)
```

Dequeue — удалить элемент с начала:

```
dequeue()
```

Peek / Front — посмотреть первый элемент, не удаляя его.

## Простой пример

Для очереди в Python удобно использовать deque:

```python
from collections import deque

queue = deque()

queue.append("Ilya")
queue.append("Alex")
queue.append("Max")

print(queue)
# deque(["Ilya", "Alex", "Max"])

first = queue.popleft()

print(first)
# Ilya

print(queue)
# deque(["Alex", "Max"])
```

Здесь:

```
append()   → добавить в конец
popleft()  → удалить с начала
```

Обе операции имеют сложность O(1).

Почему не использовать list?

Можно написать:

```python
queue = [1, 2, 3]

queue.pop(0)
```

Но pop(0) у list имеет сложность O(n), потому что остальные элементы необходимо сдвинуть.

Для очереди лучше:

```python
from collections import deque

queue = deque([1, 2, 3])

queue.popleft()
```

Здесь удаление с начала имеет сложность O(1).

## Где используется

Очереди используются, например, для:

* обработки задач в порядке поступления;
* очередей запросов;
* систем обработки сообщений;
* BFS — поиска в ширину;
* планирования задач;
* буферов.

## Главное

Запомни:

```
FIFO

1 → 2 → 3
↓
pop
↓
1
```

Первый добавленный элемент выходит первым.

Для Python:

```
queue.append(value)
queue.popleft()
```
