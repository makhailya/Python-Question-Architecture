# Двусторонняя очередь — Deque

## Коротко

`deque` (`collections.deque`) — это структура данных, которая позволяет эффективно добавлять и удалять элементы **с обоих концов**.

Главное отличие от `list`:

- `list` эффективен для добавления и удаления с конца;
- `deque` эффективен для добавления и удаления и с начала, и с конца.

## На собеседовании достаточно сказать

> `deque` — это двусторонняя очередь из модуля `collections`, которая позволяет эффективно добавлять и удалять элементы с обоих концов. В отличие от `list`, операции `append`, `appendleft`, `pop` и `popleft` имеют сложность O(1).

## Что важно помнить

Создать `deque` можно так:

```python
from collections import deque

numbers = deque([1, 2, 3])
```

Добавление в конец:

```python
numbers.append(4)
```

Добавление в начало:

```python
numbers.appendleft(0)
```

Удаление с конца:

```python
numbers.pop()
```

Удаление с начала:

```python
numbers.popleft()
```

Основные операции:

```
append()      → O(1)
appendleft()  → O(1)
pop()         → O(1)
popleft()     → O(1)
```

## Почему deque лучше list для начала очереди?

У list удаление первого элемента:

```python
numbers.pop(0)
```

имеет сложность O(n), потому что остальные элементы необходимо сдвинуть.

У deque:

```python
numbers.popleft()
```

имеет сложность O(1).

## Простой пример

```python
from collections import deque

queue = deque(["Ilya", "Alex"])

queue.append("Max")
queue.popleft()

print(queue)
# deque(["Alex", "Max"])
```

Первый элемент удалился эффективно, без необходимости сдвигать остальные элементы.

## Главное

Запомни:

```
list
 │
 ├── append() → O(1) амортизированно
 ├── pop()    → O(1)
 └── pop(0)   → O(n)


deque
 │
 ├── append()     → O(1)
 ├── appendleft() → O(1)
 ├── pop()        → O(1)
 └── popleft()    → O(1)
```

Поэтому deque хорошо подходит для реализации очередей (queue) и задач, где элементы часто добавляются или удаляются с обоих концов.
