# Приоритетная очередь — Priority Queue

## Коротко

Приоритетная очередь (`Priority Queue`) — это структура данных, в которой элементы извлекаются не обязательно в порядке добавления, а в соответствии с их приоритетом.

Например:

```text
Добавили:

приоритет 3 → задача A
приоритет 1 → задача B
приоритет 2 → задача C

Извлечение:

B → C → A
```

Чем меньше число приоритета, тем раньше элемент извлекается.

## На собеседовании достаточно сказать

Приоритетная очередь — это структура данных, в которой каждый элемент имеет приоритет, и при извлечении первым выбирается элемент с наивысшим приоритетом. Часто для реализации приоритетной очереди используют кучу (Heap).

Что важно помнить

Обычная очередь работает по принципу:

```
FIFO

первый добавлен → первый извлечён
```

Приоритетная очередь:

```
наивысший приоритет → первый извлечён
```

Например 

```
Обычная очередь:

A → B → C
↓
A → B → C
```

Приоритетная очередь:

```
A (3)
B (1)
C (2)

↓ извлекаем

B (1)
C (2)
A (3)
```

## Связь с Heap

Куча хорошо подходит для реализации приоритетной очереди.

В Python для этого можно использовать heapq:

```python
import heapq

queue = []

heapq.heappush(queue, (3, "Задача A"))
heapq.heappush(queue, (1, "Задача B"))
heapq.heappush(queue, (2, "Задача C"))

print(heapq.heappop(queue))
```

Результат:

```
(1, 'Задача B')
```

Поскольку у неё наименьшее значение приоритета.

## Сложность

При использовании бинарной кучи:

| Операция                                | Сложность |
| --------------------------------------- | --------: |
| Посмотреть элемент с высшим приоритетом |      O(1) |
| Добавить элемент                        |  O(log n) |
| Извлечь элемент                         |  O(log n) |
## Главное

Запомнить:

```
Queue
→ FIFO

Priority Queue
→ сначала элемент с наивысшим приоритетом

Heap
→ эффективная структура для реализации Priority Queue
```

В Python для простой реализации приоритетной очереди можно использовать:

```python
import heapq
```
