# Стек — Stack

## Коротко

`stack` — это структура данных, работающая по принципу **LIFO (Last In, First Out)**: последним добавили — первым извлекли.

Элементы добавляются и удаляются с одного конца — вершины стека.

## На собеседовании достаточно сказать

> Стек — это структура данных, работающая по принципу LIFO: последний добавленный элемент извлекается первым.
>
> Основные операции — добавление (`push`) и удаление (`pop`). В типичной реализации эти операции имеют сложность O(1).

## Что важно помнить

Представь стопку тарелок:

```text
      ┌───────┐
      │   3   │ ← извлечём первым
      ├───────┤
      │   2   │
      ├───────┤
      │   1   │
      └───────┘
```

Мы сначала положили:

```
1 → 2 → 3
```

Поэтому первым достанем 3.

## Основные операции

Push — добавить элемент:

```
push(4)
```

Pop — удалить верхний элемент:

```
pop()
```

Peek / Top — посмотреть верхний элемент, не удаляя его.

## Простой пример

В Python стек можно реализовать с помощью list:

```
stack = []

stack.append(1)
stack.append(2)
stack.append(3)

print(stack)
# [1, 2, 3]

last = stack.pop()

print(last)
# 3

print(stack)
# [1, 2]
```

Здесь:

```
append() → push
pop()    → pop
```

Добавление и удаление с конца list имеют сложность O(1).

## Где используется

Стек используется, например, для:

* истории действий;
* отмены операций (undo);
* обхода деревьев и графов;
* проверки скобок;
* вызовов функций и стека вызовов (call stack);
* алгоритмов, где нужно вернуться к предыдущему состоянию.

## Главное

Запомни принцип:

```
LIFO

1 → 2 → 3
        ↓
       pop
        ↓
        3
```

Последний добавленный элемент выходит первым.

Для Python простой стек можно реализовать через:

```
stack.append(value)
stack.pop()
```
