# Связный список — Linked List

## Коротко

`linked list` — это структура данных, состоящая из узлов (`node`), где каждый узел хранит данные и ссылку на следующий узел.

В двусвязном списке узел обычно хранит ссылки и на следующий, и на предыдущий узел.

В отличие от Python `list`, связный список не требует непрерывного участка памяти для всех элементов.

## На собеседовании достаточно сказать

> Связный список — это структура данных, состоящая из узлов, каждый из которых хранит значение и ссылку на следующий узел.
>
> В отличие от Python `list`, элементы связного списка не обязаны находиться рядом в памяти. Доступ по индексу у связного списка имеет сложность O(n), зато вставка или удаление элемента при наличии ссылки на нужный узел может выполняться за O(1).

## Что важно помнить

Упрощённо односвязный список выглядит так:

```text
[10 | next] → [20 | next] → [30 | next] → None
```

Каждый узел содержит:

```
значение
   +
ссылка на следующий узел
```


Например:

```
Node(10) → Node(20) → Node(30) → None
Доступ по индексу
```

Чтобы получить третий элемент, необходимо пройти через предыдущие узлы:

```
10 → 20 → 30
         ↑
      нужный элемент
```

Поэтому доступ по индексу:

```python
O(n)
```

В отличие от Python list:

```python
numbers[2]
```

где доступ по индексу имеет:

```python
O(1)
```

Вставка и удаление

### Если у нас уже есть ссылка на нужный узел, изменение связей может выполняться за O(1).

Например:

До:

```
A → B → C

После удаления B:

A ─────→ C
```

Не нужно сдвигать все последующие элементы.

Простой пример

Упрощённая реализация узла:

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None
```

Создадим несколько узлов:

```python
first = Node(10)
second = Node(20)
third = Node(30)

first.next = second
second.next = third
```

Получаем:

```
first
  ↓
[10] → [20] → [30] → None
Главное
```

Сравнение:

| Операция                            | `list` | Linked List |
| ----------------------------------- | -----: | ----------: |
| Доступ по индексу                   |   O(1) |        O(n) |
| Поиск элемента                      |   O(n) |        O(n) |
| Вставка в начало                    |   O(n) |        O(1) |
| Удаление из начала                  |   O(n) |        O(1) |
| Вставка/удаление при известном узле |   O(n) |        O(1) |
Важно: сложность вставки и удаления зависит от того, есть ли у нас уже ссылка на нужную позицию/узел. Если сначала нужно найти место, поиск может занять O(n).
