# O(1) — Константная сложность

## Коротко

`O(1)` — это **константная алгоритмическая сложность**.

Она означает, что количество операций не зависит от размера входных данных.

Даже если количество элементов увеличится в 10 или 1000 раз, операция выполняется примерно за то же количество шагов.

## На собеседовании достаточно сказать

> `O(1)` — это константная сложность. Количество операций не зависит от размера входных данных.
>
> Например, доступ к элементу списка по индексу имеет сложность `O(1)`.

## Что важно помнить

Представим список:

```python
numbers = [10, 20, 30, 40, 50]
```

Доступ по индексу:

```python
value = numbers[3]
```

Python может напрямую обратиться к нужному элементу.

Неважно, содержит список 5 элементов или 5 миллионов:

```python
numbers[3]
```

Количество действий для получения элемента не растёт вместе с размером списка.

Поэтому:

```
Доступ по индексу → O(1)
```

Важно: O(1) означает не обязательно «одна операция». Это означает, что количество операций не растёт вместе с n.

## Простой пример

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[2])
# 30
```

Мы сразу получаем элемент с индексом 2.

Сложность:

```
O(1)
```

## Сравнение

```
O(1)
↓
размер данных увеличивается
↓
количество операций практически не меняется
```

В отличие от:

```
O(n)
↓
размер данных увеличивается
↓
количество операций растёт вместе с n
```

Например, поиск элемента в обычном списке в худшем случае имеет O(n):

```python
if 100 in numbers:
    print("Нашли")
```

Потому что Python может проверить каждый элемент.

## Главное

### O(1) — одна из лучших асимптотических сложностей.

Но при оценке реальной производительности также имеют значение постоянные множители, стоимость операций, память и другие факторы.
