# Доступ к элементу списка по индексу — List Index Access Complexity

## Коротко

Доступ к элементу `list` по индексу имеет сложность **O(1)**.

Python может напрямую обратиться к нужному элементу списка, поэтому количество элементов в списке не влияет на количество операций доступа.

## На собеседовании достаточно сказать

> Доступ к элементу списка по индексу имеет сложность O(1), потому что список реализован как динамический массив и Python может напрямую обратиться к нужной позиции.

## Что важно помнить

Например:

```python
numbers = [10, 20, 30, 40, 50]

value = numbers[3]
```

Python сразу получает элемент с индексом 3:

```
numbers[3]
    ↓
40
```

Неважно, сколько элементов находится в списке:

```
10 элементов
1000 элементов
1 000 000 элементов
```

Доступ:

```
numbers[3]
```

остаётся O(1).

## Простой пример

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[2])
# 30
```

Доступ к элементу по индексу:

```
numbers[2] → O(1)
```

## Главное

### Нужно отличать доступ по индексу от поиска элемента.

Доступ по индексу:

```python
numbers[2]
```

### → O(1)

Поиск значения:

```python
30 in numbers
```
### → O(n) в худшем случае, потому что Python может последовательно проверить элементы списка.
