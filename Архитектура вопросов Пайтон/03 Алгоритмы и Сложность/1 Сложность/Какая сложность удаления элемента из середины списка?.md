# Удаление элемента из середины списка — List Middle Deletion Complexity

## Коротко

Удаление элемента из середины `list` имеет сложность **O(n)**.

После удаления Python должен сдвинуть все элементы, которые находились справа от удалённого элемента.

## На собеседовании достаточно сказать

> Удаление элемента из середины списка имеет сложность O(n), потому что после удаления остальные элементы справа нужно сдвинуть на одну позицию.

## Что важно помнить

Рассмотрим список:

```python
numbers = [10, 20, 30, 40, 50]
```

Удалим элемент с индексом 2:

```python
del numbers[2]
```

До удаления:

```
[10, 20, 30, 40, 50]
          ↑
        удаляем
```

После удаления:

```
[10, 20, 40, 50]
```

Элементы 40 и 50 должны сдвинуться влево:

```
[10, 20, 30, 40, 50]
          ↓   ↓
[10, 20, 40, 50]
```

### Поэтому в общем случае сложность — O(n).

## Простой пример

```python
numbers = [10, 20, 30, 40, 50]

del numbers[2]

print(numbers)
# [10, 20, 40, 50]
```

Удалили 30, после чего элементы справа были сдвинуты.

## Главное

Важно различать удаление с конца и удаление из середины:

```
Удаление с конца:
numbers.pop()
→ O(1)
```

```
Удаление из середины:
del numbers[index]
→ O(n)
```

### Удаление из начала также имеет сложность O(n), потому что остальные элементы необходимо сдвинуть:

```python
numbers.pop(0)
```

## Сводка операций list

| Операция             |            Сложность |
| -------------------- | -------------------: |
| Доступ по индексу    |                 O(1) |
| `append()` в конец   | O(1) амортизированно |
| `pop()` с конца      |                 O(1) |
| Поиск элемента       |                 O(n) |
| Удаление из середины |                 O(n) |
| Удаление с начала    |                 O(n) |
