# Сложность операций множества — Set Complexity

## Коротко

Основные операции с `set` в среднем имеют сложность **O(1)**:

- проверка наличия элемента;
- добавление элемента;
- удаление элемента.

Операции над всем множеством или несколькими множествами могут иметь сложность **O(n)** и выше, потому что требуется обработать множество элементов.

## На собеседовании достаточно сказать

> Проверка наличия элемента, добавление и удаление элемента в `set` в среднем имеют сложность O(1), потому что `set` использует хеш-таблицу.
>
> Операции, которым необходимо обработать множество элементов, например объединение или пересечение, могут иметь сложность O(n) и зависят от количества элементов.

## Что важно помнить

### Проверка наличия — O(1) в среднем

```python
numbers = {1, 2, 3, 4, 5}

3 in numbers
```

Python использует хеш элемента для быстрого поиска.

```
3 in numbers
     ↓
   hash(3)
     ↓
   поиск
     ↓
   O(1)
```

### Добавление — O(1) в среднем

```python
numbers.add(6)
```

Обычно новый элемент добавляется за постоянное количество операций.

### Удаление — O(1) в среднем

```python
numbers.remove(3)
```

По хешу Python быстро находит нужный элемент и удаляет его.

### Объединение множеств — O(n)

Например:

```python
a = {1, 2, 3}
b = {3, 4, 5}

result = a | b
```

Чтобы получить результат, необходимо обработать элементы множеств.

Поэтому сложность зависит от количества элементов.

### Пересечение — O(n) в типичном анализе

```python
a = {1, 2, 3}
b = {3, 4, 5}

result = a & b
```

Python проверяет элементы одного множества на наличие в другом.

Точная сложность зависит от размеров множеств, поэтому корректнее говорить, что она зависит от количества элементов, а не всегда просто O(n).

## Простой пример

```python
numbers = {1, 2, 3, 4, 5}

print(3 in numbers)
# True

numbers.add(6)

numbers.remove(2)

print(numbers)
# {1, 3, 4, 5, 6}
```

Основные операции:

```
3 in numbers  → O(1) в среднем
add()         → O(1) в среднем
remove()      → O(1) в среднем
```

## Главное

Запомни основную тройку:

```
set
 │
 ├── поиск      → O(1) в среднем
 ├── добавление → O(1) в среднем
 └── удаление   → O(1) в среднем
```

Это возможно благодаря хеш-таблице.
