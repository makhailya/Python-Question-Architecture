# Удаление с конца списка — List Pop Complexity

## Коротко

Удаление последнего элемента списка через `pop()` имеет сложность **`O(1)`**.

Python не должен сдвигать остальные элементы, потому что удаляется последний элемент.

## На собеседовании достаточно сказать

> Удаление последнего элемента списка через `pop()` имеет сложность `O(1)`, потому что после удаления не нужно сдвигать остальные элементы.

## Что важно помнить

Рассмотрим список:

```python
numbers = [10, 20, 30, 40]
```

Удаляем последний элемент:

```python
numbers.pop()
```

Получаем:

```python
[10, 20, 30]
```

Чтобы удалить последний элемент, достаточно изменить размер списка и вернуть последний элемент.

Поэтому:

```
pop() с конца → O(1)
```

Это отличается от удаления элемента из начала или середины списка.

Например:

```
numbers.pop(0)
```

При таком удалении остальные элементы должны сдвинуться, поэтому сложность будет O(n).

## Простой пример

```python
numbers = [10, 20, 30, 40]

last = numbers.pop()

print(last)
# 40

print(numbers)
# [10, 20, 30]
```

Последний элемент удаляется напрямую.

## Главное

Запомни:

```
numbers.append(50)  → O(1) амортизированно

numbers.pop()       → O(1)

numbers.pop(0)      → O(n)
```

append() и pop() с конца делают list удобным для использования как стека (stack).
