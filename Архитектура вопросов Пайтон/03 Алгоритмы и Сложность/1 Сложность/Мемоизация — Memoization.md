
# Мемоизация — Memoization

## Коротко

Мемоизация (`memoization`) — это техника оптимизации, при которой результаты уже выполненных вычислений сохраняются, чтобы не вычислять их повторно.

Основная идея:

```text
аргумент → вычисление → результат
              ↓
            cache
```

Если функция снова вызывается с тем же аргументом, результат можно взять из кеша.

## На собеседовании достаточно сказать

Мемоизация — это оптимизация, при которой результаты выполнения функции сохраняются в кеше. При повторном вызове с теми же аргументами результат берётся из кеша вместо повторного вычисления. Особенно полезна мемоизация для рекурсивных алгоритмов с повторяющимися вычислениями.

## Что важно помнить

Без мемоизации одна и та же функция может многократно вычислять одинаковые значения.

Классический пример — числа Фибоначчи:

```python
def fib(n):
    if n <= 1:
        return n

    return fib(n - 1) + fib(n - 2)
```

Например:

```
fib(5)
├── fib(4)
│   ├── fib(3)
│   └── fib(2)
└── fib(3)
    ├── fib(2)
    └── fib(1)
```

fib(3) и fib(2) вычисляются несколько раз.

Мемоизация позволяет сохранить уже полученный результат.

## Простой пример

В Python можно использовать functools.lru_cache:

```python
from functools import lru_cache


@lru_cache
def fib(n):
    if n <= 1:
        return n

    return fib(n - 1) + fib(n - 2)
```

Теперь после вычисления:

```python
fib(3)
```

результат сохраняется в кеше.

При следующем обращении к:

```python
fib(3)
```

Python может использовать сохранённый результат.

Можно посмотреть статистику кеша:

```
fib.cache_info()
```

## Мемоизация и динамическое программирование

Мемоизация часто используется в динамическом программировании (Dynamic Programming).

Например:

```
Рекурсивное решение
        ↓
повторяющиеся подзадачи
        ↓
сохраняем результаты
        ↓
меньше повторных вычислений
```

Есть два распространённых подхода:

## Top-down

Рекурсия + кеширование результатов.

```
большая задача
      ↓
меньшие задачи
      ↓
сохраняем результаты
```

Это обычно называют мемоизацией.

## Bottom-up

Решаем маленькие задачи сначала и постепенно строим решение большой задачи.

Это часто реализуют через таблицу или массив.

## Что происходит с памятью

Мемоизация ускоряет вычисления за счёт дополнительной памяти:

```
меньше вычислений
       ↕
больше памяти
```

Поэтому это классический компромисс:

```
Time ↔ Space
```

Главное

Запомнить:

```
Мемоизация
    ↓
сохраняем результаты
    ↓
не вычисляем одно и то же повторно
```

Частое применение:

```
рекурсия
+
повторяющиеся подзадачи
+
cache
```

В Python для этого удобно использовать:

```python
from functools import lru_cache
```
