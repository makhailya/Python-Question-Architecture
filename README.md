# Python Question Architecture

Конспекты и разборы вопросов для подготовки к собеседованию **Python Backend-разработчика**, а также по Linux, DevOps и системной архитектуре.

Материал организован как база знаний в **Obsidian**: каждая тема — отдельная заметка-ответ по шаблону
«короткий ответ → разбор для собеседования → детальный разбор → вопросы на собеседовании».

## 📚 Структура

### `Архитектура вопросов Пайтон`

| Раздел | Темы |
|---|---|
| `01 Python` | основы, типы и объекты, коллекции, хеш-таблицы, итераторы и генераторы, декораторы и контекстные менеджеры, память и GC, concurrency и asyncio |
| `02 OOP` | основы ООП, инкапсуляция и дескрипторы, наследование и MRO, полиморфизм, абстракция и Protocols, typing и generics, паттерны |
| `03 Алгоритмы и Сложность` | сложность, структуры данных, деревья и графы, поиск и обход |
| `04 SQL и База Данных` | SQL, индексы и query planner, транзакции и concurrency, масштабирование и репликация, ORM и SQLAlchemy, NoSQL и кэш |
| `05 Web` | network и HTTP, REST и API, auth и JWT, servers / proxy / балансировка, backend architecture и SOLID, frameworks |
| `06 Архитектура и Микросервисы` | архитектура, Kafka и RabbitMQ, распределённые системы и транзакции, task orchestration |
| `07 DevOps` | Docker и containers, Kubernetes, observability, testing и quality, Git и workflow, environment и infrastructure, Linux |
| `0. Конспекты` | крупные сводные конспекты по темам |

**Linux** вынесен в `07 DevOps/6 Environment и Infrastructure/Linux`:
файловая система, процессы и сигналы, права доступа и `chmod`, сеть,
Shell (`Shell` / `Bash` / `Terminal` / `Pipe`), SSH (`SSH` / `SSH-ключи`), systemd и `journalctl`.

Точка входа — [`Архитектура вопросов Пайтон/00 Карта Python.md`](Архитектура%20вопросов%20Пайтон/00%20Карта%20Python.md).

## 🔗 Навигация

Заметки связаны через двусмысленные ссылки Obsidian `[[...]]` — в GitHub они не кликабельны,
поэтому удобнее открывать хранилище в [Obsidian](https://obsidian.md) или искать по названию файла.

## 🤝 Хотите дополнить?

Репозиторий открыт для правок. Нажмите **Fork**, вносите изменения в своей ветке
и открывайте **Pull Request** — изменения появятся здесь после одобрения.

Подробная инструкция: **[CONTRIBUTING.md](CONTRIBUTING.md)**

Коротко:

```bash
# 1. Форк на GitHub, затем клонировать свой форк
git clone git@github.com:<ваш-ник>/Python-Question-Architecture.git
cd Python-Question-Architecture

# 2. Создать ветку под свою тему
git switch -c add-my-topic

# 3. Внести и отправить изменения
git add .
git commit -m "Добавил заметку про X"
git push origin add-my-topic
```

После `git push` откроется ссылка для создания Pull Request.

**Что можно делать:** добавлять новые заметки-вопросы, дополнять существующие,
исправлять ошибки, переносить заметки между разделами.

**Куда класть:** посмотрите структуру ниже — одна заметка соответствует одной теме.
Полный список папок — в [`00 Карта Python.md`](Архитектура%20вопросов%20Пайтон/00%20Карта%20Python.md).

## 🛠 Использование

Репозиторий является Obsidian-хранилищем и содержит папку `.obsidian` с плагинами и темой,
поэтому его можно открыть как готовое хранилище. Личные файлы состояния окон
(`workspace.json`) и кэши плагинов исключены через `.gitignore`.
